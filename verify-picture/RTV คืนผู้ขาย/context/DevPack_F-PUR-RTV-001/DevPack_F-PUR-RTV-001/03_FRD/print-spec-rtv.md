## 2. โครงหน้า (ตาม pattern เอกสารตาราง)

```
.doc-page
├── .doc-content
│   ├── HEADER   โลโก้ + ชื่อบริษัท + ที่อยู่ + เลขผู้เสียภาษี + สำนักงานใหญ่/สาขา + หัวเรื่อง "ใบคืนสินค้า / RETURN TO VENDOR"
│   ├── META     เลขที่ RTV · วันที่เอกสาร · วันที่ส่งคืน · อ้างอิง GRN · อ้างอิง PO · เลขอนุญาตคืนจากผู้ขาย (RMA) · หน้า x/y
│   ├── PARTIES  ซ้าย = ผู้ขาย (ชื่อ/ที่อยู่ส่งคืน/เลขผู้เสียภาษี/ผู้ติดต่อ/โทร) · ขวา = ผู้ส่งคืน (บริษัท/คลังต้นทาง/ผู้ส่ง/ทะเบียนรถ)
│   ├── ITEMS    ตารางรายการที่คืน (§3) — **มีคอลัมน์เหตุผลคืนเสมอ**
│   └── NOTES + TOTALS   ซ้าย = หมายเหตุ/สภาพสินค้า + จำนวนเงินเป็นตัวอักษร · ขวา = บล็อกยอดรวมมูลค่าที่คืน (§4)
└── .doc-bottom
    ├── SIGNATURES  ช่องลายเซ็น 3 ช่อง (§5)
    └── FOOTER      เลขที่ใบ + วันที่พิมพ์ (ค.ศ.) + หน้า + ข้อความสถานะ (ลายน้ำ "ตัวอย่าง" ถ้ายังไม่อนุมัติ · BR-25)
```

## 3. ตารางรายการ (ITEMS) — 1 row = 1 บรรทัด (ตารางผอม)

| คอลัมน์ | ที่มา (PREBRIEF §3.2) | จัดชิด | รูปแบบ |
|---|---|---|---|
| ลำดับ | `line_no` | กลาง | เลข |
| รายการ | `item_name` + `<span class="sub">` รหัสสินค้า / อ้าง GRN line / location ต้นทางที่ตัดของออก | ซ้าย | ข้อความ |
| **เหตุผลคืน** | `return_reason` (+ คำอธิบายเพิ่มเป็น `sub` เมื่อเลือก "อื่น ๆ") | ซ้าย | ข้อความ |
| จำนวนคืน | `qty_returned` | ขวา | `#,##0.00` (ตัดทศนิยมท้ายถ้าเป็นจำนวนเต็ม) |
| หน่วย | `uom` | กลาง | ข้อความ |
| ราคาต่อหน่วย | `unit_price` (จาก GRN — อ่านอย่างเดียว) | ขวา | `#,##0.00` |
| ส่วนลด | `line_discount` | ขวา | `#,##0.00` หรือ `%` |
| VAT | `vat_type` (7% / 0% / ยกเว้น) | กลาง | ข้อความสั้น |
| **มูลค่าที่คืน** | `line_return_amount` = `จำนวนคืน × (ราคา − ส่วนลดต่อหน่วย)` | ขวา | `#,##0.00` |

**กติกาตาราง**
- หัวตาราง = แถบ navy เข้ม ตัวอักษรขาว · เนื้อตาราง minimal ไม่มีเส้นแนวตั้ง/zebra (R3/R4 ของ skill)
- บรรทัดที่ของมาจาก **quarantine** ให้แสดง location ต้นทางใน `sub` ให้ชัด (เช่น `จาก QA-01 (quarantine)`) — ผู้ขายต้องเห็นว่าเป็นของที่ QC ไม่ผ่าน
- เกิน 1 หน้า → ทำซ้ำหัวตารางทุกหน้า + `หน้า x/y` ใน META

## 4. บล็อกยอดรวม (TOTALS)

| บรรทัด | สูตร (PREBRIEF §3.3) | หมายเหตุ |
|---|---|---|
| ยอดรวมก่อนภาษี | `Σ line_return_amount` | |
| ภาษีมูลค่าเพิ่ม 7% | `Σ (มูลค่าที่คืนของบรรทัด VAT 7%) × 7%` | **เพื่ออ้างอิงเท่านั้น** — ภาษีจริงเกิดที่ใบลดหนี้ฝั่ง AP (W5) |
| **มูลค่าที่คืนรวม** | `ยอดรวมก่อนภาษี + VAT` | แถบ navy เข้ม ตัวอักษรขาว |
| จำนวนเงินเป็นตัวอักษร | `scripts/baht_text.py <มูลค่าที่คืนรวม>` | อยู่ฝั่งซ้ายคู่กับหมายเหตุ |

**ข้อความบังคับใต้ TOTALS** (กันเข้าใจผิดเรื่องเครดิต):
> "มูลค่าตามใบนี้เป็นมูลค่าสินค้าที่ส่งคืน — การรับเครดิต/ใบลดหนี้ให้เป็นไปตามเอกสารของผู้ขาย"

## 5. ช่องลายเซ็น (SIGNATURES) — 3 ช่อง (ล็อกตาม Pattern Q / iron rule #98: ผู้จัดทำ · ผู้อนุมัติ · คู่ค้ายืนยัน)

| ช่อง | ใคร | ที่มา |
|---|---|---|
| 1 | **ผู้จัดทำ / ผู้ขอคืน** | `requester` (คนจริง — ชื่อ + ตำแหน่ง · PREBRIEF §3.1) |
| 2 | **ผู้อนุมัติ** (ตามสาย DOA — คนที่อนุมัติล่าสุด · ถ้าต้องการครบทุกขั้นให้ดูแท็บลายเซ็นในระบบ) | `approver_slot[]` (ชื่อ + ตำแหน่ง + วันที่ **ค.ศ.**) — **ห้ามพิมพ์รหัส role** |
| 3 | **ผู้รับฝั่งผู้ขาย** (เว้นว่างให้เซ็นรับหน้างาน) | `vendor_receiver` — เว้นว่างเสมอตอนพิมพ์ |

> **ผู้ส่งของคืน + ทะเบียนรถ** ไม่ใช่ช่องเซ็น — พิมพ์เป็นข้อมูลในบล็อก META/PARTIES (`shipper` · `vehicle_no`) ตามที่ต้นแบบทำไว้

- ช่องผู้อนุมัติพิมพ์ชื่อผู้อนุมัติล่าสุดตามสายที่ resolve จริง (สายเต็ม 1–3 ขั้นตาม matrix DOA_BRIEF §3 ดูได้ที่แท็บลายเซ็นในระบบ)
- ลายเซ็น + footer อยู่ใน `.doc-bottom` ชิดล่างหน้าเสมอ (R5 ของ skill)

## 6. Field map สรุป (bind data)

| field ในเทมเพลต | entity (PREBRIEF §3.1) | บังคับ |
|---|---|---|
| `rtv_no` | เลขที่ RTV (`RTV-YYYY-NNNN` · **ค.ศ.**) | ✅ (มีตั้งแต่ส่งอนุมัติ) |
| `doc_date` · `return_date` | วันที่เอกสาร · วันที่ส่งคืนจริง (**ค.ศ.**) | ✅ / ✅ เมื่อส่งคืน |
| `grn_no` · `po_no` | อ้างอิง GRN · PO ต้นทาง | ✅ / ⬜ |
| `rma_no` | เลขอนุญาตคืนจากผู้ขาย | ⬜ |
| `vendor_*` | ผู้ขาย + ที่อยู่ส่งคืน (soft-ref) | ✅ |
| `source_warehouse` | คลัง/สาขาที่ของออก | ✅ |
| `main_reason` | เหตุผลคืนหลักของใบ | ✅ |
| `lines[]` | รายการคืน (§3) | ✅ |
| `requester` · `approver_slot[]` · `shipper` · `vehicle_no` · `vendor_receiver` | ผู้เกี่ยวข้อง (คนจริง) | ตาม §5 |
| `status_watermark` | "ตัวอย่าง" เมื่อสถานะยังไม่ `อนุมัติแล้ว` (BR-25) · "ยกเลิก"/"กลับรายการ" เมื่อใบถูกยกเลิก/กลับรายการ | ระบบเติม |

**placeholder ที่ยังไม่มีข้อมูลจริง** (ต้องแทนตอน bind): ชื่อ/ที่อยู่/เลขผู้เสียภาษีของบริษัทผู้ซื้อ · โลโก้ (ยังใช้ `.doc-logo--ph` ตัวย่อ gradient)

## 7. กติกาพิมพ์

- พิมพ์ได้ตั้งแต่สถานะ **`อนุมัติแล้ว`** · ก่อนหน้านั้นพิมพ์ได้แต่ต้องมี **ลายน้ำ "ตัวอย่าง"** (BR-25)
- ทุกวันที่บนใบเป็น **ปี ค.ศ.** (BR-23) — รวมวันที่ในช่องลายเซ็นและ footer
- ตัวเลขเงินทุกช่อง `#,##0.00` + class `num` (ชิดขวา)
- ใบที่ **กลับรายการ** แล้ว ต้องพิมพ์ทับด้วยสถานะ "กลับรายการ" — ห้ามพิมพ์ออกมาเหมือนใบปกติ
- เก็บสำเนาผ่าน `ENG-DOC-STORE` เท่านั้น (DOCCFG_BRIEF §3) — ห้าม feature เก็บไฟล์เอง
