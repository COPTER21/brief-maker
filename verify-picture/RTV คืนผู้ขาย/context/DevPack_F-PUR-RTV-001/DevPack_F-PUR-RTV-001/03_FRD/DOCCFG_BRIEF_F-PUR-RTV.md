## 4. Dev wiring note (Phase B)

- `rtv.number = ENG-DOC-NUM.next('RTV', company_ctx)` ที่ transition `ร่าง → รออนุมัติ` — **ห้าม format เอง ห้าม +1 เอง**
- เลขที่ออกแล้ว **immutable** — ใบที่ถูกส่งกลับแก้ยังใช้เลขเดิม (ไม่ออกเลขใหม่) · ใบที่ยกเลิก/ปฏิเสธเก็บเลขไว้ไม่นำกลับมาใช้ซ้ำ
- render PDF แล้วเรียก `ENG-DOC-STORE.store(pdf,'RTV',rtv_id,'<event>')` — engine เช็ค flag เองว่าเก็บหรือไม่
- **ห้ามอ่าน/เขียนตาราง config ตรง** — ผ่าน engine API เท่านั้น
- ปีในเลขรันเป็น **ค.ศ.** ทุกจุด (BR-23) — ทั้งบนหน้าจอ ใน list และใน PDF
- ใน HTML Phase A จุดที่ยังต่อ engine ไม่ได้ใช้ marker `FWD-WIRE: ENG-DOC-NUM` (ใน .md ใช้ `TODO:` ตามปกติ)
