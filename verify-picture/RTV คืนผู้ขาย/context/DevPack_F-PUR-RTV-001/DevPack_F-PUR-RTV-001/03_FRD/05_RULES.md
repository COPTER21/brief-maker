# 05_RULES — F-PUR-RTV · RTV คืนผู้ขาย

> Audience: BE dev + QA · ทุกกติกามีที่มาจาก BRD §9/§10 หรือ PREBRIEF §4 และมีเคสใน `06_TESTS`
