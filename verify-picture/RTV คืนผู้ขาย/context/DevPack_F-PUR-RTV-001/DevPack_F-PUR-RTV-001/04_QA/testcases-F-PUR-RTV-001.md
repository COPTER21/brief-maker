## วิธีที่ agent รัน (Run protocol)

1. เปิด `01_HTML/F-PUR-RTV.html` ด้วยเบราว์เซอร์โดยตรง (double-click หรือ `file://`) — ไม่ต้อง build/server ขนาดหน้าต่างแนะนำ 1440×900
2. รันตามลำดับหมวด **A → B → C → D → E → F → G → H → XT** ตามที่ปรากฏในไฟล์นี้ — หลายเคสต่อเนื่องกันใช้ผลจากเคสก่อนหน้า (ระบุไว้ใน `Setup:` ของแต่ละเคสแล้ว) **ห้าม refresh หน้าเว็บระหว่างรัน** มิฉะนั้นข้อมูลจะรีเซ็ตกลับเป็นชุดตั้งต้นทันที
3. ทุก step ทำทีละ action เดียวตามคอลัมน์ Action แล้วเทียบผลกับ Expected — ติ๊ก `Result` เป็น ☐→✅/❌ ตามจริง
4. เคสที่มีป้าย **`BLOCKED (ต้นแบบ)`** (`AT-19` · `AT-19.1` · `AT-19.2` · `AT-28.1` · `AT-50.1`) ให้รายงานผลเป็น `blocked` เสมอไม่ว่าจะสังเกตเห็นค่าใดบนจอ — ห้ามรายงาน `pass`
5. เคสที่มีป้าย **`(ต้อง simulate)`** (`AT-24` · `AT-27` · `AT-X-04` · `AT-X-06`) ให้รายงานเป็น `blocked` พร้อม note ว่าต้นแบบไม่มีหน้าจอ/กลไกให้ทำตามขั้นตอนนั้นจริง
6. จบแล้วกรอกตาราง "ผลการทดสอบ" และ JSON `Result Report` ด้านล่างส่งกลับ
