## §1.2 P-01 รายการ
- head: ชื่อไทย + (IT Request Form) · sub ≤60 ตัว + badge ≤3 (จำนวน · รอฉันพิจารณา · รอดำเนินการ · ค่า 0 ซ่อน) · ขวา: ส่งออก CSV (secondary) · สร้างคำขอ (primary · disabled เมื่อ doc_type ปิด)
- seg tabs: ทั้งหมด · รอฉันพิจารณา · คำขอของฉัน (count)
- filter: ค้นหา (เลขที่/ผู้ขอ/เรื่อง) · สถานะ · ประเภทงาน · รีเซ็ต
- คอลัมน์: เลขที่ · วันที่ · ผู้ร้องขอ (person icon) · เรื่องที่ต้องการ · ประเภทงาน (ตัวแรก +n) · วันที่ต้องการส่งมอบ · สถานะเอกสาร · ลายเซ็น n/N · ⋮ (ดูรายละเอียด · แก้ไข[ร่างของตน] · พิมพ์ · บันทึกดำเนินการแล้ว[IT] · ยกเลิกเอกสาร)
- footer: แสดงต่อหน้า 10/25/50 · x – y จาก N รายการ · pager
