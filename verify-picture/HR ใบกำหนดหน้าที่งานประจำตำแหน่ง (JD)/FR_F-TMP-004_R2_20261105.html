ส่วนที่ไม่ได้ตรวจ อยู่นอกความรับผิดชอบของรายงานฉบับนี้

ตรวจแล้ว

  • ตรวจซ้ำการเปิดใช้งาน Document Type JD และปุ่มสร้างใบกำหนดหน้าที่งาน
  • ตรวจซ้ำการแสดงข้อความแจ้งเตือนบริเวณปุ่มสร้างรายการ
  • สร้างใบกำหนดหน้าที่งาน
  • แก้ไขใบกำหนดหน้าที่งาน
  • ยกเลิกเอกสารตาม flow ที่ระบบรองรับ
  • UI และ UX ของ flow ที่ทดสอบ รวม modal ส่งอนุมัติ

ไม่ได้ตรวจ

  • Validation รายฟิลด์และการคำนวณผู้ใต้บังคับบัญชาทุก edge case — ผู้ตรวจยืนยัน create/update ผ่าน แต่ไม่ได้ระบุผลแยกราย validation และ edge case
  • ส่งอนุมัติ อนุมัติ ไม่อนุมัติ และสายอนุมัติ DOA — กำลังเริ่มทดสอบรอบใหม่ ยังไม่มีผลยืนยัน
  • ระบุผู้ดำรงตำแหน่งและการรับทราบ — กำลังเริ่มทดสอบรอบใหม่ ยังไม่มีผลยืนยัน
  • ฉบับใหม่แทนฉบับเดิม สิทธิ์การมองเห็น PDF CSV ไฟล์แนบ ประวัติ และ notification — กำลังเริ่มทดสอบรอบใหม่ ยังไม่มีผลยืนยัน

L-01ความพร้อมใช้งานของการสร้าง JD บน Productionแบบเอกสาร JD เปิดใช้งานและผู้มีสิทธิ์สามารถกดสร้างใบกำหนดหน้าที่งานใหม่เพื่อเริ่ม flow หลักได้เปิดใช้งาน Document Type JD แล้ว และผู้ตรวจยืนยันว่าตรวจซ้ำผ่านผ่านProduction readiness · FN-03 · EC-09
L-02F-DOCCFG ปิดแบบเอกสาร JDแสดงว่าแบบเอกสารนี้ยังไม่เปิดใช้งาน และปุ่มสร้างถูก disabled—ไม่ได้ตรวจEC-09
L-03สร้างใบกำหนดหน้าที่งานผู้มีสิทธิ์สามารถสร้างและบันทึกใบกำหนดหน้าที่งานได้ผู้ตรวจยืนยันว่า create ครบและผ่านผ่านFN-01–FN-03 · AC-01
L-04แก้ไขใบกำหนดหน้าที่งานเจ้าของเอกสารสามารถแก้ไขร่างและบันทึกข้อมูลที่เปลี่ยนแปลงได้ผู้ตรวจยืนยันว่า update ครบและผ่านผ่านAPI-05 · BR-16

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-01Production ยังไม่เปิดใช้งาน Document Type JD ทำให้สร้างใบกำหนดหน้าที่งานไม่ได้Criticalแก้แล้ว
ขั้นตอนทำซ้ำ
  1. เข้าสู่ฟีเจอร์ HR ใบกำหนดหน้าที่งานประจำตำแหน่ง (JD) บน Production
  2. ดูบริเวณปุ่มสร้างใบกำหนดหน้าที่งาน
  3. ลองกดปุ่มสร้างรายการ
ผลที่ควรเป็นDocument Type JD เปิดใช้งานและปุ่มสร้างพร้อมให้ผู้มีสิทธิ์เริ่มสร้างรายการ
ผลที่เกิดจริงแสดงข้อความ “แบบเอกสารนี้ยังไม่เปิดใช้งาน — สร้างใบกำหนดหน้าที่งานใหม่ไม่ได้” และปุ่มสร้างถูก disabled
BUG-02ข้อความแจ้งเตือนแบบเอกสารยังไม่เปิดใช้งานแสดงซ้ำซ้อนกับ Notification CenterLowแก้แล้ว
ขั้นตอนทำซ้ำ
  1. เข้าสู่หน้ารายการใบกำหนดหน้าที่งานประจำตำแหน่ง
  2. ดูข้อความแจ้งเตือนบริเวณปุ่มสร้างรายการ
  3. เปิด Notification Center และเปรียบเทียบข้อความแจ้งเตือน
ผลที่ควรเป็นระบบสื่อสารสถานะให้ผู้ใช้เข้าใจชัดเจนโดยไม่แสดงข้อความเดียวกันซ้ำซ้อนหลายตำแหน่ง
ผลที่เกิดจริงเดิมข้อความแจ้งเตือนซ้ำซ้อนกับ Notification Center; ปัจจุบันแก้ไขแล้วและผู้ตรวจยืนยันว่าตรวจซ้ำผ่าน
BUG-03Footer ของ modal ส่งอนุมัติมีพื้นที่ว่างด้านล่างมากเกินไปLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดใบกำหนดหน้าที่งานที่สามารถส่งอนุมัติได้
  2. กดปุ่ม “ส่งอนุมัติ”
  3. สังเกตพื้นที่ด้านล่างของแถวปุ่ม “ยกเลิก” และ “ส่งอนุมัติ” ใน modal
ผลที่ควรเป็นfooter ของ modal สูงพอดีกับแถวปุ่มและระยะห่างมาตรฐาน โดยไม่มีพื้นที่ว่างขนาดใหญ่ใต้ปุ่ม
ผลที่เกิดจริงมีพื้นที่ว่างสีขาวขนาดใหญ่ใต้แถวปุ่ม ทำให้ modal สูงเกินเนื้อหาและ layout footer ดูผิดปกติ
