## §1.2 Per-Page Detail
### P-01 รายการ
- head: "ใบกำหนดหน้าที่งานประจำตำแหน่ง (Job Description)" · sub + badge (รายการ · รออนุมัติ · รอคุณ — ค่า 0 ซ่อน) · ปุ่ม ส่งออก CSV (secondary) · สร้างใบกำหนดหน้าที่งาน (primary · disabled เมื่อ F-DOCCFG ปิด)
- filter: ค้นหา (เลขที่/ตำแหน่ง/แผนก/ผู้จัดทำ) · สถานะ · ฝ่าย · รีเซ็ต
- คอลัมน์: เลขที่ · วันที่สร้าง · ตำแหน่ง · แผนก · ฝ่าย · ผู้จัดทำ · สถานะเอกสาร · ลายเซ็น x/y · ⋮ (ดูรายละเอียด · รับทราบ[ผู้ดำรงตำแหน่ง] · แก้ไข[ร่าง เจ้าของ] · พิมพ์ · ยกเลิกเอกสาร[สิทธิ์])
### P-02 สร้าง/แก้ (ขั้น 1 ข้อมูลใบกำหนดหน้าที่)
- การ์ด ① ข้อมูลทั่วไป (Job Title): `position_id` (combobox) · แผนก/ฝ่าย (ระบบ) · `position_name_en` · `reports_to` · บรรทัด "ผู้ใต้บังคับบัญชา `subordinate_summary`"
- การ์ด ②–⑥: `job_purpose` · `key_responsibilities` · `job_specification` · `kpi` · `other_qualifications`
- การ์ด ⑦: แถว superiors / subordinates (`position` · `headcount`) · เตือน "หัวหน้าแถวแรกไม่ตรงกับรายงานต่อ" (ไม่บล็อก)
- การ์ด ⑧: ผู้ดำรงตำแหน่ง `acknowledged_by`
- การ์ดสรุปขวา (sticky): ตำแหน่ง · รายงานต่อ · ผู้ใต้บังคับบัญชา · หัวข้อที่กรอก n/4 · ผู้อนุมัติค่าเริ่ม (DOA) · เตือนฉบับใช้งานเดิมจะถูกแทนที่
- ขั้น 2 เอกสารแนบ (Document Center · PDF/Word/Excel/รูป ≤20 MB) · ขั้น 3 ตรวจสอบ
- footer: ย้อนกลับ · ยกเลิก · ถัดไป / บันทึกแบบร่าง · บันทึกและส่งอนุมัติ · ปิดตอนกรอกค้าง = modal "ทิ้งข้อมูลที่กรอกไว้?"

## §1.3 Journey
สร้าง → ขั้น 1 (ครบ) → ขั้น 2 → ขั้น 3 → บันทึกและส่งอนุมัติ → modal ส่ง (slot ผู้อนุมัติต่อขั้น ค่าเริ่ม DOA) → รออนุมัติ → อนุมัติ → อนุมัติแล้ว → ผู้ดำรงตำแหน่งรับทราบ → รับทราบแล้ว
### Branch
- ไม่อนุมัติ (เหตุผล) → ร่างเลขเดิม → แก้ → ส่งใหม่
- บันทึกแบบร่าง → รายการ (ร่าง) → แก้ไข → ส่ง
- ยังไม่ระบุผู้ดำรงตำแหน่ง → HR ระบุในแท็บลายเซ็น → แจ้งให้รับทราบ
- ยกเลิก (เหตุผล) จากรายการ ⋮ หรือหัว drawer

## §1.6 Empty/Error
- รายการว่าง: "ยังไม่มีใบกำหนดหน้าที่งาน" + ปุ่มสร้าง · ค้นหาไม่พบ: "ไม่พบรายการที่ค้นหา" + ล้างตัวกรอง · sub-table ว่าง: แผง "ไม่มี"
- กดถัดไปตอนไม่ครบ: toast "กรุณากรอกข้อมูลให้ครบถ้วน" + การ์ดขอบแดง + เลื่อนไปการ์ดแรกที่ผิด
- API ล้ม: "ทำรายการไม่สำเร็จ กรุณาลองใหม่อีกครั้ง" · 409 "ข้อมูลถูกแก้โดยผู้อื่น…" · 403 "คุณไม่มีสิทธิ์ทำรายการนี้"
