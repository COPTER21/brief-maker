- หัว: "แบบฟอร์มชุดเอกสารส่งมอบงาน (สำหรับฝ่ายบริหารการลงทุนจัดเก็บ) (Handover)" · sub + badge "N รายการ · เปิดอยู่ X · รอฉันพิจารณา Y" (ค่า 0 ไม่แสดง) · ปุ่ม ส่งออก CSV · สร้างบันทึก (disabled เมื่อ F-DOCCFG ปิดใช้ + แถบแดง)
- คอลัมน์ (1 ข้อมูล = 1 คอลัมน์ · 1 บรรทัด): เลขที่ · วันที่รับมอบ · ชื่อโครงการ (ตัดท้าย …) · ผู้จัดทำ (icon คน) · เอกสาร (จำนวน) · ค้างส่ง (จำนวนแถวไม่ผ่าน · สีส้มเมื่อ > 0) · ผลการรับมอบ (pill) · สถานะเอกสาร · ลายเซ็น n/N · ⋮ (แก้ไข[ร่างของตน] · พิมพ์ · ยกเลิกเอกสาร[สิทธิ์])
- สถานะเอกสาร: ร่าง · รออนุมัติ · รับทราบแล้ว · ยกเลิก · ผลการรับมอบ: จาก HandoverConfig.handover_results
### P-02 สร้าง/แก้
**ขั้น 1 ข้อมูลการรับมอบและผลการตรวจรับ**
| ช่อง (ป้ายตามกระดาษ) | คีย์ | ชนิด |
|---|---|---|
| ชื่อโครงการ* | `handover.project_name` | text |
| ผู้ส่งมอบจากฝ่ายพัฒนาธุรกิจ* | `handover.sender` | text + รายชื่อพนักงาน (datalist) |
| ผู้รับมอบจากฝ่ายบริหารการลงทุน* | `handover.receiver` | text + รายชื่อพนักงาน (ค่าเริ่ม = ผู้จัดทำ) |
| วันที่ / เวลารับมอบ* | `handover.received_at` | ตัวเลือกวัน พ.ศ. (bedate · ≤ วันนี้ · ค่าเริ่มวันนี้) + ช่องเวลา HH:MM |
| ฉบับชุดเอกสาร* | `handover.package_version` | text |
| ผลการรับมอบ* | `handover.result` | select (handover_results) · แดงพร้อมข้อความเมื่อเลือก "รับมอบครบถ้วน" แต่มีแถวไม่ผ่าน |
- แถบสรุปสด: ผู้จัดทำ (จากระบบ) · เอกสารที่ตรวจรับ n · ไม่ได้รับ / ไม่ครบถ้วน n · legend ความครบถ้วน (config)

| คอลัมน์ตารางตรวจรับ (ป้ายตามกระดาษ) | คีย์ | ชนิด |
