### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- เลือก 'รับมอบครบถ้วน' ได้แม้มีแถว ไม่ได้รับ / ไม่ครบถ้วน / ต้องตรวจสอบเพิ่มเติม → **ผลการรับมอบ = รับมอบครบถ้วน ได้เมื่อทุกแถว ได้รับ และ ครบถ้วน · ไม่ครบ = บังคับเลือก รับมอบแบบมีเงื่อนไข หรือ ยังไม่รับมอบ**
- แถว 'ไม่ได้รับ' เลือกความครบถ้วน = ครบถ้วน ได้ (ขัดกัน) → **ได้รับแล้ว = ไม่ได้รับ → ความครบถ้วน ต้องไม่เป็น ครบถ้วน**
- แถวที่ไม่ได้รับ/ไม่ครบถ้วน/ต้องตรวจสอบเพิ่มเติม ไม่บังคับผู้รับผิดชอบแก้ไขและกำหนดส่งเพิ่มเติม → **แถวที่ไม่ผ่าน ต้องมี ประเด็นที่พบ + ผู้รับผิดชอบแก้ไข + กำหนดส่งเพิ่มเติม**
- กรอกวันที่ก่อนวันที่รับมอบได้ → **วันที่ต้อง ≥ วันที่รับมอบ**
- ผลการรับมอบ = แบบมีเงื่อนไข/ยังไม่รับมอบ แต่ไม่กรอกประเด็นค้าง → **ผลการรับมอบ ≠ รับมอบครบถ้วน → ประเด็นค้างจากการรับมอบ บังคับกรอก**
- ชื่อหัวฟอร์มซ้ำกับ FM-BDM-07 (ฝ่ายพัฒนาธุรกิจจัดเก็บ) — ชุดเดียวกันคนละฝั่ง ไม่มีช่องอ้างเลขที่ FM-BDM-07 → **ไม่เพิ่มช่อง (G5 1:1) — เสนอให้ลูกค้ายืนยันการผูกคู่ FM-BDM-07/08 ในรายงาน**
