0ขอบเขตการตรวจ

ส่วนที่ไม่ได้ตรวจ อยู่นอกความรับผิดชอบของรายงานฉบับนี้

ตรวจแล้ว

  • Create / Update / Delete
  • Create และ Edit drawer: UI, UX, step และการอัปโหลดไฟล์
  • View drawer: action, แท็บรายละเอียด, PDF Preview, ลายเซ็น และประวัติ
  • Modal เลือกสายอนุมัติ

ไม่ได้ตรวจ

  • ส่งตรวจสอบและพิจารณาจนครบสายอนุมัติ — View drawer มีปุ่มส่งตรวจสอบ แต่ modal แจ้งว่าไม่พบสายอนุมัติ
  • อัปโหลดไฟล์สำเร็จและตรวจสิทธิ์ไฟล์แนบ — อัปโหลดไม่สำเร็จในรอบตรวจ
  • Notification, CSV, PDF output, ใบซ้ำรายปี, snapshot config และ permission deny cases — ผู้ตรวจไม่ได้รายงานผลในรอบนี้

#หัวข้อตรวจผลหมายเหตุหลักฐาน

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-03ระบบไม่พบสายอนุมัติสำหรับหน่วยงานของผู้จัดทำCriticalรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดรายการของผู้จัดทำ
  2. เปิด modal เลือกสายอนุมัติ
  3. ตรวจผลการ resolve ผู้พิจารณา
ผลที่ควรเป็นแสดงผู้บังคับบัญชาตามผังองค์กร หรือมี slot ให้เลือกผู้พิจารณาตาม FRD
ผลที่เกิดจริงแสดงข้อความ ไม่พบสายอนุมัติสำหรับหน่วยงานของผู้จัดทำ
BUG-01อัปโหลดไฟล์ไม่สำเร็จ แต่ระบบยังสร้างรายการร่างMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด Create หรือ Edit drawer
  2. เลือกอัปโหลดไฟล์
  3. ดำเนินการบันทึกรายการ
ผลที่ควรเป็นไฟล์อัปโหลดและผูกกับเอกสารสำเร็จ หรือระบบแจ้งผลล้มเหลวและสถานะของร่างอย่างชัดเจน
ผลที่เกิดจริงไฟล์อัปโหลดไม่สำเร็จ แต่มีรายการร่างถูกสร้างขึ้น
BUG-02ไม่มีปุ่มบันทึกและส่งตรวจสอบใน Create / Edit drawerMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด Create drawer และตรวจ action สำหรับส่งตรวจสอบ
  2. เปิด Edit drawer และตรวจ action สำหรับส่งตรวจสอบ
  3. เปิด View drawer ของรายการร่างและยืนยันว่ามีปุ่มส่งตรวจสอบ
ผลที่ควรเป็นมีปุ่มบันทึกและส่งตรวจสอบตามสถานะและสิทธิ์ของผู้จัดทำ
ผลที่เกิดจริงไม่พบปุ่มบันทึกและส่งตรวจสอบใน Create/Edit drawer; View drawer มีปุ่มส่งตรวจสอบ

#ข้อเสนอเหตุผล

S-02จำกัด upload file ไว้เฉพาะ Create/Edit drawerView drawer ควรใช้สำหรับอ่านรายละเอียดและไฟล์ที่มีอยู่
