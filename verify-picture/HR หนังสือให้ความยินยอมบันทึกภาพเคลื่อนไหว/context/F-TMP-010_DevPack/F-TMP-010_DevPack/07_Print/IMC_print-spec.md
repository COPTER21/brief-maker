## 3. กติกาคำนวณ / ตรวจ
- `minor.* ` เสนอค่าเท่ากับ `subject.*` เมื่อผู้ให้ความยินยอมเป็นผู้เยาว์ (DEC-11)
- อายุผู้ให้ความยินยอม < `PdpaPolicy.minor_age_threshold` → บังคับกรอกส่วนผู้ปกครองครบ (DEC-04)
- `activity.date_to` ต้องไม่ก่อน `activity.date_from`
- ทุกข้อ 1–3 ต้องเลือก `ยินยอม` หรือ `ถอนความยินยอม` อย่างใดอย่างหนึ่ง ห้ามเว้นว่าง ห้ามติ๊กทั้งสอง (DEC-13)
- ชื่อตัวบรรจงใต้ลายเซ็นคัดจากชื่อที่กรอก (F09 = F03 · F17 = F11) ไม่ให้พิมพ์ซ้ำ
- ไม่มีการคำนวณเงิน ไม่มีจำนวนเงินตัวอักษร

## 4. กติกาการพิมพ์

## 7. ความต่างจากกระดาษ (ตั้งใจ · ต้องให้ลูกค้ายืนยัน)
1. **บล็อกลงชื่อย้ายมาอยู่แถวล่างสุด (B6)** — ต้นฉบับวางลายเซ็นผู้ให้ความยินยอมไว้กลางหน้า 1 (ชิดขวา) และลายเซ็นผู้ปกครองกลางหน้า 2 · ระบบรวมเป็นแถวเดียวด้านล่างตามมติ thai-doc v2.1 (ช่องลงชื่อวนจากข้อมูล ไม่ fix จำนวน)
2. **ช่อง "วันที่" ใต้ลายเซ็นผู้ปกครอง** — ต้นฉบับไม่มี (anomaly A4) · ระบบแสดงบรรทัดวันที่ให้ทุกช่องตามรูปแบบ B6 โดยใช้วันที่ยืนยันในระบบ (DEC-14) ไม่ได้เพิ่มช่องกรอกใหม่
3. **ส่วน "กรณีผู้ให้ความยินยอมเป็นผู้เยาว์" พิมพ์เสมอ** เหมือนกระดาษ (เว้นว่างเมื่อผู้ให้ความยินยอมบรรลุนิติภาวะ) — ไม่ซ่อน section เพื่อคงหน้าตาเดิม
4. **บล็อก "บันทึกการถอนความยินยอม"** เป็นส่วนที่กระดาษไม่มี — พิมพ์เฉพาะใบที่ถูกถอน (DEC-15) เพื่อให้สำเนา PDF เป็นหลักฐานครบ
5. **"อายุต่ำกว่า 20 ปี" เป็น `{{policy.minor_age}}`** — อ่านจาก config ไม่ hardcode (DEC-04) · ค่าเริ่มต้น 20 ตรงกับกระดาษ
6. **1 หน้าเทียบ 2 หน้า** — ต้นฉบับแบ่ง 2 หน้าเพราะโลโก้ซ้ำหัวทุกหน้า · ระบบจัดเนื้อหาต่อเนื่องและให้ engine ตัดหน้าเอง (ยืนยันจำนวนหน้าจริงได้เมื่อรัน render_pdf บนเครื่องที่มี browser)

## 8. ถ้อยคำกฎหมาย — คัดตรงตัว (ห้ามเรียบเรียง)
คัดจาก `orig/content.src.txt` ทุกย่อหน้า คงคำสะกดเดิมทั้งหมด รวม:
- "บูทกิจกรรม" (ย่อหน้าเจตนา) vs "บูธกิจกรรม" (ข้อ 1 · ข้อ 2) — ไม่ตรงกันในฉบับเดียว (A2) · **คงไว้ทั้งสองแห่ง**
- "เป็นผู้ปกครองของ ข้าพเจ้า ( นาย / นาง / นางสาว )" — คำว่า "ข้าพเจ้า" ซ้ำผิดที่ (A1) · **คงไว้**
- "ยินยอมให้บริษัทเปิดเผยข้อมูลส่วนของบุคคล" (ข้อ 3) — "ส่วนของบุคคล" แทน "ส่วนบุคคล" · **คงไว้**
→ แจ้งลูกค้าแก้ที่ต้นฉบับแล้วออก Rev. ใหม่ ห้ามแก้เองในระบบ
