# 00 OVERVIEW — F-TMP-010 หนังสือให้ความยินยอมในการบันทึกและเผยแพร่ภาพถ่าย หรือภาพเคลื่อนไหว

## 0.1 สิ่งที่ feature นี้ทำ
ขึ้นแบบฟอร์มกระดาษ **FM-HRM-51 (Rev. 00 : 01/07/2569)** เป็นเอกสารในระบบ CUBE: บันทึกความยินยอมของผู้ร่วมกิจกรรมในบูธให้บริษัทบันทึกและเผยแพร่ภาพถ่าย/ภาพเคลื่อนไหว เก็บหลักฐานรายข้อ พิมพ์เป็นแบบพิมพ์เหมือนกระดาษเดิม และรองรับการถอนความยินยอมที่ผูกกับใบเดิม

## 0.2 Actor
| Actor | บทบาท |
|---|---|
| เจ้าหน้าที่ประจำบูธ | เจ้าของใบ — บันทึกแทนผู้ร่วมกิจกรรม (บุคคลภายนอก) |
| ผู้ให้ความยินยอม | เจ้าของข้อมูลส่วนบุคคล — ลงนามในระบบ (ไม่มีบัญชีผู้ใช้) |
| ผู้ปกครองของผู้เยาว์ | รับรองความยินยอมเมื่อผู้ให้ความยินยอมอายุต่ำกว่าเกณฑ์ใน config |
| `role-mgr-hr` | ผู้ดูแลเอกสาร — เห็นทั้งหมด ถอน/ยกเลิกได้ |
| `role-compliance` | ผู้กำกับดูแลข้อมูลส่วนบุคคล — รับแจ้งการถอนความยินยอม |
| DOA engine | เจ้าของสายอนุมัติ (รอบนี้ 0 ขั้น · DEC-03) |

## 0.3 หน้าจอ
| ID | หน้าจอ | สรุป |
|---|---|---|
| P-01 | รายการหนังสือให้ความยินยอม | ค้นหา · ตัวกรองสถานะ/ผลความยินยอม/ช่วงอายุ · สถิติ 3 การ์ด · ส่งออก CSV |
| P-02 | สร้าง/แก้ไขร่าง (wizard 3 ขั้น) | ข้อมูลผู้ให้ความยินยอม › เอกสารแนบ › ตรวจสอบและยืนยัน |
| P-03 | รายละเอียด (4 แท็บ) | รายละเอียด · PDF Preview · ลายเซ็น/อนุมัติ · ประวัติ |

## 0.4 สถานะเอกสาร
`draft` → `pending` (เมื่อมีสาย DOA) → `confirmed` → `withdrawn`
ทางแยก: `rejected` (ผู้พิจารณาไม่รับหนังสือ) · `cancelled` (ยกเลิกก่อนยืนยัน)

## 0.5 ไม่ทำรอบนี้
1. บังคับใช้ผลความยินยอมกับงานสื่อ/การตลาด (DEC-02 — ประกาศ event ไว้แต่ไม่ยิงข้ามระบบ)
2. แก้ถ้อยคำ/ออก revision ใหม่ของหนังสือ (เป็นงานของ ConsentPurpose master + F-DOCCFG)
3. ลายมือชื่ออิเล็กทรอนิกส์แบบภาพ (DEC-07)
4. ผูกไฟล์ภาพแต่ละไฟล์กับใบยินยอม (คลังสื่อ)

## 0.6 ข้อผูกพันกับระบบกลาง
| ระบบกลาง | ใช้อย่างไร |
|---|---|
| ENG-DOC-NUM | ออกเลขที่ `IMC-{YYYY}-{run:4}` ตอนบันทึกครั้งแรก (FN-03) |
| ENG-DOC-STORE | เก็บสำเนา PDF ตอนยืนยัน (FN-06) |
| F-DOCCFG | ทะเบียน doc_type `IMC` + print_config + สถานะเปิดใช้ |
| DOA กลาง | `approval_chain` · `doa_ref` — รอบนี้ 0 ขั้น ห้าม hardcode rule |
| ENG-NOTIFY | `imc_consent_recorded` · `imc_consent_withdrawn` · `imc_minor_consent_recorded` · `imc_cancelled` |
| Document Center | ไฟล์แนบระดับใบ |
| Organization / PdpaPolicy | ชื่อบริษัท · ที่อยู่ · อีเมลติดต่อ · เกณฑ์อายุผู้เยาว์ (config) |
