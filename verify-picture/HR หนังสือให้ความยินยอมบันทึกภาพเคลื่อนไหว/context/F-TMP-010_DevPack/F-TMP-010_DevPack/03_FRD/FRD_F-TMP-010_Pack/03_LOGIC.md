# 03 LOGIC — F-TMP-010

> ทุกค่าคงที่ที่ปรากฏบนกระดาษอ่านจาก config (DEC-04) — ห้าม hardcode ในโค้ด
> ทุก mutation มี FN ปลายทางครบ (R8)

## F-TMP-010-FN-01 · รายการ + ค้นหา + ส่งออก
- คืนเฉพาะใบที่ผู้ใช้เห็นได้ตาม FN-11
- ตัวกรอง: สถานะ · ผลความยินยอม (ยินยอมครบ / มีข้อที่ถอนในใบ / ถอนภายหลัง) · ช่วงอายุ (ผู้เยาว์ / บรรลุนิติภาวะ)
- ส่งออก CSV: เลขที่ · วันที่ให้ความยินยอม · ผู้ให้ความยินยอม · ช่วงอายุ · บูธกิจกรรม · ช่วงเวลากิจกรรม · ฉบับของหนังสือ · ยินยอม (ข้อ) · ถอนความยินยอมในใบ (ข้อ) · ถอนภายหลัง (ข้อ) · สถานะ
- **ห้ามใส่เลขบัตรประชาชนใน CSV** (ข้อมูล Restricted)

## F-TMP-010-FN-02 · สร้าง/แก้ไขร่าง
- แก้ได้เฉพาะสถานะ `draft` และเป็นเจ้าของใบ (ไม่ใช่ → `NOT_OWNER` / `IMMUTABLE`)
- ตรวจช่องตามกระดาษครบตาม 05 §VR-01..VR-07 ก่อนบันทึก
- `data_subject_name_printed = data_subject_name` · `guardian_name_printed = guardian_name` (computed ฝั่ง server ตาม FORM_SPEC.formulas)
- เมื่อผู้ให้ความยินยอมไม่เข้าเกณฑ์ผู้เยาว์ ระบบล้างค่าในกลุ่มผู้ปกครอง/ผู้เยาว์ก่อนบันทึก (EC-02)

## F-TMP-010-FN-03 · ออกเลขที่เอกสาร
- ตรวจสถานะเปิดใช้ของ doc_type `IMC` ที่ **F-DOCCFG** ก่อน (ปิดอยู่ → `DOC_TYPE_DISABLED`)
- เรียก **ENG-DOC-NUM** `next('IMC')` ตอน **บันทึกครั้งแรก** (DEC-09) · รูปแบบเลขและ reset อ่านจาก F-DOCCFG ห้าม hardcode
- snapshot `form_code` · `form_revision` · `header_snapshot` (ชื่อ/ที่อยู่/โลโก้องค์กร) ลงใบตอนออกเลข

## F-TMP-010-FN-04 · กฎผู้เยาว์
- อ่านเกณฑ์อายุจาก config `PdpaPolicy.minor_age_threshold` (ห้าม hardcode ตัวเลขในโค้ด)
- `data_subject_age < เกณฑ์ใน config` → ใบนี้เป็นใบของผู้เยาว์ → ต้องมีกลุ่มผู้ปกครองและกลุ่มผู้เยาว์ครบ มิฉะนั้น `GUARDIAN_REQUIRED`
- ค่าเริ่มต้นของกลุ่มผู้เยาว์เสนอเท่ากับกลุ่มผู้ให้ความยินยอม (DEC-11) — ผู้ใช้แก้ได้
- อายุเท่ากับเกณฑ์พอดีไม่ถือเป็นผู้เยาว์ (EC-01)

## F-TMP-010-FN-05 · เลือกความยินยอมรายข้อ
- รายการข้อและถ้อยคำอ่านจาก **ConsentPurpose master** ของ `form_revision` ที่ผูกกับใบ — ห้าม hardcode ถ้อยคำ
- ทุกข้อต้องมีค่า `consent` หรือ `withdraw` (DEC-13) · ว่างแม้ข้อเดียว → `CONSENT_INCOMPLETE`
- เก็บผลแยกรายข้อใน `media_consent_line` (DEC-16)

## F-TMP-010-FN-06 · ยืนยันความยินยอม
- เงื่อนไข: สถานะ `draft` · ผ่าน FN-04 และ FN-05
- resolve `approval_chain` จาก DOA กลางแล้ว **freeze** ลงใบ (BR-DOA-02) · รอบนี้ 0 ขั้น (DEC-03)
- ตั้ง `consented_at` = เวลาปัจจุบัน · `written_date` = `signed_date` = วันที่เดียวกัน (DEC-14)
- สถานะ → `pending` ถ้ามีขั้น DOA มิฉะนั้น `confirmed`
- เมื่อเป็น `confirmed` เรียก **ENG-DOC-STORE** `store()` เก็บสำเนา PDF เป็นหลักฐานความยินยอมแบบแก้ไขไม่ได้ พร้อม `form_revision`
- ใบที่ `confirmed` แล้ว **immutable** (DEC-04) — แก้ไม่ได้ ต้องใช้ FN-08 แทน
- ยิง `imc_consent_recorded` · ถ้าเป็นใบของผู้เยาว์ยิง `imc_minor_consent_recorded` เพิ่ม

## F-TMP-010-FN-07 · ขั้น DOA รับ / ไม่รับหนังสือ
- ทำได้เฉพาะผู้พิจารณาขั้นปัจจุบัน (ไม่ใช่ → `NOT_CURRENT_APPROVER`)
- รับหนังสือ: ขั้นถัดไปเป็น `pending` แบบ sequential · ครบทุกขั้น → `confirmed` (เข้าเงื่อนไขเก็บสำเนาใน FN-06)
- ไม่รับหนังสือ: เหตุผลบังคับ · ขั้นที่เหลือ `skipped` · สถานะ → `rejected`
- จำนวนขั้นมาจาก DOA กลางทั้งหมด — `TODO: DOA engine` ห้าม hardcode rule ในฟีเจอร์

## F-TMP-010-FN-08 · ถอนความยินยอม
- เงื่อนไข: สถานะ `confirmed` · ผู้ทำคือเจ้าของใบหรือ `role-mgr-hr`
- รับ `scope[]` (ข้อที่เคยเลือก `consent` เท่านั้น) · ว่าง = ทั้งฉบับ · `reason` บังคับ
- บันทึกลง `media_consent_withdrawal` ผูกกับใบเดิม (DEC-15) — ห้ามสร้างใบใหม่แทน
- สถานะ → `withdrawn` · ข้อที่ถอนไม่นับว่ามีผลอีกต่อไป ข้ออื่นคงเดิม (DEC-16)
- ไม่ย้อนผลการเผยแพร่ที่ทำไปแล้วโดยชอบ
- ยิง `imc_consent_withdrawn` (ช่องทาง in-app + email · ผู้ใช้ปิดไม่ได้)

## F-TMP-010-FN-09 · ยกเลิกเอกสาร
- ทำได้เฉพาะสถานะ `draft` หรือ `pending` · ผู้ทำคือเจ้าของใบหรือ `role-mgr-hr` · `reason` บังคับ
- สถานะ → `cancelled` · ขั้น DOA ที่ค้างเป็น `skipped`
- ยิง `imc_cancelled`

## F-TMP-010-FN-10 · แบบพิมพ์ / PDF (Replica)
- render จาก `print/form.tpl.html` (logic-less) + data contract `IMC_data-contract.md` — template เดียวกับ prototype
- ช่องลงชื่อ = ผู้ให้ความยินยอม + ผู้ปกครองของผู้เยาว์ (ช่องคงที่ตามกระดาษ) + 1 ช่องต่อขั้นใน `approval_chain` — **ห้าม fix จำนวน** (DEC-07)
- ค่าคงที่บนกระดาษ (ชื่อบริษัท · ที่อยู่ · อีเมล · เกณฑ์ผู้เยาว์) อ่านจาก config ตอน render
- ร่างติดป้าย "ร่าง" ที่ footer · ใบที่ถอนความยินยอมพิมพ์บล็อก "บันทึกการถอนความยินยอม"

## F-TMP-010-FN-11 · สิทธิ์การมองเห็น
- เจ้าของใบเห็นใบของตัวเองทุกสถานะ
- ผู้พิจารณาเห็นใบที่ส่งถึงตน **หลังส่งแล้วเท่านั้น** — ร่างของคนอื่นต้องไม่เห็น (DEC-08)
- `role-mgr-hr` และ `role-compliance` เห็นทั้งหมด
- เลขบัตรประชาชนแสดงเฉพาะผู้มีสิทธิ์ตาม 05 §BR-SEC-02

## F-TMP-010-FN-12 · เอกสารแนบ
- ผ่าน Document Center · ชนิดและขนาดตาม file_policy กลาง · แนบได้เฉพาะสถานะ `draft`
