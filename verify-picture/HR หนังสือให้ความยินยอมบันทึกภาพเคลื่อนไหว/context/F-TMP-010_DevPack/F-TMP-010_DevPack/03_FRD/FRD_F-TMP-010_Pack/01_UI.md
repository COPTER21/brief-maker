# 01 UI — F-TMP-010

> ช่องทุกช่องตรงกับกระดาษ FM-HRM-51 แบบ 1:1 (DEC-06) — ห้ามเพิ่มช่องที่กระดาษไม่มี
> ถ้อยคำ label คัดตรงตัวจากแบบฟอร์ม (รวมคำสะกดเดิม) — ห้ามเกลา (DEC-12)

## P-01 รายการหนังสือให้ความยินยอม
- หัวข้อ: `หนังสือให้ความยินยอมในการบันทึกและเผยแพร่ภาพถ่าย หรือภาพเคลื่อนไหว`
- คำอธิบาย: `เก็บหลักฐานความยินยอมรายข้อของผู้ร่วมกิจกรรมในบูธ พร้อมช่วงเวลากิจกรรมและฉบับของหนังสือ · ถอนความยินยอมได้ภายหลัง`
- ปุ่ม: `ส่งออก CSV` · `สร้างหนังสือยินยอม` (disabled เมื่อแบบเอกสารปิดใช้งาน)
- สถิติ 3 การ์ด: `หนังสือยินยอมทั้งหมด` · `ร่าง (ยังไม่ยืนยัน)` · `รอฉันพิจารณา`
- ตัวกรอง: ค้นหา (`ค้นหาเลขที่ / ผู้ให้ความยินยอม / บูธกิจกรรม`) · `ทุกสถานะ` · `ทุกผลความยินยอม` · `ทุกช่วงอายุ`
- คอลัมน์: `เลขที่` · `วันที่ให้ความยินยอม` · `ผู้ให้ความยินยอม` · `บูธกิจกรรม` · `ยินยอม` · `ช่วงอายุ` · `สถานะเอกสาร` · `ลายเซ็น` · ⋮
- ⋮ เมนูแถว: `แก้ไข` (ร่างของตัวเอง) · `พิมพ์` · `ถอนความยินยอม` · `ยกเลิกเอกสาร`
- Empty state: `ยังไม่มีหนังสือให้ความยินยอม` / `บันทึกหนังสือให้ความยินยอมก่อนนำภาพของผู้ร่วมกิจกรรมไปเผยแพร่`

## P-02 สร้าง/แก้ไขร่าง — wizard 3 ขั้น
ขั้น: `ข้อมูลผู้ให้ความยินยอม` › `เอกสารแนบ` › `ตรวจสอบและยืนยัน`

### การ์ด 1 · หัวหนังสือ
| ช่องบนกระดาษ | key | ชนิด | บังคับ |
|---|---|---|---|
| `เขียนที่` | `written_place` | ข้อความ | ✓ |
| `วันที่` | `written_date` | วันที่ | ระบบใส่ตอนยืนยัน |

### การ์ด 2 · ผู้ให้ความยินยอม
| ช่องบนกระดาษ | key | ชนิด | บังคับ |
|---|---|---|---|
| `ข้าพเจ้า ( นาย / นาง / นางสาว )` | `data_subject_name` | ข้อความ | ✓ |
| `อายุ (ปี)` | `data_subject_age` | ตัวเลข | ✓ |
| `ผู้ถือบัตรประชาชนเลขที่` | `data_subject_citizen_id` | ข้อความ | ✓ |
- ข้อความช่วย: `ข้อมูลส่วนบุคคล — เก็บเท่าที่จำเป็นและจำกัดผู้เห็นตามสิทธิ`

### การ์ด 3 · บูธกิจกรรม
| ช่องบนกระดาษ | key | ชนิด | บังคับ |
|---|---|---|---|
| `บูทกิจกรรมของบริษัท ซึ่งตั้งอยู่ที่` | `booth_location` | ข้อความ | ✓ |
| `ช่วงเวลากิจกรรมวันที่` | `activity_date_from` | วันที่ | ✓ |
| `ถึงวันที่` | `activity_date_to` | วันที่ | ✓ |

### การ์ด 4 · ความยินยอมรายข้อ (3 ข้อ)
- แต่ละข้อแสดงถ้อยคำกฎหมายเต็มจาก ConsentPurpose master แล้วให้เลือก 1 ใน 2 ด้วยการ์ดเลือก (`.track-card`)
  - `ยินยอม` — `ให้บริษัทดำเนินการตามข้อนี้ได้`
  - `ถอนความยินยอม` — `ไม่ให้ดำเนินการตามข้อนี้`
- ป้ายบนข้อ 3: `เปิดเผยนอกองค์กร`
- ปุ่มช่วย: `เลือกยินยอมทั้งหมด` · `ล้างที่เลือก`
- ข้อความผิดพลาดต่อข้อ: `ต้องเลือกยินยอมหรือถอนความยินยอมข้อนี้`

### การ์ด 5 · กรณีผู้ให้ความยินยอมเป็นผู้เยาว์ตามกฎหมายของไทย
- เปิดอัตโนมัติเมื่ออายุต่ำกว่าเกณฑ์ใน config (ป้าย `ต้องกรอก`) · ไม่เข้าเกณฑ์แสดงป้าย `ไม่ต้องกรอก`
- แจ้งเตือน: `อายุต่ำกว่าเกณฑ์ผู้เยาว์ที่ตั้งไว้ในระบบ — ต้องมีผู้ปกครองรับรองและให้ความยินยอมตามข้อ 1 , 2 และ 3`
- ปุ่มช่วย: `คัดข้อมูลผู้เยาว์จากผู้ให้ความยินยอม`

| ช่องบนกระดาษ | key | บังคับเมื่อผู้เยาว์ |
|---|---|---|
| `ข้าพเจ้า ( นาย / นาง / นางสาว ) [ผู้ปกครอง]` | `guardian_name` | ✓ |
| `อายุผู้ปกครอง (ปี)` | `guardian_age` | ✓ |
| `เลขบัตรประชาชนผู้ปกครอง` | `guardian_citizen_id` | ✓ |
| `เป็นผู้ปกครองของ ข้าพเจ้า ( นาย / นาง / นางสาว )` | `minor_name` | ✓ |
| `อายุผู้เยาว์ (ปี)` | `minor_age` | ✓ |
| `เลขบัตรประชาชนผู้เยาว์` | `minor_citizen_id` | ✓ |

### การ์ดสรุป (ขวา)
`ผู้ให้ความยินยอม` · `บูธกิจกรรม` · `ฉบับของหนังสือ` · `วันที่ให้ความยินยอม` · `เลือกแล้ว n/3` · `ช่วงอายุ` · `ยินยอมทั้งหมด`

### ขั้น 2 · เอกสารแนบ
`แนบเอกสารประกอบ (ถ้ามี)` — `เช่น สำเนาเอกสารยืนยันตัวตนผู้ปกครองที่ปิดทับข้อมูลที่ไม่จำเป็น` · `ปิดทับข้อมูลที่ไม่จำเป็นก่อนแนบ`

### ขั้น 3 · ตรวจสอบและยืนยัน
`ยืนยันแล้วแก้ไขไม่ได้ — ถ้าต้องเปลี่ยนให้ถอนความยินยอมแล้วทำฉบับใหม่`
ปุ่ม: `บันทึกแบบร่าง` · `บันทึกและยืนยันความยินยอม`

## P-03 รายละเอียด — 4 แท็บ
| แท็บ | เนื้อหา |
|---|---|
| `รายละเอียด` | ข้อมูลเอกสาร · ผู้ให้ความยินยอม · บูธกิจกรรม · ความยินยอมรายข้อ · สรุปผลความยินยอม · กรณีผู้เยาว์ · เอกสารแนบ · สิทธิของเจ้าของข้อมูลและช่องทางติดต่อ · ข้อมูลระบบ |

| `ประวัติ` | timeline append-only |

## Modal
| ID | ชื่อ | จุดสำคัญ |
|---|---|---|
| M-01 | `ยืนยันความยินยอม?` | แสดง slot ผู้พิจารณาต่อขั้น DOA (รอบนี้ไม่มี → `ไม่มีผู้พิจารณา`) · เตือน `ยืนยันแล้วแก้ไขไม่ได้ · ระบบเก็บสำเนาเป็นหลักฐาน` |

| M-03 | `ไม่รับหนังสือยินยอมฉบับนี้?` | เหตุผลบังคับ + preset |
| M-04 | `ถอนความยินยอม?` | เลือกข้อที่ถอน (chip) + เหตุผลบังคับ · `ไม่กระทบการใช้ภาพที่เผยแพร่ไปแล้วโดยชอบ` |
