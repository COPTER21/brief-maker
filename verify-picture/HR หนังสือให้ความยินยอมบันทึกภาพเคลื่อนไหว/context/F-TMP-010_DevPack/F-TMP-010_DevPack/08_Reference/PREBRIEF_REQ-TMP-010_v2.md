### 3.2 ตัวเลือก
- **ข้อ 1 — ยินยอมให้บริษัทบันทึกภาพถ่าย ภาพนิ่งและภาพเคลื่อนไหว วีดีโอ และเนื้อหา สรุปภาพรวมการจัดงาน หรือข้อมูลส่วนบุคคลของข้าพเจ้า ซึ่งร่วมกิจกรรมภายในบริเวณบูธกิจกรรม ลงเผยแพร่บนสื่อระบบอินเทอร์เน็ต เว็บไซต์ของบริษัท ช่องทาง Social Media สื่อสิ่งพิมพ์ หรือ การประชาสัมพันธ์ ลงบนกระดานข่าวอื่นๆ** (เลือกได้ข้อเดียว): ยินยอม · ถอนความยินยอม
- **ข้อ 2 — ยินยอมว่าข้าพเจ้าจะไม่ใช้สิทธิเรียกร้อง หรือสินไหม หรือค่าตอบแทนใดๆ ในภายหลังกับบริษัท หากมีการนำภาพถ่าย ภาพนิ่งและภาพเคลื่อนไหว วีดีโอ และเนื้อหา สรุปภาพรวมการจัดงาน หรือข้อมูลส่วนบุคคลของข้าพเจ้า ลงเผยแพร่** (เลือกได้ข้อเดียว): ยินยอม · ถอนความยินยอม
- **ข้อ 3 — ยินยอมให้บริษัทเปิดเผยข้อมูลส่วนของบุคคลไปยังบริษัทในเครือและพันธมิตรทางธุรกิจเพื่อนำเสนอผลิตภัณฑ์และบริการที่หลากหลาย รวมถึงโปรโมชั่น และสิทธิพิเศษต่างๆ** (เลือกได้ข้อเดียว): ยินยอม · ถอนความยินยอม

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- ถ้อยคำเขียนว่า "เป็นผู้ปกครองของ ข้าพเจ้า ( นาย / นาง / นางสาว ) ..." — คำว่า "ข้าพเจ้า" ซ้ำผิดที่ ความหมายที่ถูกคือชื่อของผู้เยาว์ → **คงถ้อยคำตรงตัวตามต้นฉบับในแบบพิมพ์ · ระบบผูกช่องนี้เป็นชื่อผู้เยาว์ (media_consent.minor_name) และเสนอค่าเท่ากับชื่อผู้ให้ความยินยอม**
- สะกดไม่ตรงกันในเอกสารฉบับเดียว — ย่อหน้านำเขียน "บูทกิจกรรม" ส่วนข้อ 1 และข้อ 2 เขียน "บูธกิจกรรม" → **คงไว้ตรงตัวตามต้นฉบับทั้งสองแห่ง ห้ามแก้เองในระบบ · แจ้งลูกค้าแก้ที่ต้นฉบับ**
- ใบเดียวใช้ได้ทั้ง "ให้ความยินยอม" และ "ถอนความยินยอม" โดยไม่มีช่องแยกว่าถอนจากใบไหน → **ทุกข้อ 1–3 ต้องเลือกอย่างใดอย่างหนึ่ง ห้ามเว้นว่าง ห้ามติ๊กทั้งสอง · การถอนต้องผูกกับใบความยินยอมเดิมของบุคคลเดียวกัน พร้อมวันที่ถอนและผู้บันทึก**
- ไม่มีช่อง "วันที่" ใต้ลายเซ็นผู้ปกครอง ทั้งที่ส่วนผู้ให้ความยินยอมมี → **ระบบใช้วันที่ยืนยันในระบบเป็นวันที่ของทั้งสองลายเซ็น (ไม่เพิ่มช่องบนแบบพิมพ์ ตาม G5)**
- ข้อความระบุสิทธิถอนความยินยอมได้ทุกเวลาทำการ แต่กระดาษไม่มีขั้นตอน/ช่องทางถอนหลังส่งใบแล้ว → **ระบบต้องมีคำสั่งถอนความยินยอมที่ผูกกับใบเดิม บันทึกวันที่ถอนและผู้บันทึก และไม่ย้อนผลการประมวลผลที่ทำไปก่อนหน้า**
- ข้อ 3 เป็นการเปิดเผยข้อมูลให้บริษัทในเครือ/พันธมิตรเพื่อการตลาด ไม่เกี่ยวกับการบันทึกภาพตามชื่อเอกสาร → **คงไว้ตามต้นฉบับ · ระบบต้องเก็บสถานะความยินยอมแยกรายข้อ (ข้อ 3 ถอนได้โดยไม่กระทบข้อ 1–2)**
- ชื่อไฟล์ต้นฉบับ "หนังสือให้ความยินยอมบันทึกภาพเคลื่อนไหว" ไม่ตรงกับชื่อบนหัวฟอร์ม → **ยึดชื่อบนหัวฟอร์มเป็นชื่อเอกสารจริง**
