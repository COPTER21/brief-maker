# 01_UI — F-TMP-003 คำขอมีและใช้ลายเซ็นดิจิทัล (DSR)

> ต้นแบบ: `feature.html` (Pattern Q2 · Q-form) · ช่องตรงกระดาษ 1:1 (DEC-06) — ห้ามเพิ่มช่องที่กระดาษไม่มี

## 1. หน้าทะเบียน (list) — route `#/dsr`
### 1.1 หัวหน้าจอ
- ชื่อ: "คำขอมีและใช้ลายเซ็นดิจิทัล (Digital Signature Request)" · นับรายการที่ผู้ใช้เกี่ยวข้อง + เปิดอยู่
- ปุ่ม: `ส่งออก CSV` (secondary) · `สร้างคำขอ` (primary · disabled เมื่อ doc_type ยังไม่เปิดใช้ที่ F-DOCCFG)

### 1.2 การ์ดสถิติ (คลิกกรองได้)
`คำขอทั้งหมด` · `รอดำเนินการ` (status = pending) · `รอฉันพิจารณา` (ผู้ใช้เป็นผู้พิจารณาขั้นปัจจุบัน)

### 1.3 ตัวกรอง
ค้นหา (เลขที่ / ผู้ขอ / อีเมล / ชื่อใหม่) · สถานะ · กรณี · ฝ่าย

### 1.4 คอลัมน์
| # | คอลัมน์ | ที่มา |
|---|---|---|
| 1 | เลขที่ | `doc_no` |
| 2 | วันที่ขอ | `doc_date` |
| 3 | ผู้ยื่นคำขอ | `requester_first_name_th` + `requester_last_name_th` |
| 4 | สังกัดหน่วยงาน | `requester_department` |
| 5 | กรณี | `case_kind` (pill) |
| 6 | รายละเอียดกรณี | `renew_reason` หรือ `change_type` |
| 7 | สถานะเอกสาร | `status` (pill) |
| 8 | ลายเซ็น | n/N จาก `approval_chain` |
| 9 | ⋮ | พิมพ์ · แก้ไข (ร่างของตัวเอง) · ยกเลิกเอกสาร |

### 1.5 ว่าง (empty state)
ไม่มีรายการ → "ยังไม่มีคำขอลายเซ็นดิจิทัล" + ปุ่มสร้างคำขอ · กรองแล้วไม่เจอ → ล้างตัวกรอง

## 2. สร้าง / แก้ร่าง (wizard 3 ขั้น) — route `#/dsr/create` · `#/dsr/edit/:id`
### 2.1 ขั้นที่ 1 "ข้อมูลหลักคำขอ"
| การ์ด | ช่อง | แหล่ง / กติกา |
|---|---|---|
| 1 ทำคำขอที่ไหน เมื่อไหร่ | `made_at` (ทำที่) · วันที่ (แสดงอย่างเดียว) | `made_at` ผู้ใช้กรอก ค่าเริ่มจากสถานที่ทำงาน · วันที่ระบบใส่ให้ตอนบันทึก (DEC-10) |
| 2 ขอกรณีไหน | `case_kind` 3 ตัวเลือก (track-card · เลือกได้ 1) | DEC-16 · กรณี 2 → แสดงชิป `renew_reason` 3 ข้อ · กรณี 3 → แสดงชิป `change_type` 3 ข้อ + บล็อกชื่อเดิม/ชื่อใหม่ |
| 2.1 บล็อกชื่อ (เฉพาะกรณี 3) | `old_first_name_th` · `new_first_name_th` · `new_first_name_en` · `old_last_name_th` · `new_last_name_th` · `new_last_name_en` | แสดงเฉพาะส่วนที่ `change_type` ครอบ (DEC-14) · ชื่อเดิมภาษาอังกฤษดึงจากทะเบียนพนักงาน ไม่มีช่องกรอก (DEC-15) |
| 3 คำรับรอง | `certified` (checkbox) · ข้อความรับรองตามกระดาษ | บังคับติ๊กก่อนไปขั้นถัดไป · ตัวอย่างลายมือชื่อ (`specimen_signature`) และลายมือเขียนชื่อ (`specimen_handwriting`) ลงบนแบบพิมพ์หลังพิมพ์ (DEC-07) |

ช่องที่ดึงจากระบบและ **ไม่มีให้กรอก**: ชื่อ-นามสกุล ไทย/อังกฤษ · ตำแหน่ง · สังกัดหน่วยงาน · Email · โทร (แสดงในการ์ดสรุปด้านขวา)

### 2.2 ขั้นที่ 2 "เอกสารแนบ"
upload-zone หลายไฟล์ · PDF/Word/Excel/รูป ≤ 20 MB ต่อไฟล์ (DEC-11)

### 2.3 ขั้นที่ 3 "ตรวจสอบและยืนยัน"
การ์ดสรุป: ข้อมูลคำขอ · ชื่อเดิม/ชื่อใหม่ · เอกสารแนบ · ปุ่ม `บันทึกแบบร่าง` + `บันทึกและส่งอนุมัติ`

## 3. ดูรายละเอียด (view drawer) — route `#/dsr/view/:id`
แท็บล็อก: **รายละเอียด › PDF Preview › ลายเซ็น / อนุมัติ › ประวัติ**
- รายละเอียด: ข้อมูลเอกสาร · ผู้ยื่นคำขอ (8 ช่องจากทะเบียน) · ความประสงค์ · ชื่อเดิม/ชื่อใหม่ · ตัวอย่างลายมือชื่อ · เอกสารแนบ (section ในแท็บนี้) · ข้อมูลระบบ
- PDF Preview: iframe A4 จาก `print/form.tpl.html` + `docPrintData()`
- ลายเซ็น/อนุมัติ: ไทม์ไลน์ขั้น DOA + ปุ่ม `ดำเนินการได้` / `ไม่สามารถดำเนินการได้` เมื่อผู้ใช้เป็นผู้พิจารณาขั้นปัจจุบัน
- ประวัติ: append-only

## 4. Modal
ส่งอนุมัติ (เลือกผู้พิจารณาต่อขั้น · slot picker) · ดำเนินการได้ (ความเห็นไม่บังคับ) · ไม่สามารถดำเนินการได้ (เหตุผลบังคับ) · ยกเลิกเอกสาร (เหตุผลบังคับ) · ทิ้งข้อมูลที่กรอก
