## 1. บทนำ

### 1.1 ที่มา
ลูกค้าส่งแบบฟอร์มกระดาษ **"คำขอมีและใช้ลายเซ็นดิจิทัล (Digital Signature)" (FM-HRM-23 Rev. 00)** เข้ามาให้ขึ้นเป็นเอกสารในระบบ CUBE NATIVE
ปัจจุบันพนักงานกรอกกระดาษ → เซ็นตัวอย่างลายมือชื่อ → ส่งให้เจ้าหน้าที่ฝ่ายทรัพยากรบุคคลพิจารณา → เจ้าหน้าที่ติ๊ก "ดำเนินการได้ / ไม่สามารถดำเนินการได้" → เก็บแฟ้ม
ไม่มีทะเบียนกลางว่าใครมีลายเซ็นดิจิทัลแล้วบ้าง ใบไหนค้างอยู่ที่ใคร และคำขอกรณี "เปลี่ยนชื่อ-นามสกุล" มักกรอกไม่ครบคู่ไทย/อังกฤษ

## 2. วัตถุประสงค์ทางธุรกิจ

### 2.1 ปัญหาปัจจุบัน
1. คำขอลายเซ็นดิจิทัลเป็นกระดาษ — ไม่มีเลขที่อ้างอิง ตามสถานะไม่ได้
2. ไม่รู้ว่าพนักงานคนไหนยื่นกรณีไหนไปแล้ว และใบไหนค้างที่เจ้าหน้าที่
3. กรณี "ขอเปลี่ยนลายเซ็นดิจิทัล" กรอกชื่อใหม่ไม่ครบคู่ไทย/อังกฤษบ่อย ทำให้ออกใบรับรอง CA ไม่ได้ ต้องส่งกลับ
4. ช่องชื่อเดิม/ชื่อใหม่บนกระดาษอยู่นอกกรอบกรณีที่ 3 จึงมีคนกรอกทั้งที่ไม่ได้ขอเปลี่ยนชื่อ

### 2.2 เป้าหมาย
| # | เป้าหมาย |
|---|---|
| G1 | ทุกคำขอมีเลขที่เอกสารและสถานะในระบบ ค้นย้อนหลังได้ |
| G2 | ผู้ขอเห็นเองว่าใบค้างที่ขั้นไหน ไม่ต้องเดินไปถาม |
| G3 | ระบบบังคับให้กรอกเฉพาะช่องที่กรณีนั้นต้องการ และต้องครบก่อนส่ง — ลดใบตีกลับ |
| G4 | ฝ่ายทรัพยากรบุคคลเปิดดูคำขอทั้งหมดในที่เดียว และส่งออก CSV ไปทำทะเบียนผู้ถือลายเซ็นดิจิทัลได้ |

## 3. ขอบเขต

### 3.1 อยู่ในขอบเขต
ทะเบียนคำขอ · สร้าง/แก้ร่าง (wizard 3 ขั้น) · ส่งอนุมัติผ่าน DOA 1 ขั้น (dynamic) · ผลพิจารณา "ดำเนินการได้ / ไม่สามารถดำเนินการได้" · ยกเลิกเอกสาร · แบบพิมพ์ Replica + PDF · เอกสารแนบ · ส่งออก CSV · ประวัติ append-only

### 3.2 อยู่นอกขอบเขต (รอบนี้)
- การออก/เพิกถอนใบรับรอง CA กับผู้ให้บริการภายนอก (เจ้าหน้าที่ทำนอกระบบ)

- การลงลายเซ็นดิจิทัลบนเอกสารจริงในระบบ (คนละ feature)

## 5. กระบวนการธุรกิจ (To-Be)
1. พนักงานเปิดหน้า "คำขอมีและใช้ลายเซ็นดิจิทัล" → สร้างคำขอ
2. เลือกกรณี 1 ข้อ (ขอครั้งแรก / ขอใหม่ / ขอเปลี่ยน) → ระบบเปิดเฉพาะช่องที่กรณีนั้นต้องการ
3. ติ๊กคำรับรอง → บันทึก (ได้เลขที่) → ส่งอนุมัติ (เลือกผู้พิจารณาต่อขั้น)
4. เจ้าหน้าที่พิจารณา — "ดำเนินการได้" = จบ · "ไม่สามารถดำเนินการได้" = ใบกลับเป็นร่างเลขเดิมให้แก้แล้วส่งใหม่
5. ผู้ขอพิมพ์แบบพิมพ์จากระบบ ลงตัวอย่างลายมือชื่อและลายมือเขียนชื่อด้วยมือ แล้วส่งให้เจ้าหน้าที่เก็บเป็นหลักฐาน
6. กรณีที่ 3 (เปลี่ยนชื่อ-นามสกุล) ระบบแจ้งผู้ดูแลทะเบียนพนักงานให้ไปตรวจทะเบียนให้ตรงกัน
