### 3.1 รายการซ้ำ
- **รายการตรวจเช็คประจำวัน** — บนกระดาษ 30 แถว (min_rows) · ช่องในแถว: วันที่, ทะเบียนคุมเข้าออก, ถังดับเพลิง, อุณหภูมิ, ความชื้นสัมพัทธ์, เครื่องปรับอากาศ, กล้องวงจรปิด, MDB, PDU, หมายเหตุ, ผู้ตรวจสอบ

### 3.2 ตัวเลือก
- **ทะเบียนคุมเข้าออก** (เลือกได้ข้อเดียว): มี · ไม่มี
- **เครื่องปรับอากาศ** (เลือกได้ข้อเดียว): ปกติ · ไม่ปกติ
- **กล้องวงจรปิด** (เลือกได้ข้อเดียว): ปกติ · ไม่ปกติ
- **MDB** (เลือกได้ข้อเดียว): ปกติ · ไม่ปกติ
- **PDU** (เลือกได้ข้อเดียว): ปกติ · ไม่ปกติ

### 3.3 สูตร + ค่าคงที่บนกระดาษ
- ค่าคงที่ "18-27°C" = ช่วงอุณหภูมิห้อง Server ที่ยอมรับได้ → ควรอ่านจาก `ServerRoomCheckConfig.temp_min_c / temp_max_c` (ห้าม hardcode)
- ค่าคงที่ "40-55 %RH" = ช่วงความชื้นสัมพัทธ์ห้อง Server ที่ยอมรับได้ → ควรอ่านจาก `ServerRoomCheckConfig.rh_min / rh_max` (ห้าม hardcode)

### 3.4 ลายเซ็น + control
- S1 ผู้ตรวจสอบ (คอลัมน์ต่อแถว) (ผู้ขอ)
- Doc No. บนกระดาษ FM-ITS-10 · Rev.00 : 01/07/2569 · เลขรันบนกระดาษ: ไม่มี (ระบบออกเลขเอง)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- กระดาษไม่มีช่องลงชื่อผู้ตรวจทาน/ผู้อนุมัติ — มีเฉพาะชื่อผู้ตรวจสอบต่อแถว → **G2 ต้องให้ลูกค้ายืนยันว่าต้องมีผู้ตรวจทานประจำเดือนหรือไม่**
- ไม่ระบุหน่วยหรือเกณฑ์ความดันที่ถือว่าผ่าน → **เก็บเป็นข้อความ · ลูกค้ายืนยันรูปแบบ**
- ค่านอกช่วงเกณฑ์บนหัวตาราง (18-27°C · 40-55 %RH) → **ค่านอกช่วง = เตือน + ระบุหมายเหตุ (ไม่บล็อก)**
