## §5.2 State Machine
draft →(ส่ง)→ pending[1..N] →(อนุมัติ / อนุมัติแบบมีเงื่อนไข ขั้น N)→ approved · pending[n<N] →(อนุมัติ / อนุมัติแบบมีเงื่อนไข / รับทราบ)→ pending[n+1] · pending →(ให้แก้ไข / ไม่อนุมัติ)→ draft · draft/pending →(ยกเลิก)→ cancelled · approved = ล็อก
