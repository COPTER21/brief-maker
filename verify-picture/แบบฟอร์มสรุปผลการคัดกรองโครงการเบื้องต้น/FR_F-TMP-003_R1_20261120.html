ส่วนที่ไม่ได้ตรวจ อยู่นอกความรับผิดชอบของรายงานฉบับนี้

ตรวจแล้ว

  • สร้างรายการผ่าน Create drawer
  • แก้ไขรายการผ่าน Edit drawer
  • ลบรายการตามการทำงานที่หน้าจอเปิดให้ใช้
  • การแสดงไฟล์แนบใน Edit และ View drawer
  • UI/UX ของ Create, Edit และ View drawer ทุกแท็บ

ไม่ได้ตรวจ

  • การคำนวณคะแนนถ่วงน้ำหนักและผลเสนอที่ขอบช่วง 60/80 — ผู้ตรวจไม่ได้ระบุผลในรอบนี้
  • ส่งอนุมัติ, ไม่อนุมัติ, ส่งกลับร่าง และ DOA หลายขั้น — ผู้ตรวจไม่ได้ระบุผลในรอบนี้
  • Permission deny, concurrent update และ optimistic lock — ผู้ตรวจไม่ได้ระบุผลในรอบนี้
  • ความถูกต้องของ PDF, CSV, notification และ Document Store — ผู้ตรวจไม่ได้ระบุผลในรอบนี้

#กฎ / Scenarioผลที่คาดหวังผลจริงผลอ้างอิง
L-01สร้างรายการสร้างรายการใหม่ได้สำเร็จตรงตามคาดผ่านAPI-03 · FN-01/FN-02/FN-03
L-02แก้ไขรายการแก้ไขและบันทึกรายการได้สำเร็จตรงตามคาดผ่านAPI-04 · FN-01/FN-02
L-03ลบรายการตามการทำงานบนหน้าจอดำเนินการลบรายการได้สำเร็จตรงตามคาดผ่านผลตรวจจากผู้ตรวจ
L-04Edit drawer แสดงไฟล์แนบเดิมเมื่อเปิดแก้ไข ต้องเห็นไฟล์ที่เคยแนบไว้และจัดการไฟล์ต่อได้ส่วนเอกสารแนบใน Edit drawer ว่าง ไม่แสดงไฟล์เดิม ทั้งที่ View drawer แสดงไฟล์ของรายการเดียวกันไม่ผ่านBUG-01
L-05View drawer เป็นหน้าดูข้อมูลและไฟล์แนบแท็บรายละเอียดแสดงไฟล์แนบ โดยการเพิ่มหรือลบไฟล์ทำจาก Create/Edit drawerView drawer มีปุ่มแนบไฟล์และปุ่มลบไฟล์ในแท็บรายละเอียดไม่ผ่านBUG-02
L-06คำนวณคะแนนถ่วงน้ำหนักและผลเสนอคำนวณตาม ScreeningCriteria และขอบช่วง 60/80—ไม่ได้ตรวจFN-02 · BR-01..03
L-07ส่งและตัดสินตามสายอนุมัติตัดสินได้เฉพาะผู้พิจารณาขั้นปัจจุบันตาม DOA—ไม่ได้ตรวจFN-04/FN-05/FN-06
L-08ยกเลิกเอกสารตามสิทธิ์และสถานะยกเลิกได้เฉพาะ owner/admin ในสถานะ draft หรือ pending พร้อมเหตุผล—ไม่ได้ตรวจFN-07 · BR-DOA-03
L-09PDF และผลข้ามโมดูลหลังอนุมัติPDF ถูกต้อง เก็บ approved_final และแจ้งเตือนตามเงื่อนไข—ไม่ได้ตรวจFN-08/FN-09

U-02ระยะห่าง / การจัดแนว ฟอร์มและตารางมีข้อสังเกตLayout และการจัดวางบางส่วนใน Create/Edit drawer และ View drawer ยังไม่เรียบร้อย—
U-03ตาราง 1 ช่อง = 1 บรรทัด ไม่ซ้อนข้อมูลผ่าน——
U-04ปุ่ม / ไอคอน ขนาดและสไตล์สม่ำเสมอผ่าน——
U-05ข้อความไทยถูกต้อง ไม่พิมพ์ผิด ไม่ตกบรรทัดแปลกผ่าน——

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-01Edit drawer ไม่แสดงไฟล์แนบเดิมMediumรอแก้
ขั้นตอนทำซ้ำ
  1. สร้างรายการและแนบไฟล์ แล้วบันทึก
  2. เปิด View drawer และตรวจว่าไฟล์แนบแสดงอยู่
  3. กดแก้ไขเพื่อเปิด Edit drawer
  4. ไปขั้นเอกสารแนบ
ผลที่ควรเป็นEdit drawer แสดงรายการไฟล์แนบเดิมของเอกสาร
ผลที่เกิดจริงEdit drawer แสดงเฉพาะพื้นที่เลือกไฟล์และไม่แสดงไฟล์เดิม
BUG-02View drawer เปิดให้เพิ่มและลบไฟล์ในแท็บรายละเอียดMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดรายการใน View drawer
  2. เลื่อนไปส่วนเอกสารแนบในแท็บรายละเอียด
  3. ตรวจปุ่มแนบไฟล์และไอคอนลบไฟล์
ผลที่ควรเป็นView drawer แสดงไฟล์แบบอ่านอย่างเดียว การเพิ่มหรือลบไฟล์อยู่ใน Create/Edit drawer
ผลที่เกิดจริงView drawer มีทั้งปุ่มแนบไฟล์และไอคอนลบไฟล์
BUG-03Create/Edit drawer หลุด design และ layout บางส่วนไม่เรียบร้อยLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด Create drawer
  2. ตรวจแต่ละขั้นของฟอร์ม
  3. เปิด Edit drawer และตรวจ layout เดียวกัน
ผลที่ควรเป็นรูปแบบและ layout สอดคล้องกับ design ของฟีเจอร์
ผลที่เกิดจริงรูปแบบหลุด design และ layout บางส่วนไม่เรียบร้อย
BUG-04View drawer ทุกแท็บหลุด designLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด View drawer
  2. เปิดแท็บรายละเอียด
  3. เปิดแท็บ PDF Preview
  4. เปิดแท็บลายเซ็น/อนุมัติ
  5. เปิดแท็บประวัติ
ผลที่ควรเป็นทุกแท็บมี UI/UX และ layout สอดคล้องกับ design ของฟีเจอร์
ผลที่เกิดจริงUI/UX ของแท็บรายละเอียด, PDF Preview, ลายเซ็น/อนุมัติ และประวัติหลุด design
