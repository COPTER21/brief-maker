## §1.2 Per-Page Detail
### P-01 รายการ
- หัว: "แบบฟอร์มสรุปผลการคัดกรองโครงการเบื้องต้น (Project Screening)" · sub "ขั้นตอนที่ 4: คัดกรองและประเมินเบื้องต้น" + badge "N รายการ · เปิดอยู่ X · รอฉันพิจารณา Y" (ค่า 0 ไม่แสดง) · ปุ่ม ส่งออก CSV · สร้างแบบสรุปผล (disabled เมื่อ F-DOCCFG ปิดใช้ + แถบแดง)
- คอลัมน์ (1 ข้อมูล = 1 คอลัมน์): เลขที่ · วันที่ · ผู้จัดทำ (icon คน) · คะแนนรวม · ผลเสนอจากคะแนน (pill) · ผลการพิจารณา (pill) · สถานะเอกสาร · ลายเซ็น n/N · ⋮ (แก้ไข[ร่างของตน] · พิมพ์ · ยกเลิกเอกสาร[สิทธิ์])
- สถานะ: ร่าง · รออนุมัติ · อนุมัติแล้ว · ยกเลิก · ผลเสนอ: เสนอให้ดำเนินการต่อ · ดำเนินการต่อแบบมีเงื่อนไข · ไม่เสนอให้ดำเนินการต่อ (จาก recommend_bands)
### P-02 สร้าง/แก้ (ขั้น 1 ข้อมูลหลักแบบสรุปผล)
- แถบสรุปสด: ผู้จัดทำ (จากระบบ) · ให้คะแนนแล้ว n/8 เกณฑ์ · คะแนนรวมถ่วงน้ำหนัก x / 100 · ผลเสนอจากคะแนน (pill) · legend เกณฑ์ผลเสนอ (จาก config)
- ตาราง "การประเมินและคัดกรองโครงการ":
| คอลัมน์ (ป้ายตามกระดาษ) | คีย์ | ชนิด |
|---|---|---|
| เกณฑ์ประเมิน | `criteria[].criterion` | อ่านอย่างเดียว (ScreeningCriteria.items) |
| น้ำหนัก (%) | `weight` | อ่านอย่างเดียว (snapshot) |
| คะแนน (1-5)* | `score` | select 1–5 |
| คะแนนถ่วงน้ำหนัก | `weighted_score` | computed สด · ว่างจนให้คะแนน |
| เหตุผล / หลักฐาน | `rationale` | textarea |
| ความเสี่ยง / เงื่อนไข | `risk_condition` | textarea |
| แถวท้าย คะแนนรวมถ่วงน้ำหนัก | `screening.total_score` + `recommendation` | computed · ว่างจนให้คะแนนครบ |
- การ์ด "ข้อสรุปการคัดกรอง":
| ป้าย | คีย์ | ชนิด |
|---|---|---|
| จุดเด่นของโครงการ* | `summary.strengths` | textarea |
| ข้อกังวลหลัก* | `summary.concerns` | textarea |
| ข้อมูลที่ต้องจัดหาเพิ่ม | `summary.info_needed` | textarea |
| ผลการพิจารณา* | `summary.decision` | track-card 3 ค่า (มีคำอธิบายในตัว) |
| เงื่อนไข / ข้อสั่งการ (* เมื่อมีเงื่อนไข/ผลขัดคะแนน) | `summary.conditions` | textarea · ดาวแดงขึ้นสด |
| ข้อเสนอแนะขั้นตอนถัดไป | `summary.next_steps` | textarea |
- แถบเตือนส้ม "ผลการพิจารณาไม่ตรงกับผลเสนอจากคะแนน (…) — บันทึกได้ แต่ต้องระบุเหตุผลในเงื่อนไข / ข้อสั่งการ"
- ขั้น 2 เอกสารแนบ: upload zone (ไม่บังคับ)
- ขั้น 3 ตรวจสอบ: ข้อมูลแบบสรุปผล · ตารางการประเมิน · ตารางข้อสรุป · เอกสารแนบ
