### 3.1 รายการซ้ำ

### 3.3 สูตร + ค่าคงที่บนกระดาษ
- สูตร: คะแนนถ่วงน้ำหนัก = `F02 × F03 / 5` ต้นฉบับ =C13*D13/5 แสดง 0 เมื่อยังไม่ให้คะแนน
- สูตร: คะแนนรวมถ่วงน้ำหนัก = `SUM(F04)` =SUM(E13:E20) เต็ม 100 เมื่อน้ำหนักรวม 100
- สูตร: ผลเสนอจากคะแนน = `F07 ≥ 80 → เสนอให้ดำเนินการต่อ · F07 ≥ 60 → ดำเนินการต่อแบบมีเงื่อนไข · อื่น → ไม่เสนอให้ดำเนินการต่อ` เกณฑ์ 80/60 เป็นค่าคงที่ → config
- ค่าคงที่ "8 เกณฑ์ประเมิน + น้ำหนัก 15/15/15/20/10/10/10/5" = รายการเกณฑ์คัดกรองและน้ำหนัก (%) รวม 100 → ควรอ่านจาก `ScreeningCriteria.items[] (name, weight_pct)` (ห้าม hardcode)
- ค่าคงที่ "≥80 เสนอให้ดำเนินการต่อ · ≥60 ดำเนินการต่อแบบมีเงื่อนไข · <60 ไม่เสนอให้ดำเนินการต่อ" = เกณฑ์คะแนนรวมสู่ผลเสนอ → ควรอ่านจาก `ScreeningCriteria.recommend_bands` (ห้าม hardcode)
- ค่าคงที่ "คะแนน 1-5 · หาร 5" = สเกลคะแนนต่อเกณฑ์ (คะแนนเต็ม 5) → ควรอ่านจาก `ScreeningCriteria.score_max` (ห้าม hardcode)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- มีรายการ 'ผ่าน/ผ่านแบบมีเงื่อนไข/ต้องศึกษาเพิ่ม/ไม่ผ่าน' ทับช่วงคะแนน D13:D20 (ซึ่งมี 1-5 อยู่แล้ว) และลามถึงแถวข้อสรุป/ลงชื่อ → **ช่องคะแนนรับเฉพาะเลขเต็ม 1-5 · ไม่ใช้รายการ ผ่าน/ไม่ผ่าน**
- ยังไม่ให้คะแนนแต่แสดง 0 และผลเสนอขึ้น 'ไม่เสนอให้ดำเนินการต่อ' → **แสดงว่างจนกว่าให้คะแนนครบ 8 เกณฑ์ · ส่งได้เมื่อให้คะแนนครบเท่านั้น**
- เลือกผลการพิจารณาขัดกับผลเสนอจากคะแนนได้ (เช่น คะแนน < 60 แต่เลือก ดำเนินการต่อ) → **ผลการพิจารณาไม่ตรงผลเสนอ → ต้องกรอกเหตุผลใน เงื่อนไข / ข้อสั่งการ (เตือน ไม่บล็อก)**
- เลือก 'ดำเนินการต่อแบบมีเงื่อนไข' ได้โดยไม่ระบุเงื่อนไข → **ผลการพิจารณา = ดำเนินการต่อแบบมีเงื่อนไข → เงื่อนไข / ข้อสั่งการ บังคับกรอก**
- สรุปผลคัดกรอง 'โครงการ' แต่ไม่มีช่องชื่อ/เลขที่โครงการบนกระดาษ → **ไม่เพิ่มช่องบนแบบพิมพ์ (G5 1:1) — เสนอให้ลูกค้ายืนยันการผูกกับโครงการ (FM-BDM-01) ในรายงาน**
- น้ำหนักพิมพ์ตายตัวในเซลล์ แก้ได้ใน Excel โดยไม่มีตรวจผลรวม → **ผลรวมน้ำหนักต้อง = 100 (ตรวจที่ config ไม่ให้แก้ในเอกสาร)**
