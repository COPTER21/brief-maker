0ขอบเขตการตรวจ

ส่วนที่ไม่ได้ตรวจ อยู่นอกความรับผิดชอบของรายงานฉบับนี้

ตรวจแล้ว

  • สร้าง / แก้ไข / ลบ เอกสาร — ทดสอบครบ
  • แนบไฟล์ (upload) — พบ error
  • แท็บดูรายละเอียด: PDF Preview · การอนุมัติ · ประวัติ — ตรวจหน้าตา (design)
  • พฤติกรรม badge validation บน drawer (create / edit / view)
  • ตำแหน่งปุ่มยกเลิกบน drawer
  • UI/UX ส่วนที่เหลือ (ผู้ตรวจระบุว่าโอเค)

ไม่ได้ตรวจ

  • คำนวณยอดรวม 13 ช่อง (รวมทุกแถว · แก้ไม่ได้ · กัน tamper ผ่าน API) (FN-02 · DEC-12 · T-54) — ยังไม่ได้ตรวจเนื้อ logic การคำนวณในรอบนี้
  • สายอนุมัติ DOA เดินจริง + เลือกผู้พิจารณาต่อขั้น + role-line-manager wire (FN-06/07 · T-20…25) — เปิดแท็บการอนุมัติดูแค่หน้าตา ยังไม่ได้ทดสอบ flow อนุมัติจริง
  • ไม่อนุมัติ = กลับเป็นร่างเลขเดิม (วงตีกลับ) (FN-08 · DEC-08 · T-26…28) — ยังไม่ได้ทดสอบ flow อนุมัติ/ตีกลับ
  • สิทธิ์และการมองเห็น — NOT_FOUND/NOT_OWNER/NOT_CURRENT_APPROVER ผ่าน API ตรง (FN-10 · T-40…46) — ยังไม่ได้ทดสอบระดับ API
  • แบบพิมพ์ PDF — เนื้อหา 31 แถว · header snapshot · คงคำสะกดตามกระดาษ (FN-11 · T-50 · T-55) — เปิดแท็บ PDF ดูแค่ design ยังไม่ได้ตรวจเนื้อหา/ตรรกะการเติมแถว
  • ออกเลขเอกสาร TRV และเลขนิ่งตลอดชีพ ผ่าน reject/approve loop (FN-04 · T-28) — ยังไม่ได้ทดสอบเนื้อการออกเลข/วงอนุมัติ
  • ส่งออก CSV 13 ช่อง (FN-12 · T-62) · ความทนทาน API 409/403/500 (T-70…74) — ยังไม่ได้ตรวจในรอบนี้

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-01dropdown เขตการขาย/รอบการขาย ไม่แสดงตัวเลือก (จาก R1)Criticalแก้แล้ว
ขั้นตอนทำซ้ำ
  1. เปิดหน้าสร้างใบเดินทาง
  2. คลิก dropdown เขตการขาย/รอบการขาย
ผลที่ควรเป็นแสดงรายการให้เลือก → ทำรายการต่อได้
ผลที่เกิดจริงR1: ไม่มี option · R2: ใช้งานได้แล้ว (create/edit/delete ผ่าน)
BUG-02ปฏิทินช่อง 'วันที่' แสดงกลางจอ ไม่ยึดช่อง input (จาก R1)Mediumแก้แล้ว
ขั้นตอนทำซ้ำ
  1. เปิดหน้าสร้าง
  2. คลิกช่อง 'วันที่' ในตาราง
ผลที่ควรเป็นปฏิทินเปิดติดกับช่อง input
ผลที่เกิดจริงR2: ไม่พบรายงานปัญหาแล้ว (ผู้ตรวจระบุ UI/UX ส่วนที่เหลือโอเค) — ถือว่าแก้แล้ว รอยืนยัน
BUG-03แนบไฟล์ (upload) ไม่ได้ ติด error ที่ APIMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดหน้าสร้าง/แก้ไขใบเดินทาง
  2. ไปส่วนแนบไฟล์ (เอกสารแนบ) แล้วเลือกไฟล์อัปโหลด
ผลที่ควรเป็นอัปโหลดไฟล์แนบสำเร็จ (PDF/Word/Excel/รูป ≤ 20MB — BR-TRV-10 · VR-10)
ผลที่เกิดจริงอัปโหลดไม่สำเร็จ ติด error ที่ API แนบไฟล์ไม่ได้เลย
ข้อความ error (ผู้ตรวจเล่าด้วยคำพูด)
BUG-04badge validation ค้าง ไม่หายแม้แก้ให้ถูกแล้ว ต้อง refreshMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด drawer สร้าง/แก้ไข (เกิดบน view ด้วย)
  2. ทำให้เกิด validation error จน badge ขึ้น
  3. กรอกข้อมูลให้ถูกต้องเพื่อแก้ให้ผ่าน validation
ผลที่ควรเป็นbadge validation หายทันทีเมื่อแก้ข้อมูลให้ถูกต้อง
ผลที่เกิดจริงbadge ยังค้างแสดงบน drawer ทั้ง create/edit/view ต้อง refresh หน้าจอถึงจะหาย (สถานะ UI ค้าง ทำให้เข้าใจผิดว่ายังมี error)
ยังไม่มี screenshot (ผู้ตรวจเล่าด้วยคำพูด)
