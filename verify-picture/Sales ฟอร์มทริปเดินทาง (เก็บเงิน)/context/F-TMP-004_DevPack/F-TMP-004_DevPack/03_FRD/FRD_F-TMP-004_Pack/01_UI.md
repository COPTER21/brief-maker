# 01_UI — F-TMP-004 ใบเดินทาง : เขตการขาย General Trade

> archetype **Q-form** (Pattern Q2) · ต้นแบบ `feature.html` · CI CUBE Warm Light · ช่องวันที่ทุกช่องใช้ตัวเลือกวัน พ.ศ. กลาง (`bedateHTML` · Rule #114)

## 1. หน้าทะเบียน (`#/travel-sheet`)
### 1.1 ส่วนหัว
- หัวข้อ "ใบเดินทาง เขตการขาย (Sales Territory Travel Sheet)" + chip นับรายการ · เปิดอยู่ N
- คำอธิบาย: วางแผนและบันทึกผลการออกตลาดรายวันของเขตการขาย · ยอดรวมทุกคอลัมน์ระบบคำนวณให้
- ปุ่มขวา: **ส่งออก CSV** (secondary) · **สร้างใบเดินทาง** (primary · disabled เมื่อ doc_type ยังไม่เปิดใช้ที่ F-DOCCFG)

### 1.2 การ์ดสถิติ (คลิกเพื่อกรอง)
ใบเดินทางทั้งหมด · รออนุมัติ · รอฉันพิจารณา

### 1.3 ตัวกรอง
ค้นหา (เลขที่ / ผู้รับผิดชอบเขต / เขต / รอบการขาย) · สถานะ · เขต · ฝ่าย · ปุ่มล้างตัวกรอง

### 1.4 ตาราง (20 แถว/หน้า)
| คอลัมน์ | ที่มา |
|---|---|
| เลขที่ | `trip_sheet.doc_no` |
| วันที่ขอ | `trip_sheet.req_date` |
| ผู้รับผิดชอบเขต | `trip_sheet.owner_name` |
| เขต | `trip_sheet.territory` |
| รอบการขาย | `trip_sheet.sales_period` |
| ช่วงวันทำงาน | min–max ของ `trip_sheet_line.work_date` |
| สถานะเอกสาร | `trip_sheet.status` (+ ป้าย "ส่งกลับแก้ไข" เมื่อ `returned = true`) |
| ลายเซ็น | n/N จาก `approval_chain` |
| ยอดขายจริง (บาท) | `trip_sheet.total_sales_actual_amount` |
| ⋮ | แก้ไข (ร่างของตัวเอง) · พิมพ์ · ยกเลิกเอกสาร — **ไม่มี "ทำซ้ำ"** (DEC-11) |
คลิกแถว = เปิด drawer ดูรายละเอียด

## 2. Drawer สร้าง / แก้ไขร่าง (`#/travel-sheet/create` · `#/travel-sheet/edit/:id`) — 3 ขั้น
`const STEPS = ['ข้อมูลหลักใบเดินทาง', 'เอกสารแนบ', 'ตรวจสอบและยืนยัน']` (Rule #100F) · drawer กว้าง (`.wide`)

### 2.1 ขั้น 1 — ข้อมูลหลัก (ซ้ายฟอร์ม · ขวาการ์ดสรุปสด)
**การ์ด ① ใบนี้ของเขตไหน รอบไหน**
| ช่องบนกระดาษ | คีย์ | ชนิด | บังคับ |
|---|---|---|---|
| TO : | `to` | ข้อความ | ✓ |
| CC : | `cc` | ข้อความ | — |
| เขต : | `territory` | เลือกจากทะเบียนเขตการขาย | ✓ |
| รอบการขาย : | `sales_period` | เลือกจากรายการรอบ | ✓ |
- "ผู้รับผิดชอบเขต :" (`owner_name`) และ "ตำแหน่ง :" (`owner_position`) **ดึงจากระบบ** แสดงเป็นบรรทัดอ้างอิง + ในการ์ดสรุป ไม่ใช่ช่องกรอก

**การ์ด ② วันทำงานของรอบนี้** — ตาราง 19 คอลัมน์ตามกระดาษ (Rule #107: แถวซ้ำเกิน 4 ช่อง → ใช้ตาราง) เลื่อนแนวนอนได้
หัวตาราง 2 ชั้นตามกระดาษ: วันทำงาน · วันที่ · เริ่มต้นตลาด · สิ้นสุดตลาด · จำนวน · วางบิล (บิล/บาท) · Accual (บิล/บาท) · รับเช็ค (บิล/บาท) · Accual (บิล/บาท) · เป้าหมายการขาย (ร้าน/บาท) · Accual (ร้าน/บาท) · จังหวัดที่ปฎิบัติงาน · ที่พัก (จังหวัด)
| ช่องในแถว | คีย์ | ชนิด |
|---|---|---|
| วันทำงาน (เลขลำดับ) | `seq` | ระบบใส่ |
| วันที่ | `work_date` | วันที่ (`bedateHTML`) |
| เริ่มต้นตลาด | `market_from` | ข้อความ |
| สิ้นสุดตลาด | `market_to` | ข้อความ |
| จำนวน | `qty` | ตัวเลข |
| วางบิล บิล/บาท | `billing_plan_count` · `billing_plan_amount` | ตัวเลข · จำนวนเงิน |
| Accual (วางบิล) บิล/บาท | `billing_actual_count` · `billing_actual_amount` | ตัวเลข · จำนวนเงิน |
| รับเช็ค บิล/บาท | `cheque_plan_count` · `cheque_plan_amount` | ตัวเลข · จำนวนเงิน |
| Accual (รับเช็ค) บิล/บาท | `cheque_actual_count` · `cheque_actual_amount` | ตัวเลข · จำนวนเงิน |
| เป้าหมายการขาย ร้าน/บาท | `sales_target_shop` · `sales_target_amount` | ตัวเลข · จำนวนเงิน |
| Accual (เป้าหมายการขาย) ร้าน/บาท | `sales_actual_shop` · `sales_actual_amount` | ตัวเลข · จำนวนเงิน |
| จังหวัดที่ปฎิบัติงาน | `work_province` | ข้อความ |
| ที่พัก (จังหวัด) | `stay_province` | ข้อความ |
- แถวท้ายตาราง = **รวมยอด 13 ช่อง** (`total_*`) อ่านอย่างเดียว อัปเดตสดแบบ soft ขณะพิมพ์ (ไม่ rebuild — focus ไม่หลุด)
- ปุ่ม "เพิ่มวันทำงาน" ต่อแถวได้ไม่จำกัด (DEC-05) · ปุ่มถังขยะลบแถว (เหลือ 1 แถวลบไม่ได้)
- error แสดงเป็นแถบรวมเหนือตาราง (ระบุเลขแถว) + ขอบแดงช่องที่ผิด + ไฮไลต์แถว

**การ์ดสรุปสด (ขวา · sticky)** — ผู้รับผิดชอบเขต · ผู้อนุมัติแต่ละขั้นจากสาย DOA · เขต/รอบ · จำนวนวันทำงาน · วางบิล (แผน/ผลจริง) · รับเช็ค (แผน/ผลจริง) · **ยอดขายจริงรวม**

### 2.2 ขั้น 2 — เอกสารแนบ (DEC-11)
upload zone · PDF/Word/Excel/รูป ไม่เกิน 20 MB ต่อไฟล์ · ลบไฟล์ได้

### 2.3 ขั้น 3 — ตรวจสอบและยืนยัน
การ์ดข้อมูลใบเดินทาง (รวมสายอนุมัติที่จะใช้) · ตารางวันทำงานแบบอ่านอย่างเดียว · การ์ดรวมยอด (+ คำเตือนเมื่อ Accual > แผน) · เอกสารแนบ

### 2.4 ปุ่มท้าย drawer (Rule #100)
ซ้าย: ย้อนกลับ · ขวา: ยกเลิก · [ขั้น 1–2] ถัดไป · [ขั้น 3] บันทึกแบบร่าง · บันทึกและส่งอนุมัติ
ปิด drawer ขณะกรอกค้าง → modal "ทิ้งข้อมูลที่กรอกไว้?"

## 3. Drawer ดูรายละเอียด (`#/travel-sheet/view/:id`) — 4 แท็บ (Rule #101)
`รายละเอียด › PDF Preview › ลายเซ็น / อนุมัติ › ประวัติ`
- **รายละเอียด** — แบนเนอร์ตามสถานะ (รออนุมัติ / ส่งกลับแก้ไข + เหตุผล / ยกเลิกแล้ว / ร่าง) · ข้อมูลเอกสาร · ผู้รับผิดชอบเขต · ตารางวันทำงาน + แถวรวมยอด · การ์ดรวมยอด · เอกสารแนบ · ข้อมูลระบบ
- **PDF Preview** — `iframe srcdoc` จาก `form.tpl.html` + `docPrintData(record)` · ปุ่มดาวน์โหลด PDF / พิมพ์
- **ลายเซ็น / อนุมัติ** — การ์ดสรุปสาย DOA + timeline ขั้น 1..N + ปุ่มตัดสิน inline ที่ขั้นปัจจุบัน (คำตัดสินตาม role)
- **ประวัติ** — audit แบบ append-only

### 3.1 ปุ่มหัว drawer ตามสถานะ
| สถานะ · ผู้ใช้ | ปุ่ม |
|---|---|
| ร่าง · เจ้าของ | ยกเลิก · แก้ไข · **ส่งอนุมัติ** |
| รออนุมัติ · ผู้พิจารณาขั้นปัจจุบัน | ไม่อนุมัติ · **อนุมัติ** |
| ร่าง/รออนุมัติ · เจ้าของหรือ admin role | ยกเลิกเอกสาร |
ไอคอนขวา: พิมพ์ · ดาวน์โหลด PDF · ปิด (**ไม่มีไอคอนทำซ้ำ** — DEC-11)

## 4. Modal
ส่งอนุมัติ (slot picker 1 ช่องต่อขั้น DOA · ค่าเริ่มจาก resolve · ผู้ขอไม่อยู่ในรายชื่อ) · อนุมัติ (ความเห็นไม่บังคับ) · ไม่อนุมัติ (เหตุผลบังคับ + chip ตัวอย่าง) · ยกเลิกเอกสาร (เหตุผลบังคับ) · ทิ้งข้อมูลที่กรอกไว้

- ไม่มีใบเดินทาง → empty state + ปุ่มสร้าง · กรองแล้วไม่พบ → empty state + ล้างตัวกรอง
- ปุ่ม submit ระหว่างบันทึก = disabled + loader + "กำลังบันทึก…" (Rule #44)
