- หัว: "แบบฟอร์มยืมสินทรัพย์ (Asset Borrowing)" + badge จำนวน · รอฉันพิจารณา n · เลยกำหนดคืน n (ค่า 0 ซ่อน) · ปุ่ม ส่งออก CSV · สร้างคำขอยืม (disabled เมื่อ F-DOCCFG ปิดใช้ + แถบแดง)

- สถานะ: ร่าง · รออนุมัติ · ให้ยืมแล้ว · รับคืนแล้ว · ยกเลิก · pager: แสดง 10/25/50 · "x–y จาก N"
### P-02 สร้าง/แก้ (ขั้น 1 ข้อมูลหลักการยืม)
| การ์ด | ช่อง (ป้ายตามกระดาษ) | คีย์ | ชนิด |
|---|---|---|---|
| ① ยืมไปใช้ทำอะไร | ขอยืมสินทรัพย์ เพื่อใช้* | `purpose` | textarea |
| ② ยืมอะไรบ้าง (ตาราง) | ลำดับ (auto) · ทะเบียนสินทรัพย์* `items[].asset_code` (search combobox Asset Master) · รายการ `items[].asset_name` (ตามทะเบียน อ่านอย่างเดียว) · จำนวนที่ยืม* `items[].qty_requested` · วันที่ยืม* `items[].borrow_date` (bedate พ.ศ.) · วันที่ส่งคืน* `items[].return_date` (bedate min = วันที่ยืม) · หมายเหตุ `items[].remark` · ลบ | | ปุ่ม "เพิ่มรายการ" (ยกวันที่แถวก่อน + focus ทะเบียน) |
- จำนวนที่ให้ยืม `items[].qty_lent` ไม่อยู่ในฟอร์มสร้าง — ผู้ให้ยืมกรอกใน M-02 (คำอธิบายใต้ตาราง)
- error ต่อแถว: แถวแดง + ข้อความใต้แถว (ข้อแรก) + toast "กรุณากรอกข้อมูลให้ครบถ้วน"
- sumCard: ผู้ยืม (ชื่อ · ตำแหน่ง · ฝ่าย จากระบบ) · ผู้ให้ยืม (ค่าเริ่มจาก DOA) · n รายการ · รวมจำนวน · ช่วงที่ยืม
- ขั้น 2 เอกสารแนบ: upload zone (≤20MB · pdf/doc/xls/รูป)
- ขั้น 3 ตรวจสอบ: ข้อมูลคำขอ (ข้าพเจ้า · ตำแหน่ง · ฝ่าย/แผนก · วันที่ขอ · ผู้ให้ยืม · เพื่อใช้) · ตารางรายการ 8 คอลัมน์ตามกระดาษ · เอกสารแนบ · วันที่ยืมย้อนหลัง = แถบเตือน
- footer: ย้อนกลับ · ยกเลิก · ถัดไป / บันทึกแบบร่าง · บันทึกและส่งอนุมัติ · ปิดตอนกรอกค้าง = M-06 "ทิ้งข้อมูลที่กรอกไว้?"
