# UI contract · Frozen HTML
| Route | Function | Action/result |
|---|---|
| `#/records` รายการกัก | stock slice list, canonical search/filter, true onHand/held/pending/ATP summaries | choose real Item/Warehouse/location/lot snapshot; create hold/release drawer, qty/reason/origin/source and configured DOA slots |
| `#/history` รออนุมัติ | pending request queue | inspect requested details; DEMO decision harness emits mock external approval/rejection only |
| `#/settings` ประวัติ | append-only requests/decisions | audit actor/time/source; no edit/delete |

Tabs immediately under page-head; right upper region action only. No hint/banner. Drawer errors remain visible and do not close or mutate records. Required DOA slots show searchable eligible named people with initials avatar, position and department; no role-ID hierarchy. Search/filter counts derive from rows. Snapshot refs soft-linked; missing downstream reference explicit empty state.

## Demo-only elements
`data-demo="doa-policy"` policy/person fixture and `data-demo="doa-decision"` approval/rejection simulator have visible orange DEMO badge. They are local test harness controls. Production permission, policy lookup and decision event arrive from DOA service, never from this button. UI must not treat DEMO actor as real authenticated approver. No persona switcher outside these tagged controls.

## Accessibility and responsive
Drawer focus/labels/keyboard validation, empty/loading/error states, 1280px desktop list overflow and narrow viewport are visual QA WARN because browser runner unavailable; product release requires visual check. No print/export of Restricted person snapshots without authorized role.
