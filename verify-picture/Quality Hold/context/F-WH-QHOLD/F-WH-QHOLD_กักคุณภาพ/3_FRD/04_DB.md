# Data model · proposed server persistence
| Table | Key fields | Constraints / indexes | Classification |
|---|---|---|---|
| `qh_slice_projection` | tenant_id,slice_id,warehouse_ref,active_held,pending_held,pending_release,version | unique tenant+slice; nonnegative; optimistic version | Confidential |
| `qh_request` | tenant_id,id,slice_id,kind,qty,reason,origin,source_ref,policy_ref,selected_slots_json,status,version,idempotency_key,request_hash,created_at | unique tenant+idempotency_key; status requested/approved/rejected; qty decimal>0 | Restricted; selected person snapshots PII |
| `qh_event` | tenant_id,id,request_id,type,qty,actor_ref,source_event_id,source_ref,at | append-only; unique tenant+source_event_id where nonnull; no UPDATE/DELETE app permission | Restricted actor PII |
| `qh_outbox` | tenant_id,id,event_type,payload,event_key,status,created_at | unique event_key, retryable delivery | Confidential; strip person names |

Inventory owns onHand/reservedSales and movement ledger, never duplicated as writable QHold balance. External Item/Warehouse/location/lot/person refs are snapshots with nullable relation pointers; production RLS tenant+warehouse on every read/write. Retention/erasure for person snapshots owner Security/DOA `[ASSUMED]`; preserve audit lawfully. Index requests by slice/status/created_at and events by request/at. Monetary values absent.
