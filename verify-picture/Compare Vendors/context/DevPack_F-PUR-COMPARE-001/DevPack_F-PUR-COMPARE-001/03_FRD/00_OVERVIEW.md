# 00 · OVERVIEW — F-PUR-COMPARE-001 · เทียบราคาผู้ขาย

## §0.1 ฟีเจอร์นี้คืออะไร
คอนโซลปฏิบัติงานหน้าเดียวสำหรับเจ้าหน้าที่จัดซื้อ: หยิบใบขอซื้อที่อนุมัติแล้วจากคิว → บันทึกใบเสนอราคาจากผู้ขายหลายราย →
เทียบ 4 แกน (ราคา · เงื่อนไขชำระ · ระยะส่งมอบ · การรับประกัน) ทั้งระดับใบและระดับรายการ →
เลือกผู้ชนะพร้อมเหตุผล → ล็อกผล → ส่งต่อใบสั่งซื้อผ่านจุดเชื่อม

## §0.3 ขอบเขต

**อยู่ในขอบเขต**
- คิวงานใบขอซื้อที่อนุมัติแล้ว + ค้นหา/กรอง + สถานะว่าง/กำลังโหลด/ผิดพลาด
- เปิดรอบเทียบราคา · บันทึก/แก้/ลบใบเสนอราคา (ก่อนยืนยันผล) · แนบไฟล์
- ราคารายรายการ + ส่วนลด% + VAT 3 โหมด + ทำเครื่องหมาย "ไม่เสนอ"
- ตารางเทียบเคียงข้าง + ไฮไลต์ค่าดีที่สุด + แถวสรุป 6 แถว + ราคาซื้อครั้งก่อน
- เลือกผู้ชนะแบบทั้งใบ / แยกรายรายการ + เหตุผลบังคับตาม BR-04
- ยืนยันผล (ล็อก) · เปิดรอบใหม่ · ยกเลิกรอบ · ประวัติเพิ่มอย่างเดียว
- ประทับผล 7C 2 เหตุการณ์ (`master.changed` → DC · `doc.cancelled` → EC)

**นอกขอบเขต**
- จอใบสั่งซื้อ (W3) — มีแค่จุดเชื่อมทางเดียว
- พอร์ทัลให้ผู้ขายกรอกเอง · การต่อรองราคา · คะแนนประเมินผู้ขาย · หลายสกุลเงิน
- สายอนุมัติ · เลขที่เอกสาร · แบบพิมพ์ · แจ้งเตือน
