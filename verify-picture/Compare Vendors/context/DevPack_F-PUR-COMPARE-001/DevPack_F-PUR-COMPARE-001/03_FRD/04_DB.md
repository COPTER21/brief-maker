# 04 · DB — F-PUR-COMPARE-001

**หลักการ:** 5 ตาราง · ไม่มีตารางเลขรัน (LD-03) · `cmp_award_line` และ `cmp_history` **เพิ่มอย่างเดียว** (LD-07)
**อ้างอิงอ่อน (LD-08):** `pr_id` · `vendor_id` · `item_id` · `uom` เก็บเป็นค่าอ้าง **ไม่ผูก FK บังคับ ไม่ cascade delete** — เก็บ snapshot ของชื่อ/หน่วยไว้ในแถวด้วย เพื่อให้ประวัติอ่านได้แม้ master เปลี่ยน

## 1. `cmp_round` — รอบเทียบราคา

| คอลัมน์ | ชนิด | NULL | หมายเหตุ |
| --- | --- | :--: | --- |
| `round_id` | uuid / bigint PK | ✗ | **รหัสภายใน ไม่ใช่เลขที่เอกสาร** (LD-03) |
| `pr_id` | varchar(32) | ✗ | อ้างอิงอ่อนไปใบขอซื้อ |
| `pr_snapshot` | jsonb | ✗ | สำเนาหัว+บรรทัดของใบขอซื้อ ณ เวลาเปิดรอบ (กันข้อมูลเพี้ยนเมื่อ PR แก้) |
| `round_seq` | int | ✗ | 1,2,3… ต่อ `pr_id` |
| `prev_round_id` | uuid | ✓ | รอบก่อนหน้าเมื่อเปิดรอบใหม่ |
| `status` | enum | ✗ | `open` · `comparing` · `awarded` · `cancelled` |
| `award_mode` | enum | ✗ | `whole` · `split` (ค่าตั้งต้น `whole`) |
| `award_reason` | text | ✓ | **บังคับเมื่อ BR-04 เข้าเงื่อนไข** — บังคับที่ชั้น service ไม่ใช่ NOT NULL |
| `cancel_reason` | text | ✓ | บังคับเมื่อ `status='cancelled'` |
| `opened_by` `opened_at` | varchar / timestamptz | ✗ | |
| `awarded_by` `awarded_at` | varchar / timestamptz | ✓ | |
| `cancelled_by` `cancelled_at` | varchar / timestamptz | ✓ | |
| `row_version` | int | ✗ | optimistic lock (EC-08 แก้พร้อมกัน) |

**Index**
- `UNIQUE (pr_id, round_seq)`
- `INDEX (status, opened_at DESC)` — คิวงาน
- `INDEX (pr_id)` — ประวัติรอบของใบเดียวกัน
- `PARTIAL UNIQUE (pr_id) WHERE status IN ('open','comparing')` — **หนึ่งใบขอซื้อมีรอบที่ยังไม่ปิดได้ครั้งละรอบเดียว**
