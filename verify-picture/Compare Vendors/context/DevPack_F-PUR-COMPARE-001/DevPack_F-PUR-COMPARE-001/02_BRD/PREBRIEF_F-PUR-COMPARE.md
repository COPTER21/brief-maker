# PREBRIEF — F-PUR-COMPARE · Compare Vendors (เทียบราคาผู้ขาย)
source of truth เชิง business · lane CUBE-LANE-W2-PUR-LITE · P1 · 2026-09-10 · mode direction

## 1. สรุปฟีเจอร์
คอนโซลงานเทียบราคา: หยิบใบขอซื้อที่อนุมัติแล้ว → บันทึกใบเสนอราคาจากผู้ขายหลายราย → เทียบ 4 แกน (ราคา · เงื่อนไขชำระ · ระยะส่งมอบ · การรับประกัน)
ทั้งระดับใบและระดับรายการ → เลือกผู้ชนะ + เหตุผล (เพิ่มอย่างเดียว) → ส่งผลต่อใบสั่งซื้อ (W3) แบบอ้างอิงอ่อน
**ไม่ใช่เอกสารธุรกรรม** — ไม่มีเลขที่เอกสาร ไม่มีสายอนุมัติ ไม่มีแบบพิมพ์ → **ห้าม Pattern Q**

## 2. State machine ของ "รอบเทียบราคา" (comparison round)
```
OPEN ──บันทึกใบเสนอราคา ≥1 ราย──► COMPARING ──เลือกผู้ชนะ + เหตุผล──► AWARDED ──(hook)──► [PO W3]
  │                                     │
  └──────────── CANCELLED ◄─────────────┘   (ยกเลิกรอบ + เหตุผล · จาก OPEN/COMPARING เท่านั้น)
AWARDED = ล็อก แก้ไม่ได้ · ต้องการเปลี่ยน = เปิดรอบใหม่ (revision) อ้างรอบเดิม
```
> **AWARDED แล้วห้ามแก้** เพราะเป็นฐานการออกใบสั่งซื้อ — การเปลี่ยนใจต้องเห็นเป็นรอบใหม่ที่ตรวจย้อนได้

## 3. หน้าจอ — console 3 ส่วนในหน้าเดียว (ห้าม Pattern Q · ห้าม wizard)
### 3.1 แถบซ้าย — คิวงานเทียบราคา (work queue)
- รายการใบขอซื้อที่อนุมัติแล้วและยังไม่ปิดรอบ + รอบที่ทำค้างไว้
- ต่อแถว: เลขที่ใบขอซื้อ · หน่วยงาน · ยอดประมาณ · จำนวนรายการ · จำนวนผู้ขายที่บันทึกแล้ว · สถานะรอบ · อายุงาน (วัน)
- ตัวกรอง: สถานะรอบ · หน่วยงาน · ค้นหาเลขที่/ชื่อรายการ
- สถานะว่าง/กำลังโหลด/ผิดพลาด ครบ

### 3.2 พื้นที่หลัก — 3 แท็บทำงาน (แท็บของคอนโซล ไม่ใช่ view drawer ของเอกสาร)
| แท็บ | เนื้อหา |
|---|---|
| **ใบเสนอราคา** | การ์ดต่อผู้ขาย: ผู้ขาย (อ้างอิงอ่อน) · เลขที่ใบเสนอราคาของผู้ขาย · วันที่ · วันหมดอายุ · เงื่อนไขชำระ · ระยะส่งมอบ (วัน) · การรับประกัน · ไฟล์แนบ · ตารางราคารายรายการ (ราคา/หน่วย · ส่วนลด% · VAT) · ยอดสุทธิของราย · ปุ่มเพิ่ม/แก้/ลบผู้ขาย (ลบได้เฉพาะก่อน AWARDED) |
| **ตารางเทียบ** ★ | **แกนหลักของฟีเจอร์** — ตารางเคียงข้าง: แถว = รายการจากใบขอซื้อ · คอลัมน์ = ผู้ขายแต่ละราย · เซลล์ = ราคา/หน่วย + ยอดรวมรายการ · ไฮไลต์ค่าดีที่สุดรายแถว · แถวสรุปท้ายตาราง: ยอดสุทธิรวม · เงื่อนไขชำระ · ระยะส่งมอบ · การรับประกัน · ส่วนต่างจากราคาต่ำสุด (%) · ราคาซื้อครั้งก่อน (อ้างอิง) |
| **ผลการเลือก** | โหมดเลือก: **ทั้งใบ** (ผู้ขายรายเดียว) หรือ **แยกรายรายการ** · สรุปผู้ชนะ · ยอดรวมที่จะออกใบสั่งซื้อ · เหตุผลการเลือก (บังคับเมื่อไม่ใช่ราคาต่ำสุด) · ปุ่ม "ยืนยันผลการเลือก" · หลังยืนยัน: กล่องสรุป + ปุ่มส่งต่อใบสั่งซื้อ (hook) |

### 3.3 แถบขวา / ท้าย — ประวัติ (เพิ่มอย่างเดียว)

## 5. Scenario ครบ
| # | Scenario | ผลที่ต้องได้ |
|---|---|---|
| SC-01 | Happy ทั้งใบ — เปิดรอบ → บันทึก 3 ผู้ขาย → เทียบ → เลือกผู้ขายราคาต่ำสุดทั้งใบ | AWARDED · ไม่ต้องใส่เหตุผล (แต่ใส่ได้) · ประวัติครบ |
| SC-02 | Happy แยกรายรายการ — ผู้ขาย A ชนะ 2 รายการ ผู้ขาย B ชนะ 1 รายการ | AWARDED · สรุปยอดต่อผู้ขาย · ส่งต่อใบสั่งซื้อได้ 2 ใบ (hook) |
| SC-03 | เลือกผู้ที่ **ไม่ใช่** ราคาต่ำสุด | **บังคับเหตุผล** — ยืนยันไม่ได้จนกว่าจะกรอก · ไฮไลต์ส่วนต่าง % ให้เห็น |
| SC-04 | ผู้ขายบางรายไม่เสนอบางรายการ | เซลล์แสดง "ไม่เสนอ" · ไม่ถูกนับเป็นราคาต่ำสุด · เลือกผู้ชนะรายการนั้นจากรายที่เสนอเท่านั้น |
| SC-05 | มีผู้ขายรายเดียว | เทียบได้ แต่ขึ้นคำเตือน "มีผู้เสนอราคาเพียงรายเดียว" + บังคับเหตุผล (คุมความเสี่ยง) |
| SC-06 | ยังไม่มีใบเสนอราคาเลย แล้วกดยืนยันผล | บล็อก + ข้อความ "ต้องมีใบเสนอราคาอย่างน้อย 1 ราย" |
| SC-07 | ใบเสนอราคาหมดอายุก่อนวันยืนยัน | เตือนสีส้มที่การ์ดและในตารางเทียบ · ยืนยันได้แต่ต้องรับทราบ |
| SC-08 | แก้ไขใบเสนอราคาหลังยืนยันผล | ปุ่มแก้/ลบถูกปิด + ข้อความ "รอบนี้ปิดแล้ว — เปิดรอบใหม่เพื่อเทียบอีกครั้ง" |
| SC-09 | เปิดรอบใหม่จากรอบที่ปิดแล้ว | รอบใหม่ `round_seq+1` อ้างรอบเดิม · คัดลอกผู้ขาย/ราคาเป็นค่าตั้งต้น · รอบเดิมยังอ่านได้ |
| SC-10 | ยกเลิกรอบ | บังคับเหตุผล + ยืนยัน (การกระทำย้อนกลับไม่ได้) · CANCELLED · ใบขอซื้อกลับเข้าคิว |
| SC-11 | ผู้ไม่มีสิทธิ์เปิดดู | ดูได้ ปุ่มบันทึก/ยืนยันไม่ขึ้น |
| SC-12 | คิวว่าง / โหลดพัง | สถานะว่าง + สถานะผิดพลาดพร้อมปุ่มลองใหม่ |
| SC-13 | ยอดสุทธิของผู้ขายเท่ากันสองราย | ไฮไลต์ทั้งคู่เป็นค่าดีที่สุด · ผู้ใช้ตัดสินและใส่เหตุผล |
| SC-14 | สินค้าเป็นรายการนอกทะเบียน (มาจากใบขอซื้อ) | เทียบได้ปกติ — ยึดชื่อรายการจากใบขอซื้อ |
| SC-15 | ใบขอซื้อถูกยกเลิกหลังเปิดรอบแล้ว | เตือนที่หัวคอนโซล · ยืนยันผลไม่ได้ · แนะให้ยกเลิกรอบ |

## 6. Cross-boundary
- **อ้างอิงอ่อน**: ใบขอซื้อ (F-PUR-PR) · ผู้ขาย (F007) · สินค้า/หน่วยนับ — ตัวเลือกเท่านั้น ไม่ผูกคีย์
