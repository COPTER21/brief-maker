### 3.1 รายการซ้ำ
- **ทะเบียนความเสี่ยง** — บนกระดาษ 18 แถว (min_rows) · ช่องในแถว: ลำดับ, ประเภทความเสี่ยง, รายละเอียดความเสี่ยง, สาเหตุ / ผลกระทบ, โอกาสเกิดก่อนควบคุม, ผลกระทบก่อนควบคุม, คะแนนก่อนควบคุม, มาตรการควบคุม, คะแนนคงเหลือ, สถานะ

### 3.2 ตัวเลือก

### 3.3 สูตร + ค่าคงที่บนกระดาษ
- สูตร: คะแนนก่อนควบคุม = `F05 × F06` ต้นฉบับ =E21*F21 แสดง 0 เมื่อยังไม่กรอก
- ค่าคงที่ "คะแนน 1–5 โอกาสเกิด/ผลกระทบ (ต่ำมาก…สูงมาก + คำอธิบาย)" = เกณฑ์ให้คะแนนโอกาสเกิดและผลกระทบ → ควรอ่านจาก `RiskMatrix.likelihood_scale / RiskMatrix.impact_scale` (ห้าม hardcode)
- ค่าคงที่ "1-4 ต่ำ · 5-9 ปานกลาง · 10-16 สูง · 17-25 สูงมาก" = ช่วงคะแนนระดับความเสี่ยง + แนวทางดำเนินการ → ควรอ่านจาก `RiskMatrix.level_bands` (ห้าม hardcode)
- ค่าคงที่ "ประเภทความเสี่ยง 9 ประเภท" = รายการประเภทความเสี่ยง → ควรอ่านจาก `RiskMatrix.categories` (ห้าม hardcode)

### 3.4 ลายเซ็น + control
- S1 ผู้จัดทำ (ผู้ขอ)
- S2 ผู้ตรวจสอบ (ผู้อนุมัติ)
- S3 ผู้อนุมัติ / รับทราบ (ผู้อนุมัติ)
- Doc No. บนกระดาษ FM-BDM-02 · Rev.00 : 01/07/2569 · เลขรันบนกระดาษ: ไม่มี (ระบบออกเลขเอง)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- รายการตัวเลือกมี 7 ซึ่งไม่ใช่ผลคูณของโอกาสเกิด × ผลกระทบ (1–5) ได้ → **คะแนนคงเหลือต้องอยู่ในชุดผลคูณ {1,2,3,4,5,6,8,9,10,12,15,16,20,25}**
- คะแนนคงเหลือกรอกเองได้สูงกว่าคะแนนก่อนควบคุม → **คะแนนคงเหลือ ≤ คะแนนก่อนควบคุม (เกิน = เตือน)**
- แถวว่างแสดง 0 (=E×F) ทั้งที่ยังไม่ได้ประเมิน → **แสดงว่างจนกว่ากรอกทั้งโอกาสเกิดและผลกระทบ**
- ใช้ประเมินความเสี่ยง 'ของโครงการ' แต่ไม่มีช่องชื่อ/เลขที่โครงการบนกระดาษ → **ไม่เพิ่มช่อง (G5 1:1) — เสนอให้ลูกค้ายืนยันการผูกกับโครงการ (FM-BDM-01) ในรายงาน**
- ไม่มีคอลัมน์ระดับความเสี่ยงแม้มีตารางสรุประดับ — ต้นฉบับใช้สีพื้นแทน → **ระดับคำนวณจากคะแนนตาม RiskMatrix.level_bands ใช้แสดงสี/ป้ายเท่านั้น ไม่เพิ่มคอลัมน์บนแบบพิมพ์**
