# AI Test Cases — OT / Shift (โอที)

ชุดทดสอบสำหรับ `F-HR-OT` · สร้างจาก FRD Pack FULL (`3_FRD/`) + BRD v1.0 + HTML ที่ผ่าน gate (`1_HTML/โอที.html`)
