## §P.3 กติกาคำนวณ (ไม่มีสูตรเงิน)

- `line.hours_requested` = (`time_to` − `time_from`) **หักช่วงพักตามกะที่ทับซ้อน** · ข้ามเที่ยงคืนให้บวก 24 ชม. ก่อนหัก และ `work_date` = **วันเข้ากะ** (LD-01 · `03_LOGIC F-12`)
- **การปัดเศษ/หน่วยขั้นต่ำ:** ต้องอ่านจาก HR Configuration — **ยังไม่ถูกเผยแพร่** → **รอบนี้ใช้ค่าดิบไม่ปัด** (BR-30 · **OQ-OT-16** · LD-OT-07) · **ห้ามใส่ตัวเลขนาทีลงโค้ด**
- `hours_requested_total` / `hours_approved_total` / `hours_confirmed_total` = Σ ของบรรทัดตามลำดับ — **3 ตัวเลขอยู่คู่กัน ไม่เขียนทับกัน** (O-5)
- `over_cap` = (ชั่วโมงสะสมสัปดาห์ **>** `cap_snapshot_hours_week`) — **ค่าเพดานมาจาก `hr-config/resolve(date = work_date, company_id)` เท่านั้น** (BR-09 · P-8)
- **ไม่มี** ยอดก่อนภาษี / ภาษี / ยอดสุทธิ / จำนวนเงินตัวอักษร / `ชั่วโมง × ตัวคูณ × อัตรา` — **เอกสารนี้ไม่มีเงิน**
- อัตรา · ประเภทวัน · ปฏิทินวันหยุด · กะ · งวด resolve ด้วย **`date` = วันที่ทำ OT** (ไม่ใช่วันนี้) + `company_id` (C-1 · BR-02)

## §P.4 กติกาการพิมพ์

- A4 แนวตั้ง · ตัวอักษรขนาดกระชับ · หัวตารางกับแถบยอดรวมเป็นแถบเน้นตัวอักษรขาว · **บล็อกลายเซ็นกับท้ายเอกสารอยู่ในส่วนท้ายที่ไม่แยกหน้า**
- **หัวตารางซ้ำทุกหน้า** (`thead { display: table-header-group }`) — จำเป็นเมื่อใบมีหลายบรรทัด (ขอ OT ทั้งเดือนในใบเดียว)
- **ห้ามตัดแถวกลางแถว** (`tr { break-inside: avoid }`) · **บล็อกลายเซ็นห้ามขึ้นหน้าใหม่แยกจากเนื้อหา** (`.signs { break-inside: avoid }`)
- ท้ายเอกสาร "หน้า X / N" — **ต้อง bind จริงเมื่อเอกสารเกิน 1 หน้า**
- **จำนวนช่องลายเซ็นต้องมาจาก `approval_chain.length` ที่ resolve ได้จริง (2+1 หรือ 3+1)** — ห้ามวาด 3 หรือ 4 ช่องตายตัว
- **สำเนา:** เก็บอัตโนมัติเมื่ออนุมัติครบสายผ่าน `ENG-DOC-STORE.store(pdf, 'OT', ot_request_id, 'approved_final')` — **render จากข้อมูล ณ เวลาอนุมัติ ห้าม re-render จากข้อมูลปัจจุบัน** (FN-38 · `03_LOGIC F-55`)
