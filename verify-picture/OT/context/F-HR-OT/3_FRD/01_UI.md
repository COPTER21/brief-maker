## §1.3 User Journey (Happy Path)

**เส้นทาง A — ใบในเพดาน (2 ขั้น):** `#/ot/list` → สร้าง → W1 เลือกตัวเอง+โหมด → W2 กรอกบรรทัด (ระบบเติมอัตรา/ชั่วโมง) → W3 เหตุผล+งานที่ทำ → W4 ผลตรวจผ่าน → W5 เลือกคน **2 ช่อง** → ส่งอนุมัติ (ออกเลข + freeze สาย) → หัวหน้าอนุมัติ → HR อนุมัติ (สร้าง PDF + เก็บสำเนา) → `#/ot/confirm` ยืนยันเวลาจริง → `#/ot/period` ยอดเข้าสรุปงวด

**เส้นทาง B — ใบเกินเพดาน (3 ขั้น):** เหมือน A จนถึง W4 → **W4 แจ้งว่าเกินเพดาน + แสดงสายที่จะได้** → W5 เลือกคน **3 ช่อง** → ส่งอนุมัติ (action id คนละตัว) → หัวหน้า → HR → **ผู้บริหารต้นสังกัด** → PDF มีช่องลงนามช่องที่ 4 → ยืนยันเวลาจริง → สรุปงวด

## §1.7 Accessibility & i18n

- ภาษาไทยทั้งระบบ · ตัวเลขชั่วโมงใช้ทศนิยม 2 ตำแหน่งเสมอ (`#,##0.00`)
- `<input type="time">` เก็บค่าแบบ 24 ชั่วโมง แม้เบราว์เซอร์จะแสดง 12 ชั่วโมงตาม locale (INFO-02)
- ทุกปุ่มที่ทำ mutation มีสถานะ disabled ระหว่างรอผล (กันกดซ้ำ · VR-21)
- ป้ายสถานะไม่พึ่งสีอย่างเดียว — มีข้อความกำกับเสมอ
- ตารางกว้างเลื่อนแนวนอนใน `.table-wrap` — **หน้าไม่เลื่อนแนวนอนทั้งหน้า**
