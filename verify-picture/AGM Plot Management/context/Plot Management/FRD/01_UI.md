## §1.7 OV-05 CSV Import (wizard modal)
**5 ขั้นทางการ (G4):** `Template → Upload → Mapping → Validate → Commit`
- **Template** — ดาวน์โหลดแม่แบบ `plot_template.csv` (UTF-8 BOM) · header **13 คอลัมน์** (G1/G3):
  `quota_no, ownership_type, deed_number, deed_issue_date, deed_owner_name, address, province, district, subdistrict, latitude, longitude, area, shapefile_url`
  → **`shapefile_url` บังคับ** (แถวที่ไม่มี = แถวเสีย · LOCK-05) · **postal_code ไม่มีในคอลัมน์** (ระบบเติมอัตโนมัติจากตำบล · VR-10) · `ownership_type/deed_issue_date/deed_owner_name` = superset ที่จัดทำเพิ่ม (คงไว้)
- **Upload** — เลือกไฟล์ .csv (≤5MB) · guard นามสกุล/ขนาด
- **Mapping** — auto-match header ↔ 13 คอลัมน์แม่แบบ · header ไม่ตรง → reject ทั้งไฟล์ + column error
- **Validate** — ตรวจรายแถว (quota มีในระบบ · lat/long/area/postal · deed ไม่ซ้ำ · **shapefile_url มี**) → chip ผ่าน/ไม่ผ่าน + ตารางข้อผิดพลาด
- **Commit** — ยืนยันนำเข้า → summary total/created/failed + error report · ทุกแถว → Waiting for verify
> **หมายเหตุ prototype:** รวม Mapping+Validate เป็น preview เดียว (intentional demo compression) — behavior เท่ากับ 5 ขั้นทางการ
