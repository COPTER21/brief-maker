## §4.2 T_plot
| Column | Type | Null | Classification | Note |
|---|---|---|---|---|
| `id` | uuid | NO | Internal | PK |
| `tenant_id` | uuid | NO | Internal | RLS |
| `plot_code` | varchar(20) | NO | Internal | auto `PLT-YYYY-NNNN` · unique |
| `quota_id` | uuid | NO | Internal | **FK T_quota (cross-module read)** |
| `quota_no` | varchar(50) | NO | Internal | denormalized snapshot |
| `farmer_name` | varchar(200) | NO | Confidential | snapshot (read-only จาก quota) |
| `ownership_type` | varchar(50) | NO | Internal | |
| `deed_number` | varchar(50) | NO | Internal | **unique ต่อ tenant** (LOCK-12) |
| `deed_issue_date` | date | NO | Internal | |
| `deed_owner_name` | varchar(200) | NO | Confidential | |
| `address_line` | varchar(255) | NO | Confidential | **single line** (LOCK-04) |
| `province_id`/`district_id`/`subdistrict_id` | varchar(10) | NO | Internal | FK M-01 |
| `postal_code` | char(5) | NO | Internal | 5 digits · auto |
| `latitude` | decimal(9,6) | NO | Internal | [-90,90] · 6 dp |
| `longitude` | decimal(9,6) | NO | Internal | [-180,180] · 6 dp |
| `area_rai` | decimal(12,2) | NO | Internal | > 0 |
| `gmaps_link` | varchar(255) | YES | Internal | optional (derive lat/long) |
| `shapefile_ref` | varchar(255) | NO | Confidential | **mandatory** (LOCK-05) |
| `verify_status` | varchar(20) | NO | Internal | 'Waiting for verify'(default)/'Verified'/'Verification failed' |
| `fail_reason` | text | YES | Internal | บังคับเมื่อ Verification failed |
| `verified_by`/`verified_at` | — | YES | Internal | |
| `is_deleted`/`deleted_at`/`deleted_by`/`delete_type`/`delete_reason` | — | NO/YES | Internal | soft(default false)/hard · LOCK-09 |
| `version` | int | NO | Internal | optimistic (LOCK-11) default 1 |
| `created_by/at`,`updated_by/at` | — | NO | Internal | audit |

**Constraints:** PK(id) · UNIQUE(tenant_id, plot_code) · **UNIQUE(tenant_id, deed_number) WHERE is_deleted=false** · CHECK verify_status IN(3) · CHECK latitude BETWEEN -90 AND 90 · CHECK longitude BETWEEN -180 AND 180 · CHECK area_rai > 0 · CHECK postal_code ~ '^[0-9]{5}$'
**Indexes:** IDX_plot_tenant_status · IDX_plot_quota(quota_id) · IDX_plot_deed(unique) · IDX_plot_province · IDX_plot_search(trigram plot_code/deed/farmer) · IDX_plot_waiting_age
**RLS:** tenant_id = current_setting('app.current_tenant')

## §4.3 T_plot_history
id, tenant_id, plot_id_fk, event(create/edit/verify_pass/verify_fail/delete/import/verify_bulk), actor_id, event_at, note(fail_reason/delete_reason), diff_before/after(jsonb), bulk_count(int) · **REVOKE UPDATE/DELETE** (append-only)

## §4.4 T_plot_document
id, tenant_id, plot_id_fk, doc_type(shapefile/land_deed), file_ref, file_name, mime, size · shapefile ≤50MB (zip/shp) · doc ≤5MB (pdf/jpg/png)

## §4.5 Relationships
```
T_quota (F-AGM-002) ──(1:N)──▶ T_plot   [quota_id FK · READ-ONLY · ไม่มี write-back]
m_address_hierarchy (M-01) ◀── T_plot (province/district/subdistrict)
T_plot ──(1:N)──▶ T_plot_history · T_plot ──(1:1..2)──▶ T_plot_document
```

## §4.6 Data Classification
Confidential: farmer_name, deed_owner_name, address_line, shapefile/documents · Internal: ที่เหลือ · PII overlay: farmer_name, deed_owner_name, address (PDPA)

## §4.9 Note 1:N + cross-module
- 1 quota : N plots (ไม่มี unique constraint บน quota_id — ต่างจาก Quota 1:0..1) · LOCK-06
- quota_id FK read-only; farmer_name/quota_no เก็บ snapshot กัน quota เปลี่ยน/ลบ
