### 3.1 รายการซ้ำ
- **รายการตรวจสอบทั่วไป** — บนกระดาษ 15 แถว (min_rows) · ช่องในแถว: ลำดับ, รายการตรวจสอบ, 1 … 31 (ผลตรวจรายวัน ✓ / ✗)
- **รายการตรวจสอบเฉพาะรถฟอร์คลิฟท์น้ำมัน** — บนกระดาษ 8 แถว (min_rows) · ช่องในแถว: ลำดับ, รายการตรวจสอบ, 1 … 31 (ผลตรวจรายวัน ✓ / ✗)
- **รายการตรวจสอบเฉพาะรถฟอร์คลิฟท์ไฟฟ้า** — บนกระดาษ 6 แถว (min_rows) · ช่องในแถว: ลำดับ, รายการตรวจสอบ, 1 … 31 (ผลตรวจรายวัน ✓ / ✗)

### 3.2 ตัวเลือก
- **ประเภทรถ** (เลือกได้ข้อเดียว): ฟอร์คลิฟท์น้ำมัน → ใช้ช่อง ลำดับ, รายการตรวจสอบ, 1 … 31 (ผลตรวจรายวัน ✓ / ✗) · ฟอร์คลิฟท์ไฟฟ้า → ใช้ช่อง ลำดับ, รายการตรวจสอบ, 1 … 31 (ผลตรวจรายวัน ✓ / ✗)
- **เกณฑ์การประเมิน (ค่าในช่องรายวัน)** (เลือกได้ข้อเดียว): ✓ = ปกติ / พร้อมใช้งาน · ✗ = ผิดปกติ / ต้องแก้ไข

### 3.3 สูตร + ค่าคงที่บนกระดาษ
- ค่าคงที่ "รายการตรวจสอบทั่วไป 15 รายการ (สภาพตัวรถโดยรวม … ตรวจสอบการรั่วซึม)" = รายการตรวจส่วนกลางทุกประเภทรถ → ควรอ่านจาก `ForkliftChecklistConfig.items[section=general]` (ห้าม hardcode)
