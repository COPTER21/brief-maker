## §1.2 หน้ารายการ (`#/memo`)
- หัวหน้า: ชื่อไทย + (Internal Memo) + chip นับรายการ · ปุ่ม "ส่งออก CSV" และ "สร้างบันทึก" อยู่ใน `.ph-actions`
- การ์ดสถิติ 3 ใบ (กดกรองได้): บันทึกทั้งหมด · รออนุมัติ · รอฉันพิจารณา
- ตัวกรอง: ค้นหา (เลขที่/ผู้จัดทำ/เรียน/เรื่อง) · สถานะ · หน่วยงาน · ปุ่มล้างตัวกรอง
- ตาราง: เลขที่ · วันที่ · จาก · เรียน · เรื่อง · สถานะเอกสาร · ลายเซ็น (n/N) · ⋮
- เมนู ⋮: แก้ไข (ร่างของตัวเอง) · แก้แล้วส่งใหม่ (ใบที่ถูกตีกลับ) · พิมพ์ · ยกเลิกเอกสาร
- กดแถว = เปิดหน้าดูเอกสาร · empty state แยก "ไม่พบรายการที่ค้นหา" กับ "ยังไม่มีบันทึกภายใน"
- แบบเอกสารปิดใช้งาน (F-DOCCFG) → ปุ่มสร้าง disabled + แถบแดง

## §1.3 Wizard สร้าง/แก้ไข (3 ขั้นล็อก)
`['ข้อมูลหลักบันทึก', 'เอกสารแนบ', 'ตรวจสอบและยืนยัน']`

**ขั้น 1 — ข้อมูลหลักบันทึก** (`.wz-split` = ฟอร์มซ้าย + การ์ดสรุปขวา)
| การ์ด | ช่อง | ชนิด | บังคับ |
|---|---|---|---|
| ① ส่งถึงใคร เรื่องอะไร | เรียน | input text | ✓ |
| | เรื่อง | input text | ✓ |
| ② เนื้อหาบันทึก | เนื้อความ | textarea 10 แถว | ✓ |

- การ์ดสรุปขวา (sticky): จาก · วันที่ · เลขที่ (ดึงจากระบบ ไม่ใช่ช่องกรอก) · เรียน · เรื่อง · ความยาวเนื้อหา — อัปเดตสดแบบ soft (focus ไม่หลุด)
- hint ใต้การ์ด ②: ช่อง "ข้อคิดเห็นฝ่ายกฎหมาย" บนแบบพิมพ์เป็นของผู้พิจารณา กรอกตอนอนุมัติ
- **ไม่มีช่องวันที่ให้ผู้ใช้กรอก** → ไม่ใช้ช่องวันที่ของเบราว์เซอร์ (Rule #114)

**ขั้น 2 — เอกสารแนบ:** upload zone + รายการไฟล์ + ปุ่มลบ (PDF/Word/Excel/รูป ≤ 20 MB)

**ขั้น 3 — ตรวจสอบและยืนยัน:** การ์ดสรุป ข้อมูลบันทึก · เรื่อง · เนื้อหาบันทึก · เอกสารแนบ

**footer:** ย้อนกลับ · ยกเลิก · ถัดไป / (ขั้นสุดท้าย) บันทึกแบบร่าง + บันทึกและส่งอนุมัติ
ปิด drawer ขณะกรอกค้าง → modal "ทิ้งข้อมูลที่กรอกไว้?"

## §1.4 หน้าดูเอกสาร (4 แท็บล็อก)
`รายละเอียด › PDF Preview › ลายเซ็น / อนุมัติ › ประวัติ`

- **รายละเอียด:** แบนเนอร์ตามสถานะ · ข้อมูลเอกสาร · จาก (ผู้จัดทำ) · เรื่อง · เนื้อหาบันทึก · ข้อคิดเห็นฝ่ายกฎหมาย · เอกสารแนบ · ข้อมูลระบบ
- **PDF Preview:** `.pdf-slot > iframe.pdf-frame[srcdoc]` render จาก `form.tpl.html` + `docPrintData()` · ปุ่มดาวน์โหลด/พิมพ์
- **ลายเซ็น / อนุมัติ:** การ์ดสรุปสาย DOA + timeline ขั้น 1..N + ปุ่มตัดสิน inline ที่ขั้นปัจจุบัน
- **ประวัติ:** timeline append-only

ปุ่มหัวตามสถานะ: ร่าง (เจ้าของ) = ยกเลิก · แก้ไข · ส่งอนุมัติ | รอ (ผู้พิจารณาขั้นปัจจุบัน) = ไม่อนุมัติ · อนุมัติ | ไม่อนุมัติ (เจ้าของ) = แก้แล้วส่งใหม่ | รอ/อนุมัติแล้ว (เจ้าของ/admin) = ยกเลิกเอกสาร

## §1.5 Modal
| modal | เนื้อหา |
|---|---|
| ส่งอนุมัติ? | 1 `.slot-row` ต่อขั้น DOA · ค่าเริ่มจาก resolve · บังคับเลือกครบ · ตัดผู้จัดทำออกจากรายชื่อ |
| อนุมัติ? | ข้อมูลขั้นที่พิจารณา + textarea "ข้อคิดเห็นฝ่ายกฎหมาย" (ไม่บังคับ) |
| ไม่อนุมัติ? | ชิปเหตุผลสำเร็จรูป + textarea "ข้อคิดเห็นฝ่ายกฎหมาย (เหตุผล)" **บังคับ** |
| ยกเลิกเอกสาร? | ชิปเหตุผล + textarea เหตุผล **บังคับ** |
| ทิ้งข้อมูลที่กรอกไว้? | ยืนยันก่อนปิด wizard ที่แก้ค้าง |
