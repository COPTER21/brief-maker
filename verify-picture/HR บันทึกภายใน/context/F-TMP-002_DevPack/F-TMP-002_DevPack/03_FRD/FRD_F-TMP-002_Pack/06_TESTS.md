## §6.3 สิทธิ์ / การมองเห็น (DEC-09)
| TC | เรื่อง | ขั้นตอน | ผลที่ต้องได้ |
|---|---|---|---|
| PM-01 | **ผู้พิจารณาไม่เห็นร่างของคนอื่น** | ผู้จัดทำสร้างร่างไว้ (ยังไม่ส่ง) → สลับเป็นผู้พิจารณา → ดูรายการและเปิด url ของใบนั้นตรง ๆ | **ร่างของคนอื่นไม่เห็นในรายการ** · เปิด url ตรงได้ `NOT_FOUND` — ไม่เปิดเผยว่ามีใบนี้อยู่ |
| PM-02 | ผู้พิจารณาเห็นใบหลังส่งแล้ว | ผู้จัดทำกดส่ง → สลับเป็นผู้พิจารณา | ใบโผล่ในรายการและในสถิติ "รอฉันพิจารณา" |
| PM-03 | คนนอกสายไม่เห็นใบ | สลับเป็นพนักงานที่ไม่ใช่เจ้าของและไม่อยู่ในสาย | ไม่เห็นใบในรายการ · เปิด url ตรงได้ `NOT_FOUND` |
| PM-04 | admin role เห็นทั้งหมด | สลับเป็นผู้ดูแลทะเบียนเอกสาร | เห็นทุกใบ รวมร่างของคนอื่น |
| PM-05 | แก้ร่างของคนอื่นไม่ได้ | เรียก `PUT /api/memo/{id}` กับใบของคนอื่น | `403 NOT_OWNER` · toast "แก้ไขได้เฉพาะร่างของตัวเอง" |
| PM-06 | ไม่ใช่ผู้พิจารณาขั้นปัจจุบันกดอนุมัติ | สลับเป็นผู้พิจารณาขั้นถัดไปแล้วกดอนุมัติ | `403 NOT_CURRENT_APPROVER` · ปุ่มอนุมัติไม่ขึ้นบนหน้าจอด้วย |
| PM-07 | ผู้จัดทำพิจารณาใบตัวเอง | เลือกตัวเองใน slot ผู้พิจารณา | ไม่มีชื่อตัวเองให้เลือก · ถ้าแนบทาง API ได้ `403 SELF_APPROVAL_DENIED` |
