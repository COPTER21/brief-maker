# 04_DB — F-TMP-002 บันทึกภายใน

## ตาราง `memo`
| column | ชนิด | null | ที่มา | หมายเหตุ |
|---|---|---|---|---|
| `id` | uuid PK | ✗ | system | |
| `doc_no` | varchar(20) | ✗ | ENG-DOC-NUM | unique · **immutable** (DEC-10) |
| `doc_date` | date | ✗ | system | วันที่บนหัวบันทึก (ช่อง "วันที่") |
| `to` | varchar(200) | ✗ | user | ช่อง "เรียน" — ข้อความอิสระ ไม่ผูก user id (ตามกระดาษ) |
| `from` | varchar(200) | ✗ | snapshot จาก Employee | ช่อง "จาก" = ชื่อ · หน่วยงาน ณ วันที่บันทึก |
| `subject` | varchar(300) | ✗ | user | ช่อง "เรื่อง" |
| `body` | text | ✗ | user | พื้นที่เนื้อหาบันทึก · ย่อหน้าแยกด้วย `\n` |
| `legal_opinion` | text | ✓ | ผู้พิจารณา | ช่อง "ข้อคิดเห็นฝ่ายกฎหมาย" (มิเรอร์จาก `approval_chain[].note` ของขั้นที่ตัดสินล่าสุด) |
| `legal_opinion_date` | timestamptz | ✓ | system | วันที่ในบล็อกลงชื่อ — **คนละ column กับ `doc_date`** (DEC-13) |
| `status` | enum | ✗ | system | `draft` · `pending` · `approved` · `rejected` · `cancelled` |
| `owner_emp_id` | varchar | ✗ | system | ผู้จัดทำ (ใช้ตรวจสิทธิ์ DEC-09) |
| `owner_position` | varchar(120) | ✗ | snapshot | ตำแหน่ง ณ วันที่บันทึก |
| `owner_dept` | varchar(120) | ✗ | snapshot | หน่วยงาน ณ วันที่บันทึก |
| `header_snapshot` | jsonb | ✗ | Organization ตอนออกเลข | `{company_name, logo}` — `print_config.header_source = organization_snapshot_at_numbering` · ไม่ดึงสดหลังออกเลข |
| `doa_ref` | varchar(40) | ✓ | DOA entry | อ้างทะเบียน DOA ของ feature นี้ |
| `approval_chain` | jsonb | ✓ | DOA snapshot ตอนส่ง | `[{step, role_id, role_label, assignee, status, at, note}]` — append-only |
| `submitted_at` | timestamptz | ✓ | system | |
| `cancel_reason` | text | ✓ | user | บังคับเมื่อยกเลิก |
| `created_by` / `created_at` | varchar / timestamptz | ✗ | system | |
| `updated_by` / `updated_at` | varchar / timestamptz | ✗ | system | |

**Index:** `memo(doc_no) UNIQUE` · `memo(status, doc_date DESC)` · `memo(owner_emp_id)` · GIN บน `approval_chain` สำหรับค้นผู้พิจารณา
