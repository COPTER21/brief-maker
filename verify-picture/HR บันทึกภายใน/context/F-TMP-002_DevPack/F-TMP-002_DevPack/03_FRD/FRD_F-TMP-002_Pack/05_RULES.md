# 05_RULES — F-TMP-002 บันทึกภายใน

## §5.1 Business Rules
| ID | กฎ | Tag | ที่มา |
|---|---|---|---|
| BR-MEM-01 | `to` `subject` `body` ต้องไม่ว่าง จึงบันทึกได้ | FIXED | FORM_SPEC required |
| BR-MEM-02 | เลขที่ออกจาก ENG-DOC-NUM ตอนบันทึกครั้งแรก · ออกแล้วห้ามเปลี่ยน | FIXED | DEC-10 |
| BR-MEM-03 | แก้ไขได้เฉพาะร่างของตัวเอง | FIXED | DEC-09 |
| BR-MEM-04 | ไม่อนุมัติ → กลับเป็น `draft` **ด้วยเลขที่เดิม** | CONFIGURABLE | DEC-08 |
| BR-MEM-05 | ยกเลิกได้เฉพาะ `draft`/`pending` โดยเจ้าของหรือ admin role · ต้องมีเหตุผล | CONFIGURABLE | DEC-08 |
| BR-MEM-06 | ผู้พิจารณาเห็นใบได้หลังกดส่งเท่านั้น · admin role เห็นทั้งหมด | CONFIGURABLE | DEC-09 |
| BR-MEM-07 | จำนวนขั้นและ role อ่านจาก DOA กลาง ณ เวลาส่ง แล้ว freeze ลง `approval_chain` — **ห้าม hardcode สายอนุมัติใน feature** | DYNAMIC | DEC-03 · BR-DOA-02 |
| BR-MEM-08 | ผู้จัดทำพิจารณาใบตัวเองไม่ได้ | FIXED | BR-DOA-04 |
| BR-MEM-09 | ไฟล์แนบ PDF/Word/Excel/รูป ≤ 20 MB ต่อไฟล์ | CONFIGURABLE | DEC-11 |
| BR-MEM-10 | อนุมัติครบทุกขั้นแล้ว **ไม่เปลี่ยนค่าในระบบ และไม่ส่งข้อมูลต่อระบบอื่น** | FIXED | DEC-01 · DEC-02 |
| BR-MEM-11 | ไม่มีฟังก์ชันทำซ้ำ และไม่ประกาศเมื่ออนุมัติ | FIXED | DEC-11 |

> **BR-DOA-03 ใช้ค่าตั้งต้น (reject → กลับ draft)** ตาม DEC-08 — ไม่มีข้อยกเว้นให้จบใบในรอบนี้

## §5.2 Validation Rules จากกฎตรวจของมติ (VALID)
| ID | กฎ | มติ |
|---|---|---|
| VR-01 | เส้นประเปล่ามุมขวาล่างของกรอบ "ข้อคิดเห็นฝ่ายกฎหมาย" เป็นเส้นบนแบบพิมพ์เท่านั้น — ไม่สร้างช่องกรอกและไม่เก็บลงฐานข้อมูล | **DEC-12** |
| VR-02 | `doc_date` (ช่อง "วันที่" หัวบันทึก) กับ `legal_opinion_date` (ช่อง "วันที่" ในบล็อกลงชื่อ) ต้องเป็นคนละค่า ห้าม bind ค่าเดียวกัน แม้ป้ายบนกระดาษเขียนเหมือนกัน | **DEC-13** |
| VR-03 | ห้ามเพิ่มช่องลงชื่อผู้จัดทำบนแบบพิมพ์ — ผู้จัดทำแสดงผ่านช่อง "จาก" + ผู้สร้าง record เท่านั้น | **DEC-14** |
| VR-04 | ข้อมูลตัวอย่างใน prototype · แบบพิมพ์ · test case ต้องเป็นข้อมูลสมมติ ห้ามนำข้อมูลจากไฟล์ลูกค้ามาใช้ | **DEC-15** |

## §5.3 Edge Cases
| EC | เหตุการณ์ | ผลที่ต้องการ | code |
|---|---|---|---|
| EC-01 | กด "ถัดไป" โดยกรอกไม่ครบ | ขอบแดงช่องที่ขาด + toast "กรุณากรอกข้อมูลให้ครบถ้วน" | `VALIDATION_FAILED` |
| EC-02 | ปิด drawer ขณะกรอกค้าง | modal "ทิ้งข้อมูลที่กรอกไว้?" | — |
| EC-03 | ตัดสินซ้ำหลังมีคนตัดสินไปแล้ว | toast "ข้อมูลถูกแก้โดยผู้อื่น กรุณารีเฟรชแล้วลองใหม่" | `STALE_STATE` |
| EC-04 | ผู้ที่ไม่ใช่ผู้พิจารณาขั้นปัจจุบันกดอนุมัติ | toast "คุณไม่มีสิทธิ์ทำรายการนี้" | `NOT_CURRENT_APPROVER` |
| EC-05 | ผู้พิจารณาเปิดร่างของคนอื่น | ตอบเหมือนไม่มีใบนี้ | `NOT_FOUND` |
| EC-06 | ผู้จัดทำเลือกตัวเองเป็นผู้พิจารณา | ไม่มีชื่อตัวเองให้เลือก · ถ้าแนบมาทาง API ปฏิเสธ | `SELF_APPROVAL_DENIED` |
| EC-07 | แบบเอกสารถูกปิดใช้งานที่ F-DOCCFG | ปุ่มสร้าง disabled + แถบแดง · เรียก API ตรงถูกปฏิเสธ | `DOCTYPE_INACTIVE` |
| EC-08 | DOA เปลี่ยนจาก 1 ขั้นเป็น N ขั้น | ใบใหม่ได้ N ขั้น · ใบที่ส่งแล้วคงสายเดิม · แบบพิมพ์ขึ้นช่องลงชื่อ N ช่องเอง (แถวละ ≤4) | — |
| EC-09 | ยกเลิกใบที่ `pending` | ยิง `mem_cancelled` ให้ผู้พิจารณาขั้นปัจจุบัน | — |
| EC-10 | เนื้อหายาวจนล้นหน้า | `layout.dense` + บล็อกลงชื่อไม่ถูกตัดข้ามหน้า | — |
| EC-11 | แนบไฟล์ผิดชนิด/ใหญ่เกิน | ปฏิเสธเฉพาะไฟล์นั้น + toast บอกเหตุผล | — |
