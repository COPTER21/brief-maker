## §7 Interaction Spec
- Esc chain: ปฏิทิน → modal → drawer (handler ใน BASE-KIT + be-datepicker capture)
- Wizard ถัดไป: `wizNext()` → `validateMain()` ไม่ผ่าน = อยู่ขั้น 1 + `.is-invalid` + toast "กรุณากรอกข้อมูลให้ครบถ้วน" · ถึง < จาก = error ที่ช่อง "ถึง" · ถึง > วันที่ขอ = ข้อความเตือนใต้ช่อง (ไม่บล็อก)
- พิมพ์ในช่อง = soft update `setF2()` (ไม่ rebuild) · การ์ดสรุปอัปเดต `#sumTypes` `#sumPeriod`
- เลือกวันที่: `pickFrom()` / `pickTo()` · ติ๊ก ☐: `toggleCh()` (อื่นๆ = render เปิด/ปิดช่องระบุ)
- ส่งอนุมัติ: `openSubmit()` → `.slot-row` ต่อขั้น `resolveDoa()` (ค่าเริ่ม 2 ขั้น) → `confirmSubmit()` · อนุมัติ `confirmApprove()` (sequential) · ไม่อนุมัติ/ยกเลิก `confirmReason()` (ไม่อนุมัติ = กลับร่าง) · บันทึกการทำลาย `openDone()` → `confirmDone()`
- ทุก commit ผ่าน `commitRejected()` (prototype จำลอง 409/403/500)
