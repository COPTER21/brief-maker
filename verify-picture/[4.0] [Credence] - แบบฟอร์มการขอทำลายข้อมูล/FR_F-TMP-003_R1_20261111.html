  • ความถูกต้องของ PDF ที่ดาวน์โหลด, CSV และ audit log — ตรวจเฉพาะหน้าจอ/แท็บตามผลที่แจ้ง ยังไม่ได้ระบุผลด้านข้อมูล

1Logic — ทำงานถูกตามกฎธุรกิจ

เทียบผลจริงกับ FRD / Test Case — ข้อที่ไม่ผ่านต้องผูกกับ Bug ในข้อ 4

#กฎ / Scenarioผลที่คาดหวังผลจริงผลอ้างอิง
L-01สร้างคำขอและบันทึกแบบร่างสร้างคำขอและบันทึกร่างได้ทำงานได้ครบตามที่ผู้ตรวจระบุผ่านAT-01
L-02แก้ไขข้อมูลคำขอแก้ไขและบันทึกข้อมูลคำขอได้ทำงานได้ครบตามที่ผู้ตรวจระบุผ่านAPI-04
L-03ลบ/ยกเลิกคำขอทำรายการลบ/ยกเลิกตามการทำงานที่ระบบเปิดให้ได้ทำงานได้ครบตามที่ผู้ตรวจระบุผ่านFN-06
L-04แนบเอกสารใน Create/Edit Drawer ขั้นตอนที่ 2แนบเอกสารได้จากขั้นตอนเอกสารแนบใน Drawerแนบไม่ได้ ต้องบันทึกร่างก่อน แล้วไปแนบที่หน้ารายละเอียดไม่ผ่านBUG-01
L-05Create Drawer — บันทึกและส่งอนุมัติเมื่อเลือกผู้พิจารณาและยืนยันสำเร็จ modal ปิดและแสดงผลรายการสำเร็จทำรายการสำเร็จ แต่ modal เลือกผู้พิจารณายังค้างเปิดอยู่มีข้อสังเกตBUG-02
L-06Edit Drawer — บันทึกและส่งอนุมัติบันทึกข้อมูลแล้วส่งเข้าสายอนุมัติระบบบันทึกเป็นร่างเท่านั้น ไม่ได้ส่งอนุมัติไม่ผ่านBUG-03
L-07Validation ช่องบังคับและช่วงวันที่ตรวจ VR-01..09 และบล็อกช่วงวันที่ผิด—ไม่ได้ตรวจAT-02..09
L-08ช่วงวันที่สิ้นสุดหลังวันที่ขอเตือนแต่ยังส่งได้—ไม่ได้ตรวจAT-06
L-09สายอนุมัติ dynamic และจำนวนขั้นตาม DOAผู้พิจารณาและจำนวนขั้นตรง DOA—ไม่ได้ตรวจAT-11..12
L-10อนุมัติตามลำดับทุกขั้นผ่านทีละขั้นจนครบแล้วเป็นรอทำลายข้อมูล—ไม่ได้ตรวจAT-13..14
L-11ไม่อนุมัติและกลับเป็นร่างเลขเดิมเหตุผลบังคับ กลับร่างเลขเดิม และส่งใหม่ได้—ไม่ได้ตรวจAT-15..16
L-12เจ้าหน้าที่ IT บันทึกการทำลายแล้วทำได้เฉพาะใบอนุมัติแล้ว พร้อมชื่อและเวลา—ไม่ได้ตรวจAT-17
L-13ยกเลิกใบรออนุมัติและส่ง Notificationเหตุผลบังคับและแจ้งผู้พิจารณาปัจจุบัน—ไม่ได้ตรวจAT-18
L-14สิทธิ์การมองเห็นและการทำรายการของแต่ละบทบาทผู้ไม่มีสิทธิ์ดูหรือทำรายการไม่ได้—ไม่ได้ตรวจDN-01..08
L-15PDF ทุกสถานะและการส่งออก CSVPDF 1 หน้า ข้อมูลครบ และ CSV UTF-8 BOM—ไม่ได้ตรวจAT-19
L-16กรณี API ล้มเหลว, stale และ modal/drawer ซ้อนกันไม่เปลี่ยนสถานะผิดและมีทางให้ผู้ใช้ดำเนินการต่อ—ไม่ได้ตรวจER-01..03

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-03Edit Drawer กดบันทึกและส่งอนุมัติ แต่ระบบบันทึกเป็นร่างเท่านั้นHighรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด Edit Drawer ของคำขอสถานะร่าง
  2. แก้ไขข้อมูล
  3. กดบันทึกและส่งอนุมัติ
ผลที่ควรเป็นบันทึกข้อมูลและส่งคำขอเข้าสายอนุมัติ
ผลที่เกิดจริงระบบบันทึกร่าง แต่ไม่ได้ส่งอนุมัติ
BUG-01Create/Edit Drawer ขั้นตอนที่ 2 ไม่สามารถแนบเอกสารได้Mediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด Create Drawer หรือ Edit Drawer
  2. ไปขั้นตอนที่ 2 เอกสารแนบ
  3. ลองแนบเอกสาร
ผลที่ควรเป็นแนบเอกสารได้จากขั้นตอนที่ 2 ตาม flow ของ Drawer
ผลที่เกิดจริงแนบไม่ได้ ระบบบังคับให้บันทึกร่าง แล้วไปแนบจากหน้ารายละเอียด
BUG-02Create Drawer ส่งอนุมัติสำเร็จแล้ว modal เลือกผู้พิจารณาไม่ปิดMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด Create Drawer และกรอกข้อมูล
  2. กดบันทึกและส่งอนุมัติ
  3. เลือกผู้พิจารณาแล้วกดยืนยัน
ผลที่ควรเป็นทำรายการสำเร็จแล้ว modal ปิดและแสดงสถานะล่าสุด
ผลที่เกิดจริงทำรายการสำเร็จ แต่ modal ยังค้างเปิดอยู่
BUG-04UI ของ View Drawer ทั้ง 4 แท็บไม่สอดคล้องกับ designLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด View Drawer
  2. สลับดูแท็บรายละเอียด, PDF Preview, ลายเซ็น/อนุมัติ และประวัติ
  3. เปรียบเทียบกับ design ที่ใช้อ้างอิง
ผลที่ควรเป็นองค์ประกอบของทั้ง 4 แท็บสอดคล้องกับ design system
ผลที่เกิดจริงผู้ตรวจพบว่า UI/UX ของทั้ง 4 แท็บหลุดจาก design

5ข้อเสนอแนะ (ไม่ใช่ Bug)

ทำงานถูกตาม spec แล้ว แต่ควรปรับให้ดีขึ้น — ส่งต่อเป็น Enhancement ถ้าทีมเห็นด้วย

#ข้อเสนอเหตุผล
S-01เพิ่ม tooltip/popover ที่ +จำนวน ในคอลัมน์ประเภทข้อมูล เพื่อแสดงชื่อประเภทที่เหลือทั้งหมดเมื่อ hover และ keyboard focusFRD กำหนดให้ตารางแสดงประเภทแรก +n อยู่แล้ว จึงไม่ใช่ Bug; แต่ปัจจุบัน hover แล้วไม่มีรายละเอียด ทำให้ต้องเปิดเอกสารเพื่อดูรายการทั้งหมด

6การรับรองผลตรวจ
