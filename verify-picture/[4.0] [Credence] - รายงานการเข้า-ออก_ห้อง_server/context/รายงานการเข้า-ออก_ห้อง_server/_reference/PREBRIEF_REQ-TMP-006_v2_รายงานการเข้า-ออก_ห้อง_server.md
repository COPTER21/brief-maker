### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- กระดาษไม่มีช่องลงชื่อผู้อนุมัติท้ายใบ — มีเฉพาะลายเซ็นผู้เข้า/ผู้รับรองต่อแถว → **G2 ลูกค้ายืนยันว่าการเข้าห้องต้องขออนุมัติล่วงหน้าหรือไม่ (รอบนี้ = รับรองต่อแถว ไม่มี DOA)**
- กระดาษไม่บังคับลำดับเวลา → **วันเวลาออก ต้องไม่ก่อนวันเวลาเข้า → บล็อก (ขัดแย้งทางตรรกะ) · อยู่ในห้องเกิน 12 ชม. → เตือน**
- กระดาษไม่ระบุว่าผู้รับรองคือใคร → **ผู้รับรองต้องเป็นเจ้าหน้าที่ IT ผู้ดูแลห้อง และไม่ใช่ผู้เข้าคนเดียวกัน (SoD)**
- 'เหตุผลการเข้าใช้ ' มีช่องว่างท้าย → **ตัดช่องว่าง (G5 แก้คำสะกดชัดเจน)**
