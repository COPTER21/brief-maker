## §1.3 Journey
สร้าง → แถวการเข้าห้อง → บันทึกร่าง (ได้เลข · ลงชื่อผู้เข้า) → ผู้เข้าออก → แก้ร่างบันทึกเวลาออก → เจ้าหน้าที่ IT อีกคนรับรอง (M-01) → ครบรอบ → ส่งปิดรอบ (M-02) → ปิดรอบแล้ว
### Branch
