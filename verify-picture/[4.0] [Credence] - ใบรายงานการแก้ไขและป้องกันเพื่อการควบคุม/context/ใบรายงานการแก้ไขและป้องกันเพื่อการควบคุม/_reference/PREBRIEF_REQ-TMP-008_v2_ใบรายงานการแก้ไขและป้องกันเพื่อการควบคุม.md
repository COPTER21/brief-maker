### 3.3 สูตร + ค่าคงที่บนกระดาษ
- สูตร: % = `จำนวน ÷ จำนวนทั้งหมด × 100 (ทศนิยม 2)` 
- สูตร: 6.3 ตรวจสอบประสิทธิผล (C) · % = `6.3 จำนวน ÷ จำนวนทั้งหมด × 100` 
- สูตร: รวม · จำนวน = `Σ จำนวน` 
- สูตร: รวม · % = `Σ จำนวน ÷ จำนวนทั้งหมด × 100` 
- สูตร: รวม · 6.3 จำนวน = `Σ 6.3 จำนวน` 
- สูตร: รวม · 6.3 % = `Σ 6.3 จำนวน ÷ จำนวนทั้งหมด × 100` 
- ค่าคงที่ "(วิเคราะห์สาเหตุและเริ่มดำเนินการภายใน 30 นาที)" = เวลาสูงสุดจากพบปัญหาถึงเริ่มวิเคราะห์ (นาที) → ควรอ่านจาก `CarConfig.analysis_start_minutes (ค่าเริ่ม 30)` (ห้าม hardcode)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี

- ผลรวม % อาจไม่เท่า 100 และจำนวนรวมอาจเกินจำนวนทั้งหมด → **Σ จำนวน > จำนวนทั้งหมด → เตือน ไม่บล็อก · % คำนวณอัตโนมัติ**
- กระดาษให้กรอกทั้งสองช่องได้ → **ติ๊กเกิดใหม่แล้วกรอกเกิดซ้ำครั้งที่ไม่ได้ · ไม่ติ๊กต้องกรอกเกิดซ้ำครั้งที่ ≥ 1 → บล็อก**

## 8. กติกา / declaration
- DOA: ถาม (มีช่องลงชื่อผู้อนุมัติ 4 จุด) — gate G2
- DOCCFG: ประกาศ doc_type + print_config (form_code/revision/min_rows/sign_boxes) — ร่างก่อน HTML
- MDOC: ลงทะเบียนแบบเอกสาร (F-DOCCFG / F003) · source=request
- NTF: event ของ feature เอง (เช่น ยกเลิกระหว่างรอ) — DOA ส่งแจ้งรออนุมัติ/ผลเอง
