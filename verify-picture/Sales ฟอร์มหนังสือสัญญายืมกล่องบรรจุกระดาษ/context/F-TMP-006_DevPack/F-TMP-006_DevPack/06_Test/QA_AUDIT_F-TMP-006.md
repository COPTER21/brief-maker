## หมายเหตุการแปลงเป็นภาษาคน
- ตัดป้ายคำสั่งของ AI (OPEN / CLICK / TYPE / SELECT / VERIFY / PRESS) ออก แล้วเขียนเป็นประโยคภาษาคน
- ไม่มีการตัดจุดตรวจ (expected) ใด ๆ ออกจากเคสที่เก็บไว้
- ชุดข้อมูลตัวอย่าง (`data`) ยังว่างไว้ — รอเติมค่าที่ลูกค้าใช้จริงตอนเตรียม UAT · **ห้ามใช้ชื่อหรือที่อยู่ลูกค้าจริงจากไฟล์ต้นฉบับ**

## สิ่งที่ยังทำไม่ได้ในรอบนี้
- **[NO-BROWSER]** ยังไม่ได้รันเคสใด ๆ จริงบนหน้าจอ — ต้องรันรอบเต็มบนเครื่องที่มี browser ก่อน UAT
- เคสที่ต้องตั้งค่าที่ DOA กลาง (สายหลายขั้น) หรือที่ F-DOCCFG (ปิดการใช้งานแบบเอกสาร) ยังไม่อยู่ในชุดนี้ — ต้องเตรียมค่าทดสอบก่อน
- เคสที่ตรวจว่าลงนามแล้วไม่กระทบระบบอื่น (DEC-01 · DEC-02) ตรวจที่ชั้น API ไม่ใช่หน้าจอ
