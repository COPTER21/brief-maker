## 2. `box_loan_agreement_line` (รายละเอียดกล่องที่สนับสนุน)
| คอลัมน์ | ชนิด | null | หมายเหตุ |
|---|---|---|---|
| `id` | uuid | ✗ | PK |
| `agreement_id` | uuid | ✗ | FK → `box_loan_agreement` · ON DELETE CASCADE |
| `seq` | int | ✗ | ลำดับแสดงผล |
| `detail` | varchar(500) | ✗ | ข้อความอิสระ (ชนิด ขนาด จำนวนกล่อง) ตรงกับหัวข้อย่อยบนกระดาษ |

> ไม่จำกัดจำนวนแถว (DEC-05) · แบบพิมพ์แสดงอย่างน้อย 1 แถวตามกระดาษ
> **ไม่มีคอลัมน์จำนวน/ขนาดแยกช่อง** เพราะกระดาษเป็นบรรทัดข้อความเปิด — ไม่เพิ่มช่องเกินกระดาษ (DEC-06)

## 6. ความครบของช่องตามกระดาษ (FORM_SPEC → DB)
| ช่องบนกระดาษ | เก็บที่ |
|---|---|
| ต้นฉบับ / สำเนา | ไม่เก็บในตาราง — เป็นชุดที่สั่งพิมพ์จาก `print_config.copies` |
| เลขที่ `0001-2026` | `print_no` |
| วันที่ | `doc_date` |
| ชื่อลูกค้าผู้ยืม | `customer_name` (snapshot) |
| รหัสลูกค้า | `customer_code` |
| ที่อยู่ที่ตั้งกล่อง | `customer_address` |
| รายละเอียดกล่อง (แถวซ้ำ) | `box_loan_agreement_line.detail` |
| ช่องเติมในเงื่อนไขข้อ 1 | `damage_exception` |
| ลงนามผู้รับมอบ | `receiver_name` · `receiver_position` |
| ลงนามผู้ส่งมอบ | `box_loan_agreement_chain.approved_by` (1 ช่องต่อขั้น) |
| Doc No. / Rev. | `form_code` · `form_revision` |
| ร้อยละเปลี่ยนกล่องฟรีในเนื้อสัญญา | `free_replace_pct` + `free_replace_pct_text` (snapshot จาก config) |
| ชื่อบริษัทผู้ให้ยืมในเนื้อสัญญา | `header_snapshot.legal_name` |

ครบ 10 ช่องตาม FORM_SPEC + ค่าคงที่ 2 ตัวที่ต้องอ่านจาก config — ไม่มีช่องเพิ่มเกินกระดาษ (DEC-06)
