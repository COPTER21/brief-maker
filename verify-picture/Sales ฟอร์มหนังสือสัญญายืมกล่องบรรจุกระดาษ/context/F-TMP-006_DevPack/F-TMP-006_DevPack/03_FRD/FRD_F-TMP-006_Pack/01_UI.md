# 01_UI — F-TMP-006 หนังสือสัญญายืม (LOA)

> ต้นแบบ: `feature.html` · archetype Q-form · เส้นทาง `#/loan-agreement`
> ช่องทุกช่องตรงกระดาษ FM-SAL-14 แบบ 1:1 (DEC-06) — ไม่เพิ่ม ไม่รวม ไม่แยก

## 1. หน้าทะเบียน (`#/loan-agreement`)

### 1.1 หัวหน้า
- ชื่อหน้า: **หนังสือสัญญายืม** (Box Loan Agreement) · ตัวนับ "N รายการ · เปิดอยู่ M"
- คำอธิบาย: หนังสือสัญญาให้ลูกค้ายืมกล่องบรรจุกระดาษไปใช้ในกิจการโดยไม่คิดมูลค่า · ผู้ส่งมอบลงนามก่อนส่งให้ลูกค้า
- ปุ่ม: **ส่งออก CSV** (รอง) · **สร้างหนังสือสัญญา** (หลัก — ปิดเมื่อแบบเอกสารยังไม่เปิดใช้ที่ F-DOCCFG)

### 1.2 การ์ดสรุป 3 ใบ (กดเพื่อกรอง)
| การ์ด | ค่า | คำกำกับ |
|---|---|---|
| หนังสือสัญญาทั้งหมด | จำนวนใบที่ผู้ใช้เห็น | ที่คุณเกี่ยวข้อง |
| รอลงนาม | สถานะ `pending` | รอผู้ส่งมอบพิจารณา |
| รอฉันพิจารณา | ใบที่ถึงคิวผู้ใช้ | คลิกเพื่อดูรายการ |

### 1.3 แถบกรอง
ค้นหา (เลขที่ · ลูกค้า · รายละเอียดกล่อง) · ทุกสถานะ · ทุกลูกค้า · ทุกฝ่าย · ปุ่มล้างตัวกรอง

### 1.4 ตาราง
| คอลัมน์ | ที่มา | เรียงได้ |
|---|---|---|
| เลขที่ | `box_loan_agreement.doc_no` | ✓ |
| วันที่ | `doc_date` | ✓ |
| ลูกค้าผู้ยืม | `Customer.name` + รหัส | ✓ |
| ผู้จัดทำ | `Employee.full_name` | ✓ |
| รายการกล่อง | จำนวนบรรทัดรายละเอียด | ✓ |
| สถานะเอกสาร | ร่าง · รอลงนาม · ลงนามแล้ว · ยกเลิก | — |
| ลายเซ็น | ความคืบหน้า n/N ตามสาย DOA | — |
| ⋮ | แก้ไข (ร่างของตัวเอง) · พิมพ์ · ยกเลิกเอกสาร | — |

> DEC-11: **ไม่มีเมนูสร้างใบใหม่จากใบเดิม** ทั้งในเมนู ⋮ และหัวลิ้นชัก
> แบ่งหน้า 20 รายการ · สถานะว่าง = empty state พร้อมปุ่มสร้าง

## 2. ลิ้นชักสร้าง/แก้ไข (3 ขั้น)

### 2.1 ขั้น 1 — ข้อมูลหนังสือสัญญา
**การ์ด 1 · ลูกค้าผู้ยืมและที่ตั้งกล่อง**
| ช่อง | ถ้อยคำบนกระดาษ | ชนิด | บังคับ | ที่มา |
|---|---|---|---|---|
| ลูกค้าผู้ยืม | "ขอสนับสนุนกล่องบรรจุกระดาษสำหรับ ……" | เลือกจากทะเบียน | ✓ | `Customer.name` |
| รหัสลูกค้า | "(รหัสลูกค้า ……)" | อ่านอย่างเดียว | ✓ | `Customer.code` เติมอัตโนมัติ |
| ที่อยู่ที่ตั้งกล่อง | "ซึ่งตั้งอยู่เลขที่ ……" | ข้อความหลายบรรทัด | ✓ | ค่าเริ่มจาก `Customer.address` แก้ได้ |
| วันที่ของหนังสือ | "วันที่" | ตัวเลือกวัน พ.ศ. (`bedateHTML`) | ✓ | ค่าเริ่ม = วันนี้ |

**การ์ด 2 · รายละเอียดกล่องที่สนับสนุน** (แถวซ้ำ · ไม่จำกัดจำนวน · DEC-05)
- 1 แถว = 1 บรรทัดข้อความ (ชนิด ขนาด จำนวนกล่อง) ตรงกับหัวข้อย่อยบนกระดาษ
- ปุ่ม "เพิ่มรายการกล่อง" · ลบได้เมื่อมีมากกว่า 1 แถว

**การ์ด 3 · คู่สัญญาผู้รับมอบและข้อความในเงื่อนไข**
| ช่อง | ถ้อยคำบนกระดาษ | บังคับ |
|---|---|---|
| ชื่อผู้รับมอบ | "ผู้รับมอบ · ลงนาม ____ ( )" | ✓ |
| ตำแหน่งผู้รับมอบ | — (ใต้ชื่อในวงเล็บ) | ✗ |
| ข้อความในเงื่อนไขข้อ 1 | "แตกหักโดยมิใช่การใช้ ……" | ✗ |

- บรรทัดกำกับ: ถ้อยคำเงื่อนไขข้อ 1 และ 2 เป็นข้อความคงที่ตามแบบพิมพ์ แก้ไขในเอกสารรายฉบับไม่ได้

**แถบสรุปด้านขวา** — ผู้จัดทำ · ผู้ส่งมอบ (จากสาย DOA) · ลูกค้าผู้ยืม · วันที่ · จำนวนรายการกล่อง

### 2.2 ขั้น 2 — เอกสารแนบ
แนบไฟล์หลายไฟล์ (PDF · Word · Excel · รูปภาพ ไม่เกิน 20 MB ต่อไฟล์) ผ่าน Document Center (DEC-11)

### 2.3 ขั้น 3 — ตรวจสอบและยืนยัน
การ์ดสรุป 4 ใบ (ข้อมูลหนังสือสัญญา · รายละเอียดกล่อง · คู่สัญญาผู้รับมอบ · เอกสารแนบ)
ปุ่มท้าย: **บันทึกแบบร่าง** · **บันทึกและส่งให้ลงนาม**

## 3. ลิ้นชักดูเอกสาร (4 แท็บ)

### 3.1 หัวลิ้นชัก
เลขที่ + ป้ายสถานะ · ลูกค้า · จำนวนรายการกล่อง · ผู้จัดทำ
ปุ่มตามสถานะและสิทธิ์: ยกเลิก · แก้ไข · **ส่งให้ลงนาม** (ร่างของตัวเอง) / **ไม่ลงนาม** · **ลงนาม** (ผู้ถึงคิว) / ยกเลิกเอกสาร
ปุ่มไอคอน: พิมพ์ · ดาวน์โหลด PDF · ปิด

### 3.2 แท็บ รายละเอียด
แถบแจ้งสถานะ (รอใครลงนาม / ส่งกลับแก้ไขพร้อมเหตุผล / ลงนามแล้ว / ยกเลิกแล้ว) แล้วต่อด้วย
ข้อมูลเอกสาร · ลูกค้าผู้ยืม · รายละเอียดกล่องที่สนับสนุน · **เงื่อนไขตามหนังสือสัญญา** (ข้อความคงที่ 2 ข้อ · ร้อยละอ่านจากค่าที่ snapshot) · คู่สัญญาผู้ลงนาม · เอกสารแนบ · ข้อมูลระบบ

### 3.3 แท็บ PDF Preview
- แถบบน: "ตัวอย่าง PDF · A4 · แบบพิมพ์ FM-SAL-14 Rev.00 · 1 เลขที่ พิมพ์ 2 ชุด"
- ปุ่มสลับชุด: **ต้นฉบับ** · **สำเนา** (print_config.copies) — เนื้อความและเลขข้อเหมือนกันทุกชุด (DEC-12)
- ปุ่ม ดาวน์โหลด PDF · พิมพ์ → ออกทั้ง 2 ชุดในครั้งเดียว
- แสดงผ่าน iframe จาก `print/form.tpl.html` + `loaPdfData(record)` (template เดียวกับฝั่ง server)

### 3.4 แท็บ ลายเซ็น
ความคืบหน้า n/N · อ้างอิง DOA entry · ไทม์ไลน์ต่อขั้น (ขั้น · บทบาท · ผู้พิจารณา · ผลและเวลา)
ปุ่มในไทม์ไลน์เมื่อถึงคิวผู้ใช้: **ไม่ลงนาม** · **ลงนาม** (ถ้อยคำมาจาก `print_config.decision_words.by_role` — ผูก role ไม่ผูกลำดับขั้น)

### 3.5 แท็บ ประวัติ
รายการ append-only เรียงใหม่ไปเก่า (การกระทำ · ผู้ทำ · เวลา · เหตุผล)

## 4. กล่องยืนยัน (modal)
| กล่อง | เมื่อไร | มีอะไร |
|---|---|---|
| ส่งให้ผู้ส่งมอบลงนาม | กดส่ง | ช่องเลือกผู้พิจารณาต่อขั้น (ค่าเริ่มจากสาย DOA + ผังองค์กร) |
| ลงนาม | ผู้ถึงคิวกดลงนาม | สรุปรายการกล่อง + ที่อยู่ · ช่องความเห็น (ไม่บังคับ) |
| ส่งกลับแก้ไขโดยยังไม่ลงนาม | ผู้ถึงคิวกดไม่ลงนาม | ชิปเหตุผลสำเร็จรูป + ช่องเหตุผล (บังคับ) |
| ยกเลิกเอกสาร | เจ้าของหรือ admin role | ชิปเหตุผลสำเร็จรูป + ช่องเหตุผล (บังคับ) |
| ทิ้งข้อมูลที่กรอกไว้ | ปิดลิ้นชักขณะมีข้อมูลค้าง | ยืนยันก่อนทิ้ง |

## 5. Microcopy สำคัญ
| จุด | ข้อความ |
|---|---|
| แถบร่าง | ยังเป็นร่าง — ส่งให้ผู้ส่งมอบลงนามเมื่อข้อมูลครบ |
| แถบส่งกลับแก้ไข | ส่งกลับแก้ไขโดย {ชื่อ} — {เหตุผล} |
| แถบลงนามแล้ว | ลงนามแล้ว — พิมพ์ชุดต้นฉบับและสำเนาให้คู่สัญญาลงนามรับมอบ |
| ใต้ช่องที่อยู่ | ค่าเริ่มจากที่อยู่ลูกค้า แก้ได้เมื่อที่ตั้งกล่องต่างจากที่อยู่จดทะเบียน |
| ใต้ช่องเติมในเงื่อนไข | ตรงกับเส้นประหลังข้อความ "แตกหักโดยมิใช่การใช้" บนแบบพิมพ์ |
| ใต้เนื้อสัญญา | เพดานเปลี่ยนกล่องฟรีอ่านจากนโยบายขาย (SalesPolicy) และบันทึกลงเอกสารตอนออกเลข |
| แบบเอกสารยังไม่เปิดใช้ | แบบเอกสารนี้ยังไม่เปิดใช้งาน — สร้างเอกสารใหม่ไม่ได้ |
