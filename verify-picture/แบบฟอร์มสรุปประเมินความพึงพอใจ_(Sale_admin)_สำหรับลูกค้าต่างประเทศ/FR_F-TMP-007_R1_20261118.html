L-02แก้ไขรายการ (Update/Edit)แก้ไขและบันทึกรายการได้สำเร็จผู้ตรวจทดลอง Update ครบแล้วและไม่รายงานปัญหา logic การบันทึกผ่าน—
L-03ลบรายการ (Delete)ดำเนินการ Delete ตาม flow ที่ระบบเปิดให้ได้สำเร็จผู้ตรวจทดลอง Delete ครบแล้วและไม่รายงานปัญหาผ่าน—

#หัวข้อตรวจผลหมายเหตุหลักฐาน
X-01ทำงานหลักจบได้เองโดยไม่ต้องเดามีข้อสังเกตView drawer แท็บรายละเอียดมีการอัปโหลดไฟล์ ทั้งที่ flow ที่คาดหวังคือ View ใช้แสดงไฟล์ และอัปโหลดจาก Create/Edit—
X-02กดแล้วระบบบอกผลทุกครั้ง (แจ้งเตือน / สถานะเปลี่ยน)ผ่าน——

X-05หน้าว่าง / กำลังโหลด / โหลดไม่สำเร็จ มีทางไปต่อผ่าน——

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-03Edit drawer ไม่แสดงไฟล์ที่เคยแนบไว้Mediumรอแก้
ขั้นตอนทำซ้ำ
  1. สร้างหรือเปิดรายการแล้วแนบไฟล์
  2. บันทึกรายการ
  3. กลับมาเปิดรายการเดิมด้วย Edit drawer
  4. ตรวจส่วนเอกสารแนบ
ผลที่ควรเป็นเห็นรายการไฟล์ที่เคยแนบไว้ครบ เพื่อเปิดหรือลบ/จัดการตามสิทธิ์
ผลที่เกิดจริงEdit drawer ไม่แสดงไฟล์ที่เคยแนบไป
BUG-04View drawer แท็บรายละเอียดมีส่วนอัปโหลดไฟล์ผิดตำแหน่งของ flowMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดรายการที่มีอยู่ด้วย View drawer
  2. เปิดแท็บรายละเอียด
  3. ตรวจส่วนเอกสารแนบ
ผลที่ควรเป็นView drawer แสดงไฟล์แนบเพื่อดูเท่านั้น; การอัปโหลดอยู่ใน Create/Edit drawer
ผลที่เกิดจริงแท็บรายละเอียดใน View drawer มีส่วนอัปโหลดไฟล์
BUG-01Create/Edit drawer หลุด design และ layout บางส่วนไม่เรียบร้อยLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดฟีเจอร์แบบฟอร์มสรุปประเมินความพึงพอใจสำหรับลูกค้าต่างประเทศ
  2. เปิด Create drawer
  3. เปิด Edit drawer
  4. ตรวจการจัดวาง ระยะห่าง และความสม่ำเสมอขององค์ประกอบ
ผลที่ควรเป็นCreate/Edit drawer ใช้รูปแบบและ layout สม่ำเสมอกับ design ของระบบ
ผลที่เกิดจริงDrawer หลุด design และ layout บางส่วนไม่เรียบร้อย
BUG-02View drawer หลายแท็บหลุด designLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดรายการที่มีอยู่ใน View drawer
  2. เปิดแท็บรายละเอียด
  3. เปิดแท็บ PDF Preview
  4. เปิดแท็บลายเซ็น/อนุมัติ
  5. เปิดแท็บประวัติ
ผลที่ควรเป็นทุกแท็บใช้ layout และองค์ประกอบที่สม่ำเสมอกับ design ของระบบ
ผลที่เกิดจริงแท็บรายละเอียด, PDF Preview, ลายเซ็น และประวัติ มี UI/UX หลุด design
