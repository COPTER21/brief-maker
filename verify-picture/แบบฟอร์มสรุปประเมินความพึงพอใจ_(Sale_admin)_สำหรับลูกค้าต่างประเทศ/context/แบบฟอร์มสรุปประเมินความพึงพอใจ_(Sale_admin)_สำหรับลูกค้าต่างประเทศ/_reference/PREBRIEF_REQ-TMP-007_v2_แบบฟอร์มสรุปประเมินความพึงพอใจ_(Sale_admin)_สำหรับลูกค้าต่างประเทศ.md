### 3.1 รายการซ้ำ
- **ลูกค้าที่ประเมิน (คอลัมน์)** — บนกระดาษ 8 แถว (min_rows) · ช่องในแถว: หัวข้อการประเมิน (ชื่อลูกค้า — หัวคอลัมน์), ความชัดเจนในการสื่อสาร, ความรวดเร็วในการตอบกลับ, การติดตามงานอย่างสม่ำเสมอ, ความถูกต้องของเอกสาร, ความรวดเร็วในการส่งเอกสาร, การสนับสนุนประสานงานขนส่ง, การแก้ปัญหาอย่างมีประสิทธิภาพ, การอัปเดตสถานะงาน, ความเป็นมืออาชีพของทีมงาน, ความพึงพอใจในบริการ

### 3.3 สูตร + ค่าคงที่บนกระดาษ
- ค่าคงที่ "ความชัดเจนในการสื่อสาร … ความพึงพอใจในบริการ (10 ข้อ · 3 กลุ่ม)" = หัวข้อการประเมิน 10 ข้อ = q1–q10 ของ FM-SAL-22 (ถ้อยคำไทย · กระดาษ SEA เป็นอังกฤษ) → ควรอ่านจาก `SalesConfig.sea_topics[] (ชุดเดียวกับ SEA · ป้ายไทยสำหรับใบสรุป)` (ห้าม hardcode)
- ค่าคงที่ "ด้านการสื่อสารและการตอบสนอง / ด้านเอกสารและการดำเนินงาน / ด้านความเป็นมืออาชีพ" = ชื่อกลุ่มหัวข้อ 3 กลุ่ม (3+5+2) → ควรอ่านจาก `SalesConfig.sea_topic_groups[]` (ห้าม hardcode)
- ค่าคงที่ "ระดับความพึงพอใจ" = สเกล 1–5 (1=Very Dissatisfied … 5=Very Satisfied) ตาม FM-SAL-22 — ไม่ได้พิมพ์บนกระดาษ → ควรอ่านจาก `SalesConfig.sea_scale[] (label + weight 1–5)` (ห้าม hardcode)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- ไม่มีช่องประจำเดือน/งวด ทั้งที่เป็นใบสรุป → **เพิ่มช่อง ประจำเดือน (บังคับ) ใช้ดึงแบบประเมิน SEA ในเดือนนั้น**
- ใบประเมินต้นทาง FM-SAL-22 เป็นอังกฤษล้วน แต่ใบสรุปเป็นไทย (ถ้อยคำหัวข้อแปลไทย) → **จับคู่หัวข้อตามลำดับ q1–q10 · พิมพ์ถ้อยคำไทยตามกระดาษ FM-SAL-23**
- ชื่อลูกค้าพิมพ์ตายตัว 4 รายบนกระดาษ → **ลูกค้าเป็นข้อมูลจากแบบประเมิน (ไม่ตายตัว) · ลูกค้าเดียวกันซ้ำในใบเดียวกันไม่ได้ → บล็อก · หลายใบในเดือนใช้ใบล่าสุด**
- ใน Word ช่อง 'ผู้รับทราบและอนุมัติ' มาก่อนในโค้ด แต่บนกระดาษผู้สรุปอยู่ซ้าย ผู้อนุมัติอยู่ขวา · เส้นลงชื่อ MD ตกบรรทัด → **วาง ผู้สรุป (ซ้าย) → ผู้รับทราบและอนุมัติ (ขวา) ตามภาพ · จัดเส้นให้เท่ากัน (layout เท่านั้น)**
