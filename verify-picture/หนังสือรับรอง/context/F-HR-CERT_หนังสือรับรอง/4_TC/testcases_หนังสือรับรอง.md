## Result Report (schema)

```json
{
  "feature_id": "F-HR-CERT",
  "run_at": "<iso datetime>",
  "results": [
    { "id": "TC-RQ01", "status": "pass|fail|blocked", "failed_step": null, "evidence": "", "note": "" }
  ],
  "summary": { "total": 100, "pass": 0, "fail": 0, "blocked": 0 }
}
```

> `evidence` = สิ่งที่เห็นจริงบนจอตอน fail หรือ blocked (ข้อความจริง · route ที่ค้าง · สิ่งที่แสดงแทน Expected) เพื่อให้ triage ได้โดยไม่ต้องรันซ้ำ
