# 06_TESTS — F-HR-CERT · หนังสือรับรอง

> Audience: **QA** · ⭐ **อ่าน §6.3 ก่อน** — Invariant Assertion 14 ข้อ **ตกข้อใดข้อหนึ่ง = หยุดปล่อยรุ่นทันที**

## §6.1 Test Strategy

| ระดับ | ครอบอะไร | จำนวน |
|---|---|---|
| **AT** Acceptance Test | 1 ข้อต่อ 1 FN (AT-01…AT-97) + edge (AT-98…AT-118) | **118** |
| **IA** Invariant Assertion ⭐ | สิ่งที่ผิดแล้ว **เอกสารที่อยู่ในมือคนนอกองค์กรผิด และแก้ย้อนหลังไม่ได้** | **14** |
| **CM** Cross-Module Test | สัญญากับต้นทาง 4 ตัว + engine 4 ตัว + ปลายทาง 1 ตัว | **12** |
| **NS** Scope Guard | ทดสอบว่า "ไม่รองรับ" 10 รายการไม่มีจริง | รวมอยู่ใน AT |

⭐ **หลักการตรวจของฟีเจอร์นี้ต่างจากฟีเจอร์คำนวณ:** ที่นี่ **ไม่มีสูตรให้ตรวจ** — สิ่งที่ต้องตรวจคือ **"สิ่งที่พิมพ์ลงเอกสารถูกต้องตามวันที่ระบุไว้บนเอกสาร"** กับ **"สิ่งที่ไม่ควรพิมพ์ ไม่มีทางถูกพิมพ์"**

## §6.3 ⭐⭐ Invariant Assertion (IA-01…IA-14) — ตกข้อใดข้อหนึ่ง = หยุดปล่อยรุ่น

> ทุกข้อในนี้คือสิ่งที่ **ผิดแล้วเอกสารที่อยู่ในมือธนาคาร/สถานทูต/นายจ้างใหม่ผิด และเรียกกลับไม่ได้**

| IA | Invariant | วิธีทดสอบ | ตกแล้วเกิดอะไร |
|---|---|---|---|
| **IA-01** ⭐ | **ทุกการอ่านต้นทางตอนออกหนังสือใช้ `as_of = issue_date` ค่าเดียวกัน** | ดักจับ call ทั้ง 5 ตอนกด API-11 → ตรวจว่า `as_of`/`date` เท่ากันหมด **และเท่ากับ `issue_date`** · รันซ้ำโดยตั้ง `issue_date` เป็นวันในอดีต | หนังสือพูดความจริงของวันผิด |
| **IA-02** ⭐ | **หนังสือที่ออกแล้วเนื้อหาไม่เปลี่ยนตลอดไป + มี `version_id` ครบ 4 ก้อน** | ออกหนังสือ → เปลี่ยนต้นทางทั้ง 4 → เปิดใบเดิม + re-render → **ไฟล์ต้องเหมือนเดิม** และ `source_version_ids` ยังเป็นชุดเดิม | เอกสารเปลี่ยนย้อนหลังโดยไม่มีใครรู้ |
| **IA-03** | **สายอนุมัติมาจากทะเบียนกลาง 100 %** | grep `APPROVAL_CHAIN` / array ของ `role-*` ในไฟล์ feature = ไม่พบ · แก้ทะเบียนแล้วสายเปลี่ยน | governance พัง |
| **IA-04** ⭐⭐ | **ไม่มีจำนวนเงินอยู่ในกติกาการเลือกสายอนุมัติ** | ตรวจ signature ของ `F-05`/`ENG-03` = ไม่มี argument ที่เป็นตัวเลข · ดักจับ query ที่ส่งเข้า `doa/resolve` = ไม่มี parameter ที่เป็นเงิน · ⭐ **ทดสอบด้วยพนักงาน 2 คนที่เงินเดือนต่างกันมาก → สายต้องยาวเท่ากัน** | ⭐ **เงินเดือนรั่วผ่านความยาวของสาย — ผ่านชั้น masking ทุกชั้น** |
| **IA-05** | **ผู้ยื่นเซ็นใบตัวเองไม่ได้** | ตั้งให้ DOA คืนสายที่มีแต่ผู้ยื่น → ต้องบล็อก · ทดสอบทั้งกรณียื่นเองและยื่นแทน | SoD พัง |
| **IA-06** | **เลขที่ออกครั้งเดียว ไม่เปลี่ยน ไม่ reuse** | ปฏิเสธ 3 ใบติดกัน → ใบที่ 4 ได้เลขถัดจากใบที่ 3 · ลอง UPDATE `cert_doc_no` ตรงฐาน = trigger ปฏิเสธ | ทะเบียนไม่เป็นหลักฐาน |
| **IA-07** ⭐⭐ | **`masked = true` + ประเภทเงินเดือน → ไม่มีเอกสารออก** | ผู้ออกไม่มีสิทธิ์ RESTRICTED กด API-11 → `422` · ⭐ **ตรวจว่าไม่มีแถวใน `T_certificate_snapshot` · ไม่มีไฟล์ใน store · สถานะยังเป็น `approved`** · และมี event `cert.issue_blocked_masked` | ข้อมูลค่าจ้างรั่ว หรือได้เอกสารครึ่งใบออกไปข้างนอก |
| **IA-08** ⭐⭐ | **`scheduled[]` ไม่มีทางขึ้นไปอยู่บนหนังสือ** | พนักงานมีคำสั่งอนุมัติแล้วมีผล 15 วันข้างหน้า → ออกหนังสือ → ⭐ **ตำแหน่งบนเอกสารต้องเป็นค่าปัจจุบัน** · ตรวจ `snap_position` ในฐาน · ⭐ **ตรวจว่า `buildSnap()` ไม่มี parameter ที่รับ `ScheduledItem[]`** | หนังสือพูดถึงสิ่งที่ยังไม่เกิด |
| **IA-09** | **ไม่อ่านจำนวนเงินจาก Employee Movement** | ดักจับ response ของ X-API-02/03 → ตรวจว่าไม่มี field ที่เป็นเงิน และโค้ดไม่พยายามอ่าน | ทางอ้อมของ `SS-5` |
| **IA-10** | **`last_working_day = null` ไม่ถูกตีความว่า "ทำงานตลอดไป"** | ตั้งพนักงาน `active` ที่ `last_working_day = null` → ข้อความต้องเป็น "ปัจจุบันยังปฏิบัติงานอยู่" ⭐ **ไม่ใช่ข้อความที่บอกเป็นนัยว่าไม่มีวันสิ้นสุด** | เอกสารรับรองสิ่งที่ไม่จริง |
| **IA-11** ⭐ | **event ต้นทางหลังออกหนังสือ ติดธงอย่างเดียว** | ส่ง `ofb_case_cancelled` → ⭐ **ตรวจว่า snapshot ไม่เปลี่ยนแม้แต่คอลัมน์เดียว · `status` ไม่เปลี่ยน · ไฟล์ไม่ถูก re-render · ไม่มีแจ้งเตือนถึงพนักงาน** · มีเพียงธง + แถว history | เอกสารในระบบไม่ตรงกับฉบับที่คนนอกถืออยู่ |
| **IA-12** ⭐ | **ไม่มีการลบและไม่มีการแก้ในสิ่งที่ออกไปแล้ว** | ลอง `DELETE`/`UPDATE` ตรงฐานทั้ง `T_certificate_snapshot` · `T_certificate_history` · `T_certificate_access_log` และคอลัมน์ที่ตรึงของ `T_certificate` → **trigger ต้องปฏิเสธทุกกรณี** | ทะเบียนไม่เป็นหลักฐาน |
| **IA-13** ⭐⭐ | **อดีตพนักงานขอหนังสือได้จริง (สิทธิตามกฎหมาย)** | สร้างพนักงานสถานะ `left` → HR ยื่นแทน → ⭐ **ต้องเดินได้จนออกหนังสือสำเร็จ** · ตรวจว่า `assertIssuable` ไม่มีด่านที่ตรวจ `left` · ตรวจว่าช่องทางรับใช้ได้จริง | ⭐ **ละเมิด ป.พ.พ. ม.585 โดยที่ไม่มีใครตั้งใจ** |
| **IA-14** ⭐⭐ | **ไม่มีช่องทางใดที่ข้อความอิสระของคนจะไปโผล่บนเอกสาร** | ⭐ รัน `F-44 assertNoFreeTextOnDocument()` — placeholder ทุกตัวในแม่แบบทั้งสองไฟล์ต้อง map ไป field ของ snapshot หรือค่าคงที่ · ⭐ ตรวจ schema: ไม่มีคอลัมน์ที่ผู้ใช้พิมพ์ได้แล้วถูก render · ⭐ ตรวจหน้าจอ: ไม่มีช่องกรอกอิสระในทุกขั้น | ⭐ **ละเมิดข้อห้ามตามกฎหมายเรื่องข้อความอันเป็นที่เสียหายแก่ลูกจ้าง** |
