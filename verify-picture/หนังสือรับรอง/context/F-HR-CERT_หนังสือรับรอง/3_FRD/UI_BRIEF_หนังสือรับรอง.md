## §7 Interaction Spec

### §7.1 Esc chain (ตามลำดับใน handler จริง)

ประกาศ **2 ที่** — ชุดฐานที่บรรทัด **1919–1924** และของฟีเจอร์ที่บรรทัด **4263–4267** ลำดับเหมือนกันทั้งคู่:

```
1. state.modal.open  → closeModal()
2. state.drawer.open → closeDrawer()
```

- **modal ก่อน drawer เสมอ** — เพราะ modal เปิดจากในลิ้นชัก (กด Esc ครั้งเดียวปิด modal แล้วยังอยู่ในใบ)
- combobox มี Esc ของตัวเองที่ **บรรทัด 2055** (`ssOnKey`) ซึ่งปิดเฉพาะ dropdown ไม่ปิด modal/drawer
- ⭐ **ไม่มี overlay ใดที่ห้ามปิด** — ทุกตัวปิดด้วย Esc ได้หมด
- ⚠️ **หมายเหตุสำหรับ dev:** handler ซ้ำสองที่เป็นของตกทอดจากชุดฐาน (ตัวหนึ่งเป็น `window` อีกตัวเป็น `document`) — พฤติกรรมไม่ผิดเพราะลำดับเหมือนกัน แต่ **ของจริงควรเหลือตัวเดียว** (ดู §13 ข้อเสนอ)

### §7.2 การรักษาสภาพหน้าจอ

- กรอง/เรียง/เปลี่ยนหน้า → วาดเฉพาะตาราง ไม่ใช่ทั้งหน้า (#35/#95/#103) — หน้าไม่กระโดด scroll ไม่รีเซ็ต
- `goTab()` (3035) รีเซ็ต `pagination.page = 1` และ `selRow = null` โดยตั้งใจ — กันสถานะเลือกแถวข้ามแท็บ
- overlay ลอยทับ **ไม่ดันเนื้อหา** · คำอธิบายชี้ค้าง (`.tip`) ก็ลอยเช่นกัน

**กลุ่มสถานะที่โค้ดใช้ตัดสิน (บรรทัด 2670–2672):**
- `OPEN_ST = ['draft','pending','approved']` → `isOpen(d)`
