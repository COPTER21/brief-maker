## §1.3 Journey
สร้าง → ขั้น 1 (ครบ) → ขั้น 2 → ขั้น 3 → บันทึกและส่งอนุมัติ → modal ส่ง (slot ผู้อนุมัติต่อขั้น ค่าเริ่ม DOA) → รออนุมัติ → ขั้น 1 อนุมัติ → ขั้น 2 อนุมัติ → อนุมัติแล้ว (แจ้ง TO/CC · ใบเดิมถูกแทนที่)
### Branch
- ไม่อนุมัติ (เหตุผล) ขั้นใดก็ได้ → ร่างเลขเดิม → แก้ → ส่งใหม่
- บันทึกแบบร่าง (ต้องมีเขต + รอบ) → รายการ (ร่าง) → แก้ไข → ส่ง
- ยกเลิก (เหตุผล) จากรายการ ⋮ หรือหัว drawer

## §1.6 Empty/Error
- รายการว่าง: "ยังไม่มีใบเป้าหมายการเยี่ยมร้านค้า" + ปุ่มสร้าง · ค้นหาไม่พบ: "ไม่พบรายการที่ค้นหา" + ล้างตัวกรอง · ตารางแผนว่าง: แผง "ยังไม่มีแผนเยี่ยมรายวัน"
- กดถัดไปตอนไม่ครบ: toast "กรุณากรอกข้อมูลให้ครบถ้วน" + การ์ดขอบแดง + เลื่อนไปการ์ดแรกที่ผิด
- ร้านซ้ำ: toast "ร้านนี้อยู่ในวันนี้แล้ว" · เปลี่ยนเขต: toast "นำร้านนอกเขตออก N ร้าน"
- API ล้ม: "ทำรายการไม่สำเร็จ กรุณาลองใหม่อีกครั้ง" · 409 "ข้อมูลถูกแก้โดยผู้อื่น…" · 403 "คุณไม่มีสิทธิ์ทำรายการนี้"
