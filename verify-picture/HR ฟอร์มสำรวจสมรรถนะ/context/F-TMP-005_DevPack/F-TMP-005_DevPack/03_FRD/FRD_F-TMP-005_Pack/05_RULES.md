# FRD 05 · RULES — F-TMP-005 แบบฟอร์มสำรวจสมรรถนะ

## 5.1 Validation (VR)
| id | กฎ | ระดับ | ที่มา |
|---|---|---|---|
| VR-01 | `assessed_on` ต้องมีค่า | บล็อก | FORM_SPEC required |
| VR-02 | ต้องมีสมรรถนะหลักอย่างน้อย 1 รายการที่มีชื่อ | บล็อก | FORM_SPEC repeat_groups.core |
| VR-03 | ต้องมีสมรรถนะเฉพาะสายงานอย่างน้อย 1 รายการที่มีชื่อ | บล็อก | FORM_SPEC repeat_groups.func |
| VR-04 | แถวที่มี `competency_name` ต้องเลือก `level` 1–4 — ไม่เลือก = `LEVEL_REQUIRED` | บล็อก | FORM_SPEC fields.F07/F10 required |
| VR-05 | แถวที่ไม่มี `competency_name` แต่มี `description` หรือ `level` = แถวค้าง ต้องแก้หรือลบ | บล็อก | DEC-07 1:1 |
| VR-06 | `level` ต้องเป็นค่าที่มีใน `CompetencyLevelConfig` เท่านั้น | บล็อก | DEC-04 |
| VR-07 | `development_plan` รับได้เฉพาะ `training` · `coaching` · `ojt` (เลือกหลายข้อได้) | บล็อก | FORM_SPEC choices.dev_plan |
| VR-08 | มี `gaps` แต่ไม่ได้เลือก `development_plan` เลย | **เตือน ไม่บล็อก** | DEC-04 (เกินเกณฑ์ = เตือน) |
| VR-09 | `reason` บังคับเมื่อส่งกลับแก้ไข และเมื่อยกเลิกเอกสาร | บล็อก | DEC-09 |

## 5.2 Business rules (BR)
| id | กฎ |
|---|---|
| BR-01 | อนุมัติครบทุกขั้นแล้ว **ไม่เปลี่ยนค่าใด ๆ ในระบบ** และ **ไม่ส่งต่อ module อื่น** (DEC-01 · DEC-02) |
| BR-02 | เลขที่เอกสารออกตอนบันทึกครั้งแรกจาก ENG-DOC-NUM เท่านั้น · แก้ร่างซ้ำใช้เลขเดิม (DEC-11) |
| BR-03 | ส่งกลับแก้ไข = เอกสารกลับเป็นร่าง **เลขเดิม** · resolve สายอนุมัติใหม่ตอนส่งรอบถัดไป (DEC-09) |
| BR-04 | ยกเลิกได้เฉพาะสถานะ ร่าง / รออนุมัติ โดยเจ้าของใบหรือ admin role ของฝ่ายบุคคล · ต้องมีเหตุผล (DEC-09) |
| BR-05 | ช่องบนเอกสารตรงกระดาษ FM-HRM-40 แบบ 1:1 — ห้ามเพิ่มช่องเอง (เช่น คะแนนรวม/เฉลี่ย) (DEC-07) |
| BR-06 | จำนวนแถวสมรรถนะไม่จำกัด · แบบพิมพ์แสดงอย่างน้อยตามกระดาษ (core 5 · func 6) (DEC-05 · DEC-06) |
| BR-07 | ตารางระดับการประเมินเป็นค่าจาก config — ลูกค้าแก้คำอธิบายได้เองโดยไม่ต้องแก้ feature (DEC-04) |
| BR-08 | ช่องลงชื่อในแบบพิมพ์ = ผู้รับประเมิน + 1 ช่องต่อขั้นของสายอนุมัติ แบ่งแถวละไม่เกิน 4 · ไม่ใช้ภาพลายมือชื่อ (DEC-08) |
| BR-09 | แนบไฟล์และส่งออก CSV เปิดใช้ · ไม่มีคำสั่งทำซ้ำ · ไม่มีการประกาศเมื่ออนุมัติ (DEC-12) |
