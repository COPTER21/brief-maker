## ตาราง `hr_competency_survey_line` (แถวซ้ำ 2 กลุ่ม)
| คอลัมน์ | ชนิด | หมายเหตุ |
|---|---|---|
| `id` | uuid PK | |
| `survey_id` | uuid FK | |
| `group` | enum(core, func) | `core` = สมรรถนะหลัก · `func` = สมรรถนะเฉพาะสายงาน |
| `seq` | int | ลำดับแสดงผลภายในกลุ่ม |
| `competency_name` | varchar(200) not null | ช่อง "รายการสมรรถนะ" |
| `description` | varchar(400) | ช่อง "คำอธิบาย" |
| `level` | smallint check (1..4) not null | ช่อง "ระดับประเมิน (1–4)" — ค่าที่ใช้ได้มาจาก `CompetencyLevelConfig` |

- unique `(survey_id, group, seq)` · index `(survey_id, group)`
- **ไม่จำกัดจำนวนแถว** (DEC-05 · DEC-06) — ขั้นต่ำ 5 / 6 เป็นเรื่องของ **แบบพิมพ์** ไม่ใช่ข้อบังคับของฐานข้อมูล
