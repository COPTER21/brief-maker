## §5.2 State Machine
draft →(ส่ง)→ pending[1..N] →(อนุมัติขั้น N)→ approved · pending →(ส่งกลับ/ไม่อนุมัติ)→ draft · draft/pending →(ยกเลิก)→ cancelled · approved = ล็อก

## §5.4 Validation
| VR | ช่อง | เงื่อนไข | ข้อความ |
|---|---|---|---|
| VR-01 | project_name | required | กรุณากรอกชื่อโครงการ / ธุรกรรม (DEC-16) |
| VR-02 | folders[].folder_name · owner · access_level | required ต่อแถว | โฟลเดอร์ที่ n: กรอก ชื่อโฟลเดอร์ · ผู้รับผิดชอบ · ระดับสิทธิ |
| VR-03 | documents[].doc_name · owner · version · version_date · doc_status | required ต่อแถว | เอกสารที่ n: กรอก ชื่อเอกสาร · ผู้รับผิดชอบ · ฉบับ · วันที่ฉบับ · สถานะเอกสาร |
| VR-04 | documents[].version | `^(V\d{2}|Final)$` | ฉบับต้องเป็น V01, V02 … หรือ Final (DEC-19) |
| VR-05 | changes[].change_date · doc_ref · detail · status | required ต่อแถว | การเปลี่ยนแปลงที่ n: กรอก วันที่ · ชื่อเอกสาร / ฉบับ · รายละเอียดการเปลี่ยนแปลง · สถานะ |
| VR-06 | changes[].effective_date | required เมื่อ status = applied | สถานะ นำไปใช้แล้ว ต้องระบุวันที่มีผล (DEC-21) |
| VR-07 | access[].user_name · access_level · scope · granted_date · status | required ต่อแถว | ผู้ใช้งานที่ n: กรอก ชื่อผู้ใช้งาน · ระดับสิทธิ · ขอบเขตโฟลเดอร์ / เอกสาร · วันที่ให้สิทธิ · สถานะสิทธิ |
| VR-08 | access[].revoked_date | ≥ granted_date | วันที่ยกเลิกสิทธิต้องไม่ก่อนวันที่ให้สิทธิ (DEC-20) |
| VR-09 | access[].revoked_date | required เมื่อ status ∈ {expired, revoked} | สถานะ หมดอายุ / ยกเลิก ต้องระบุวันที่ยกเลิกสิทธิ (DEC-20) |
| VR-10 | folders[] · documents[] | ≥ 1 แถว | ต้องมีโฟลเดอร์อย่างน้อย 1 รายการ · ต้องมีเอกสารอย่างน้อย 1 รายการ |
| VR-11 | assignees | ทุกขั้น · ≠ ผู้จัดทำ | กรุณาเลือกผู้พิจารณา |
| VR-12 | reason (ส่งกลับ/ไม่อนุมัติ/ยกเลิก) | required | กรุณาระบุเหตุผล |

## §5.5 Edge Cases
