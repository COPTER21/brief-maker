## §1.2 Per-Page Detail
### P-01 รายการ
- หัว: "แบบฟอร์มบันทึกเหตุผลการไม่ดำเนินโครงการต่อ (Project Discontinuation)" · sub + badge "N รายการ · เปิดอยู่ X · รอฉันพิจารณา Y" (ค่า 0 ไม่แสดง) · ปุ่ม ส่งออก CSV · สร้างบันทึก (disabled เมื่อ F-DOCCFG ปิดใช้ + แถบแดง)
- คอลัมน์ (1 ข้อมูล = 1 คอลัมน์): เลขที่ · วันที่ · ผู้จัดทำ (icon คน) · ชื่อโครงการ (ตัด … บรรทัดเดียว) · เหตุผล (จำนวนที่เลือก) · สถานะการปิดโครงการ (pill) · สถานะเอกสาร · ลายเซ็น n/N · ⋮ (แก้ไข[ร่างของตน] · พิมพ์ · ยกเลิกเอกสาร[สิทธิ์])
- สถานะเอกสาร: ร่าง · รออนุมัติ · อนุมัติแล้ว · ยกเลิก · สถานะการปิด: จาก ProjectClosure.closure_statuses
### P-02 สร้าง/แก้ (ขั้น 1 ข้อมูลหลักบันทึกการไม่ดำเนินโครงการ)
- แถบสรุปสด: ผู้จัดทำ (จากระบบ) · เหตุผลที่เลือก n / 8 ข้อ · เหตุผลหลัก (ชื่อที่เลือก) · สถานะการปิดโครงการ
- ① ข้อมูลโครงการ
| ช่อง (ป้ายตามกระดาษ) | คีย์ | ชนิด |
|---|---|---|
| ชื่อโครงการ* | `project_name` | input |
| ผู้รับผิดชอบ* | `owner` | search-select พนักงาน (ค่าเริ่ม = ผู้จัดทำ) |
| วันที่มีมติไม่ดำเนินการต่อ* | `decision_date` | ตัวเลือกวัน พ.ศ. (bedate · max วันนี้ · ค่าเริ่มวันนี้) |
| ขั้นตอนที่ยุติ* | `stopped_stage` | input |
- ② เหตุผลการไม่ดำเนินโครงการต่อ (ตาราง 8 แถวตายตัวจาก ProjectClosure.reason_types)
| คอลัมน์ | คีย์ | ชนิด |
|---|---|---|
| เหตุผลหลัก | `reasons[].reason` | ข้อความ (config) |
| เลือก* | `selected` | select ใช่/ไม่ใช่ (ค่าเริ่ม ไม่ใช่) |
| รายละเอียดประกอบ | `detail` | textarea (บังคับเมื่อ ใช่ · placeholder "ระบุเหตุผลอื่น" ที่แถวเหตุผลอื่น) |
| หลักฐานอ้างอิง | `evidence` | textarea |
| ผลกระทบ | `impact` | textarea |
| เงื่อนไขที่จะพิจารณาใหม่ | `revisit_condition` | textarea |
- แถว "ไม่ใช่" = ช่องข้อความ disabled + ล้างค่า · แถว "ใช่" = ชื่อเหตุผลเน้นสี · error ใต้ตาราง
- ③ สรุปและปิดโครงการ: สรุปเหตุผล* (`summary`) · เอกสารที่ใช้ประกอบการตัดสินใจ (`decision_documents`) · บทเรียนที่ได้รับ (`lessons_learned`) · แนวทางจัดเก็บเอกสาร (`archive_method`) · ข้อเสนอให้ติดตามในอนาคต (`future_followup` · * เมื่อสถานะติดตามเงื่อนไข) · สถานะการปิดโครงการ* (`closure_status` · track card 3 ใบ + คำอธิบาย)
- ขั้น 2 เอกสารแนบ: upload zone (ไม่บังคับ)
- ขั้น 3 ตรวจสอบ: ข้อมูลเอกสาร · ข้อมูลโครงการ · ตารางเหตุผล · สรุปและปิดโครงการ · เอกสารแนบ
- footer: ย้อนกลับ · ยกเลิก · ถัดไป / บันทึกแบบร่าง · บันทึกและส่งอนุมัติ · ปิดตอนกรอกค้าง = M-05
- ร่างที่ถูกส่งกลับ: แถบแดง "ส่งกลับแก้ไข: {เหตุผล}" ที่ขั้น 1
