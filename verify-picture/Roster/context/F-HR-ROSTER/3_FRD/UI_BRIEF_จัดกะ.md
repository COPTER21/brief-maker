**Dismiss / keyboard chain (จาก handler จริง):**
- `Escape` → `closeOverlay()` — ปิด **overlay ชั้นบนสุดทีละชั้น** (modal ก่อน drawer)
- `ArrowUp` / `ArrowDown` / `Enter` → ใช้ใน combobox (`searchSelectHTML`) เท่านั้น
- `dragEndAny()` **ล้าง mark ของการลากเสมอ** แม้ปล่อยนอกเป้าหมาย
- **overlay ทั้งหมดเป็น `position: fixed`** → ลอยทับโดยไม่ดันเนื้อหา (LD-UI-05)
