- ค่าคงที่ "ยังไม่เริ่ม · กำลังดำเนินการ · แล้วเสร็จ · พักงาน" = สถานะของเอกสาร/เงื่อนไขประกอบ → ควรอ่านจาก `InvestmentMemo.condition_statuses` (ห้าม hardcode)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- เลือกสถานะได้ทั้งที่ไม่มีรายการเอกสาร/เงื่อนไขในแถวนั้น → **แถวที่มีสถานะต้องกรอกรายการเอกสาร / เงื่อนไข**
- สถานะ 'กำลังดำเนินการ' หรือ 'ยังไม่เริ่ม' ไม่บังคับผู้รับผิดชอบและกำหนดเสร็จ → **สถานะที่ยังไม่ 'แล้วเสร็จ' ต้องมีผู้รับผิดชอบและกำหนดเสร็จ**
- ช่องข้อความว่าง ไม่บังคับเป็นตัวเลข — กรอกตัวอักษร/ค่าติดลบได้ → **วงเงินต้องเป็นตัวเลข ≥ 0**
- ส่งเสนออนุมัติได้ทั้งที่เงื่อนไขก่อนอนุมัติในตารางยังไม่ 'แล้วเสร็จ' → **ไม่บล็อก — แสดงจำนวนเงื่อนไขที่ยังไม่แล้วเสร็จให้ผู้อนุมัติเห็น (เตือน)**
- ไม่มีเลขที่โครงการ/การอ้างถึงแบบฟอร์มเริ่มต้นโครงการ (FM-BDM-01) และผลคัดกรอง (FM-BDM-03) → **ไม่เพิ่มช่อง (G5 1:1) — เสนอให้ลูกค้ายืนยันการผูกกับโครงการในรายงาน**
