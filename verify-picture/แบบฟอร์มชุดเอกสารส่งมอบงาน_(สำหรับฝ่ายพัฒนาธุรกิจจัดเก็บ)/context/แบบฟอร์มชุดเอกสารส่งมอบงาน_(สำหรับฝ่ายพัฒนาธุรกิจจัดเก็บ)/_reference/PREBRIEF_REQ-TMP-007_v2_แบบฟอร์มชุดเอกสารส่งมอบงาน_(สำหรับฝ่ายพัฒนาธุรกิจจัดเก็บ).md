### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- รายการ 1,2,3,4,5 ที่ C13:C18 อยู่บนเซลล์หัวข้อ (A13:D13 merge) ของตารางข้อมูลการส่งมอบ — ค้างจากแบบฟอร์มอื่น ไม่มีความหมายในฟอร์มนี้ → **ตัดรายการ 1–5 ทิ้ง · ใช้เฉพาะ สถานะข้อมูล (E18) และ สถานะเอกสาร (G22:G33)**
- สถานะข้อมูล 'สมบูรณ์' เลือกได้แม้มีรายการเอกสารสถานะ 'ขาดเอกสาร' หรือ 'มีข้อจำกัด' → **สถานะข้อมูล = สมบูรณ์ ได้เมื่อทุกรายการสถานะ = ครบถ้วน หรือ ไม่เกี่ยวข้อง (ไม่ครบ = เตือน)**
- สถานะข้อมูล 'มีข้อจำกัด' แต่ช่อง ข้อจำกัดของข้อมูล ว่างได้ → **สถานะข้อมูล = มีข้อจำกัด หรือ รายการใดสถานะ = มีข้อจำกัด → ต้องกรอก ข้อจำกัดของข้อมูล**
- ผู้รับมอบ (ฝ่ายบริหารการลงทุน) ถูกบันทึก 2 ที่ — ช่องผู้รับมอบ และแถว ผู้อนุมัติ / รับทราบ อาจขัดกัน → **ผู้รับมอบที่เลือก = ผู้พิจารณาขั้นรับทราบใน DOA (ค่าเริ่ม) · บล็อกลงชื่อมาจาก DOA เท่านั้น**
- วันที่เอกสารในรายการอาจหลังวันที่ส่งมอบ → **วันที่เอกสาร ≤ วันที่ส่งมอบ (เกิน = เตือน)**
