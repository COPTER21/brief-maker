ส่วนที่ไม่ได้ตรวจ อยู่นอกความรับผิดชอบของรายงานฉบับนี้

ตรวจแล้ว

  • สร้างข้อมูล (create)
  • แก้ไขข้อมูล (update)
  • ลบข้อมูล (delete) ตาม action ที่ผู้ตรวจเรียกระบุ
  • UI/UX ของ create และ edit drawer
  • UI/UX ของ view drawer: แท็บรายละเอียด, PDF Preview, ลายเซ็น และประวัติ
  • UI/UX ส่วนที่เหลือ

ไม่ได้ตรวจ

  • ส่งอนุมัติและตัดสินตามสาย DOA ทุกขั้น — ผู้ตรวจไม่ได้รายงานผลในรอบนี้
  • ตีกลับเป็นร่าง เลขเดิม แก้ไข และส่งใหม่ — ผู้ตรวจไม่ได้รายงานผลในรอบนี้
  • สิทธิ์การมองเห็นและการปฏิเสธ action สำหรับผู้ใช้ต่างบทบาท — ผู้ตรวจไม่ได้รายงานผลในรอบนี้
  • Business validation, warning เอกสารขาด/มีข้อจำกัด และวันที่เอกสาร — ผู้ตรวจไม่ได้รายงานผลในรอบนี้
  • PDF 2 หน้า, ลายเซ็นตาม DOA, approved final, notification และ audit — ผู้ตรวจไม่ได้รายงานผลในรอบนี้
  • Idempotency, optimistic lock, retry, double-click และ concurrent update — ผู้ตรวจไม่ได้รายงานผลในรอบนี้

1Logic — ทำงานถูกตามกฎธุรกิจ

เทียบผลจริงกับ FRD / Test Case — ข้อที่ไม่ผ่านต้องผูกกับ Bug ในข้อ 4

#กฎ / Scenarioผลที่คาดหวังผลจริงผลอ้างอิง
L-01สร้างข้อมูล (create)สร้างข้อมูลได้สำเร็จตาม flow ของระบบตรงตามคาดผ่านFRD AC-01 · API-03
L-02แก้ไขข้อมูล (update)แก้ไขข้อมูลได้สำเร็จตาม flow ของระบบตรงตามคาดผ่านFRD API-04
L-03ลบข้อมูล (delete) ตาม action ที่ผู้ตรวจระบุทำ action ได้สำเร็จตามพฤติกรรมของระบบตรงตามคาดผ่าน—
L-04Validation ช่องบังคับและรายการเอกสารบล็อกข้อมูลไม่ครบตาม VR-01..VR-05—ไม่ได้ตรวจFRD AC-02, AC-03, AC-06
L-05สถานะข้อมูลสมบูรณ์แต่มีเอกสารขาด/มีข้อจำกัดเตือนแต่ไม่บล็อก และนับ gap ถูกต้อง—ไม่ได้ตรวจFRD AC-04
L-06วันที่เอกสารหลังวันที่ส่งมอบเตือนระบุรายการแต่ไม่บล็อก—ไม่ได้ตรวจFRD AC-05
L-07ส่งอนุมัติและ resolve สาย DOAslot ครบทุกขั้น ผู้จัดทำเลือกตัวเองไม่ได้ และผู้รับมอบเป็นค่าเริ่มขั้นรับทราบ—ไม่ได้ตรวจFRD AC-07
L-08อนุมัติเรียงขั้นจนรับมอบอนุมัติตามลำดับ เก็บ approved final และแจ้งเมื่อยังมี gap—ไม่ได้ตรวจFRD AC-08
L-09ไม่ผ่านการตรวจสอบหรือไม่รับมอบกลับเป็นร่าง ใช้เลขเดิม และบันทึกเหตุผลใน audit—ไม่ได้ตรวจFRD AC-09
L-10PDF และลายเซ็นตามจำนวนขั้น DOAPDF 2 หน้าและมีแถวลงชื่อผู้จัดทำบวกหนึ่งแถวต่อ DOA step—ไม่ได้ตรวจFRD AC-10, AC-13
L-11ยกเลิกตามสถานะและสิทธิ์เจ้าของหรือ admin ยกเลิกได้เฉพาะร่าง/รออนุมัติและต้องมีเหตุผล—ไม่ได้ตรวจFRD AC-11
L-12Admin, ตัวกรอง และ CSVAdmin เห็นทุกใบและ CSV ตรงตามตัวกรอง—ไม่ได้ตรวจFRD AC-12
L-13Deny cases สำหรับผู้ไม่มีสิทธิ์หรือคนผิดขั้นไม่เห็นร่างคนอื่นและไม่สามารถแก้ไข ตัดสิน หรือยกเลิกข้ามสิทธิ์—ไม่ได้ตรวจFRD TC-D01..TC-D07

U-02ระยะห่าง / การจัดแนว ฟอร์มและตารางมีข้อสังเกตCreate/Edit drawer และ View drawer มีการจัด layout บางส่วนไม่เรียบร้อย—
U-03ตาราง 1 ช่อง = 1 บรรทัด ไม่ซ้อนข้อมูลผ่าน——
U-04ปุ่ม / ไอคอน ขนาดและสไตล์สม่ำเสมอผ่าน——
U-05ข้อความไทยถูกต้อง ไม่พิมพ์ผิด ไม่ตกบรรทัดแปลกผ่าน——

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-01Create/Edit drawer หลุด design และ layout บางส่วนไม่เรียบร้อยLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดฟีเจอร์แบบฟอร์มชุดเอกสารส่งมอบงาน
  2. กดสร้างข้อมูลเพื่อเปิด Create drawer
  3. เปิดข้อมูลเดิมเพื่อเข้าสู่ Edit drawer
  4. ตรวจรูปแบบและการจัดวางภายใน drawer
ผลที่ควรเป็นCreate/Edit drawer แสดงรูปแบบและการจัดวางสม่ำเสมอตาม design ของระบบ
ผลที่เกิดจริงรูปแบบหลุด design และ layout บางส่วนไม่เรียบร้อย
BUG-02View drawer หลายแท็บหลุด designLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดรายการข้อมูลที่มีอยู่เพื่อเข้าสู่ View drawer
  2. เปิดแท็บรายละเอียด
  3. เปิดแท็บ PDF Preview
  4. เปิดแท็บลายเซ็น
  5. เปิดแท็บประวัติและตรวจรูปแบบแต่ละแท็บ
ผลที่ควรเป็นทุกแท็บใน View drawer แสดง UI/UX สม่ำเสมอตาม design ของระบบ
ผลที่เกิดจริงแท็บรายละเอียด, PDF Preview, ลายเซ็น และประวัติมี UI/UX บางส่วนหลุด design
