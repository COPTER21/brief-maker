## 1. Business Context
### 1.1 ปัญหา / โอกาส
ฝ่ายพัฒนาธุรกิจบันทึกการเริ่มโครงการ (ขั้นตอนที่ 1: รับโจทย์และกำหนดขอบเขตงานวิเคราะห์) ด้วยไฟล์ Excel FM-BDM-01 — ส่งต่อ ตรวจทาน และอนุมัติด้วยมือ · ไม่มีเลขที่เอกสาร · ไม่มีประวัติการแก้ไขที่เชื่อถือได้ · ค้นหา/ติดตามสถานะโครงการรวมไม่ได้
### 1.2 เป้าหมาย
1. ขึ้นแบบฟอร์มเป็นเอกสารในระบบ ช่องตรงกระดาษ 1:1 ลูกค้าจำแบบเดิมได้ (PDF Replica 2 หน้า)
2. มีเลขที่ PJI · สายตรวจทาน/อนุมัติจาก DOA กลาง (ผู้ตรวจสอบ → ผู้อนุมัติ/รับทราบ) · ประวัติการแก้ไขบันทึกอัตโนมัติ
3. รายการโครงการค้นหา/กรองตามสถานะ ระดับความสำคัญ และส่งออก CSV ได้
### 1.3 ตัวชี้วัด
ไม่มีใน input → **OQ-01** (ห้ามแต่งตัวเลข)
### 1.4 ที่มา
ไฟล์ `1. FM-BDM-01 แบบฟอร์มบันทึกภาพรวมและเริ่มต้นโครงการ.xlsx` (ไม่มี PREBRIEF จาก CMS → PREBRIEF v2 สร้างจาก FORM_SPEC)

## 2. Scope
### 2.1 In Scope

### 2.2 Out of Scope

## 4. User Journey
### 4.1 Happy Path
ผู้จัดทำ สร้าง → กรอกข้อมูลทั่วไป + วัตถุประสงค์และขอบเขต + แผนงาน → (แนบไฟล์) → ตรวจสอบและยืนยัน → บันทึกได้เลข PJI → ส่ง (เลือกผู้พิจารณาต่อขั้น) → ผู้ตรวจสอบ "ตรวจสอบแล้ว" → ผู้อนุมัติ "อนุมัติ / รับทราบ" → อนุมัติแล้ว · ระบบเพิ่มประวัติการแก้ไขฉบับ 00 · แจ้งผู้รับผิดชอบ (pji_owner_assigned) · PDF เก็บ approved_final
### 4.2 Alternative
- ส่งกลับแก้ไข/ไม่อนุมัติ (เหตุผลบังคับ) → ร่างเลขเดิม + แถบเหตุผล → แก้ → ส่งใหม่ (resolve สายใหม่)
- ยกเลิก (owner/admin · ร่าง/รออนุมัติ · เหตุผลบังคับ) → pji_cancelled ถึงผู้พิจารณาขั้นปัจจุบัน (ถ้ารออยู่)
- doc_type PJI ปิดใช้ที่ F-DOCCFG → สร้างไม่ได้
