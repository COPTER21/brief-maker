### 3.2 ตัวเลือก
- **ประเภท** (เลือกได้ข้อเดียว): Notebook · Workstation · Printer · อื่นๆ → ใช้ช่อง อื่นๆ
- **ผลของการตรวจเช็ค/ซ่อม อุปกรณ์ตามที่ได้รับการแจ้งซ่อม** (เลือกได้ข้อเดียว): ดำเนินการซ่อมแล้วเสร็จ · รอดำเนินการ/ยังไม่แล้วเสร็จ · ซ่อมไม่ได้ต้องส่งไปที่บริษัทเนื่องจากอยู่ระยะประกัน → ใช้ช่อง ระยะเวลา, ถึง, ระบุร้านค้าที่ส่งเคลม, วันที่ส่งเคลม · ซ่อมไม่ได้ต้องส่งไปที่บริษัทแต่ไม่อยู่ระยะในประกัน → ใช้ช่อง ระยะเวลา, ถึง, ระบุร้านค้าที่ส่งเคลม, วันที่ส่งเคลม · สั่งซื้ออุปกรณ์ / เปลี่ยนอุปกรณ์ → ใช้ช่อง ระยะเวลา, ถึง, ระบุร้านค้าที่ส่งเคลม, วันที่ส่งเคลม
- **ผลการซ่อม** (เลือกได้ข้อเดียว): แก้ไขเรียบร้อย · ไม่สามารถแก้ไขได้ → ใช้ช่อง ผลการซ่อม

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- สะกด ตําแหน่ง (ํ + า) → **แก้คำสะกดเป็น ตำแหน่ง (G5)**
- สะกด ส่งเครม (3 จุด) ขณะที่บรรทัดถัดไปสะกด ส่งเคลม → **แก้เป็น ส่งเคลม (G5)**
- สะกด สั้งซื้อ → **แก้เป็น สั่งซื้อ (G5)**
- บรรทัดใต้ตัวเลือกใช้คำ ร้านค้าที่ส่งเคลม / วันที่ส่งเคลม เหมือน 2 ตัวเลือกบน (น่าจะคัดลอกมา) แต่กรณีสั่งซื้อไม่ใช่การเคลม → **คงคำตามกระดาษ (G5 1:1) · บันทึกเป็นคำถามลูกค้า (OQ) ว่าควรเป็น ร้านค้าที่สั่งซื้อ/วันที่สั่งซื้อ หรือไม่**
- กระดาษไม่กำหนดว่าวันสิ้นสุดต้องไม่ก่อนวันเริ่ม → **ถึง ≥ ระยะเวลา (เตือน)**
- กระดาษไม่กำหนดว่าต้องไม่ก่อนวันที่แจ้ง → **วันที่ต้องการส่งมอบ ≥ วันที่แจ้ง (เตือน)**
- มีเส้นประให้ระบุเฉพาะตัวเลือก อื่นๆ → **ติ๊ก อื่นๆ = ต้องระบุข้อความ**
