ส่วนที่ไม่ได้ตรวจ อยู่นอกความรับผิดชอบของรายงานฉบับนี้

ตรวจแล้ว

  • UX/UI ทุกหน้าจอ: ตำแหน่งที่เปิด (req) / คลังผู้สมัคร (pool) / บอร์ดสรรหา (board) / รายงาน (report)
  • UX/UI ของ view drawer + form drawer + modal
  • การแสดงผล column / layout ตาราง / timeline / tab ใน drawer
  • การค้นหา-กรองรายการ และเอกสารแนบ

ไม่ได้ตรวจ

  • Logic / กฎธุรกิจ: สายอนุมัติ DOA + SoD (maker≠approver), consent PDPA gate, masking ข้อมูล RESTRICTED ตาม role (3 persona), state machine req/candidate/offer, offer band freeze + out-of-band, handoff event ตอน hired, audit append-only — รอบนี้ได้รับมอบหมายให้ตรวจเฉพาะ UX/UI

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-01ตัวควบคุม persona / ปุ่มทดสอบ (demo) โผล่บน productionMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดระบบสรรหาบน prod
  2. สังเกตแถบ/ปุ่มสลับ persona (เจ้าหน้าที่สรรหา/ผู้จัดการ/ผู้ชม) ที่เป็นของ demo
ผลที่ควรเป็นไม่มีตัวสลับ persona/ปุ่มทดสอบบน prod — ควรมีเฉพาะใน demo HTML (Iron #105 demo-strip)
ผลที่เกิดจริงตัวควบคุม demo ปรากฏบน prod
BUG-02ค้นหาด้วยแผนกไม่ได้Mediumรอแก้
ขั้นตอนทำซ้ำ
  1. เข้าหน้ารายการ (ตำแหน่งที่เปิด หรือ คลังผู้สมัคร)
  2. พิมพ์ชื่อแผนกในช่องค้นหา
ผลที่ควรเป็นกรองรายการตามแผนกที่ค้นได้
ผลที่เกิดจริงค้นด้วยแผนกไม่ได้ผล
BUG-03เอกสารแนบยังเป็น mock และเปิดไฟล์ดูไม่ได้Mediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด view drawer ที่มีส่วนเอกสารแนบ
  2. กดเปิด/ดาวน์โหลดไฟล์แนบ
ผลที่ควรเป็นเปิด/ดาวน์โหลดไฟล์แนบจริงได้
ผลที่เกิดจริงยังเป็นข้อมูล mock · กดเปิดไฟล์ไม่ขึ้น/เปิดไม่ได้
BUG-04view drawer คลังผู้สมัคร มีปุ่มย้อนกลับ/ถัดไปที่ footer ซึ่งไม่มีใน designMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด view drawer ของผู้สมัคร (tab คลังผู้สมัคร)
  2. ดูที่ footer ของ drawer
ผลที่ควรเป็นตาม design (FRD §1.2 D-01 + prototype) ไม่มีปุ่มย้อนกลับ/ถัดไปใน footer ของ view drawer — ปุ่มเลื่อนสถานะอยู่ที่บอร์ด (P-03) เท่านั้น
ผลที่เกิดจริงมีปุ่มย้อนกลับ/ถัดไปโผล่ที่ footer drawer โดยไม่มีในแบบ
BUG-05column เลขที่ / ตำแหน่ง / ผู้สมัคร แสดงผล layout แปลกLowรอแก้
ขั้นตอนทำซ้ำ
  1. เข้าหน้ารายการ
  2. ดู column เลขที่ / ตำแหน่ง / ผู้สมัคร
ผลที่ควรเป็นข้อมูลจัดวางเรียบร้อย 1 ช่อง 1 บรรทัด ตรงหัว column
ผลที่เกิดจริงlayout/ข้อมูลที่แสดงผลดูแปลก (จัดวางไม่ตรง)
BUG-06Timeline ในลิ้นชัก (drawer) จัดวางเพี้ยนLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด view drawer ที่มี timeline (เช่น approval timeline / offer status / ประวัติ)
  2. ดูการจัดวาง timeline
ผลที่ควรเป็นtimeline จัดวางเรียบร้อย เส้น/จุด/ข้อความตรงแนว
ผลที่เกิดจริงlayout timeline เพี้ยน
BUG-07Tab ในลิ้นชัก (drawer) จัดวางเพี้ยนLowรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด view drawer (4 tab: รายละเอียด/สัมภาษณ์-ประเมิน/ข้อเสนอ/ประวัติ)
  2. ดูแถบ tab
ผลที่ควรเป็นแถบ tab จัดวางเรียบร้อย
ผลที่เกิดจริงlayout tab เพี้ยน
