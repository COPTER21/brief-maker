## §4.3 Relationships (ER Diagram)
```
T_osw_request 1──N T_osw_line
T_osw_request 1──N T_osw_attachment ──▶ Document Center (file_id)
T_osw_request 1──N T_osw_audit
T_osw_request N──1 T_employee (employee_id) · N──1 T_org_unit (org_unit_id)
T_osw_request 0..1──1 T_osw_request (copy_of)
DOA engine ──(doa_ref)──▶ T_osw_request · ENG-DOC-STORE ──(pdf_store_ref)──▶ T_osw_request
```
Indexes: `(tenant_id, status, req_date desc)` · `(tenant_id, employee_id)` · `(tenant_id, org_unit_id)` · `(tenant_id, osw_no) unique` · `T_osw_line(request_id, line_no)` · GIN `approval_chain` (หา assignee ขั้นปัจจุบัน — หรือคอลัมน์ `current_assignee` materialized ถ้า perf ต้องการ)

## §4.6 Data Classification & Sensitive Data
### §4.6.1 Classification Levels (CUBE 4.0 Standard)
| Level | นิยาม | ใน feature นี้ |
|---|---|---|
| Public | เผยแพร่ภายนอก | ไม่มี |
| Internal | คนในบริษัท (default) | สถานะ · วันที่ · ลักษณะ · ตำแหน่ง/ฝ่าย · audit |
| Confidential | จำกัด role | ชื่อผู้ขอ · เพื่อ (ที่อยู่ระหว่างปฏิบัติงาน) · ยอดเบี้ยเลี้ยง · actor_name |
| Restricted | ACL รายบุคคล | ไม่มี |
### §4.6.2 Default Rule
Default = Internal · ไม่มี Public
### §4.6.3 Enforcement Mapping
| Classification | DB | API | UI | Audit |
|---|---|---|---|---|
| Internal | RLS tenant | JWT | — | mutation |
| Confidential | RLS + row scope ตาม BR-OSW-19 (เจ้าของ / ผู้พิจารณาในสาย / HR) | role/scope check ทุก read (API-01/02/10/11) | ไม่แสดงใบที่ไม่มีสิทธิ์ (ไม่ใช่ mask — ทั้งแถวไม่มา) | view (PDF/export) + mutation |
### §4.6.4 PII Overlay
PII = `employee_id`, `employee_name`, `purpose`, `actor_name` → PDPA scope · encrypt at rest ตาม platform
### §4.6.5 Security Bible Domain Mapping
D7 PII → 4 fields ข้างบน · D9 Audit → T_osw_audit ทุก transition · D17 → RLS ทุกตาราง · D5 → ไม่ trigger (ยอดอ้างอิง ไม่ลงบัญชี — แต่ per_diem_amount = Confidential)
### §4.6.6 Linkage with Policy Center
classification ทั้งหมด register ที่ Data Classification module · ไม่มี Restricted → ไม่ต้อง wire Restricted Resources · PII → PDPA consent scope (ข้อมูลพนักงานภายใต้สัญญาจ้าง)

## §4.7 Data Retention
