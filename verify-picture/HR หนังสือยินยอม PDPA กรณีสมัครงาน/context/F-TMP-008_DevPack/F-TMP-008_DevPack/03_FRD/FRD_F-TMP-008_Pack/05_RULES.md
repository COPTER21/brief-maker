## §5.2 State Machine
| จาก | เหตุการณ์ | ไป | เงื่อนไข |
|---|---|---|---|
| (ไม่มี) | สร้างร่าง | draft | ออกเลขที่ (FN-03) |
| draft | ยืนยันความยินยอม | confirmed | เลือกครบทุกข้อ · ไม่มีขั้น DOA |
| draft | ยืนยันความยินยอม | pending | มีขั้น DOA ที่ตั้งไว้ |
| draft | ยกเลิก | cancelled | เหตุผลบังคับ |
| pending | รับหนังสือครบทุกขั้น | confirmed | |
| pending | ไม่รับหนังสือ | rejected | เหตุผลบังคับ |
| pending | ยกเลิก | cancelled | เจ้าของข้อมูลหรือผู้ดูแล |
| confirmed | ถอนความยินยอม | withdrawn | ขอบเขต + เหตุผล (BR-03) |

## §5.3 Permission Matrix
| Action | เจ้าของข้อมูล | ผู้พิจารณาขั้นปัจจุบัน | ผู้ดูแลงานบุคคล | ผู้กำกับดูแล | อื่น ๆ |
|---|---|---|---|---|---|
| เห็นรายการ/ใบ | เฉพาะของตัวเอง | เฉพาะใบที่ยืนยันแล้วและตนอยู่ในสาย | ทั้งหมดในหน่วยงาน | อ่านอย่างเดียว | ไม่เห็น |
| เห็นร่างของผู้อื่น | ✗ | ✗ | ✗ (ร่างของผู้อื่นไม่ปรากฏ) | ✗ | ✗ |
| สร้าง/แก้ไขร่าง | เฉพาะร่างของตัวเอง | ✗ | ✗ | ✗ | ✗ |
| ยืนยันความยินยอม | ✓ | ✗ | ✗ (BR-06) | ✗ | ✗ |
| พิจารณาตามขั้น | ✗ (BR-DOA-04) | ✓ | ตามที่ตั้งใน DOA | ✗ | ✗ |
| ถอนความยินยอม | ✓ | ✗ | ✓ (ตามคำขอ) | ✗ | ✗ |
| ยกเลิกเอกสาร | ✓ (ยังไม่มีผล) | ✗ | ✓ | ✗ | ✗ |
| พิมพ์ / ดาวน์โหลด PDF | ✓ ของตัวเอง | ใบที่ตนอยู่ในสาย | ✓ | ✓ | ✗ |
| ส่งออก CSV | ✗ | ✗ | ✓ | ✓ | ✗ |

> หมายเหตุ: ผู้ดูแลงานบุคคลเห็นใบที่ยืนยันแล้วทั้งหมด แต่ **ร่าง**ยังเป็นของเจ้าของข้อมูลจนกว่าจะยืนยัน (ตาม DEC-08 ที่กำหนดให้ผู้พิจารณาเห็นหลังส่งเท่านั้น) — การตั้งค่าว่าผู้ดูแลเห็นร่างด้วยหรือไม่ รอลูกค้ายืนยัน (OQ-02)

## §5.4 Validation
| VR | กฎ | ข้อความ |
|---|---|---|
| VR-01 | ต้องเลือกครบทุกข้อก่อนยืนยัน | "ต้องเลือกความยินยอมให้ครบทุกข้อ" |
| VR-02 | เลือกได้ข้อละหนึ่งค่า | (UI บังคับเป็นปุ่มสองทาง เลือกใหม่ทับค่าเดิม) |
| VR-03 | ถอนความยินยอมต้องเลือกขอบเขตอย่างน้อยหนึ่งข้อ | "กรุณาเลือกอย่างน้อย 1 ข้อที่ต้องการถอน" |
| VR-04 | ถอน/ยกเลิก/ไม่รับหนังสือ ต้องมีเหตุผล | "กรุณาระบุเหตุผล" |
| VR-05 | ไฟล์แนบตาม file_policy (ชนิด/ขนาด) | "ชนิดไฟล์ไม่รองรับ" · "ไฟล์ใหญ่เกินกำหนด (สูงสุด 20 MB)" |
| VR-06 | ขอบเขตการเปิดเผยของข้อสุดท้ายต้องไม่อ้างถึงตัวเอง | ตรวจตอนตั้งค่า master · DEC-11 · OQ-05 |

## §5.5 Edge Cases
| EC | กรณี | ผล |
|---|---|---|
| EC-01 | ยืนยันทั้งที่เลือกไม่ครบ | บล็อก + ชี้ข้อที่ยังไม่เลือก (VR-01) |
| EC-02 | ไม่ยินยอมข้อมูลอ่อนไหว | บันทึกได้ + เตือนผลต่อกระบวนการ + ยิง `pdc_sensitive_refused` |
| EC-03 | ถอนซ้ำข้อเดิม | ไม่สร้างรายการใหม่ ใช้บันทึกเดิม |
| EC-04 | ออกฉบับใหม่ของหนังสือ | ใบเดิมคงถ้อยคำเดิม (snapshot) · ใบใหม่ใช้ถ้อยคำใหม่ |
| EC-05 | ผู้สมัครงานยังไม่มีระเบียนในระบบ | `data_subject_id` ว่าง ใช้ชื่อที่กรอก (OQ-01) |
| EC-06 | ผู้ดูแลพยายามยืนยันแทนเจ้าของข้อมูล | ปฏิเสธ 403 NOT_OWNER (BR-06) |
| EC-07 | แนบไฟล์ผิดชนิด/ใหญ่เกิน | ปฏิเสธพร้อมบอกเหตุผล (VR-05) |
| EC-08 | ใบถูกแก้โดยผู้อื่นระหว่างทำรายการ | 409 STALE — ให้รีเฟรชแล้วทำใหม่ |

## §5.7 Security
- `pdpa_consent_line.choice` ของข้อที่ `is_sensitive` = **Restricted** (PDPA ม.26 · DEC-15) — จำกัดผู้เห็นตาม §5.3 และบันทึก audit ทุกการเข้าดู/ส่งออก
- ชื่อเจ้าของข้อมูลและเหตุผลการถอนเป็น PII — mask ใน log
- สำเนา PDF ที่เก็บเป็นหลักฐานแก้ไขไม่ได้ ผูกกับ `form_revision`
- ห้ามใช้ข้อมูลบุคคลจริงจากไฟล์ลูกค้าเป็นข้อมูลตัวอย่างใน prototype/แบบพิมพ์
