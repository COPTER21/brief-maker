**Constraints:** PK(id) · UNIQUE(tenant_id, crop_id) · CHECK status IN(5) · CHECK production_year_be BETWEEN 2500 AND 2600 · CHECK planted_month BETWEEN 1 AND 12 · CHECK total_tons >= 0
**Indexes:** IDX_crop_tenant_status · IDX_crop_quota · IDX_crop_plot · IDX_crop_year · IDX_crop_search(trigram crop_id/farmer) · IDX_crop_remaining_neg (partial WHERE remaining<0)
**RLS:** tenant_id = current_setting('app.current_tenant')

## §4.9 Notes
- quota_id + plot_id เก็บ + snapshot denormalized (farmer/address/size) กัน source เปลี่ยน · READ-ONLY ทั้งคู่
- remaining computed (ไม่เก็บ authoritative — คิดจาก ETCD ตอน serve; cache สั้นได้) · negative badge
- cancelled/deleted = soft (ตัดจาก list default; filter ดูได้)
- `plant_age_months` = derived read-only (FN-AT-CROP-192): gregorian_year = production_year_be − 543 · นับเดือนจากวันแรกของ planted_month ถึงวันนี้ (floor ≥ 0) · ไม่รับ input จากผู้ใช้
- `geo_lat`/`geo_long` (2 ช่องแยก) = prototype เก็บละเอียดกว่า authoritative single `geo_coordinate` "lat,long" · functionally equivalent (map → geo_coordinate บน API/DB contract)
