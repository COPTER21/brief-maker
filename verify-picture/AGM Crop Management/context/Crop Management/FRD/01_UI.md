## §1.2 OV-01 Create (drawer) — double-binding cascade ⭐
```
Section 0 · เลือกโควตาและแปลง (บังคับก่อนกรอก):
  0a search-select "ค้นหาเลขโควตา (Quota Id) — exact" → verified เท่านั้น · ไม่พบ/ไม่ verified → "ไม่พบ Quota หรือสถานะไม่เป็น verified"
     → พบ → farmer owner snapshot card (read-only)
  0b select "เลือกแปลง (ของเจ้าของโควตา · verified)" — โหลดหลังเลือก quota · owner mismatch → block
     → เลือก → plot snapshot card (ที่อยู่ + ขนาดไร่ read-only)
Section 1 · ข้อมูลรอบปลูก: ปีผลิต(พ.ศ. 2500-2600) · เดือนที่ปลูก(1-12 select) · ปริมาณรวม(ตัน ≥0) · รหัสแปลง(text optional)
Section 1b · ลักษณะอ้อย (optional):
  - สายพันธุ์ (variety) select: ขอนแก่น 3 / LK 92-11 / UT 8 (→ cane_variety)
  - ประเภทอ้อย (cane_type) select: อ้อยใหม่ / อ้อยตอ
  - อายุอ้อย (เดือน) — **derived read-only** คำนวณอัตโนมัติจาก เดือนที่ปลูก + ปีผลิต (FN-AT-CROP-192)
  - พบโรค/ศัตรูพืช (found_disease_insect) select: ไม่พบ / พบ (→ disease_pest_found)
  - รายละเอียดโรค/ศัตรูพืช (disease_details) textarea optional
Section 2 · ตำแหน่ง (optional): พิกัด(lat,long — prototype 2 ช่องแยก) · รหัสไปรษณีย์(5 หลัก)
Section 3 · รูปแปลง/หลักฐาน: photos[] upload หลายไฟล์ (ชนิด/ขนาดตาม policy)
Footer: ยกเลิก · ยืนยันสร้าง
```
Fields ล็อกจนครบ quota+plot (LOCK-03)

## §1.5 OV-03 Verify/Reject (modal, single/bulk)
radio ผลตรวจสอบ: ยืนยัน(verified) / ปฏิเสธ(rejected) · ปฏิเสธ → reason textarea **บังคับ** ("กรุณาระบุเหตุผลในการปฏิเสธ...") · ยืนยัน → note optional ("หมายเหตุเพิ่มเติม (ไม่บังคับ)") · bulk → "ยืนยัน/ปฏิเสธ N รายการ" + skip non-eligible · Confirm/ยกเลิก

## §1.6 OV-04 Cancel/Delete (modal danger)
radio: ยกเลิก(cancelled) / ลบ(deleted) · เหตุผล **บังคับ** · warn soft delete · Confirm/ยกเลิก

## §1.7 OV-05 CSV Upload (wizard)
Step Upload(.csv, schema=create) → Validate(per-row quota/plot verified + field) → Confirm(per-row idempotent) → Report(success/fail + download) · ทุกแถว waiting_for_verify
CSV schema = **8 คอลัมน์ (ลำดับเป๊ะ):** `quota_id, plot_id, production_year_be, plot_code, variety, cane_type, planted_month, total_tons` (เดิม 5 · `year_be`→`production_year_be`)
