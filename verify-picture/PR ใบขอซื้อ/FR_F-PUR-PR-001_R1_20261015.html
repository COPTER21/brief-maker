1Logic — ทำงานถูกตามกฎธุรกิจ

เทียบผลจริงกับ FRD / Test Case — ข้อที่ไม่ผ่านต้องผูกกับ Bug ในข้อ 4

#กฎ / Scenarioผลที่คาดหวังผลจริงผลอ้างอิง
L-01สร้างใบขอซื้อ (Create)สามารถสร้างใบขอซื้อและบันทึกข้อมูลตาม flow ที่กำหนดตรงตามคาดผ่านFRD 03_LOGIC FN-03 · 06_TESTS AT-01..AT-05
L-02แก้ไขใบขอซื้อ (Update)สามารถแก้ไขใบขอซื้อในสถานะที่อนุญาตและบันทึกผลได้ถูกต้องตรงตามคาดผ่านFRD 03_LOGIC FN-06 · 05_RULES BR-04
L-03ลบ/ยกเลิกใบขอซื้อ (Delete/Cancel)ระบบดำเนินการลบหรือยกเลิกตาม flow และสถานะที่กำหนดตรงตามคาดผ่านFRD 03_LOGIC FN-14 · 05_RULES State Transition
L-04V-01 ช่องข้อมูลหัวเอกสารบังคับกรอกข้อมูลไม่ครบต้องไปต่อไม่ได้ตรงตามคาดผ่านFRD 05_RULES V-01
L-05V-02 วันที่ต้องการใช้ต้องไม่ก่อนวันที่เอกสารวันที่ไม่ถูกต้องต้องถูก blockตรงตามคาดผ่านFRD 05_RULES V-02
L-06V-03 ต้องมีอย่างน้อยหนึ่งรายการที่ข้อมูลครบไม่มีรายการที่ใช้ได้ต้องไปต่อไม่ได้ตรงตามคาดผ่านFRD 05_RULES V-03
L-07V-04 ห้ามมีแถวรายการว่างมีแถวว่างต้องไปต่อไม่ได้ตรงตามคาดผ่านFRD 05_RULES V-04
L-08V-05 ห้ามสินค้าและหน่วยซ้ำกันเพิ่มสินค้าชนิดเดียวกันและหน่วยเดียวกัน 2 แถวแล้วต้องไปต่อไม่ได้ระบบยอมให้ไปต่อ โดยนำสินค้าชนิดเดียวกันและหน่วยเดียวกันทั้ง 2 แถวมาคิดรวมกัน แทนการ block ให้รวมเป็นแถวเดียวไม่ผ่านBUG-01
L-09V-06 ชนิดและขนาดไฟล์แนบไฟล์ผิดเงื่อนไขต้องถูกปฏิเสธโดยไม่กระทบไฟล์อื่นตรงตามคาดผ่านFRD 05_RULES V-06
L-10V-07 เหตุผลไม่อนุมัติต้องมีอย่างน้อย 3 ตัวอักษรไม่อนุมัติโดยไม่มีเหตุผลหรือเหตุผลสั้นเกินไปไม่ได้ตรงตามคาดผ่านFRD 05_RULES V-07
L-11V-07 เหตุผลยกเลิกต้องมีอย่างน้อย 3 ตัวอักษรหน้าต่างยกเลิกต้องมีช่องกรอกเหตุผลและยืนยันไม่ได้จนกว่าจะกรอกครบCancel ไม่มีช่องให้กรอกเหตุผลไม่ผ่านBUG-02
L-12V-08 ต้องเลือกผู้อนุมัติครบทุกขั้นก่อนส่งเลือกผู้อนุมัติไม่ครบต้องส่งไม่ได้ตรงตามคาดผ่านFRD 05_RULES V-08
L-13V-09 ขอบเขตส่วนลดส่วนลดเกินขอบเขตต้องไม่ทำให้ยอดติดลบตรงตามคาดผ่านFRD 05_RULES V-09
L-14EC-01 รายการนอกทะเบียนสินค้าสามารถพิมพ์ชื่อรายการเองและบันทึกได้ตรงตามคาดผ่านFRD 05_RULES EC-01
L-15EC-02 ไม่ระบุศูนย์ต้นทุนข้ามการตรวจงบและไม่ถือเป็นข้อผิดพลาดตรงตามคาดผ่านFRD 05_RULES EC-02
L-16EC-03 เรียกคืนหลังมีผู้อนุมัติบางขั้นลายเซ็นเดิมเป็น void แต่ประวัติยังอยู่—ไม่ได้ตรวจFRD 05_RULES EC-03
L-17EC-04 ยกเลิกใบที่อนุมัติแล้วยกเลิกตามเงื่อนไขและบันทึกเหตุผล—ไม่ได้ตรวจFRD 05_RULES EC-04
L-18EC-05 ไฟล์แนบผิดเงื่อนไขหนึ่งไฟล์ปฏิเสธเฉพาะไฟล์ที่ผิดและไฟล์อื่นยังอยู่ครบตรงตามคาดผ่านFRD 05_RULES EC-05
L-19EC-06 ผู้ไม่มีสิทธิ์เปิดดูเอกสารผู้ไม่มีสิทธิ์ต้องเปิดเอกสารไม่ได้—ไม่ได้ตรวจFRD 05_RULES EC-06
L-20EC-07 งบไม่พอเตือนแต่ไม่ block การส่งอนุมัติ—ไม่ได้ตรวจFRD 05_RULES EC-07
L-21Technical/Error Edgeทำงานตาม error catalog และ concurrency rules—ไม่ได้ตรวจFRD 06_TESTS AT-31..AT-36
L-22Calculation Edgeคำนวณยอด ส่วนลด VAT WHT และการปัดเศษตาม ENG-PR-CALC—ไม่ได้ตรวจFRD 03_LOGIC ENG-PR-CALC · 06_TESTS AT-28..AT-29
L-23Integration และ audit trailเลขเอกสาร การแจ้งเตือน สำเนา PDF และประวัติทำงานตาม FRD—ไม่ได้ตรวจFRD 06_TESTS XT-04..XT-06

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-01รายการสินค้าและหน่วยซ้ำถูกนำไปคิดรวมและผ่านต่อ แทนการ block ตาม FRDMediumรอแก้
ขั้นตอนทำซ้ำ
  1. สร้างหรือแก้ไขใบขอซื้อ
  2. เพิ่มสินค้าชนิดเดียวกันและเลือกหน่วยเดียวกัน 2 แถว
  3. กดถัดไป
ผลที่ควรเป็นระบบต้องไม่ให้ไปต่อและแจ้งให้รวมสินค้าและหน่วยที่ซ้ำเป็นแถวเดียว
ผลที่เกิดจริงระบบยอมให้ไปขั้นถัดไปและนำยอดของรายการซ้ำทั้ง 2 แถวมาคิดรวมกัน
BUG-02การ Cancel ไม่มีช่องให้กรอกเหตุผลMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดใบขอซื้อที่มีคำสั่ง Cancel
  2. กด Cancel
ผลที่ควรเป็นแสดงช่องกรอกเหตุผลและปิดปุ่มยืนยันจนกว่าจะกรอกอย่างน้อย 3 ตัวอักษร
ผลที่เกิดจริงไม่มีช่องให้กรอกเหตุผล
