## §5.2 State Machine
draft →(ส่ง)→ pending[1..N] →(รับทราบ/อนุมัติขั้น N)→ approved · pending →(ส่งกลับ)→ draft · draft/pending →(ยกเลิก)→ cancelled · approved = ล็อก

## §5.4 Validation
| VR | ช่อง | เงื่อนไข | ข้อความ |
|---|---|---|---|
| VR-01 | project_name · sender_name · receiver_name · package_version · handover_result | required | กรุณากรอกชื่อโครงการ · กรุณากรอกผู้ส่งมอบ · กรุณากรอกผู้รับมอบ · กรุณากรอกฉบับชุดเอกสาร · กรุณาเลือกผลการรับมอบ |
| VR-02 | handover_at | วันที่ required · เวลา HH:mm | กรุณาเลือกวันที่รับมอบ · กรุณากรอกเวลาแบบ HH:mm |
| VR-03 | items[].doc_name | required ต่อแถว | ลำดับ n: กรอก ชื่อเอกสาร |
| VR-04 | items[].completeness | ≠ complete เมื่อ received = no | ลำดับ n: ไม่ได้รับ เลือก ครบถ้วน ไม่ได้ (DEC-13) |
| VR-05 | items[].issue · fix_owner · due_date | required เมื่อแถวไม่ใช่ ได้รับ + ครบถ้วน | ลำดับ n: กรอก ประเด็นที่พบ · ผู้รับผิดชอบแก้ไข · กำหนดส่งเพิ่มเติม (DEC-14) |
| VR-06 | items[].due_date | ≥ วันที่รับมอบ | ลำดับ n: กำหนดส่งเพิ่มเติมต้องไม่ก่อนวันที่รับมอบ (DEC-16) |
| VR-07 | handover_result = full | ทุกแถวครบ | รับมอบครบถ้วน ต้องได้รับและครบถ้วนทุกรายการ (ค้าง n รายการ) (DEC-15) |
| VR-08 | open_issues · followup_schedule | required เมื่อ result = conditional | รับมอบแบบมีเงื่อนไข ต้องระบุประเด็นค้างจากการรับมอบ · รับมอบแบบมีเงื่อนไข ต้องระบุกำหนดการติดตาม |
| VR-09 | ivm_remark | required เมื่อ result = not_accepted | ยังไม่รับมอบ ต้องระบุหมายเหตุจากฝ่ายบริหารการลงทุน |
| VR-10 | items | ≥ 1 แถว | ต้องมีรายการเอกสารอย่างน้อย 1 รายการ |
| VR-11 | assignees | ทุกขั้น · ≠ ผู้จัดทำ | กรุณาเลือกผู้พิจารณา |
| VR-12 | reason (ส่งกลับ/ยกเลิก) | required | กรุณาระบุเหตุผล |

## §5.5 Edge Cases
