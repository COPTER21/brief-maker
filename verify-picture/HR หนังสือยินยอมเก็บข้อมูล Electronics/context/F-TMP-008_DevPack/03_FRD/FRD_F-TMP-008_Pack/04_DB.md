# 04_DB — F-TMP-008

## §4.1 Table Overview
| ตาราง | หน้าที่ |
|---|---|
| `pdpa_consent` | หัวใบหนังสือยินยอม 1 ฉบับ |
| `pdpa_consent_line` | ความยินยอมรายข้อ (snapshot ถ้อยคำจากฉบับ) |
| `pdpa_consent_withdrawal` | บันทึกการถอนความยินยอม |
| `pdpa_consent_audit` | ประวัติ append-only |
| `attachment` | ไฟล์แนบ (Document Center — อ้างอิง) |

## §4.6 Data Classification
| ระดับ | ที่ไหน | การบังคับ |
|---|---|---|
| Restricted | `pdpa_consent_line.choice` (ข้อที่ `is_sensitive`) | เห็นได้เฉพาะเจ้าของข้อมูลและ role ผู้ดูแลงานบุคคล/ผู้กำกับดูแล · ทุกการเข้าดูบันทึก audit · ไม่ส่งออกเป็นข้อความอธิบายใน CSV |
| Confidential · PII | `data_subject_name`, `data_subject_name_printed`, `withdrawal.reason` | mask ใน log · ห้ามใช้เป็นข้อมูลตัวอย่าง |
| Internal | ที่เหลือ | ตาม role ปกติ |

## §4.7 Retention
เก็บหลักฐานความยินยอมและการถอนตลอดอายุความสัมพันธ์ + ตามอายุความที่กฎหมายกำหนด · ห้ามลบใบที่ยืนยันแล้ว (ใช้สถานะแทน) · สำเนา PDF เก็บที่ ENG-DOC-STORE ตามนโยบายเดียวกัน — ระยะเวลาที่แน่นอนรอลูกค้ายืนยัน (OQ-02)
