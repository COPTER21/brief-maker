## §1.2 Per-Page Detail
### P-01 รายการ
- หัวเรื่อง + จำนวนฉบับ · ปุ่ม `ส่งออก CSV` · ปุ่ม `สร้างหนังสือยินยอม` (ปิดเมื่อแบบเอกสารยังไม่เปิดใช้ที่ F-DOCCFG)
- stats 3 ใบ: ทั้งหมด · ร่าง (ยังไม่ยืนยัน) · รอฉันพิจารณา
- filter: ค้นหา (เลขที่/เจ้าของข้อมูล/ฝ่าย) · สถานะ · ผลความยินยอม (ยินยอมครบ · มีข้อที่ไม่ยินยอม · ไม่ยินยอมข้อมูลอ่อนไหว) · ฝ่าย
- ตาราง: เลขที่ · วันที่ให้ความยินยอม · เจ้าของข้อมูล · ฝ่าย · ยินยอม n/N · ข้อมูลอ่อนไหว · สถานะเอกสาร · ลายเซ็น · ⋮ (แก้ไข[ร่าง] · พิมพ์ · ถอนความยินยอม · ยกเลิกเอกสาร)
- empty state แยกกรณี "ยังไม่มีหนังสือยินยอม" กับ "ไม่พบรายการที่ค้นหา"

### P-02 สร้าง/แก้ไข (ขั้น 1 ข้อมูลหลักหนังสือยินยอม)
- ซ้าย การ์ด ① ความยินยอมรายข้อ — ต่อข้อ: ลำดับ · ป้ายข้อมูลส่วนบุคคล (`line.data_label`) · วัตถุประสงค์ (`line.purpose`) · ป้าย "ข้อมูลอ่อนไหว (ม.26)" เมื่อ `line.is_sensitive` · ปุ่มเลือก `consent` / `refuse`
- ปุ่มช่วย: เลือกยินยอมทั้งหมด · ล้างที่เลือก
- การ์ด ② ข้อความที่ท่านรับทราบ — ถ้อยคำกฎหมายคัดตรงตัวจากฉบับ (อ่านอย่างเดียว)
- ขวา การ์ดสรุปสด: เจ้าของข้อมูล (`consent.data_subject_name` จากระบบ) · ฉบับของหนังสือ · วันที่ให้ความยินยอม (`consent.consented_at` ระบบใส่ตอนยืนยัน) · เลือกแล้ว n/N · ไม่ยินยอมข้อมูลอ่อนไหว
- ขั้น 2 เอกสารแนบ (upload-zone + รายการไฟล์) · ขั้น 3 ตรวจสอบและยืนยัน (สรุป + ตารางผลรายข้อ + ไฟล์แนบ)
- footer: ย้อนกลับ · ยกเลิก · ถัดไป / บันทึกแบบร่าง + บันทึกและยืนยันความยินยอม

### P-03 ดู
- หัว: เลขที่ · สถานะ · ยินยอม n/N · ชื่อเจ้าของข้อมูล · ฉบับของหนังสือ · วันที่ให้ความยินยอม
- แท็บ `รายละเอียด`: แบนเนอร์ตามสถานะ · ข้อมูลเอกสาร · เจ้าของข้อมูล · ความยินยอมรายข้อ · สรุปผล · เอกสารแนบ · นโยบายความเป็นส่วนตัว · ข้อมูลระบบ
- แท็บ `PDF Preview` · แท็บ `ลายเซ็น / อนุมัติ` (ลำดับการลงนาม + ขั้น DOA ถ้ามี + บันทึกการถอน) · แท็บ `ประวัติ`
- ปุ่มตามสถานะ: ร่าง = ยกเลิก · แก้ไข · ยืนยันความยินยอม / ยินยอมแล้ว = ถอนความยินยอม

## §1.3 Journey
สร้าง → เลือกครบทุกข้อ → ยืนยัน → ยินยอมแล้ว → (ถ้าใช้สิทธิ) ถอนความยินยอม
### Branch
- ยังเลือกไม่ครบ → บันทึกแบบร่าง (ยังไม่มีผล)
- ลูกค้าเพิ่มขั้นพิจารณาที่ DOA กลาง → หลังยืนยันจะเข้าสถานะ "รอพิจารณา" ตามจำนวนขั้น

## §1.4 COSO Touchpoints
ยืนยันความยินยอม (เจ้าของข้อมูลเท่านั้น) · ถอนความยินยอม (บันทึกผู้ทำและเหตุผล) · ยกเลิกเอกสาร (เหตุผลบังคับ) · ส่งออก CSV (บันทึก audit)

## §1.5 Notifications
`pdc_consent_recorded` · `pdc_consent_withdrawn` · `pdc_sensitive_refused` (ดู NTF_BRIEF_F-TMP-008.md · 05_RULES §5.8)

## §1.6 Empty/Error
- ยังไม่มีหนังสือยินยอม / ไม่พบรายการที่ค้นหา
- เลือกไม่ครบ → ชี้ข้อที่ยังไม่เลือก + toast "ต้องเลือกความยินยอมให้ครบทุกข้อ"
- ถอนความยินยอมโดยไม่เลือกข้อ/ไม่ใส่เหตุผล → บล็อกพร้อมข้อความในฟอร์ม
- แบบเอกสารยังไม่เปิดใช้งาน → แถบแดง + ปุ่มสร้างถูกปิด
