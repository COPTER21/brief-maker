## §1.4 P-02 All-in-One Payment Modal ⭐
Header: id + เกษตรกร + net_tons + ประเภทอ้อย. **3 tabs**: `งวดที่ 1` · `งวดที่ 2` · `โปรโมชัน` (แสดงเฉพาะมีโปร).

### §1.4.1 Step-by-step calc section (ต่องวด — ตายตัว 7 ขั้น)
```
1 มูลค่าอ้อย            price_per_ton = base@10CCS × [1+(CCS−10)×K] · cane_total_base = net_tons × price_per_ton
2 ปรับประเภทอ้อย        cane_type_adj = net_tons × adj_price_per_ton (±) → cane_total_adjusted (หลัง CCS ก่อนแบ่งงวด)
  แบ่งงวด               inst_amount = cane_total_adjusted × inst_percent (50/50)
3 VAT / ภาษี            amount_tax_total = base × vatRate/100 · after_tax = base − tax
4 Additional charges    config (read-only) + manual (เพิ่ม/ลบ) · FLAT → per_unit · PER_TON → per_unit × net_tons_inst · before_debt = after_tax − Σ
5 หักหนี้               desired = before_debt × debt%/100 · actual = min(desired, outstanding) · after_debt
6 ดอกเบี้ย (บิลขาว)     daily_rate = interest%/100/base_days · days_early = max(0,ceil((normal−actual)/day)) · interest = after_debt × daily_rate × days_early · after_interest
7 ค่าธนาคาร (โอน)       branch province → in/out/unknown · after − bank_fee
= ยอดสุทธิ             amount_final = max(0, after_interest − bank_fee)
```
GREEN หรือ days_early=0 → บรรทัดดอกเบี้ยแสดง "ไม่คิดดอกเบี้ย". เงินสด/เช็ค → ค่าธนาคาร 0.

### §1.4.2 Payment method selector
`โอน` (TRANSFER) · `เงินสด` (CASH) · `เช็ค` (CHEQUE). เช็ค → กรอกเลขเช็ค (cheque_number). โอน + quota → ต้องมี bank_account (แสดง masked ****1234). แนบหลักฐาน = optional.

### §1.4.3 Auto-switch + สรุป
ยืนยันงวด 1 สำเร็จ → modal ไม่ปิด → **auto ไป tab งวด 2**. ล่างสุด: **สรุปยอดรวมทั้งหมด** (งวด1 + งวด2 + โปร) + ปุ่ม **[ยืนยันทำจ่ายทั้งหมด]** (all-in-one /confirm).

## §1.5 P-03 Detail Drawer
Tabs: `Summary` · `งวด 1` · `งวด 2` · `โปรโมชัน` · `Timeline`.
- Summary: header + ประเภทอ้อย + สถานะ + ยอดสุทธิรวม
- งวด 1/2: breakdown 7 ขั้น (read-only) + วิธีจ่าย + bank_fee_type + หลักฐานไฟล์ (ถ้ามี) + ใบเสร็จ
- โปรโมชัน: promo_rate_per_ton · promo_amount · วิธีจ่าย · สถานะ
- Timeline: ccs.synced · installment.paid · completed
- ปุ่มพิมพ์: [พิมพ์บิลงวด 1] [พิมพ์บิลงวด 2] [พิมพ์บิลโปรโมชัน] [พิมพ์ใบเสร็จการจ่ายเงินอ้อยรวม] (completed)
