## §5.2 State Machine
draft →(ส่ง)→ pending[1..N] →(อนุมัติขั้น N)→ approved · pending →(ส่งกลับ/ไม่อนุมัติ)→ draft · draft/pending →(ยกเลิก)→ cancelled · approved = ล็อก

## §5.3 Permission
| Action | owner | ผู้พิจารณาขั้นปัจจุบัน | ผู้ในสาย (ไม่ใช่ขั้นปัจจุบัน) | admin | อื่น |
|---|:-:|:-:|:-:|:-:|:-:|
| ดู | ✓ | ✓ (หลังส่ง) | ✓ (หลังส่ง) | ✓ | ✗ 404 |

| ตัดสิน | ✗ | ✓ | ✗ 403 | ✗ | ✗ |
| ยกเลิก | ✓ draft/pending | ✗ | ✗ | ✓ draft/pending | ✗ 403 |

## §5.4 Validation
| VR | ช่อง | เงื่อนไข | ข้อความ |
|---|---|---|---|
| VR-01 | project_name | required | กรุณากรอกชื่อโครงการ / ธุรกรรม (DEC-13) |
| VR-02 | items[].item · requestee · owner · due_date · status | required ต่อแถว | คำขอ {รหัส}: กรอก เอกสาร / ข้อมูลที่ขอ · ผู้ถูกขอข้อมูล · ผู้รับผิดชอบ · กำหนดส่ง |
| VR-03 | items[].request_date | required เมื่อ status ∈ {requested, partial, received} | สถานะ {ป้ายสถานะ} ต้องระบุวันที่ขอ (DEC-14) |
| VR-04 | items[].received_date | required เมื่อ status = received | สถานะ ได้รับครบ ต้องระบุวันที่ได้รับ (DEC-14) |
| VR-05 | items[].received_date | ว่างเมื่อ status = not_requested | สถานะ ยังไม่ขอ ต้องไม่มีวันที่ได้รับ (DEC-14) |
| VR-06 | items[].due_date | ≥ request_date | กำหนดส่งต้องไม่ก่อนวันที่ขอ (DEC-15) |
| VR-07 | items[].received_date | ≥ request_date | วันที่ได้รับต้องไม่ก่อนวันที่ขอ (DEC-15) |
| VR-08 | items[].remark | required เมื่อ status ∈ {not_applicable, cancelled} | สถานะ {ไม่เกี่ยวข้อง/ยกเลิก} ต้องระบุเหตุผลในหมายเหตุ (DEC-16) |
| VR-09 | items[].doc_link | URL หรือ path | ลิงก์เอกสารต้องเป็น path หรือ URL (DEC-17) |
| VR-10 | items[] | ≥ 1 แถว ตอนส่ง | ต้องมีรายการคำขออย่างน้อย 1 รายการก่อนส่ง |
| VR-11 | assignees | ทุกขั้น · ≠ ผู้จัดทำ | กรุณาเลือกผู้พิจารณา |
| VR-12 | reason (ส่งกลับ/ไม่อนุมัติ/ยกเลิก) | required | กรุณาระบุเหตุผล |
