## §1.4 P-02 Area Detail drawer (C · 4 tabs) 920px
Header: area_name + status pill + "อัปเดต: [date]" · actions [แก้ไข][เปิด/ปิดใช้งาน — guard][Export] (SA/Director)
Tabs:
- **Overview**: ข้อมูลพื้นที่ (ชื่อ/จังหวัด/อำเภอ/ตำบล/รหัสไปรษณีย์/สถานะ/ที่อยู่/คำอธิบาย + created/updated by) + สรุป (Area Heads / Extension Codes / เวอร์ชัน)
- **Area Heads**: table [ชื่อ-สกุล · Email · มอบหมายเมื่อ · ลบ] + เพิ่มหัวหน้าพื้นที่ · empty "ยังไม่มีหัวหน้าพื้นที่"
- **Extension Codes**: table [หมายเลขโค้ด · สถานะ(ว่าง/ใช้งานอยู่) · มอบหมายให้ · หมายเหตุ] · empty "ยังไม่มี Extension Codes ในพื้นที่นี้"
- **Audit**: timeline (action badge · actor_name · timestamp · details)

## §1.5 P-03 Roles (B · 3 sub-tabs) — tab "Roles" (SA/Director)
- **Directors**: search ERP + table [รหัส · ชื่อ-สกุล · Email · แผนก/ตำแหน่ง · มอบหมายเมื่อ · ลบ] + เพิ่ม Director + Export
- **Area Heads**: global view table (ชื่อ/email/พื้นที่/มอบหมายเมื่อ)
- **Extension Officers**: codes cross-area + filter (พื้นที่ + สถานะ EMPTY/OCCUPIED) + table [หมายเลขโค้ด · พื้นที่ · มอบหมายให้ · สถานะ · เปิด] + Create Code
