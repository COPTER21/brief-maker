## §4.2 T_agm_areas
| Column | Type | Note |
|---|---|---|
| `id`/`area_id` | uuid | unique |
| `tenant_id` | uuid | RLS |
| `area_name` | varchar | ค้นหา |
| `province_id`/`district_id`/`subdistrict_id` | fk | geography cascade (consistent) |
| `postal_code` | char(5) | `^\d{5}$` auto จากตำบล |
| `address_line`/`description` | text NULL | |
| `status` | varchar(8) | Active/Inactive |
| `heads_count`/`codes_count` | int | derived (cache) |
| `version` | int | optimistic |
| `created/updated_at/by` | audit | |

**Constraints:** CHECK status IN('Active','Inactive') · FK province/district/subdistrict consistent · Index(status)(province_id)(area_name) · RLS tenant_id

## §4.3 T_agm_extension_codes
| Column | Type | Note |
|---|---|---|
| `id`/`ext_code_id` | uuid | |
| `display_code` | char(4) | `^\d{4}$` |
| `area_id` | fk | area ต้อง Active ตอนสร้าง |

| `assigned_at`/`assigned_by` | ts/uuid NULL | |

| audit | created/updated_at/by | |

**Constraints:** UNIQUE(tenant_id, area_id, display_code) · CHECK status IN('EMPTY','OCCUPIED') · **CHECK: status='OCCUPIED' ⇒ assigned_employee_id NOT NULL** · Index(area_id)(status)(assigned_employee_id)

## §4.4 T_agm_area_heads / T_agm_directors
- **area_heads:** id, area_id_fk, employee_id, assigned_at, assigned_by · UNIQUE(area_id, employee_id)
- **directors:** id, employee_id, dept, title, assigned_at · UNIQUE(employee_id) · (global)
- employee ต้อง status=active ตอน add (join T_erp_employee)

## §4.5 T_agm_audit (append-only) ⭐
id, entity_type(area/ext_code/head/director), entity_id, action, actor_id, actor_name, timestamp, details, before_snapshot(jsonb), after_snapshot(jsonb) · **REVOKE UPDATE/DELETE**

## §4.6 Relationships
```
T_geo_* ──read──▶ T_agm_areas (province→district→subdistrict→postal)
T_erp_employee ──read──▶ area_heads/directors/ext_codes.assigned
T_agm_areas ──(1:N)──▶ T_agm_extension_codes · T_agm_area_heads · T_agm_audit
T_agm_areas ──scope──▶ Farmer(F-AGM-001)/Quota(F-AGM-002)  [area_id FK]
```
