## §7 Interaction Spec
- Esc chain (kit): ปิด search-select → modal → drawer ตามลำดับ handler
- backdrop ปิดด้วย `onmousedown` เมื่อ target = backdrop เท่านั้น (U25) — ลากจากในออกนอกไม่ปิด
- `render()` เก็บ/คืน scroll + focus (`preserveRenderState()`/`restoreRenderState()`) · ช่องข้อความ/คะแนนไม่เรียก `render()` — อัปเดตเฉพาะ `#wzSum` + `#wzCalc` (`softSum()`)
- ยกเลิกเลือกสินค้า/บริการ = ล้างช่องระบุ · ยกเลิก อื่นๆ = ล้างชื่อมาตรฐาน
- ส่งจากหน้าดูขณะคะแนนไม่ครบ → toast + เปิดแก้ไข (`openSubmit()`)
- PDF: `genPdf()` เปิดหน้าต่างพิมพ์จาก iframe ซ่อน `.pdf-gen` (ชื่อ = เลขที่)
