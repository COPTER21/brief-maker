## §7.2 Locked Decisions ของเลนนี้ (LD-NN)

### **LD-01** · ไม่ออกใบประกาศ DOA / NTF / pdfdoc — **ไม่ใช่การตกหล่น**

| ใบ | เหตุผลที่ไม่ออก |
|---|---|
| `DOA_BRIEF` | **Putaway ไม่มีสายอนุมัติเลย** — เป็นงาน execution · "ยืนยันจัดเก็บ" คือการบันทึกว่างานเสร็จ ไม่ใช่การอนุมัติ · registry F081 ไม่ติดชิป `doa` · state machine ไม่มีสถานะ "รออนุมัติ" |
| `NTF_BRIEF` | registry ไม่ติดชิป `ntf` รอบนี้ · ถ้าอนาคตต้องเตือน "งานค้างเกินเกณฑ์" **ให้ไปประกาศที่ ENG-NOTIFY ห้าม hardcode ในฟีเจอร์** (`CSQ-Q4` ตัดสินชั่วคราวว่าเป็น KPI + NC rules เท่านั้น) |
| print spec / `pdfdoc` | **ไม่มีใบพิมพ์** — ไม่ใช่เอกสาร · `static_scan.a4 = false` |

**ล็อกเพราะ:** ผู้อ่านแพ็กที่เคยเห็น F-PUR-PR/F-PUR-PO (ครบ 5 ใบ) จะสงสัยว่าตกหล่น — **ไม่ตก · เป็นเจตนา**

### **LD-02** · `PT-<seq>` เป็นรหัสภายใน ไม่ใช่เลขที่เอกสาร

**ล็อกว่า:** แสดงได้เฉพาะในแถว meta ขนาดเล็กของหัวงาน · **ห้ามย้ายขึ้นเป็นหัวเรื่อง ห้ามผูก `F-DOCCFG` ห้ามมีรูปแบบเลขรันที่ตั้งค่าได้**
**เหตุผล:** ทันทีที่มันดูเหมือนเลขที่ใบ ฟีเจอร์จะกลายเป็นเอกสาร → ชน L1/L3 และต้องออก DOCCFG brief ที่ chip ห้าม

### **LD-03** ★ · HTML ถูกแก้ 2 บรรทัด — **ไม่ byte-identical กับต้นน้ำอีกต่อไป**

| | |
|---|---|
| แก้อะไร | ถอด marker `FWD-WIRE:` ออกจาก **ข้อความที่ผู้ใช้เห็น** 2 จุด — บรรทัด **2561** (คำเตือนคิวกักกัน) และ **2584** (ป้ายไม่กระทบบัญชีในแถบยืนยัน) · marker ย้ายไปเป็น **JS comment ท้ายบรรทัดเดิม** |

| อำนาจที่ใช้ | **HANDOFF §5** คอลัมน์ "ทำได้เลย (ไม่ต้อง re-gate business)" แถว *"ปรับถ้อยคำ microcopy · ป้าย · ข้อความ empty state"* **+ อนุมัติจากผู้ใช้ 2026-09-14** |
| กระทบ L1–L10 ไหม | **ไม่กระทบข้อใดเลย** — อยู่ใต้ `END BASE-KIT UTILS` (L9 ปลอดภัย) · ไม่แตะตรรกะ ไม่แตะ location model |
