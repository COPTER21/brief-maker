## §5.5 ผลกระทบ 7C (CSQ)

> ใบประกาศเต็ม: **`CSQ_BRIEF_F-WH-PUTAWAY-001.md`** — ไฟล์นี้สรุปเฉพาะข้อผูกพันกับโค้ด

### §5.5.1 event ที่ประกาศ — **2 ตัวเท่านั้น**

| # | event | ท่อ | ยิงเมื่อ | กติกา |
|---|---|---|---|---|
| 1 | `putaway_forced_override` | **EC** | ยืนยันจัดเก็บ · **เฉพาะแถวปลายทางที่ `violation_kind ≠ null`** (R11/R15) | `basis: declared` (qty-only) · **ห้ามใส่ตัวเลขเงิน** · ส่ง `violation_kind` เพื่อให้ engine แยกชนิดต้นทุนแฝง |
| 2 | `putaway_reversed` | **EC** | กลับรายการจัดเก็บ (R17) | **ต้องมี `reversal_of` เสมอ** (BR-CSQ-04) · หัวหน้าคลัง + เหตุผลบังคับ · **ห้ามลบ/แก้ผลเดิม** |

`idempotency_key` **unique ต่อ (feature, task_id, to_bin_ref, action)** — **ต้องมี bin ในคีย์** เพราะ 1 งานเก็บได้หลายช่อง (BR-CSQ-02 · DR-09)

### §5.5.2 ท่อที่ **ไม่** ประกาศ + เหตุผล (สำคัญเท่ากับที่ประกาศ)

| ท่อ | เหตุผลที่ไม่ประกาศ |
|---|---|
| **OC** | เจ้าของคือ Operation Process (`sow.*`) — ประกาศ = **reject 422** |
| **DC** | **ไม่มีสายอนุมัติเลย** · "ยืนยันจัดเก็บ" ไม่ใช่ terminal decision |
| **SC** | สงวนไว้ `trigger = false` เสมอ |
| **SecC** | ไม่แตะข้อมูลอ่อนไหว/สิทธิ์/นโยบาย — master ทุกตัวเป็น soft-ref อ่านอย่างเดียว (R23) |
| **AC** | ย้ายภายในคลังเดียวกัน → ไม่เกิดรายการบัญชี · **`grn_posted` ตั้ง GR/IR ไปแล้ว** → ยิงอีก = นับซ้ำ · กรณีข้ามเขตตีมูลค่า → `CSQ-Q3` / `OQ-PUT-08` |
| **FC** | **ใบสั่งซื้อเป็นเจ้าของวงจร commitment ทั้งหมด** — putaway ไม่แตะเงินสด/งบ |
| **EC จากการจัดเก็บปกติ** (`putaway_confirmed`) | ★ **มูลค่าของก้อนนี้ถูก `grn_posted` ประกาศ EC ไปแล้ว** — ประกาศอีก = **นับซ้ำทั้งก้อน** → `CSQ-Q1` |
| **EC ของ quarantine** | `grn_quarantined` เป็นเจ้าของมูลค่าที่ถูกกักแล้ว · ผู้ปลดคือใบคืนผู้ขาย |

### §5.5.3 ★ ความขัดแย้งที่ต้องรู้ — PREBRIEF vs CSQ_BRIEF

`PREBRIEF §2 (S-01)` และ `§6.2` เขียนว่ามี event **`csq putaway.confirmed`** ตอนยืนยันจัดเก็บ
`CSQ_BRIEF §2/§3` เขียนชัดว่า **ห้ามประกาศ** (นับซ้ำกับ `grn_posted`)

**ตัดสิน: ยึด `CSQ_BRIEF`** — เพราะเป็นใบประกาศที่ผูกสัญญากับ ENG-CSQ จริง (ทำทีหลังใน S1.8) และเป็นข้างที่ทำให้เจตนาหลักของท่อ EC (ไม่นับซ้ำ) เป็นจริง
→ ตราที่ **`07_LOCKED` LD-04** + เปิด **`OQ-PUT-10`** ให้ BA แก้ถ้อยคำฝั่ง PREBRIEF
**ยืนยันว่า HTML ทำถูกแล้ว:** `emitCsq()` ที่เรียกจริงในซอร์ส = 2 ตัวตาม `CSQ_BRIEF` พอดี

### §5.5.4 ข้อห้ามระดับโค้ด (CSQ_BRIEF §6)

- ❌ ห้ามมี `const PIPES_HIT = [...]` หรือคอลัมน์เก็บผลรายท่อในตารางของฟีเจอร์ — **ยืนยัน: ไม่มีในไฟล์**
- ❌ ห้ามคำนวณ "ต้นทุนแฝงจากการเก็บผิดที่" เป็นเงินในหน้าจอ — **ยืนยัน: ไม่มี**
- ✅ แสดงได้แค่ **ป้าย `ฝืนเกณฑ์`** + **KPI อัตราฝืนเกณฑ์ (นับรายการ)** — ยืนยัน: `33% (1 จาก 3 รายการที่จัดเก็บ)`
- 💤 **Rate Card ของงานย้ายซ้ำยังไม่มีเจ้าของ** (`CSQ-Q2`) → ทั้ง 2 event ยังเป็น `basis: declared` (qty-only)
