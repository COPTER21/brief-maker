## สิ่งที่ไม่รองรับ (ตัดสินแล้ว — อย่าเผลอทำ)

- Putaway จากแหล่งอื่นที่ไม่ใช่ GRN (ของคืนจากลูกค้า · ผลิตเสร็จ · ปรับยอดเพิ่ม) — [มติ S-18] แหล่งเดียวคือ GRN · ของที่โผล่มาเองใช้ Stock Adjustment
- แก้ bin ปลายทางหลังยืนยันแล้ว — [มติ S-14] movement append-only · ใช้กลับรายการ หรือ Stock Transfer แทน
- ออกเอกสาร / เลขรัน / PDF / ลายเซ็น / สายอนุมัติ — [มติ OB-1, OB-9] Putaway ไม่ใช่เอกสาร chip = csq เท่านั้น
- Cross-docking (รับแล้วส่งออกเลยไม่เก็บ) — [มติ S-25] backlog
- Lot / Batch / Serial + FEFO ตอนเก็บ — [มติ S-26] ยังไม่มี Lot master ในเลนนี้
- RF scan / barcode ยิง bin จริง — [มติ S-27] รอบนี้เป็นช่องค้นหาปกติ เผื่อโครงไว้เท่านั้น
- Pallet / Handling Unit / License Plate — [มติ S-28] เก็บระดับหน่วยนับของสินค้า
- Slotting / ABC velocity optimization + เส้นทางเดินในคลัง — [มติ BASELINE N-03, N-07] backlog
- เขียนของเข้า location ประเภท `in-transit` หรือ `damage` — [มติ BR-05] เจ้าของคือ Stock Transfer และ Stock Adjustment ตามลำดับ
- ปรับยอดคงเหลือด้วยมือที่ bin — [มติ §7] ทางเดียวคือ Stock Adjustment
