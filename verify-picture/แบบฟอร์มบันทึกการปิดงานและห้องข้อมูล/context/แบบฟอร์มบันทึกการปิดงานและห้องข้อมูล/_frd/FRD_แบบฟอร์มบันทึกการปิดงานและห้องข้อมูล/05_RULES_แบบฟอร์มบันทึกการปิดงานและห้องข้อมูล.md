## §5.2 State Machine
draft →(ส่ง · BR-02/05 ผ่าน)→ pending[1..N] →(อนุมัติขั้น N)→ approved · pending →(ส่งกลับ/ไม่อนุมัติ)→ draft · draft/pending →(ยกเลิก)→ cancelled · approved = ล็อก

## §5.4 Validation
| VR | ช่อง | เงื่อนไข | ข้อความ |
|---|---|---|---|
| VR-01 | project_name | required | กรุณากรอกชื่อโครงการ / ธุรกรรม |
| VR-02 | closing_date (≤ วันนี้) · post_owner | required | กรุณาเลือกวันที่ปิดงาน · กรุณาเลือกผู้รับผิดชอบหลังปิดงาน |
| VR-03 | outcome · archive_location | required | กรุณากรอกผลลัพธ์ของธุรกรรม · กรุณาระบุสถานที่จัดเก็บเอกสารถาวร |
| VR-04 | checks[].owner · checks[].done_date (เมื่อ done) | required | ใส่ผู้รับผิดชอบ · เลือกวันที่ดำเนินการ (DEC-15) |
| VR-05 | checks[].done_date | ≤ closing_date | วันที่ดำเนินการต้องไม่เกินวันที่ปิดงาน (DEC-17) |
| VR-06 | checks[].remark (เมื่อ na) | required | ไม่เกี่ยวข้อง ต้องระบุหมายเหตุ (DEC-15) |
| VR-07 | checks (ตอนส่ง) | ทุกข้อ done/na | ยังส่งอนุมัติไม่ได้ — รายการตรวจสอบยังไม่แล้วเสร็จ / ไม่เกี่ยวข้อง N ข้อ (DEC-14) |
| VR-08 | lessons (ตอนส่ง · รายการบันทึกบทเรียนที่ได้รับ done) | ≥ 1 แถว | "บันทึกบทเรียนที่ได้รับ" แล้วเสร็จ ต้องมีบทเรียน ≥ 1 แถว (DEC-16) |
| VR-09 | lessons[].lesson (มี topic) · lessons[].topic (มีช่องอื่น) | required | ใส่ข้อสังเกต / บทเรียน · ใส่ประเด็น |
| VR-10 | assignees | ทุกขั้น · ≠ ผู้จัดทำ | กรุณาเลือกผู้พิจารณา |
| VR-11 | reason (ส่งกลับ/ไม่อนุมัติ/ยกเลิก) | required | กรุณาระบุเหตุผล |

## §5.5 Edge Cases
| EC | กรณี | ผล |
|---|---|---|
| EC-01 | ส่งทั้งที่ยังมีรายการไม่เสร็จ | บล็อก VR-07 · 422 CHECKLIST_INCOMPLETE · ร่างบันทึกได้ |
| EC-02 | รายการบันทึกบทเรียนที่ได้รับ แล้วเสร็จ แต่ไม่มีบทเรียน | บล็อก VR-08 · 422 LESSON_REQUIRED |
| EC-03 | วันที่ดำเนินการ > วันที่ปิดงาน (รวมเลื่อนวันปิดงานย้อนหลัง) | บล็อก VR-05 |
| EC-04 | เปลี่ยนสถานะจาก แล้วเสร็จ เป็นอื่น | ล้าง done_date |
| EC-05 | บทเรียน > 10 แถว | PDF หัวตารางซ้ำ · dense · ยัง 2 หน้า (14 แถว) |
| EC-06 | resolve ขั้น 1 = ผู้จัดทำ | slot ว่าง ต้องเลือกคนอื่น |
| EC-07 | แก้ DOA / config รายการตรวจสอบ ระหว่างใบค้าง | ใช้ snapshot (approval_chain · item_text · checklist_config_ver) |
| EC-08 | DOA 6 ขั้น | PDF 7 แถวลงชื่อ · 2 หน้า |
| EC-09 | stale | 409 STALE · สถานะไม่เปลี่ยน |
| EC-10 | doc_type IVMK ปิดใช้ | สร้างไม่ได้ (409 DOC_TYPE_INACTIVE) |
| EC-11 | ชื่อชีต ≠ Doc No. | ใช้ FM-IVM-11 (DEC-13) |
