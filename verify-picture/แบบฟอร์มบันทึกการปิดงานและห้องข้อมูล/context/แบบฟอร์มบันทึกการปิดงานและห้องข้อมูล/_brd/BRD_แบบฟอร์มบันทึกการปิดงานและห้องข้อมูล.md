## 1. Business Context
### 1.1 ปัญหา / โอกาส
ฝ่ายบริหารการลงทุนสรุปการปิดงานธุรกรรมด้วยแบบฟอร์ม Excel FM-IVM-11 — สรุปการปิดงาน รายการตรวจสอบ 8 ข้อ (ชุดเอกสาร · ห้องข้อมูล · สิทธิ · ประเด็นคงค้าง · คืน/ทำลายข้อมูล · บทเรียน) และบทเรียน อยู่ในไฟล์แยกต่อธุรกรรม · การตรวจทาน/อนุมัติ 3 ช่องส่งต่อด้วยมือ · ไม่มีกติกาว่าปิดงานได้เมื่อรายการตรวจสอบเป็นสถานะใด · "แล้วเสร็จ" ไม่บังคับผู้รับผิดชอบ/วันที่ · ตรวจย้อนหลังว่าใครปรับสิทธิ/ทำลายข้อมูลเมื่อไรได้ยาก
### 1.2 เป้าหมาย
1. ขึ้นแบบฟอร์มเป็นเอกสารในระบบ ช่องตรงกระดาษ 1:1 (PDF Replica FM-IVM-11 · 2 หน้า)
2. บังคับให้ทุกรายการตรวจสอบ "แล้วเสร็จ" หรือ "ไม่เกี่ยวข้อง" (พร้อมหลักฐานขั้นต่ำ) ก่อนส่งปิดงาน
3. สายอนุมัติ 2 ขั้นจาก DOA กลาง (dynamic) · ประวัติ append-only · ส่งต่อผู้รับผิดชอบหลังปิดงานและผู้ติดตามบทเรียน
### 1.3 ตัวชี้วัด
ไม่มีใน input → **OQ-01** (ห้ามแต่งตัวเลข)
### 1.4 ที่มา
แบบฟอร์มลูกค้า FM-IVM-11 (xlsx · ชื่อชีต INV-FM-11) → FORM_SPEC 14 ช่อง · รายการตรวจสอบ 8 ข้อพิมพ์ตายตัว (ค่าคงที่ → config) · สถานะ 4 ค่าจาก data validation D21:D28 · บทเรียน 10 แถว · gate 10 หมวด = AI-DEFAULT ทั้งหมด (โหมดไม่เฝ้า)

## 2. Scope
### 2.1 In Scope
- รายการบันทึก (ค้นหา · กรองสถานะ/ความครบของรายการตรวจสอบ · CSV) · สร้าง/แก้ร่าง wizard 3 ขั้น · ดูรายละเอียด 4 แท็บ (รายละเอียด › PDF Preview › ลายเซ็น/อนุมัติ › ประวัติ)
- สรุปการปิดงาน 5 ช่อง · รายการตรวจสอบ 8 ข้อ (ถ้อยคำจาก config ivmk.checklist_items · สถานะ 4 ค่า · ผู้รับผิดชอบ · วันที่ดำเนินการ · หมายเหตุ) · บทเรียน 4 คอลัมน์ (ไม่จำกัดแถว)

## 4. User Journey
### 4.1 Happy Path
1. ผู้จัดทำ: สร้าง → ชื่อโครงการ · วันที่ปิดงาน · ผู้รับผิดชอบหลังปิดงาน · ผลลัพธ์ของธุรกรรม · สถานที่จัดเก็บเอกสารถาวร → ไล่รายการตรวจสอบ 8 ข้อ (แล้วเสร็จ = ผู้รับผิดชอบ + วันที่ · ไม่เกี่ยวข้อง = หมายเหตุ) → บันทึกบทเรียน → แนบไฟล์ → บันทึก (ได้เลข IVMK) → ส่ง เลือกคน 2 ขั้น
2. ขั้น 1 ตรวจสอบแล้ว → ขั้น 2 อนุมัติ → **อนุมัติแล้ว (ปิดงานสมบูรณ์)** · PDF เก็บสำเนา (approved_final) · แจ้งผู้รับผิดชอบหลังปิดงาน (ivmk_closed_handover) + ผู้รับผิดชอบบทเรียน (ivmk_lesson_assigned)
### 4.2 Alternative
- บันทึกร่างระหว่างที่รายการยังไม่เสร็จ (ทุกสถานะ) → กลับมาแก้ต่อ → ส่งเมื่อครบ
- ส่งกลับ / ไม่อนุมัติ ขั้นใดก็ได้ → กลับร่าง เลขเดิม + เหตุผล → ผู้จัดทำแก้ ส่งใหม่ (resolve สายใหม่)
- ยกเลิก (ร่าง/รออนุมัติ) โดยเจ้าของหรือ admin → ถ้ารออนุมัติ แจ้งผู้พิจารณาขั้นปัจจุบัน (ivmk_cancelled)
