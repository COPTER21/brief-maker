### 3.1 รายการซ้ำ
- **รายการตรวจสอบการปิดงานและห้องข้อมูล** — บนกระดาษ 8 แถว (min_rows) · ช่องในแถว: รายการตรวจสอบ, สถานะ, ผู้รับผิดชอบ, วันที่ดำเนินการ, หมายเหตุ
- **บทเรียนที่ได้รับและการติดตามผล** — บนกระดาษ 10 แถว (min_rows) · ช่องในแถว: ประเด็น, ข้อสังเกต / บทเรียน, ผู้รับผิดชอบ, กำหนดส่ง

### 3.2 ตัวเลือก
- **สถานะ (ต่อรายการตรวจสอบ)** (เลือกได้ข้อเดียว): ยังไม่ดำเนินการ · กำลังดำเนินการ · แล้วเสร็จ → ใช้ช่อง ผู้รับผิดชอบ, วันที่ดำเนินการ · ไม่เกี่ยวข้อง → ใช้ช่อง หมายเหตุ

### 3.3 สูตร + ค่าคงที่บนกระดาษ
- ค่าคงที่ "รายการตรวจสอบ 8 รายการ (ข้อความพิมพ์ตายตัว)" = รายการตรวจสอบการปิดงานตั้งต้น → ควรอ่านจาก `config: ivmk.checklist_items (รายการตั้งต้น ต่อบริษัท)` (ห้าม hardcode)

### 3.4 ลายเซ็น + control
- S1 ผู้จัดทำ (ผู้ขอ)
- S2 ผู้ตรวจสอบ (ผู้อนุมัติ) · ตัวเลือก: ตรวจสอบแล้ว / ส่งกลับ
- S3 ผู้อนุมัติ / รับทราบ (ผู้อนุมัติ) · ตัวเลือก: อนุมัติ / ไม่อนุมัติ
- Doc No. บนกระดาษ FM-IVM-11 · Rev.00 : 01/07/2569 · เลขรันบนกระดาษ: ไม่มี (ระบบออกเลขเอง)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- ชื่อชีตเป็น INV-FM-11 แต่ Doc. No. ท้ายกระดาษเป็น FM-IVM-11 → **ยึด FM-IVM-11 ตาม footer เป็นรหัสแบบฟอร์ม**
- ไม่มีกติกาว่าปิดงานได้เมื่อสถานะเป็นอะไร — ส่งได้ทั้งที่ยังไม่ดำเนินการ → **ส่งอนุมัติได้เมื่อทุกรายการเป็น แล้วเสร็จ หรือ ไม่เกี่ยวข้อง (บล็อกตอนส่ง)**
- สถานะ แล้วเสร็จ ไม่บังคับผู้รับผิดชอบ/วันที่ดำเนินการ และ ไม่เกี่ยวข้อง ไม่บังคับเหตุผล → **แล้วเสร็จ → ผู้รับผิดชอบ + วันที่ดำเนินการ บังคับ · ไม่เกี่ยวข้อง → หมายเหตุ บังคับ**
- บันทึกบทเรียนที่ได้รับ = แล้วเสร็จ แต่ตารางบทเรียนอาจว่าง → **ข้อ 8 แล้วเสร็จ → ตารางบทเรียนต้องมีอย่างน้อย 1 แถว · แถวที่มีประเด็นต้องกรอกข้อสังเกต / บทเรียน**
- วันที่ดำเนินการอาจหลังวันที่ปิดงาน → **วันที่ดำเนินการต้องไม่เกินวันที่ปิดงาน (บล็อก)**
