## §1.2 OV-01 Create (drawer) — build-path cascade ⭐
```
Section 0 · เลือกโควตาและรายการ (บังคับก่อน):
  0a search-select "ค้นหาเลขโควตา" → farmer snapshot card (read-only)
  0b multi-select "เลือกแปลง (ของโควตา)" ≥1 → checklist plots
  0c multi-select "เลือกรอบปลูก (verified ของโควตา)" ≥1 → checklist crops verified · **กัน crop ที่ทำสัญญาแล้ว (contracted)** · แสดงผลรวมตันของ crop เป็น helper
Section 1 · ประเภทสัญญา (บังคับ): select 5 ประเภท (ตันสูญเปล่า/ส่งเสริม/โปร 7 วัน/เครน/ตกเขียว)
  → total_tons "จำนวนตันที่ทำสัญญา" · **manual input บังคับ > 0 ทุกประเภท** · helper แสดงผลรวมตันจาก crop + ปุ่ม "ใช้ค่านี้" เติมค่าให้อัตโนมัติ (ไม่ auto-derive)
  → type-specific:
     support → รายการส่งเสริม (support_items[] repeater เพิ่มได้หลายรายการ, บังคับ ≥1) · แต่ละรายการ: ประเภทส่งเสริม (dropdown 5 masters: ปุ๋ย/ยาปราบ · เครื่องจักร · พันธุ์อ้อย · ยาปราบ · เงินส่งเสริม) + ราคา (number ≥0) + วันที่รับส่งเสริม (date) + เอกสารแนบต่อรายการ (simulated)
     promotion-7 → เลือกช่วงโปรโมชั่น (promotion7_period) dropdown 4 ค่า: โปรโมชัน 7 วันหลังเปิดหีบ · โปรโมชัน 7 วันก่อนปิดปีใหม่ · โปรโมชัน 7 วันหลังเปิดปีใหม่ · โปรโมชัน 7 วันก่อนปิดหีบ
     promotion-crane → เลือกเครน (selected_crane) dropdown 4 ค่า: กุดโดน · ชื่นชม2 · หนองกุงสวรรค์ · โนนสำราญ
     price-per-ton / early-purchase → ไม่มี type field เพิ่ม
Section 2 · สรุปสัญญา: ประเภท + จำนวนตัน (manual) + จำนวนแปลง/รอบปลูก (read-only summary)
Section 3 · เอกสารแนบ: attachments[] upload · **early-purchase (ตกเขียว) ไม่มีเอกสารแนบ — ซ่อน block นี้** (อีก 4 ประเภทมี attachments)
Footer: ยกเลิก · ยืนยันสร้าง
```
Fields ล็อกจนครบ quota+plots+crops (LOCK-03)

## §1.4 P-02 Detail (view drawer, tabs)
```
head: เลขสัญญา + status pill + [แก้ไข][อนุมัติ*waiting][ปฏิเสธ*waiting][ลบ]
snapshot card (teal): "โควตา [QT] · [เกษตรกร] · ประเภท [type]" + ปุ่ม ดูโควตา

footer: อัปเดตล่าสุด + เวอร์ชัน + ปิด
```
Reject → แสดง reject_reason box

## §1.5 OV-03 Approve/Reject (modal, single/bulk)
radio ผลตรวจสอบ: อนุมัติ(Verified) / ปฏิเสธ(Reject) · ปฏิเสธ → reason textarea **บังคับ** · อนุมัติ → ไม่ต้องมีเหตุผล · bulk → "อนุมัติ/ปฏิเสธ N รายการ" + skip non-waiting · Confirm/ยกเลิก
> ปฏิเสธ → คืน crop license=none (แสดง note "จะคืนสถานะสิทธิ์รอบปลูกที่ผูกไว้")

## §1.6 OV-04 Delete (modal danger)
confirm "ยืนยันการลบสัญญา" · warn "ข้อมูล+ไฟล์แนบจะถูกลบ" · Confirm/ยกเลิก
