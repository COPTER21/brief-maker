## §4.2 T_contract

| `id` | uuid | NO | Internal | PK |

| `contract_id` | varchar(20) | NO | Internal | `CT-YYYY-NNN` · unique |
| `quota_id` | varchar(50) | NO | Internal | FK T_quota (read) |

| `version` | int | NO | Internal | optimistic (default 1) |
| `created_by/at`,`updated_by/at` | — | NO | Internal | audit |

**Constraints:** PK(id) · UNIQUE(tenant_id, contract_id) · CHECK status IN(3) · CHECK contract_type IN(5) · CHECK total_tons > 0
**Indexes:** IDX_contract_tenant_status · IDX_contract_quota · IDX_contract_type · IDX_contract_search(trigram contract_id/farmer)
**RLS:** tenant_id = current_setting('app.current_tenant')

## §4.3 T_contract_plot / T_contract_crop
- T_contract_plot: id, contract_id_fk, plot_id · UNIQUE(contract_id, plot_id)
- T_contract_crop: id, contract_id_fk, crop_id, tons_snapshot · UNIQUE(contract_id, crop_id) · **partial: crop ที่ license=contracted ผูก active contract ได้ 1** (LOCK-08)

## §4.4 T_contract_support_item / attachment / history
- support_item (**structured**, type=support): id, contract_id_fk, `support_type` (enum 5 masters: `ปุ๋ย/ยาปราบ`/`เครื่องจักร`/`พันธุ์อ้อย`/`ยาปราบ`/`เงินส่งเสริม`), `price` decimal(14,2) ≥0, `received_date` date, `item_attachments` (per-item repeater, simulated ใน prototype) · **บังคับ ≥1 รายการ · แต่ละรายการต้องมี support_type + price + received_date**
- attachment: id, contract_id_fk, file_ref, file_name, mime, size
- history: id, contract_id_fk, event(create/approve/reject/delete/license_write), actor_id, event_at, note(reason), bulk_count, linked_write(jsonb {crop_ids, license}) · **REVOKE UPDATE/DELETE**

## §4.5 Relationships
```
T_quota (F-AGM-002) ──read──▶ T_contract [quota_id]
T_plot  (F-AGM-003) ──M:N──▶ T_contract_plot
T_crop  (F-AGM-004) ──M:N──▶ T_contract_crop  ◀── T_contract WRITE crop.license_status (contracted/none) ⭐
T_contract ──(1:N)──▶ support_item / attachment / history
```

## §4.6 Data Classification
Confidential: farmer_name, attachments · Internal: ที่เหลือ · PII: farmer_name

## §4.9 Notes
- Contract เป็น feature เดียว (นอกจาก Quota) ที่ **write-back** cross-module (crop.license_status)
- crop license: 'none' (default) → 'contracted' (มีสัญญา active) → 'none' (reject/delete) · 1 crop : 1 active contract
- write ใน transaction เดียวกับ contract mutation + retry queue (OQ)
