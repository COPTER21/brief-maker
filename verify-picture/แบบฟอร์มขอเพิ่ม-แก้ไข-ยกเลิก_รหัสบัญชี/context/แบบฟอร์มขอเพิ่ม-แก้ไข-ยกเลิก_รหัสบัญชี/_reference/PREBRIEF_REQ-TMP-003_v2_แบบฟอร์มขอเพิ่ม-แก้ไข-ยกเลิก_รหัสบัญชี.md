### 3.1 รายการซ้ำ
- **ชื่อบัญชีที่ต้องการขอเพิ่ม** — บนกระดาษ 4 แถว (min_rows) · ช่องในแถว: ชื่อบัญชีที่ต้องการขอเพิ่ม

### 3.2 ตัวเลือก
- **ประเภทคำขอ** (เลือกได้ข้อเดียว): เพิ่มรหัสบัญชี → ใช้ช่อง ชื่อบัญชีที่ต้องการขอเพิ่ม, วัตถุประสงค์ในการเพิ่ม · แก้ไขรหัสบัญชี → ใช้ช่อง รหัสบัญชี, แก้ไขเป็น, วัตถุประสงค์ในการแก้ไข · ยกเลิกรหัสบัญชี → ใช้ช่อง รหัสบัญชี, ชื่อบัญชี, วัตถุประสงค์ในการแก้ไข

### 3.3 สูตร + ค่าคงที่บนกระดาษ

### 3.4 ลายเซ็น + control
- S1 ผู้ขอเพิ่ม/แก้ไข/ยกเลิกรหัสบัญชี (ผู้ขอ)
- S2 ผู้ตรวจสอบ (ผู้อนุมัติ)
- S3 ผู้อนุมัติ (ลงนามผู้อนุมัติ) (ผู้อนุมัติ) · ตัวเลือก: อนุมัติ / ไม่อนุมัติ

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- หัวช่องพิมพ์ว่า "วัตถุประสงค์ในการแก้ไข" ทั้งที่อยู่ในส่วนยกเลิก (คัดลอกจากส่วนแก้ไข) → **แสดงเป็น "วัตถุประสงค์ในการยกเลิก" (G5 แก้คำผิดชัดเจน) · key แยก cancel.purpose**
- ☐ 3 ตัวเลือกไม่ได้บอกว่าเลือกได้ข้อเดียวหรือหลายข้อ → **1 ใบ = 1 ประเภทคำขอ · ส่วนที่ไม่ได้เลือกต้องว่าง (validation)**
- ไม่อนุมัติ มีช่องเหตุผล แต่ไม่บังคับบนกระดาษ → **เลือก ไม่อนุมัติ → เหตุผลบังคับ**
