### 3.3 สูตร + ค่าคงที่บนกระดาษ
- สูตร: รวมคะแนนเต็ม = `SUM(คะแนน (1-5) ทุกหัวข้อ)` ต้นฉบับ =SUM(C3:C11) = 45
- สูตร: รวมคะแนน (ต่อช่องทาง) = `SUM(คะแนนของช่องทางนั้น ทุกหัวข้อ)` ต้นฉบับไม่มีสูตร (ดู anomalies)
- สูตร: % (ต่อช่องทาง) = `รวมคะแนนของช่องทาง ÷ รวมคะแนนเต็ม × 100` ต้นฉบับ =D12/C12 · ช่องทางไม่ได้ประเมิน → —
- สูตร: ผลเทียบมาตรฐาน (ต่อช่องทาง) = `% ≥ 95 → ผ่านมาตรฐาน (เขียว) · 80 ≤ % < 95 → ต่ำกว่ามาตรฐาน (เหลือง) · % < 80 → ค่อนข้างต่ำกว่ามาตรฐาน (แดง)` เกณฑ์อ่านจาก config · ป้ายตามคำอธิบายสีบนกระดาษ
- สูตร: ช่องทางที่ ผ่านมาตรฐาน 95% ขึ้นไป ได้แก่ = `รายชื่อช่องทางที่สถานะ = ผ่านมาตรฐาน (คั่นด้วย , )` 
- สูตร: ช่องทางที่ ต่ำกว่ามาตรฐานเล็กน้อย (80–94%) ได้แก่ = `รายชื่อช่องทางที่สถานะ = ต่ำกว่ามาตรฐาน` 
- สูตร: ช่องทางที่ ต่ำกว่า 80% ได้แก่ = `รายชื่อช่องทางที่สถานะ = ค่อนข้างต่ำกว่ามาตรฐาน` 
- ค่าคงที่ "มาตรฐานที่กำหนด 95%" = เกณฑ์ผ่านมาตรฐาน → ควรอ่านจาก `SalesConfig.mt_csat_standard_pct (=95)` (ห้าม hardcode)
- ค่าคงที่ "(80–94%) / ต่ำกว่า 80%" = เกณฑ์แบ่งกลุ่มต่ำกว่ามาตรฐานเล็กน้อย / ต่ำกว่า 80% → ควรอ่านจาก `SalesConfig.mt_csat_low_pct (=80)` (ห้าม hardcode)
- ค่าคงที่ "คะแนน (1-5) = 5 ทุกหัวข้อ" = คะแนนเต็มต่อหัวข้อ → ควรอ่านจาก `SalesConfig.mt_csat_criteria[].max_score (=5)` (ห้าม hardcode)
- ค่าคงที่ "หัวข้อประเมิน 9 ข้อ" = หัวข้อคงที่บนกระดาษ → ควรอ่านจาก `SalesConfig.mt_csat_criteria[] (ตามกระดาษ Rev.00)` (ห้าม hardcode)
- ค่าคงที่ "บิ๊กซี … PT (15 ช่องทาง)" = รายชื่อช่องทาง MT หัวคอลัมน์ → ควรอ่านจาก `SalesConfig.mt_channels[] (ผูก Customer master กลุ่ม MT)` (ห้าม hardcode)
- ค่าคงที่ "กลุ่ม MT." = กลุ่มลูกค้า Modern Trade → ควรอ่านจาก `SalesConfig.mt_customer_group (=MT)` (ห้าม hardcode)
- ค่าคงที่ "ผ่านมาตรฐาน / ต่ำกว่ามาตรฐาน / ค่อนข้างต่ำกว่ามาตรฐาน + สีเขียว/เหลือง/แดง" = ป้ายสถานะและสี → ควรอ่านจาก `SalesConfig.mt_csat_bands[]` (ห้าม hardcode)
- ค่าคงที่ "ควร รักษาคุณภาพ… / ควร ปรับปรุงบางด้าน… / ต้องเร่งแก้ไขอย่างเร่งด่วน…" = ข้อความแนะนำค่าเริ่มต่อกลุ่ม → ควรอ่านจาก `SalesConfig.mt_csat_bands[].default_note` (ห้าม hardcode)
- ค่าคงที่ "100%" = หัวแถว % (คะแนนเต็ม = 100%) → ควรอ่านจาก `คงที่ (ไม่ใช่ค่าตั้ง)` (ห้าม hardcode)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- ไม่มีสูตรรวมคะแนนต่อช่องทาง แต่แถว % อ้าง D12/C12 → **รวมคะแนนต่อช่องทาง = SUM ทุกหัวข้อ**
- สีเซลล์ (เขียว/เหลือง/แดง) ระบายตายตัว ไม่ผูกกับค่า % (ทุกช่องเป็น 0%) → **สีและสถานะคำนวณจาก % เทียบเกณฑ์ 95/80**
- พิมพ์ "ผ่านมาตรฐาน/ต่ำกว่ามาตรฐาน/ค่อนข้างต่ำกว่ามาตรฐาน" เอง และไม่ตรงกับภาพรวมโดยสรุป (เช่น 108 ระบายเหลืองแต่อยู่ในกลุ่มต่ำกว่า 80%) → **สถานะคำนวณจาก % เท่านั้น ผู้ใช้แก้ไม่ได้**
- รายชื่อช่องทางต่อกลุ่มพิมพ์ตายตัว ไม่ผูกกับตาราง และสะกดชื่อไม่ตรงหัวคอลัมน์ (เบ็ทส์ซี/จั๊ฟฟี่/แมคแวลู) → **รายชื่อต่อกลุ่มสร้างจากสถานะช่องทางอัตโนมัติ ใช้ชื่อจาก config**
- ป้ายสีแดง = "ค่อนข้างต่ำกว่ามาตรฐาน" แต่ในข้อความใช้ "ต่ำกว่า 80%" และสีเหลือง = "ต่ำกว่ามาตรฐาน" แต่ข้อความใช้ "ต่ำกว่ามาตรฐานเล็กน้อย (80–94%)" → **ยึดเกณฑ์ตัวเลขจากข้อความ (≥95 / 80–<95 / <80) + ป้ายตามคำอธิบายสี — รอลูกค้ายืนยันถ้อยคำ**
- สะกด "ประเมิณ" "ลุกค้า" ผิด · หัวคอลัมน์ 108 เป็นตัวเลข → **แก้คำสะกด (G5) · ชื่อช่องทางเป็นข้อความ**
- พิมพ์ชื่อจริงพนักงานในไฟล์ตัวอย่าง → **ชื่อ/ตำแหน่งดึงจากผู้สร้างเอกสาร (pdpa — ไม่ใช้เป็นข้อมูลตัวอย่าง)**
- "สรุปการประเมิณครั้งที่1" — คัดลอกชีตทุกครั้ง → **1 ใบในระบบ = 1 ครั้ง · ครั้งที่ซ้ำในปีเดียวกัน = เตือน**
