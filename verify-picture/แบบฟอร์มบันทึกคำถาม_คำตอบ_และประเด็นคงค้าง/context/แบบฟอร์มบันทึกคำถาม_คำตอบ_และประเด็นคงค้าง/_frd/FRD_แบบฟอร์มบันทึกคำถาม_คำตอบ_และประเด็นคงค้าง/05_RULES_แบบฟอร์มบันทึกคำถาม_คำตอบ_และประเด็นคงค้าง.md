## §5.2 State Machine
draft →(ส่ง)→ pending[1..N] →(อนุมัติขั้น N)→ approved · pending →(ส่งกลับ/ไม่อนุมัติ)→ draft · draft/pending →(ยกเลิก)→ cancelled · approved = ล็อก

## §5.4 Validation
| VR | ช่อง | เงื่อนไข | ข้อความ |
|---|---|---|---|
| VR-01 | project_name | required | กรุณากรอกชื่อโครงการ / ธุรกรรม (DEC-14) |
| VR-02 | questions[].asked_date · question · asker · responder | required ต่อแถว | Q-00n: กรอก วันที่ · คำถาม / คำขอ · ผู้ถาม · ผู้รับผิดชอบตอบ |
| VR-03 | questions[].answer | required เมื่อ status ∈ {answered, closed} | Q-00n: สถานะ ตอบแล้ว ต้องกรอกคำตอบ (DEC-16) |
| VR-04 | questions[].due_date | ≥ asked_date | Q-00n: กำหนดตอบต้องไม่ก่อนวันที่ |
| VR-05 | issues[].opened_date · issue · owner · due_date | required ต่อแถว | OI-00n: กรอก วันที่เปิด · ประเด็นคงค้าง · ผู้รับผิดชอบ · กำหนดเสร็จ |
| VR-06 | issues[].due_date | ≥ opened_date | OI-00n: กำหนดเสร็จต้องไม่ก่อนวันที่เปิด |
| VR-07 | issues[].remark | required เมื่อ escalate = ใช่ | OI-00n: ต้องยกระดับ = ใช่ ต้องระบุเหตุผลในหมายเหตุ (DEC-17) |
| VR-08 | questions + issues | รวม ≥ 1 แถว | ต้องมีคำถามหรือประเด็นคงค้างอย่างน้อย 1 รายการ |

| VR-10 | reason (ส่งกลับ/ไม่อนุมัติ/ยกเลิก) | required | กรุณาระบุเหตุผล |
