## §1.4 Empty / Error / Loading
- ตารางว่าง: empty state + ปุ่มสร้าง · ผลค้นหาว่าง: ล้างตัวกรอง · section ว่างใน drawer: empty-sub (U23)
- validate ตอนกดถัดไป/ส่งเท่านั้น: กรอบแดง + ข้อความใต้ช่อง + toast "กรุณากรอกข้อมูลให้ครบถ้วน" + เลื่อนไปช่องแรกที่ผิด
- เตือน (ไม่บล็อก): วันที่ผ่านมาแล้ว · วันที่ลงนามก่อนวันที่เข้าพื้นที่ (DEC-15)
- ปุ่มระหว่างบันทึก: spinner "กำลังบันทึก…" + disabled · API ล้ม/stale/denied = toast + สถานะไม่เปลี่ยน
- F-DOCCFG ปิด → ปุ่มสร้าง disabled + แถบแจ้ง
