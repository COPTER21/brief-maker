## 1. Business Context
### 1.1 ปัญหา / โอกาส
- ปัจจุบันใช้แบบฟอร์มกระดาษ FM-HRM-05 เมื่อบุคคลภายนอกขอเข้าพื้นที่สำนักงาน: ผู้มาติดต่อกรอกข้อมูลตัวเอง + พนักงานที่ติดต่อ · พนักงานผู้รับการติดต่อกรอกส่วนเจ้าหน้าที่ · ผู้บังคับบัญชาต้นสังกัดติ๊กอนุมัติ/ไม่อนุมัติ แล้วลงนาม
- ปัญหา: ชื่อผู้รับการติดต่อเขียนซ้ำ 2 ที่ · ชื่อบริษัทบนกระดาษเขียนไม่ตรงกัน 2 จุด · ไม่มีเหตุผลเมื่อไม่อนุมัติ · ค้นย้อนหลังว่าใครเข้าพื้นที่วันไหนยาก
- ขึ้นระบบเพื่อ: ดึงฝ่าย/ผู้บังคับบัญชาจากผังองค์กร · ส่งพิจารณาตามสาย DOA · เก็บประวัติค้นได้ · พิมพ์แบบฟอร์มหน้าตาเดิมให้ผู้มาติดต่อลงนามที่จุดรับแขก

### 1.2 เป้าหมาย
1. พนักงานบันทึกคำขอเข้าพื้นที่ของผู้มาติดต่อในระบบ และส่งให้ผู้บังคับบัญชาต้นสังกัดพิจารณา
2. ผู้บังคับบัญชาอนุมัติ/ไม่อนุมัติพร้อมความเห็น · ไม่อนุมัติแล้วกลับเป็นร่างให้แก้ส่งใหม่
3. พิมพ์ PDF ตามแบบ FM-HRM-05 ได้ทุกสถานะ · HR ค้น/ส่งออกรายการได้

### 1.3 ตัวชี้วัด
- ไม่มีใน input → OQ-03 (ห้ามแต่งตัวเลข)

### 1.4 ที่มา
- ไฟล์ลูกค้า `แบบฟอร์มขออนุญาตเข้าพื้นที่สำนักงาน.docx` (sha256 a5c141db353878c3) · ฟอร์มว่าง ไม่มีข้อมูลส่วนบุคคลตัวอย่าง · ไม่มี PREBRIEF จาก CMS → PREBRIEF v2 สร้างจาก FORM_SPEC

## 2. Scope
### 2.1 In Scope
- หน้ารายการ · สร้าง/แก้ร่าง (wizard 3 ขั้น) · ดู (รายละเอียด › PDF Preview › ลายเซ็น / อนุมัติ › ประวัติ) · ส่งขออนุมัติ · อนุมัติ / ไม่อนุมัติ · ยกเลิก · ส่งออก CSV · แนบไฟล์
- แบบพิมพ์ Replica FM-HRM-05 (thai-doc v2.1) · เลขที่ VAR จาก F-DOCCFG / ENG-DOC-NUM
- สายอนุมัติจาก DOA กลาง (DOA_BRIEF_F-TMP-003) · แจ้งเตือน var_cancelled (ENG-NOTIFY) + doa_pending/doa_result จาก DOA engine

### 2.2 Out of Scope
- ระบบแลกบัตร/ประตู/ลงทะเบียนหน้าจุดรับแขก — ไม่ส่งต่อรอบนี้ (DEC-01 · DEC-02)
- บัญชีผู้ใช้ของผู้มาติดต่อ (บุคคลภายนอกไม่ login) · ลายมือชื่อภาพ (DEC-07)
- ทำซ้ำ · ประกาศ (DEC-11)

### 2.3 Assumptions
- Employee มี line_manager ตามผังองค์กร (F-ORG-001) · ผู้รับการติดต่อที่ไม่มีผู้บังคับบัญชา (เช่น กรรมการผู้จัดการ) ส่งพิจารณาไม่ได้ → OQ-02
- ผู้บันทึก (เจ้าของใบ) = พนักงานผู้รับการติดต่อ หรือผู้ที่บันทึกแทน (เช่น HR) · ผู้มาติดต่อลงนามด้วยมือบนแบบพิมพ์

## 4. User Journey
### 4.1 Happy Path
1. พนักงานเปิด "แบบฟอร์มขออนุญาตเข้าพื้นที่สำนักงาน" → สร้างคำขอ → ระบบเลือกผู้รับการติดต่อ = ตัวเอง และดึงสังกัดฝ่าย/ผู้บังคับบัญชาต้นสังกัดให้
2. กรอกวันที่ · คำนำหน้า + ชื่อผู้มาติดต่อ · หมายเลขโทรศัพท์ · ชื่อบริษัท/หน่วยงาน · วัตถุประสงค์ (วันที่ลงนามผู้มาติดต่อตั้งค่าเริ่ม = วันที่เข้าพื้นที่)
3. แนบไฟล์ (ถ้ามี) → ตรวจสอบ → บันทึกและส่งขออนุมัติ → ระบบออกเลข VAR · สถานะ "รอพิจารณา" · DOA engine แจ้งผู้บังคับบัญชา (doa_pending)
4. ผู้บังคับบัญชาเปิดดู → อนุมัติ (ใส่ความเห็นได้) → สถานะ "อนุมัติแล้ว" · แจ้งผล (doa_result)
5. พนักงานพิมพ์ PDF FM-HRM-05 ให้ผู้มาติดต่อลงนามที่จุดรับแขก

### 4.2 Alternative
- A1 ผู้บังคับบัญชาไม่อนุมัติ (ความเห็นบังคับ) → ใบกลับเป็นร่างเลขเดิม + แถบแจ้งเหตุผล → แก้แล้วส่งใหม่
- A2 HR หรือผู้ช่วยบันทึกแทน → เลือกพนักงานที่ผู้มาติดต่อขอพบ (ผู้พิจารณา = ผู้บังคับบัญชาของพนักงานนั้น)
- A3 บันทึกร่างไว้ก่อน → กลับมาแก้ → ส่ง
- A4 ยกเลิก (เหตุผลบังคับ) โดยเจ้าของหรือ HR ระหว่างร่าง/รอพิจารณา → แจ้งผู้พิจารณา (var_cancelled)

## 7. Status & Lifecycle
`draft (ร่าง)` → ส่ง → `pending (รอพิจารณา)` → อนุมัติครบทุกขั้น → `approved (อนุมัติแล้ว)`
- ไม่อนุมัติขั้นใดก็ได้ → `draft` เลขเดิม (เก็บเหตุผลล่าสุด · chain resolve ใหม่ตอนส่งรอบถัดไป) — DEC-08
- `draft|pending` → ยกเลิก (เหตุผลบังคับ) → `cancelled` · `approved` ยกเลิกไม่ได้ (OQ-04)
- ส่งแล้วแก้ไม่ได้ (ล็อก) · เลขออกตอนบันทึกครั้งแรก (DEC-10)
