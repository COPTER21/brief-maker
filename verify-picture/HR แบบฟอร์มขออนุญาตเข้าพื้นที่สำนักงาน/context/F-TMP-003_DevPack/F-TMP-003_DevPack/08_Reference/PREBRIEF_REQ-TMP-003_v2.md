### 3.1 รายการซ้ำ

### 3.2 ตัวเลือก
- **ผู้บังคับบัญชาพิจารณา** (เลือกได้ข้อเดียว): อนุมัติ · ไม่อนุมัติ

### 3.3 สูตร + ค่าคงที่บนกระดาษ
- ค่าคงที่ "บริษัท ครีเดนซ์ จำกัด (มหาชน) / บริษัท ครีเดนซ์ จำกัด" = ชื่อบริษัทเจ้าของสำนักงาน → ควรอ่านจาก `Organization.Company.name_th` (ห้าม hardcode)

### 3.4 ลายเซ็น + control
- S1 ลงนามผู้มาติดต่อ (อื่น)
- S2 พนักงานผู้รับการติดต่อ (ผู้ขอ)
- S3 ผู้บังคับบัญชาต้นสังกัด (ผู้อนุมัติ) · ตัวเลือก: อนุมัติ / ไม่อนุมัติ
- Doc No. บนกระดาษ FM-HRM-05 · Rev. 00 : 01/07/2569 · เลขรันบนกระดาษ: ไม่มี (ระบบออกเลขเอง)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- ชื่อพนักงานที่ติดต่อ (F06) กับ ชื่อผู้รับการติดต่อ (F09) เป็นคนเดียวกันแต่กรอก 2 ที่ → **F09 = F06 อัตโนมัติ (อ่านอย่างเดียว) — ห้ามต่างกัน**
- ส่วนบนเขียน "บริษัท ครีเดนซ์ จำกัด (มหาชน)" ส่วนล่างเขียน "บริษัท ครีเดนซ์ จำกัด" ไม่ตรงกัน → **ทั้งสองจุดแสดง Company.name_th จาก Organization ค่าเดียว**
- ตัวเลือก อนุมัติ/ไม่อนุมัติ ไม่ระบุว่าต้องมีเหตุผล → **ไม่อนุมัติ → ต้องกรอกเหตุผล (ช่อง ผู้บังคับบัญชาพิจารณา) — บล็อก**
- วันที่ลงนามผู้มาติดต่อไม่ควรก่อนวันที่ขอเข้าพื้นที่ → **visitor.sign_date ≥ visit.request_date (เตือน)**
