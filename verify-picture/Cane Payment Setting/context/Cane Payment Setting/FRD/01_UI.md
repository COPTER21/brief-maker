### §1.3.1 ข้อมูลทั่วไป (General)
- สินค้าอ้อย (select) · หมายเหตุ (textarea)
- **กลุ่ม ดอกเบี้ยบิลขาว** ⭐: ดอกเบี้ยต่อปี (%) (0–100, 2 dec) · วันฐาน (Base Days, int) · ดอกเบี้ยต่อวัน (Daily Rate, read-only 7 dec = roundUp)
- **กลุ่ม ค่าธนาคาร** ⭐: จังหวัดหลัก (select) · ค่าธรรมเนียมในจังหวัด · ค่าธรรมเนียมต่างจังหวัด (≥0, บาท)

### §1.3.2 สูตรคำนวณ CCS (CCS Delta)
- note "สูตร: ราคาต่อตัน = Base @10CCS + (CCS − 10) × (Base @10CCS × K)" · ค่า K (0–1, step 0.001, default 0.060)
- preview: ค่า CCS ตัวอย่าง → Base Price @10CCS / ราคาต่อ 1 CCS / ราคาต่อตัน @CCS / ราคาต่อกิโลกรัม

### §1.3.3 รายการหักเพิ่มเติม (Additional Charges)
- table (ชื่อรายการ · ประเภท(amount/percent) · ค่า · หมายเหตุ) + เพิ่มรายการ / แก้ไข / ลบ

### §1.3.4 ภาษี (Tax)
- Switch "หัก VAT ก่อนแบ่งงวด" + note (VAT ก่อนแบ่งงวด 1/2) · ถ้าเปิด → rate (%)

### §1.3.5 ตารางกำหนดวันจ่าย (Payout Schedule) — 2 sub-tabs ⭐
- **ตารางวันจ่ายบิลเขียว (green)**: table [# · ช่วงวันที่ส่ง/ขึ้นเงิน · วันจ่ายงวด 1 · วันจ่ายงวด 2 · การใช้งาน(toggle) · จัดการ(แก้ไข/ลบ)] + เพิ่มช่วง
- **ตารางวันจ่ายบิลขาว (white)**: table [# · ช่วงวันที่เบิกบิลขาว · วันจ่าย (FIXED_DATE→date / WITH_CANE→"ตามตารางบิลเขียว") · การใช้งาน · จัดการ] + เพิ่มช่วง
- Modal "เพิ่ม/แก้ไขช่วงการจ่าย": เดือน · ปี พ.ศ. · วันเริ่มต้น · วันสิ้นสุด + (green: วันจ่ายงวด 1/2) / (white: ประเภทวันจ่าย [วันที่กำหนด/พร้อมค่าอ้อย] → FIXED_DATE ต้องกรอกวัน, WITH_CANE ไม่กรอก)

### §1.3.6 ทดสอบและดูตัวอย่าง (Preview & Test) ⭐
- Inputs: ค่า CCS · น้ำหนัก (ตัน) · วันที่ส่ง/ขึ้นเงิน · ประเภทบิลงวด 1 (บิลเขียว/บิลขาว) · ประเภทบิลงวด 2 · % หักหนี้ (จาก Booking) · จังหวัดบัญชีเกษตรกร · [คำนวณ]
- Outputs: ราคาต่อตัน/ต่อกก. · ยอดรวม · ต่องวด (วันจ่ายปกติ · วันจ่ายจริง · จำนวนวันล่วงหน้า · ยอดก่อนหักหนี้ · ยอดหลังหักหนี้ · ดอกเบี้ย · ค่าธนาคาร · ยอดสุทธิ) · วิธีจ่าย
