## §1.1 P-01 Booking List (`#/bookings`)
```
.ph h1 "จัดการจองรอบส่งอ้อย" + count + sub "ทะเบียนการจองส่งอ้อย · สถานะ 3 แกน (อนุมัติ · ตัด&ขนส่ง · ชำระเงิน) · พิมพ์เอกสาร"
    .ph-actions: [ดาวน์โหลด ▾ (bulk)] [ตรวจสอบที่เลือก (N)] [สร้างการจอง primary]
.stats 4: การจองทั้งหมด · รออนุมัติ · กำลังตัด/ขนส่ง · รอผลการเท/รอทำจ่าย (+เสร็จสิ้น)
.card
 ├ filter-bar: search (booking/quota/farmer/ทะเบียนรถ) + select ฤดูกาล + 3 select สถานะ (อนุมัติ/ตัด&ขนส่ง/ชำระเงิน · แต่ละอันมี "ยังไม่เริ่ม")
 ├ bulk-bar (selected): "เลือก N" + [ดาวน์โหลด ใบสั่งตัด/ใบนำส่ง (ZIP)] + ยกเลิกการเลือก
 ├ table คอลัมน์: ☑ · เลขจอง(mono แดง link) · เกษตรกร/โควตา · ฤดูกาล · วันเวลา/เลน · รถ(ทะเบียน) · **การอนุมัติ**(badge/-) · **ตัด&ขนส่ง**(badge/- + 🔒 ถ้า system) · **ชำระเงิน**(badge/-) · ดาวน์โหลด([CUT][DLV] gate) · อัปเดต · การดำเนินการ
 │  row .is-clickable → openView(booking_id) · sortable: booking_id/updated_at
 └ footer: pagination + "X – Y จาก Z"
```
Phase display (LOCK-06): แกน B "-" ถ้า approval≠verified · "รอส่งอนุมัติตัด" ถ้า verified&cut=null · แกน C "-" ถ้า closed_at=null
Empty: "ยังไม่มีการจอง" +สร้าง · filter empty: "ไม่พบรายการที่ค้นหา" + ล้างตัวกรอง

## §1.2 OV-01 Create (drawer)
```
Section 1 · ข้อมูลจอง: เลือกโควตา (search → farmer snapshot) · เลือกรอบปลูก(crop, optional) · เลือกฤดูกาล(open) · สถานที่(factory/crane)
Section 2 · รอบเวลา/เลน: วันเวลา · รอบ(slot) · เลน(lane)
Section 3 · รถ/น้ำหนัก: ประเภทรถ(e-tan/6/10/16 ล้อ) · ทะเบียน · คนขับ · ปริมาณคาดส่ง(ตัน)
Section 4 · การชำระ/หักหนี้: ประเภทบิล(green/white) · หักหนี้ (%) 0-100 + แสดง "ยอดหนี้คงค้าง" (Debt Mgt) หรือ "ไม่มีแฟ้มลูกหนี้"
Footer: ยกเลิก · ยืนยันสร้าง → waiting_for_verify
```

## §1.4 P-02 Detail (view drawer)
```
head: เลขจอง + combined-progress chip + [actions ตามสถานะ/RBAC]
Combined Timeline (10 ขั้น) — highlight ขั้นปัจจุบัน · ขั้น system มี 🔒
3-axis badges: การอนุมัติ · ตัด&ขนส่ง (+ "ปิดงานขนส่งแล้ว" ถ้า closed) · การชำระเงิน
Sections:
 1) ข้อมูลจอง (farmer/quota/season/slot/lane/vehicle)
 2) รายละเอียดการตัด (cutting_method/summary) + [พิมพ์ใบสั่งตัด] (≥awaiting_cutting)
 3) รายละเอียดจัดส่ง (รถ/เลน/เวลา) + [พิมพ์ใบส่งอ้อย] (≥awaiting_dispatch)
 4) การชำระเงิน (debt% · outstanding snapshot · ยอดหักจริง) — แสดงเมื่อแกน C เริ่ม
 5) ประวัติ & Events (timeline audit)
Actions (no-skip, RBAC):
 - approval: [อนุมัติ][ปฏิเสธ*reason][ยกเลิก*reason] (waiting_for_verify)
 - cut: [ขออนุมัติตัด](verified&cut=null) · [อนุมัติตัด] · [จบการตัด] · [เริ่มจัดส่ง](awaiting_dispatch)
 - **จำลอง event ระบบ**: [check-in→รอผลการเท] [receiving→รอทำจ่าย] [payment→เสร็จสิ้น] (badge "ระบบกำหนด")
 - [ย้อนสถานะ*reason] (void, ก่อน completed) · completed → read-only
footer: อัปเดตล่าสุด + row_version + ปิด
```

## §1.5 OV-03/04/05 Modals
