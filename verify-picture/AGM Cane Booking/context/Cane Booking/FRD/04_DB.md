**Constraints/Guards:**
- CHECK approval_status IN(5) · cut_transport_status IN(null+4) · payment_status IN(3)
- **CHECK: cut_transport_status != null ⇒ approval_status='verified'** (Gate B)
- **CHECK: payment_status != 'not_due' ⇒ cut_transport_closed_at IS NOT NULL** (Gate C)
- Service guard: block manual set payment ∈ {awaiting_payment, completed} + "รอผลการเท"(derived) — system only
**Indexes:** (approval_status)(cut_transport_status)(payment_status)(updated_at desc)(season_id)(quota_id)
**RLS:** tenant_id
