# Data model and classification
| Entity | Fields | Control/class |
|---|---|---|
| `abc_policy_version` | tenant,id,version,basis,window_days,threshold_a/b/c,cadence_a/b/c,effective_date,created_at | append-only policy; Confidential |
| `abc_item_snapshot` | item_ref,warehouse_ref,value,movement_count,as_of,source_version | source lineage; Confidential monetary |
| `cycle_plan` | id,tenant,warehouse,item_ref,class_snapshot,policy_snapshot_json,last_review,due,assigned_counter_ref,version,status | immutable policy snapshot; person ref Restricted PII |
| `cycle_session` | id,plan_id,lot/location/uom refs,expected_base_qty,conversion_factor_snapshot,status,version,review_reason,adjustment_mock_ref | expected Confidential; counter projection excludes |
| `cycle_attempt` | id,session_id,attempt_no,counted_qty,counted_base,conversion_snapshot,actor_ref,at,idempotency_key | append-only; Restricted actor |
| `cycle_event/outbox` | id,session_id,type,attempt_id,actor_ref,source_ref,event_key,at,payload | append-only unique event/key, no hard delete |

Unique tenant+plan/idempotency/attempt; index tenant+warehouse+status/due and event session/time. Inventory owns real onHand/movement, never writable here. Item/Lot/UoM soft refs/snapshots; preserve count audit according to Security retention policy `[ASSUMED]`. RLS tenant/warehouse, counter assignment and reviewer authorization on server.
