# 01_UI — F-TMP-001 แบบฟอร์มขอใช้รถตู้

ต้นแบบ: `feature.html` · archetype **Q-form** · route หลัก `#/van`

## 1. หน้าทะเบียน (`#/van`)
### 1.1 ส่วนหัว
- ชื่อหน้า "แบบฟอร์มขอใช้รถตู้ (Van Request Form)" + จำนวนรายการที่เห็น + จำนวนที่เปิดอยู่
- ปุ่ม **ส่งออก CSV** (DEC-11) · ปุ่ม **สร้างคำขอ** (ปิดเมื่อ doc_type ยังไม่เปิดใช้ที่ F-DOCCFG)
- แถบแดงเมื่อแบบเอกสารยังไม่เปิดใช้งาน

### 1.2 การ์ดสถิติ (คลิกเพื่อกรอง)
| การ์ด | ค่า |
|---|---|
| คำขอทั้งหมด | จำนวนใบที่ผู้ใช้ปัจจุบันเห็น |
| รออนุมัติ | สถานะ `pending` |
| รอฉันพิจารณา | ใบที่ผู้ใช้เป็นผู้พิจารณาขั้นปัจจุบัน |

### 1.3 ตัวกรอง
ค้นหา (เลขที่ / ผู้ขอ / วัตถุประสงค์ / ชื่อผู้เดินทาง) · สถานะ · ลักษณะการเดินทาง · ฝ่าย · ปุ่มล้างตัวกรอง

### 1.4 ตาราง (20 แถว/หน้า)
| คอลัมน์ | ที่มา | เรียงได้ |
|---|---|:---:|
| เลขที่ | `doc_no` | ✅ |
| วันที่ขอ | `doc_date` | ✅ |
| ผู้ขอ | `requester_name` | ✅ |
| ช่วงที่ขอใช้รถ | `use_date_from` – `use_date_to` | ✅ |
| วัน | `total_days` | ✅ |
| ผู้เดินทาง | จำนวนแถวใน `VanRequestTraveler` | — |
| ลักษณะการเดินทาง | `trip_mode` (pill) | — |
| สถานะเอกสาร | `status` (pill) | — |
| ลายเซ็น | n/N จาก `approval_chain` | — |
| ⋮ | เมนู: แก้ไข (ร่างของตัวเอง) · พิมพ์ · ยกเลิกเอกสาร | — |

> ไม่มีเมนู "ทำซ้ำ" ในรอบนี้ (DEC-11 ทำซ้ำ ✗)

## 2. Drawer สร้าง / แก้ไขร่าง (`#/van/create` · `#/van/edit/:id`) — 3 ขั้น
`STEPS = ['ข้อมูลหลักคำขอ', 'เอกสารแนบ', 'ตรวจสอบและยืนยัน']`

### 2.1 ขั้น 1 — ข้อมูลหลัก (ซ้ายฟอร์ม · ขวาการ์ดสรุปสด)
**การ์ด ① ใช้รถตู้เมื่อไหร่ เพื่ออะไร**
| ช่อง | key | ชนิด | บังคับ | หมายเหตุ |
|---|---|---|:---:|---|
| มีความประสงค์จะขอใช้รถตู้ วันที่ | `use_date_from` | ตัวเลือกวัน พ.ศ. (`bedateHTML`) | ✅ | ห้ามใช้ช่องวันที่ของเบราว์เซอร์ (Rule #114) |
| ถึงวันที่ | `use_date_to` | ตัวเลือกวัน พ.ศ. | ✅ | `min` อ้างช่องต้น |
| รวมเป็นจำนวน … วัน | `total_days` | ข้อความคำนวณสด | — | ผู้ใช้แก้ไม่ได้ |
| เพื่อวัตถุประสงค์ | `purpose` | ข้อความ | ✅ | ≤ 255 ตัวอักษร |

**การ์ด ② ใช้รถเที่ยวไหน** — 3 ตัวเลือกแบบการ์ด (`เดินทางเฉพาะขาไป` / `เดินทางเฉพาะขากลับ` / `เดินทางไป-กลับ`)
เลือกแล้วเปิด/ปิดบล็อกด้านล่างตาม DEC-14:
| บล็อก | ช่อง | key |
|---|---|---|
| การเดินทางขาไป | สถานที่รับ (ต้นทาง) · เวลา | `outbound_pickup_place` · `outbound_pickup_time` |
| | สถานที่ส่ง (ปลายทาง) · เวลา | `outbound_dropoff_place` · `outbound_dropoff_time` |
| การเดินทางขากลับ | สถานที่รับ (ต้นทาง) · เวลา | `return_pickup_place` · `return_pickup_time` |
| | สถานที่ส่ง (ปลายทาง) · เวลา | `return_dropoff_place` · `return_dropoff_time` |

**การ์ด ③ ใครเดินทางบ้าง** — 1 คน = 1 การ์ด (ชื่อ `name` + ฝ่าย `division`) · ปุ่ม "เพิ่มผู้เดินทาง" ไม่จำกัดจำนวน
ข้อความใต้การ์ด: "แบบฟอร์มกระดาษมี 5 บรรทัด — ในระบบใส่ได้ไม่จำกัด แบบพิมพ์แสดงอย่างน้อย 5 บรรทัด"

**การ์ดสรุป (ขวา · sticky)** — ผู้ขอ · ผู้พิจารณาต่อขั้นที่ resolve จาก DOA · ช่วงที่ขอใช้รถ + จำนวนวัน · ลักษณะการเดินทาง · จำนวนผู้เดินทาง
> ชื่อ/รหัสพนักงาน/ตำแหน่ง/ฝ่าย/แผนก **ไม่ใช่ช่องกรอก** — แสดงในการ์ดสรุป ดึงจากระบบ

### 2.2 ขั้น 2 — เอกสารแนบ
พื้นที่อัปโหลดหลายไฟล์ · PDF/Word/Excel/รูป ≤ 20 MB ต่อไฟล์ · รายการไฟล์พร้อมปุ่มลบ

### 2.3 ขั้น 3 — ตรวจสอบและยืนยัน
การ์ดสรุป 4 ใบ: ข้อมูลคำขอ (รวมผู้พิจารณาต่อขั้น) · รายชื่อผู้เดินทาง · สถานที่รับ-ส่งและเวลา · เอกสารแนบ
แถบเตือนเมื่อวันที่เริ่มเป็นวันที่ผ่านมาแล้ว

### 2.4 ปุ่มท้าย drawer
ย้อนกลับ · ยกเลิก · ถัดไป → ขั้นสุดท้ายเป็น **บันทึกแบบร่าง** + **บันทึกและส่งอนุมัติ**
ปิด drawer ขณะกรอกค้าง → modal "ทิ้งข้อมูลที่กรอกไว้?"

## 3. Drawer ดูรายละเอียด (`#/van/view/:id`) — 4 แท็บ
| แท็บ | เนื้อหา |
|---|---|
| รายละเอียด | แถบสถานะ · ข้อมูลเอกสาร · ผู้ขอ · ความประสงค์ขอใช้รถตู้ · รายชื่อผู้เดินทาง · สถานที่รับ-ส่งและเวลา · เอกสารแนบ · ข้อมูลระบบ |
| PDF Preview | iframe A4 render จาก `form.tpl.html` + ปุ่มดาวน์โหลด/พิมพ์ |
| ลายเซ็น / อนุมัติ | การ์ดสรุปสาย + timeline ขั้น 1..N + ปุ่มตัดสินในขั้นปัจจุบัน |
| ประวัติ | รายการ append-only เรียงใหม่→เก่า |

### 3.1 ปุ่มหัว drawer ตามสถานะ
| สถานะ | ผู้ใช้ | ปุ่ม |
|---|---|---|
| `draft` | เจ้าของ | ยกเลิก · แก้ไข · ส่งอนุมัติ |
| `pending` | ผู้พิจารณาขั้นปัจจุบัน | *(คำตัดสินตาม role)* ไม่อนุมัติ/ไม่เห็นควร · อนุมัติ/เห็นควร |
| `pending` | เจ้าของ / admin role | ยกเลิกเอกสาร |
| `approved` / `rejected` / `cancelled` | ทุกคนที่เห็น | พิมพ์ · ดาวน์โหลด PDF เท่านั้น |

## 4. Modal
| modal | เนื้อหา |
|---|---|
| ส่งอนุมัติ | 1 แถวต่อขั้น DOA (เลขขั้น · ชื่อ role · ช่องเลือกผู้พิจารณา) · ค่าเริ่มจาก resolve · ผู้ขอไม่อยู่ในรายชื่อ · บังคับเลือกครบ |
| อนุมัติ / เห็นควร | สรุปใบ + ช่องความเห็น (ไม่บังคับ) |
| ไม่อนุมัติ / ไม่เห็นควร | ชิปเหตุผลสำเร็จรูป + ช่องเหตุผล (**บังคับ**) |
| ยกเลิกเอกสาร | ชิปเหตุผลสำเร็จรูป + ช่องเหตุผล (**บังคับ**) |
| ทิ้งข้อมูล | ยืนยันก่อนปิด drawer ที่กรอกค้าง |
