## 1. บทนำ

### 1.1 ที่มา
ลูกค้าส่งแบบฟอร์มกระดาษ **"แบบฟอร์มขอใช้รถตู้" (FM-HRM-22 Rev. 00)** เข้ามาให้ขึ้นเป็นเอกสารในระบบ CUBE NATIVE
ปัจจุบันพนักงานกรอกกระดาษ → เดินไปให้ผู้บังคับบัญชาเซ็น → ส่งต่อฝ่ายทรัพยากรบุคคล → เก็บแฟ้ม
ไม่มีทะเบียนกลาง ไม่รู้ว่ารถถูกจองช่วงไหนบ้าง และตามใบที่ค้างอนุมัติไม่ได้

## 2. วัตถุประสงค์ทางธุรกิจ

### 2.1 ปัญหาปัจจุบัน
1. ใบขอใช้รถตู้เป็นกระดาษ — หาไม่เจอ ตามไม่ได้ ไม่มีเลขที่อ้างอิง
2. ไม่รู้สถานะว่าใบอยู่กับใคร ค้างที่ขั้นไหน ต้องเดินไปถาม
3. ฝ่ายทรัพยากรบุคคลไม่มีภาพรวมว่าช่วงไหนมีคำขอใช้รถซ้อนกัน
4. ผู้ขอกรอก "รวมเป็นจำนวน … วัน" เอง จึงไม่ตรงกับช่วงวันที่ที่กรอกอยู่บ่อยครั้ง

### 2.2 เป้าหมาย
| # | เป้าหมาย |
|---|---|
| G1 | ทุกคำขอใช้รถตู้มีเลขที่เอกสารและสถานะในระบบ ค้นย้อนหลังได้ |
| G2 | ผู้ขอเห็นได้เองว่าใบค้างที่ขั้นไหน ไม่ต้องเดินไปถาม |
| G3 | จำนวนวันคำนวณจากช่วงวันที่ให้อัตโนมัติ ไม่มีใบที่จำนวนวันไม่ตรงช่วง |
| G4 | ฝ่ายทรัพยากรบุคคลเปิดดูคำขอทั้งหมดในที่เดียว และส่งออก CSV ไปทำตารางใช้รถได้ |

### 2.3 ตัวชี้วัด (มีคู่ใน §17.3 ทุกตัว)
| KPI | Baseline (กระดาษ) | Target | วิธีวัด | จังหวะวัด |
|---|---|---|---|---|
| M1 เวลารออนุมัติเฉลี่ย (ส่ง → อนุมัติครบ) | 2.5 วันทำการ (ประมาณการจาก HR) | ≤ 1 วันทำการ | `approved_at − submitted_at` เฉลี่ยต่อเดือน | รายเดือน |
| M2 สัดส่วนใบที่จำนวนวันไม่ตรงช่วงวันที่ | ~15% ของใบกระดาษ (HR สุ่มตรวจ) | 0% | นับใบที่ `total_days ≠ (date_to − date_from) + 1` | รายเดือน |
| M3 สัดส่วนคำขอที่ทำผ่านระบบ (ไม่ใช้กระดาษ) | 0% | ≥ 90% ภายใน 2 เดือนหลังเปิดใช้ | จำนวนใบในระบบ ÷ จำนวนใบที่ HR รับทั้งหมด | รายเดือน |
| M4 ใบค้างเกิน 3 วันทำการ | ไม่มีข้อมูล | ≤ 5% ของใบที่ส่งในเดือน | นับใบสถานะ `pending` อายุ > 3 วันทำการ | รายสัปดาห์ |

## 3. ขอบเขต

### 3.1 In Scope
- หน้าทะเบียนคำขอใช้รถตู้ (ค้นหา · กรอง · เรียง · แบ่งหน้า · ส่งออก CSV)
- สร้าง / แก้ไขร่าง / ส่งอนุมัติ / อนุมัติ / ไม่อนุมัติ / ยกเลิก
- แบบพิมพ์ PDF A4 เหมือนกระดาษเดิม (โหมด Replica) ทุกสถานะ
- เลขที่เอกสารจาก ENG-DOC-NUM (F-DOCCFG) · ประกาศแบบเอกสารที่ F185
- สายอนุมัติอ่านจาก DOA กลาง (F-DLG-001) แบบ dynamic
- แนบไฟล์ประกอบ (Document Center)

### 3.2 Out of Scope
- **ตารางการใช้รถ / ปฏิทินรถตู้ / ตรวจรถว่าง** — ยังไม่มี feature ทะเบียนยานพาหนะใน CUBE (ดู §15 OQ-02)
- **มอบหมายคนขับ · บันทึกเลขไมล์ · ค่าน้ำมัน** — ไม่มีบนกระดาษ (DEC-06 1:1)
- **เชื่อมเวลาทำงาน / เบิกจ่าย / เงินเดือน** — DEC-02 ไม่ส่งต่อระบบอื่นในรอบนี้
- **เปลี่ยนค่าตั้งค่าใด ๆ ในระบบเมื่ออนุมัติ** — DEC-01
- **ทำซ้ำเอกสาร (copy)** — DEC-11 ปิดไว้ในรอบนี้
- **ประกาศ/แจ้งผู้เดินทางเมื่ออนุมัติ** — DEC-11 ปิดไว้ (ดู §15 OQ-04)
