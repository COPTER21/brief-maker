### 3.1 รายการซ้ำ
- **รายชื่อผู้เดินทาง** — บนกระดาษ 5 แถว (min_rows) · ช่องในแถว: รายชื่อผู้เดินทาง, ฝ่าย

### 3.2 ตัวเลือก
- **ลักษณะการเดินทาง** (เลือกได้ข้อเดียว): เดินทางเฉพาะขาไป → ใช้ช่อง สถานที่รับ (ต้นทาง), เวลา, สถานที่ส่ง (ปลายทาง), เวลา · เดินทางเฉพาะขากลับ → ใช้ช่อง สถานที่รับ (ต้นทาง), เวลา, สถานที่ส่ง (ปลายทาง), เวลา · เดินทางไป-กลับ → ใช้ช่อง สถานที่รับ (ต้นทาง), เวลา, สถานที่ส่ง (ปลายทาง), เวลา, สถานที่รับ (ต้นทาง), เวลา, สถานที่ส่ง (ปลายทาง), เวลา

### 3.3 สูตร + ค่าคงที่บนกระดาษ
- สูตร: รวมเป็นจำนวน ... วัน = `(F08 - F07) + 1` จำนวนวันนับรวมวันเริ่มและวันสิ้นสุด · F08 ต้องไม่ก่อน F07

### 3.4 ลายเซ็น + control
- S1 ผู้ขอใช้รถตู้ (ผู้ขอ)
- S2 ผู้บังคับบัญชา (ผู้อนุมัติ) · ตัวเลือก: อนุมัติ / ไม่อนุมัติ
- S3 ผู้จัดการฝ่ายทรัพยากรบุคคล (ผู้อนุมัติ) · ตัวเลือก: เห็นควร / ไม่เห็นควร

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- ต้นฉบับพิมพ์ชื่อบุคคลจริงไว้ตายตัวใต้ช่องลงชื่อ → **ชื่อผู้พิจารณาต้องมาจาก DOA resolve ตอนส่ง ห้าม hardcode ชื่อบุคคล และเป็นข้อมูลส่วนบุคคล (ห้ามใช้เป็นข้อมูลตัวอย่าง)**
- ต้นฉบับให้ผู้ขอกรอกจำนวนวันเอง ซึ่งอาจไม่ตรงกับช่วงวันที่ที่กรอก → **ระบบคำนวณจำนวนวันจากช่วงวันที่ และบล็อกเมื่อถึงวันที่ ก่อน วันที่เริ่ม**
- ต้นฉบับมีช่องขาไปและขากลับครบเสมอ แม้ติ๊กเดินทางเฉพาะขาเดียว → **ติ๊กเฉพาะขาไป → ต้องกรอกเฉพาะบล็อกขาไป · เฉพาะขากลับ → เฉพาะบล็อกขากลับ · ไป-กลับ → ครบทั้งสองบล็อก**
