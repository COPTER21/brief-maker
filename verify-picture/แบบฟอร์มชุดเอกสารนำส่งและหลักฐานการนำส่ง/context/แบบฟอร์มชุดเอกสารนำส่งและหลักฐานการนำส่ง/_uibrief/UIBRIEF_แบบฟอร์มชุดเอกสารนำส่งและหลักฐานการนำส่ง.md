## §7 Interaction Spec
- พิมพ์ในช่อง = soft update ไม่ rebuild (focus ไม่หลุด) · `setTop()` · `setDoc(…, soft)` · `setDel(…, soft)` + `softSum()` อัปเดตการ์ดสรุป
- กดถัดไป = `validateMain()` → ช่องแดง + ข้อความใต้แถว + toast · ขาดเอกสาร/มีข้อจำกัด ไม่มีหมายเหตุ บล็อก · ขาดเอกสาร = เตือน · ไม่มีแถว บล็อก
- บันทึกหลักฐาน = `validateDels()` → รับแล้วไม่มีหลักฐาน บล็อก · อื่น ๆ/ส่งไม่สำเร็จ/ยกเลิก ไม่มีหมายเหตุ บล็อก · เวลาอนาคต บล็อก · ก่อนวันที่นำส่ง เตือน (`S.dw.warn`) · ไม่เปลี่ยนสถานะ (ไม่อนุมัติซ้ำ)
- ส่ง → modal slot ต่อขั้น DOA (`resolveDoa()` · MOCK_DOA_RESOLVED) · อนุมัติเรียงขั้น `confirmApprove()` · ส่งกลับ/ยกเลิก `confirmReason()` · ปิดการนำส่ง `openClose()` → `confirmClose()` (บล็อกตาม `closeBlock()`) · modal render เฉพาะตอนเปิด (state.modal.open) + guard กันพังระหว่างปิด
- จำลอง API ล้ม: `commitRejected()` (S.sim) · persona เดโม `switchPersona()`
