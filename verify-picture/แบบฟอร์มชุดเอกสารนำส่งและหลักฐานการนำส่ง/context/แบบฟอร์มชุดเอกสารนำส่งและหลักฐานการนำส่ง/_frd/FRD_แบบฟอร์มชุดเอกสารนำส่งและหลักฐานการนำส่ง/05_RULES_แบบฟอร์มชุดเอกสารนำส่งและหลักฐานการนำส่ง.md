## §5.2 State Machine
draft →(ส่ง)→ pending[1..N] →(อนุมัติขั้น N)→ approved →(บันทึกหลักฐาน · คงสถานะ)→ approved →(ปิดการนำส่ง)→ closed · pending →(ส่งกลับ)→ draft · draft/pending →(ยกเลิก)→ cancelled · closed = ล็อก

## §5.3 Permission
| Action | owner | ผู้พิจารณาขั้นปัจจุบัน | ผู้ในสาย (ไม่ใช่ขั้นปัจจุบัน) | admin | อื่น |
|---|:-:|:-:|:-:|:-:|:-:|
| ดู | ✓ | ✓ (หลังส่ง) | ✓ (หลังส่ง) | ✓ | ✗ 404 |
| แก้/ส่ง | ✓ draft | ✗ | ✗ | ✗ | ✗ |
| ตัดสิน | ✗ | ✓ | ✗ 403 | ✗ | ✗ |
| บันทึกหลักฐาน / ปิดการนำส่ง | ✓ approved | ✗ 403 | ✗ 403 | ✓ approved | ✗ |
| ยกเลิก | ✓ draft/pending | ✗ | ✗ | ✓ draft/pending | ✗ 403 |

## §5.4 Validation
| VR | ช่อง | เงื่อนไข | ข้อความ |
|---|---|---|---|
| VR-01 | project_name · purpose · recipient · dispatch_date | required | กรุณากรอกชื่อโครงการ / ธุรกรรม · กรุณากรอกวัตถุประสงค์การนำส่ง · กรุณากรอกผู้รับการนำส่ง · กรุณาเลือกวันที่นำส่ง |
| VR-02 | docs[].doc_name · version | required ต่อแถว | ลำดับ n: กรอก เอกสาร · ฉบับ |
| VR-03 | docs[].remark | required เมื่อ status ∈ {missing, limited} | ลำดับ n: กรอก หมายเหตุ (สถานะ ขาดเอกสาร / มีข้อจำกัด) (DEC-15) |
| VR-04 | docs | ≥ 1 แถว | ต้องมีรายการตรวจสอบชุดเอกสารอย่างน้อย 1 รายการ |
| VR-05 | deliveries[].sent_at | วันที่ + HH:mm · ≤ ตอนนี้ | ลำดับ n: กรอก วันที่ · เวลา (HH:mm) · วันที่ / เวลาต้องไม่เป็นเวลาในอนาคต (DEC-19) |
| VR-06 | deliveries[].sender · receiver · receiver_org · docs_sent | required ต่อแถว | ลำดับ n: กรอก ผู้ส่ง · ผู้รับ · หน่วยงาน · เอกสารที่ส่ง |
| VR-07 | deliveries[].evidence | required เมื่อ received (หรือ evidence_file_id) | ลำดับ n: รับแล้ว ต้องมีหลักฐาน / ลิงก์ หรือไฟล์แนบ (DEC-17) |
| VR-08 | deliveries[].remark | required เมื่อ channel = other ∨ receipt_status ∈ {failed, cancelled} | ลำดับ n: ช่องทาง อื่น ๆ / ส่งไม่สำเร็จ / ยกเลิก ต้องมีหมายเหตุ (DEC-18) |
| VR-09 | deliveries | ≥ 1 แถวเมื่อบันทึก | ต้องมีรายการนำส่งอย่างน้อย 1 รายการ |
| VR-10 | close | received ≥ 1 · pending = 0 | ยังปิดการนำส่งไม่ได้ — ยังไม่มีแถวสถานะการรับ "รับแล้ว" / ยังมีแถว "รอยืนยัน" n รายการ |
| VR-11 | assignees | ทุกขั้น · ≠ ผู้จัดทำ | กรุณาเลือกผู้พิจารณา |
| VR-12 | reason (ส่งกลับ/ยกเลิก) | required | กรุณาระบุเหตุผล |
