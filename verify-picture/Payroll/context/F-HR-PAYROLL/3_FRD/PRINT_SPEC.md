### §P.2.1 สลิปของ **รอบปรับปรุง** (`S-46` · `FN-66`)

เพิ่ม **บล็อกก่อนตาราง** ชื่อ **`รายการปรับปรุงงวดก่อน`** ระบุ `adjust_of_period_code` · `adjust_of_run_no` · เหตุผลรายบรรทัด · เอกสารต้นทางที่ทำให้เกิดส่วนต่าง
- ตารางเงินได้/เงินหักของฉบับนี้ **แสดงเฉพาะส่วนต่าง** ไม่ใช่ยอดเต็มของงวดเดิม
- **หัวเอกสารต้องเขียนชัดว่าเป็นรอบปรับปรุง** เพื่อไม่ให้ถูกเข้าใจว่าเป็นสลิปประจำงวดฉบับที่สอง
- ⭐ **สลิปของงวดเดิมยังใช้ได้และยังถูกต้อง** — ข้อความหมายเหตุข้อ 1 ครอบเรื่องนี้อยู่แล้ว

### §P.2.2 สลิปของ **รอบกลับรายการ**

ใช้แบบเดียวกับ §P.2.1 แต่ยอดกลับด้าน · หัวเอกสารระบุ **"รอบกลับรายการ"** · อ้างรอบต้นฉบับ

## §P.5 ⭐ ชั้นความลับ — all-or-nothing (ไม่มี rendition ปิดบัง)

ต่างจาก `F-HR-MOVE` และ `F-HR-CERT` ที่ทำ 2 rendition (`full` / `masked`) — **สลิปทำ rendition เดียว**

**เหตุผล:** สลิปที่ตัวเลขถูกปิดบังคือ **เอกสารที่ไม่มีเนื้อหาเหลือเลย** (ทุกบรรทัดของมันเป็นเงิน) และการมอบเอกสารเปล่าให้ผู้เรียกจะทำให้เข้าใจผิดว่า **ได้รับข้อมูลครบแล้ว** ซึ่งอันตรายกว่าการถูกปฏิเสธตรง ๆ

| ผู้เรียก | ผลลัพธ์ |
|---|---|
| **เจ้าของสลิป** (ผ่าน ESS ⏳W6) | ✅ เอกสารเต็ม |
| **HR Payroll Officer · Comp Admin** ในขอบเขตบริษัทนั้น | ✅ เอกสารเต็ม · **บันทึก SecC** (`payroll.restricted_viewed` · `view_surface: payslip_other`) |
| **ผู้อนุมัติของรอบ** | ✅ เอกสารเต็ม · บันทึก SecC |
| **หัวหน้าหน่วยงาน · Finance · อื่น ๆ** | ❌ **`403 ERR_PAYSLIP_FORBIDDEN`** · บันทึก SecC (`payroll.access_denied`) |

⛔ **ไม่มี query param · ไม่มี header · ไม่มี role ใด ที่ทำให้ได้เอกสารแบบตัวเลขถูกปิดบัง** — ถ้ามีคนเพิ่มภายหลัง ถือว่าขัด `LOCK-SLIP403` และต้องแก้ FRD ก่อน (`IA-19`)

## §P.6 Render — คำสั่งที่ใช้จริง (ทำซ้ำได้)

```
# 1) ประกอบไฟล์เดี่ยว (ฝังฟอนต์ Sarabun 4 น้ำหนักเป็น base64 + base.css)
python3 .claude/skills/thai-doc-pdf-generator/scripts/build_html.py \
        _body.html --title "สลิปเงินเดือน" -o template.html

# 2) render เป็น PDF ด้วย WeasyPrint (แทน Chromium ที่ติดตั้งไม่ได้)
python3 -c "from weasyprint import HTML; HTML(filename='template.html').write_pdf('sample.pdf')"

# 3) ตรวจ
pdfinfo sample.pdf     # → Pages: 1 · Page size: 595.276 x 841.89 pts (A4) · Producer: WeasyPrint 69.0
```

**ผลการตรวจของไฟล์ที่ส่งมอบ:** ✅ `Pages: 1` · ✅ `595.276 × 841.89 pts (A4)` · ✅ `Producer: WeasyPrint 69.0` · ✅ ฟอนต์ไทยแสดงถูกต้อง · ✅ **ไม่มี asset ภายนอก**
