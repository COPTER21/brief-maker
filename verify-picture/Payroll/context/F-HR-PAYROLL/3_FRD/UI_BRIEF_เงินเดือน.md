## §4 Page Anatomy

### §4.1 P-01 · `#/payroll/runs` — รายการรอบจ่าย

```
page-header (ชื่อหน้า + ปุ่ม สร้างรอบ)
└ page-tabs  [ รอบจ่าย | คิวรอบปรับปรุง | สลิปเงินเดือน ]
  └ stat row (4 การ์ด)
  └ filter bar (แถวเดียว: งวด · ชนิดรอบ · สถานะ · บริษัท · ค้นหา)
  └ table-wrap > table (11 คอลัมน์ · thead sticky)
     └ แถว: เลขที่ · งวด · ชนิด · ขอบเขต · สถานะ(pill) · จำนวนคน · วันจ่าย · ยอดรวม · ธงความต่าง · ผู้จัดทำ · การกระทำ
```
- `thead th { position: sticky; top: 0; z-index: var(--z-sticky) }` — หัวตารางค้างเมื่อ scroll
- คลิกแถว → `#/payroll/run/<เลขที่>`

### §4.2 P-02 · `#/payroll/queue` — คิวรอบปรับปรุง

`page-tabs` เดียวกัน → ตารางรายการที่มาจากเหตุการณ์ต้นทางหลังปิดรอบ (ต้นทาง · เหตุการณ์ · พนักงาน · รอบที่ปิดแล้วที่เกี่ยวข้อง · เวลา) + ปุ่ม **สร้างรอบปรับปรุง** ต่อแถว

### §4.3 P-03 · `#/payroll/slips` — ทะเบียนสลิป

`page-tabs` เดียวกัน → ตารางสลิปข้ามรอบ (เลขที่สลิป · รอบ · งวด · พนักงาน · สถานะการเผยแพร่ · สุทธิ ปิดบังตามสิทธิ์) · **ไม่มีปุ่มสร้าง/แก้สลิป**

### §4.4 P-04 · `#/payroll/run/<no>` — หน้ารอบจ่าย

```
run-header
├ เลขที่รอบ + ชนิดรอบ + งวด + วันจ่าย + จำนวนคน
├ state rail (เครื่องสถานะ 9 สถานะ · ไฮไลต์สถานะปัจจุบัน)
└ action bar (ปุ่มตามสถานะ — ดู §8)
run-tabs  [ ความพร้อม | ผลคำนวณ | เทียบรอบก่อน | ลายเซ็น/อนุมัติ | สลิป | ไฟล์และบัญชี | ประวัติ ]
```

| แท็บ | region หลัก |
|---|---|
| **ความพร้อม** | แถบความพร้อม 6 แถว → ตารางสรุปการดึงข้อมูล → บล็อกรหัสเวอร์ชัน → การ์ดค่าตามกฎหมาย → gate ตามสภาพ (ดึงไม่ครบ · ต้องแก้ก่อน · ข้อมูลเวลาไม่ครบ · ถูกคัดออก · สิทธิ์อ่านอัตราไม่พอ · ชั่วโมงนอกกะ) → **ตาราง "ขอบเขตของหน้าจอนี้" 10 แถว** |
| **ผลคำนวณ** | การ์ดยอดรวมของรอบ → ตารางบรรทัดของรอบ (พร้อมบรรทัดรอง "ไล่กลับต้นทาง") → section รายการเบิกที่จ่ายผ่านเงินเดือน → ปุ่มเพิ่มรายการปรับด้วยมือ → drawer รายการที่คำนวณไม่ได้ |
| **เทียบรอบก่อน** | ตารางรายคน → ตารางรายองค์ประกอบ → section คนเข้า/คนหาย → สรุปต้นทุนแรงงานแยกศูนย์ต้นทุน → gate ไม่มีรอบก่อน / ยังไม่มีเกณฑ์ |
| **ลายเซ็น/อนุมัติ** | บล็อก `action_id` ที่เลือกได้ + เหตุผล → **บล็อก payload ที่ส่งเข้าเครื่องมืออนุมัติกลาง** → สายอนุมัติ 3–5 ขั้น → gate "ข้อมูลต้นทางเปลี่ยนหลังคำนวณ" |
| **สลิป** | ตารางสลิปของรอบ → drawer สลิป → gate ประกาศว่าไม่มีตัวช่วยสร้างสลิปรายใบ |
| **ไฟล์และบัญชี** | ปุ่มออกไฟล์โอน → รายการ "ต้องจ่ายด้วยวิธีอื่น" → ปุ่มทำเครื่องหมายว่าส่งไฟล์แล้ว → รายการบัญชี + สถานะ "รอปลายทาง" → สรุปเงินหักตามกฎหมายต่อรอบ |
| **ประวัติ** | ไทม์ไลน์ append-only → บล็อกค่าตรวจสอบของชุดข้อมูล → section ความสัมพันธ์กับรอบอื่น |

## §7 Interaction Spec

| เรื่อง | พฤติกรรมจริง |
|---|---|
| Esc | ตาม chain ใน §6 |
| คลิกนอก | backdrop ของ drawer/modal ปิด overlay นั้น |
| scrollbar | `scrollbar-gutter: stable` — เปิด/ปิด overlay แล้วหน้าจอไม่ขยับซ้าย-ขวา (#35) |
| dropdown positioning | `.menu-fixed { position: fixed !important }` — ไม่ถูกตัดด้วย `overflow` ของตาราง |
| sticky | `thead th` ค้างบนสุดของ `.table-wrap` |
| ตารางกว้าง | scroll ในกรอบของตัวเอง — **หน้าไม่ scroll แนวนอน** |
| ค้นหาใน combobox | ไฮไลต์คำค้นด้วย `<mark>` |
| การเปลี่ยนแท็บในหน้ารอบ | render เฉพาะส่วนเนื้อหา ไม่ reload ทั้งหน้า |
| ปุ่มที่ใช้ไม่ได้ | disabled พร้อม ⓘ ที่บอกเหตุผล — **ไม่ซ่อนปุ่มเงียบ ๆ ยกเว้นกรณีรอบที่ปิดแล้วซึ่งปุ่มแก้หายไปทั้งชุด** |
