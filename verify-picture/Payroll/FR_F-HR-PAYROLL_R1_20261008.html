ส่วนที่ไม่ได้ตรวจ อยู่นอกความรับผิดชอบของรายงานฉบับนี้

ตรวจแล้ว

  • UX/UI ของหน้าจอ Payroll (ไล่เล่นทั้งหน้า)
  • Drawer ตัวช่วยสร้างรอบ (wizard) — layout และเนื้อหาแต่ละ step
  • Combobox ค้นหาพนักงาน
  • หน้ารายละเอียดรอบ — แท็บผลการคำนวณ และแท็บประวัติ
  • เปิดดูสลิป / PDF preview
  • ปุ่ม 'ไปที่การจ่ายเงิน'

ไม่ได้ตรวจ

  • ความถูกต้องของตัวเลข (เงินได้/เงินหัก/ภาษี/ประกันสังคม/กองทุนสำรองฯ) — รอบนี้เน้น UX/UI ไม่ได้ตรวจกฎธุรกิจการคำนวณ
  • สายอนุมัติ DOA + SoD (ผู้จัดทำเซ็นเองไม่ได้) — นอกขอบเขต UX/UI รอบนี้
  • การปิดรอบ + รอบที่ปิดแล้วแก้ไม่ได้ (immutable) — นอกขอบเขต UX/UI รอบนี้
  • การปิดบังตัวเลขตามสิทธิ์ (masking) และสลิป 403 all-or-nothing — นอกขอบเขต UX/UI รอบนี้
  • Fail-closed — ส่งอนุมัติไม่ได้เมื่อมีบรรทัด 'ยังคำนวณไม่ได้' — นอกขอบเขต UX/UI รอบนี้
  • 3 สถานะของช่องจำนวนเงิน (NULL / 0 / ปิดบัง) แยกกันถูกต้อง — นอกขอบเขต UX/UI รอบนี้

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-01เปิดดูสลิปเงินเดือนแล้ว API error 404 — เปิดสลิปไม่ได้Criticalรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดหน้ารายละเอียดรอบ → แท็บผลการคำนวณ (หรือแท็บสลิป)
  2. กดดูสลิปของพนักงาน
ผลที่ควรเป็นเปิด drawer สลิปได้ (รายละเอียด › PDF › ลายเซ็น › ประวัติ)
ผลที่เกิดจริงAPI error 404 — ไม่เปิดสลิป
BUG-02ปุ่มในแท็บผลการคำนวณกดแล้วไม่ตอบสนองHighรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดหน้ารายละเอียดรอบ → แท็บผลการคำนวณ
  2. กดปุ่ม (ระบุปุ่มที่กด)
ผลที่ควรเป็นปุ่มทำงานตามหน้าที่ของมัน
ผลที่เกิดจริงกดแล้วไม่เกิดอะไรขึ้น
BUG-03ปุ่ม 'ไปที่การจ่ายเงิน' กดแล้วไม่ตอบสนองHighรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดหน้ารายละเอียดรอบ
  2. กดปุ่ม 'ไปที่การจ่ายเงิน'
ผลที่ควรเป็นเปิดแท็บ/หน้าไฟล์และบัญชี (การจ่ายเงิน)
ผลที่เกิดจริงไม่เกิดอะไรขึ้น
BUG-04ส่วนทดลอง (เดโม/สลับบทบาททดสอบ) โผล่บนระบบจริงMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด Payroll บน Production
ผลที่ควรเป็นไม่มีส่วนทดลอง/เดโมบนระบบจริง (เดโมมีได้เฉพาะ prototype)
ผลที่เกิดจริงพบส่วนที่เป็นการทดลองแสดงอยู่ (ระบุตำแหน่งที่พบเพิ่มได้)
BUG-05combobox ค้นหาพนักงานต้องพิมพ์ก่อน option ถึงจะขึ้นMediumรอแก้
ขั้นตอนทำซ้ำ
  1. เปิด drawer สร้างรอบ → ขั้น 'ขอบเขตของรอบ'
  2. กดช่องค้นหาพนักงาน (ยังไม่พิมพ์)
ผลที่ควรเป็นแสดงรายการพนักงานให้เลือกได้ทันที แล้วพิมพ์เพื่อกรอง
ผลที่เกิดจริงไม่ขึ้น option จนกว่าจะพิมพ์ และ layout ของ option เพี้ยน
