## 1. Business Context
### 1.1 ปัญหา / โอกาส
- ปัจจุบันฝ่ายบุคคลใช้แบบฟอร์มกระดาษ FM-HRM-06 เก็บความเห็นของผู้พ้นจากงาน 3 หน้า (ข้อมูลบุคลากร · ความพึงพอใจ 26 ข้อ · ปัจจัยที่ออก 21 ข้อเรียงลำดับ · ข้อเสนอแนะ) — กรอกมือ นับคะแนนเอง สรุปภาพรวมยาก และกระดาษมีความเห็นต่อผู้บังคับบัญชาซึ่งต้องเก็บเป็นความลับ
- ขึ้นระบบเพื่อ: ดึงข้อมูลพนักงานจากระบบ (ไม่ต้องกรอกซ้ำ) · คำนวณอายุตัว/อายุงานให้ · บังคับตอบครบ · เก็บเป็นความลับ (HR เท่านั้น) · ส่งออก CSV ไปวิเคราะห์ · พิมพ์แบบฟอร์มหน้าตาเดิมได้

### 1.2 เป้าหมาย
1. ผู้พ้นจากงาน (หรือ HR สัมภาษณ์แทน) กรอกแบบสอบถามครบในระบบเดียว
2. ฝ่ายบุคคลเห็นทุกใบ · ผู้บังคับบัญชาไม่เห็น
3. พิมพ์ PDF ตามแบบ FM-HRM-06 ได้ทุกสถานะ

### 1.3 ตัวชี้วัด
- ไม่มีใน input → OQ-03 (ห้ามแต่งตัวเลข)

### 1.4 ที่มา

## 2. Scope
### 2.1 In Scope
- หน้ารายการ · สร้าง/แก้ร่าง (wizard 3 ขั้น) · ดู (รายละเอียด › PDF Preview › ลายเซ็น / อนุมัติ › ประวัติ) · ส่ง · ยกเลิก · ส่งออก CSV · แนบไฟล์
- แบบพิมพ์ Replica FM-HRM-06 (thai-doc v2.1) · เลขที่ EXI จาก F-DOCCFG / ENG-DOC-NUM
- แจ้งเตือน exi_submitted / exi_cancelled (ENG-NOTIFY)

### 2.2 Out of Scope
- การพ้นสภาพพนักงานในระบบ (HR · Offboard) — แบบสอบถามไม่เปลี่ยนสถานะพนักงาน (DEC-01)
- ส่งต่อระบบอื่น / รายงานวิเคราะห์ภาพรวม (dashboard) — รอบนี้ส่งออก CSV เท่านั้น (DEC-02 · DEC-11)
- สายอนุมัติ — กระดาษไม่มีช่องผู้อนุมัติ (DEC-03) · ทำซ้ำ · ประกาศ (DEC-11)

### 2.3 Assumptions
- Employee มี birth_date, hire_date, employment_type, probation_status, education (ถ้าไม่มี = กรอกเอง) · พนักงานชั่วคราวมี contract_end_date
- ผู้พ้นจากงานยังเข้าระบบได้จนวันสุดท้าย · ถ้าเข้าไม่ได้ HR สร้างแทน (DEC-04)

## 4. User Journey
### 4.1 Happy Path
1. ผู้ให้ข้อมูลเปิด "แบบสอบถามบุคลากรที่พ้นจากงาน" → สร้าง → ระบบเติมข้อมูลบุคลากรจาก Employee
2. เลือก "วันที่ลาออก" + วันที่ → ระบบคำนวณอายุตัว/อายุงาน
3. ตอบส่วนที่ 2 ครบ 26 ข้อ → เลือกปัจจัยส่วนที่ 3 ตามลำดับ → ข้อเสนอแนะ (ไม่บังคับ)
4. แนบไฟล์ (ถ้ามี) → ตรวจสอบ → บันทึกและส่ง → ระบบออกเลข EXI · สถานะ "ส่งแล้ว" · แจ้ง HR (exi_submitted)
5. HR เปิดดู · พิมพ์ PDF FM-HRM-06

### 4.2 Alternative
- A1 ไม่จ้างต่อ (ครบสัญญาจ้าง) → เลือกเหตุผลข้อ 5 (ประสงค์พนักงาน/หน่วยงาน/อื่น ๆ + ระบุ)
- A2 HR สร้างแทน (สัมภาษณ์) → เลือกผู้ให้ข้อมูลก่อน
- A3 บันทึกร่างไว้ก่อน → กลับมาแก้ → ส่ง
- A4 ยกเลิก (เหตุผลบังคับ) โดยเจ้าของหรือ HR

## 7. Status & Lifecycle
`draft (ร่าง)` → ส่ง → `submitted (ส่งแล้ว)` · `draft|submitted` → ยกเลิก → `cancelled`
- ถ้าภายหลังตั้งขั้นที่ DOA กลาง: ส่ง → `pending` → รับทราบครบ → `approved` · ส่งกลับ → `draft` เลขเดิม (policy G7)
- ส่งแล้วแก้ไม่ได้ (ล็อก) · เลขออกตอนบันทึกครั้งแรก (DEC-10)
