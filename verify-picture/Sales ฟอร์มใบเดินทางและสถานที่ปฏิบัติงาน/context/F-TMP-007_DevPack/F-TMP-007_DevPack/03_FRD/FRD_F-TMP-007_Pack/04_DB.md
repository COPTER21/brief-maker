## 4. `approval_chain` (jsonb ใน `travel_sheet`) — โครงต่อขั้น
```json
[ { "step": 1, "role_id": "role-line-manager", "label": "ผู้อนุมัติ",
    "assignee_id": "<uuid>", "status": "pending", "at": null, "note": "" } ]
```
`status`: `waiting` · `pending` · `approved` · `rejected` · `skipped`
จำนวนขั้นมาจาก DOA กลาง — **ห้าม fix จำนวนขั้นหรือ role ในสคีมา/โค้ด** (`doa_ref` ชี้ entry ที่ใช้)

## 7. การ map ช่องบนกระดาษ → คอลัมน์
| บนกระดาษ | คอลัมน์ |
|---|---|
| เรียน : (2 บรรทัด) | `to` / `to_line2` |
| จาก : / โทรศัพท์ : | `from_name` (จากระบบ) / `from_phone` |
| Date : / รอบการขายที่ : | `doc_date` / `sales_period` |
| ตารางวันทำงาน 27 บรรทัด × 21 คอลัมน์ | `travel_sheet_line` (ไม่จำกัดจำนวนแถว) |
| แถว "รวมค่าใช้จ่ายในการเดินทาง" 11 ช่อง | `travel_sheet.total_*` (computed) |
| ค่าโทรศัพท์ / รวมค่าใช้จ่ายทั้งสิ้นเป็นเงิน | `phone_cost` / `grand_total` (computed) |
| เบิกเงินสำรองของบริษัทฯ / คงเหลือ (เบิกเพิ่มบริษัทฯ) | `advance_received` / `balance` (computed) |
| หมายเหตุ : / สำเนา : | `remark` / `cc` |
| เอกสารที่แนบ 1–3 | `travel_sheet_attachment_line` |
| ลงชื่อ 2 ช่อง (ไม่มีคำกำกับ) | `approval_chain` + ผู้สร้างเอกสาร (ไม่เก็บภาพลายมือชื่อ — DEC-08 · DEC-16) |
| Doc.No.FM-SAL-13 / Rev.00: 01/07/2569 (footer) | `print_config.form_code` / `revision` |
