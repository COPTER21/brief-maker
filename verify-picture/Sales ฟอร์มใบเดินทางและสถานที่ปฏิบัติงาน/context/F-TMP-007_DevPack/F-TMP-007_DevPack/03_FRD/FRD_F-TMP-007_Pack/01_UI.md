# 01_UI — F-TMP-007 ใบเดินทางและสถานที่ปฎิบัติงาน  สำหรับ General Trade

> archetype **Q-form** (Pattern Q2) · ต้นแบบ `feature.html` · CI CUBE Warm Light · ช่องวันที่ทุกช่องใช้ตัวเลือกวัน พ.ศ. กลาง (`bedateHTML` · Rule #114)

## 1. หน้าทะเบียน (`#/travel-workplace-sheet`)
### 1.1 ส่วนหัว
- หัวข้อ "ใบเดินทางและสถานที่ปฏิบัติงาน (General Trade Travel and Work Place Sheet)" + chip นับรายการ · เปิดอยู่ N
- คำอธิบาย: บันทึกวันทำงาน สถานที่พัก และค่าใช้จ่ายที่ขอเบิกของรอบการขาย · ยอดรวมทุกคอลัมน์ระบบคำนวณให้
- ปุ่มขวา: **ส่งออก CSV** (secondary) · **สร้างใบเดินทาง** (primary · disabled เมื่อ doc_type ยังไม่เปิดใช้ที่ F-DOCCFG)

### 1.2 การ์ดสถิติ (คลิกเพื่อกรอง)
ใบเดินทางทั้งหมด · รออนุมัติ · รอฉันพิจารณา

### 1.3 ตัวกรอง
ค้นหา (เลขที่ / ผู้จัดทำ / รอบการขายที่ / เรียน) · สถานะ · รอบการขายที่ · ฝ่าย · ปุ่มล้างตัวกรอง

### 1.4 ตาราง (20 แถว/หน้า)
| คอลัมน์ | ที่มา |
|---|---|
| เลขที่ | `travel_sheet.doc_no` |
| วันที่ขอ | `travel_sheet.doc_date` |
| ผู้จัดทำ | `travel_sheet.from_name` |
| รอบการขายที่ | `travel_sheet.sales_period` |
| ช่วงวันทำงาน | min–max ของ `travel_sheet_line.work_date` |
| สถานะเอกสาร | `travel_sheet.status` (+ ป้าย "ส่งกลับแก้ไข" เมื่อ `returned = true`) |
| ลายเซ็น | n/N จาก `approval_chain` |
| รวมค่าใช้จ่ายทั้งสิ้น (บาท) | `travel_sheet.grand_total` |
| คงเหลือ (บาท) | `travel_sheet.balance` |
| ⋮ | แก้ไข (ร่างของตัวเอง) · พิมพ์ · ยกเลิกเอกสาร — **ไม่มี "ทำซ้ำ"** (DEC-12) |
คลิกแถว = เปิด drawer ดูรายละเอียด

## 2. Drawer สร้าง / แก้ไขร่าง (`#/travel-workplace-sheet/create` · `/edit/:id`) — 3 ขั้น
`const STEPS = ['ข้อมูลหลักใบเดินทาง', 'เอกสารที่แนบ', 'ตรวจสอบและยืนยัน']` (Rule #100F) · drawer กว้าง (`.wide`)

### 2.1 ขั้น 1 — ข้อมูลหลัก (ซ้ายฟอร์ม · ขวาการ์ดสรุปสด)
**การ์ด ① ใบนี้เรียนถึงใคร รอบไหน**
| ช่องบนกระดาษ | คีย์ | ชนิด | บังคับ |
|---|---|---|---|
| เรียน : | `to` | ข้อความ | ✓ |
| เรียน : (บรรทัดที่ 2) | `to_line2` | ข้อความ | — |
| รอบการขายที่ : | `sales_period` | เลือกจากรายการรอบ | ✓ |
| สำเนา : | `cc` | ข้อความ | — |
- "จาก :" (`from_name`) · "โทรศัพท์ :" (`from_phone`) · "Date :" (`doc_date`) **ดึงจากระบบ** แสดงเป็นบรรทัดอ้างอิง + ในการ์ดสรุป

**การ์ด ② วันทำงานของรอบนี้** — ตาราง 21 คอลัมน์ตามกระดาษ (Rule #107: แถวซ้ำเกิน 4 ช่อง → ใช้ตาราง) เลื่อนแนวนอนได้
หัวตาราง 2 ชั้นตามกระดาษ: รอบวันทำงาน (ลำดับ · วันทำงาน · วันที่) · ใบเดินทาง/ตลาดที่ปฏิบัติงาน (เริ่มต้น · ช่องกลาง · สิ้นสุด) · สถานที่พัก · ค่าใช้จ่ายที่พัก (ที่พัก · ค่าโรงแรม) · ค่าใช้จ่ายในการทำงาน (เบี้ยเลี้ยง · ซักรีด · ธรรมเนียม · ไปรษณีย์ · จอดรถ · อื่นๆ) · รวมค่าใช้จ่ายที่เบิก · หมายเหตุ · บิลน้ำมัน (เลขไมล์เริ่มต้น · เลขไมล์สิ้นสุด · ลิตร · บาท)
| ช่องในแถว | คีย์ | ชนิด |
|---|---|---|
| วันทำงาน (ลำดับ) | `seq` | ระบบใส่ |
| วันทำงาน (ชื่อวัน) | `work_day_name` | ข้อความ (เติมอัตโนมัติจากวันที่ แก้ไขได้) |
| วันที่ | `work_date` | วันที่ (`bedateHTML`) |
| ใบเดินทาง/ตลาดที่ปฏิบัติงาน เริ่มต้น · ช่องกลาง · สิ้นสุด | `route_from` · `route_mid` · `route_to` | ข้อความ |
| สถานที่พัก | `stay_place` | ข้อความ |
| ค่าใช้จ่ายที่พัก ที่พัก · ค่าโรงแรม | `cost_lodging` · `cost_hotel` | จำนวนเงิน |
| ค่าใช้จ่ายในการทำงาน เบี้ยเลี้ยง · ซักรีด · ธรรมเนียม · ไปรษณีย์ · จอดรถ · อื่นๆ | `cost_perdiem` · `cost_laundry` · `cost_fee` · `cost_post` · `cost_parking` · `cost_other` | จำนวนเงิน |
| รวมค่าใช้จ่ายที่เบิก | `line_total` | คำนวณให้ อ่านอย่างเดียว |
| หมายเหตุ | `remark` | ข้อความ |
| บิลน้ำมัน เลขไมล์เริ่มต้น · เลขไมล์สิ้นสุด | `odometer_start` · `odometer_end` | ตัวเลข |
| บิลน้ำมัน ลิตร · บาท | `fuel_liter` · `fuel_amount` | ตัวเลข · จำนวนเงิน |
- แถวท้ายตาราง = **รวมค่าใช้จ่ายในการเดินทาง** (`total_*`) อ่านอย่างเดียว อัปเดตสดแบบ soft ขณะพิมพ์ (ไม่ rebuild — focus ไม่หลุด)
- ปุ่ม "เพิ่มวันทำงาน" ต่อแถวได้ไม่จำกัด (DEC-05) · ปุ่มถังขยะลบแถว (เหลือ 1 แถวลบไม่ได้)
- error แสดงเป็นแถบรวมเหนือตาราง (ระบุเลขแถว) + ขอบแดงช่องที่ผิด + ไฮไลต์แถว

**การ์ด ③ สรุปค่าใช้จ่ายท้ายใบ**
| ช่องบนกระดาษ | คีย์ | ชนิด |
|---|---|---|
| ค่าโทรศัพท์ | `phone_cost` | จำนวนเงิน (กรอก) |
| เบิกเงินสำรองของบริษัทฯ | `advance_received` | จำนวนเงิน (กรอก) |
| หมายเหตุ : | `remark` | ข้อความ |
"รวมค่าใช้จ่ายทั้งสิ้นเป็นเงิน" และ "คงเหลือ (เบิกเพิ่มบริษัทฯ)" คำนวณให้ แสดงในการ์ดสรุปสด

**การ์ดสรุปสด (ขวา · sticky)** — จาก (ผู้จัดทำ) · ผู้อนุมัติแต่ละขั้นจากสาย DOA · รอบการขายที่ · จำนวนวันทำงาน · รวมค่าใช้จ่ายในการเดินทาง + ค่าโทรศัพท์ · เบิกเงินสำรอง + คงเหลือ · **รวมค่าใช้จ่ายทั้งสิ้น**

### 2.2 ขั้น 2 — เอกสารที่แนบ (DEC-06 · DEC-12)
- การ์ด ① รายการเอกสารที่แนบตามกระดาษ 3 บรรทัด (`attachment_lines[].title`) · เพิ่มบรรทัดได้
- การ์ด ② ไฟล์แนบจริง: upload zone · PDF/Word/Excel/รูป ไม่เกิน 20 MB ต่อไฟล์ · ลบไฟล์ได้

### 2.3 ขั้น 3 — ตรวจสอบและยืนยัน
การ์ดข้อมูลใบเดินทาง (รวมสายอนุมัติที่จะใช้) · ตารางวันทำงานแบบอ่านอย่างเดียว · การ์ดสรุปค่าใช้จ่าย (+ คำเตือนเมื่อคงเหลือติดลบ หรือเลขไมล์ย้อนกลับ) · รายการเอกสารที่แนบ · ไฟล์แนบ

### 2.4 ปุ่มท้าย drawer (Rule #100)
ซ้าย: ย้อนกลับ · ขวา: ยกเลิก · [ขั้น 1–2] ถัดไป · [ขั้น 3] บันทึกแบบร่าง · บันทึกและส่งอนุมัติ
ปิด drawer ขณะกรอกค้าง → modal "ทิ้งข้อมูลที่กรอกไว้?"

## 3. Drawer ดูรายละเอียด (`#/travel-workplace-sheet/view/:id`) — 4 แท็บ (Rule #101)
`รายละเอียด › PDF Preview › ลายเซ็น / อนุมัติ › ประวัติ`
- **รายละเอียด** — แบนเนอร์ตามสถานะ (รออนุมัติ / ส่งกลับแก้ไข + เหตุผล / ยกเลิกแล้ว / ร่าง) · ข้อมูลเอกสาร · จาก · ตารางวันทำงาน + แถวรวมยอด · การ์ดรวมค่าใช้จ่าย · เอกสารที่แนบ · ไฟล์แนบ · หมายเหตุ/สำเนา · ข้อมูลระบบ
- **PDF Preview** — `iframe srcdoc` จาก `form.tpl.html` + `docPrintData(record)` · ปุ่มดาวน์โหลด PDF / พิมพ์
- **ลายเซ็น / อนุมัติ** — การ์ดสรุปสาย DOA + timeline ขั้น 1..N + ปุ่มตัดสิน inline ที่ขั้นปัจจุบัน (คำตัดสินตาม role)
- **ประวัติ** — audit แบบ append-only

### 3.1 ปุ่มหัว drawer ตามสถานะ
| สถานะ · ผู้ใช้ | ปุ่ม |
|---|---|
| ร่าง · เจ้าของ | ยกเลิก · แก้ไข · **ส่งอนุมัติ** |
| รออนุมัติ · ผู้พิจารณาขั้นปัจจุบัน | ไม่อนุมัติ · **อนุมัติ** |
| ร่าง/รออนุมัติ · เจ้าของหรือ admin role | ยกเลิกเอกสาร |
ไอคอนขวา: พิมพ์ · ดาวน์โหลด PDF · ปิด (**ไม่มีไอคอนทำซ้ำ** — DEC-12)

## 4. Modal
ส่งอนุมัติ (slot picker 1 ช่องต่อขั้น DOA · ค่าเริ่มจาก resolve · ผู้ขอไม่อยู่ในรายชื่อ) · อนุมัติ (ความเห็นไม่บังคับ) · ไม่อนุมัติ (เหตุผลบังคับ + chip ตัวอย่าง) · ยกเลิกเอกสาร (เหตุผลบังคับ) · ทิ้งข้อมูลที่กรอกไว้

- ปุ่ม submit ระหว่างบันทึก = disabled + loader + "กำลังบันทึก…" (Rule #44)
