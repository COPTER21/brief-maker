### 3.3 สูตร + ค่าคงที่บนกระดาษ
- สูตร: รวมค่าใช้จ่ายที่เบิก = `F14+F15+F16+F17+F18+F19+F20+F21` ต้นฉบับไม่มีสูตรรายแถว (ช่องว่าง) → ระบบรวมค่าใช้จ่ายที่พัก + ค่าใช้จ่ายในการทำงานของแถวนั้นให้ (anomaly A02)
- สูตร: รวมค่าใช้จ่ายในการเดินทาง — ที่พัก = `SUM(lines.ค่าใช้จ่ายที่พัก—ที่พัก)` ต้นฉบับไม่มีสูตรที่ช่องนี้ → เพิ่มให้ครบคอลัมน์ (anomaly A01)

- สูตร: รวมค่าใช้จ่ายในการเดินทาง — ธรรมเนียม = `SUM(lines.ธรรมเนียม)` ต้นฉบับ =SUM(L9:L35) ครบทุกแถว
- สูตร: รวมค่าใช้จ่ายในการเดินทาง — ไปรษณีย์ = `SUM(lines.ไปรษณีย์)` ต้นฉบับ =SUM(M9:M35) ครบทุกแถว
- สูตร: รวมค่าใช้จ่ายในการเดินทาง — จอดรถ = `SUM(lines.จอดรถ)` ต้นฉบับ =SUM(N9:N35) ครบทุกแถว
- สูตร: รวมค่าใช้จ่ายในการเดินทาง — อื่นๆ = `SUM(lines.อื่นๆ)` ต้นฉบับ =SUM(O9:O35) ครบทุกแถว

- สูตร: รวมค่าใช้จ่ายในการเดินทาง — ลิตร = `SUM(lines.ลิตร)` ต้นฉบับ =SUM(T9:T35) ครบทุกแถว

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- คอลัมน์ "ค่าใช้จ่ายที่พัก — ที่พัก" ไม่มีสูตรรวมยอด และ "รวมค่าใช้จ่ายทั้งสิ้นเป็นเงิน" (=P36) ไม่ได้บวก "ค่าโทรศัพท์" (P37) ทำให้ยอดรวมต่ำกว่าความจริง → **ยอดรวมทุกคอลัมน์ต้องรวมทุกแถวเสมอ และยอดรวมทั้งสิ้น = รวมค่าใช้จ่ายในการเดินทาง + ค่าโทรศัพท์ (ระบบคำนวณให้ ผู้ใช้แก้ไม่ได้)**
- ต้นฉบับปล่อยว่าง ไม่มีสูตรรวมรายแถว ทั้งที่แถวรวมยอดอ้าง SUM(P9:P35) → **ยอดรวมรายแถว = ค่าใช้จ่ายที่พัก (ที่พัก + ค่าโรงแรม) + ค่าใช้จ่ายในการทำงานทุกช่อง (ระบบคำนวณให้)**
- หัวคอลัมน์ครอบมากกว่า 1 ช่องในตาราง แต่ช่องย่อยไม่มีคำกำกับ จึงตีความหน่วย/ความหมายจากกระดาษไม่ได้ → **ตั้งค่าเริ่มเป็น วันทำงาน = ลำดับ + ชื่อวัน · เส้นทาง = เริ่มต้น/จุดแวะ/สิ้นสุด · เลขไมล์ = เริ่มต้น/สิ้นสุด แล้วให้ลูกค้ายืนยันในใบลงนาม**
- กระดาษไม่มีคำกำกับว่าช่องใดเป็นผู้จัดทำ ช่องใดเป็นผู้อนุมัติ → **ช่องซ้าย = ผู้จัดทำ/ผู้ขอเบิก · ช่องขวา = ผู้อนุมัติ (สายอนุมัติเป็น dynamic ตาม DOA กลาง)**
- กระดาษสะกด "ปฎิบัติงาน" ซึ่งเพี้ยนจาก "ปฏิบัติงาน" (หัวคอลัมน์ในตารางสะกด "ปฏิบัติงาน" ถูกต้อง) → **คงถ้อยคำตามกระดาษในแบบพิมพ์ (ความตรงกระดาษ 1:1) และเสนอให้ลูกค้าแก้ในรอบปรับปรุงฟอร์ม**
