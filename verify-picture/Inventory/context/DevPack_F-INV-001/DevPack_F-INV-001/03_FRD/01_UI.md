## §1.1 Route Table

| Route | Page/Drawer | Refresh-safe | Notes |
|---|---|---|---|
| `#/stock` or `#` / `#/` | P-01 Gate | ✓ | `getRoute()` L1261 treats empty/bare hash as gate |
| `#/stock/{ctx}/sku` | P-02 List by Product | ✓ | `ctx` = `all` \| `WH-01` \| `WH-02`; `warehouse_staff` is force-redirected to their own `ctx` regardless of hash (`syncRouteToState()` L1280-1282) |
| `#/stock/{ctx}/sku/{balanceId}` | P-02 + D-02 Balance Drawer | ✓ | `balanceId` matches `/^S\d+$/` (L1318) |
| `#/stock/{ctx}/sku/{pid}` | P-02 + D-01 Product Drawer | ✓ | any other token resolves against `PRODUCTS` + `isStockable` guard (L1326) — a service-item pid or unknown pid silently falls through to "no drawer" |
| `#/stock/{wh}/loc` | P-03 List by Location | ✓ | `wh` must be a real, non-`all` warehouse (`validCtx()` L1272) |
| `#/stock/{wh}/loc/{locId}` | P-03 + D-03 Location Drawer | ✓ | only opens if `locId` resolves to a location **inside** `wh` (L1295) |
| `#/stock/{wh}/bp` | P-04 Break/Pack | ✓ | |
| `#/stock/{wh}/bp/{id}` | P-04 + D-04 BP Drawer | ✓ | |
| `#/stock/{wh}/log` | P-06 Audit Log | ✓ | |
| `#/stock/{wh}/log/{id}` | P-06 + D-05 ADJ Drawer | ✓ | |

**Router implementation:** `getRoute()` (L1261) parses `location.hash` into
`{gate, view, whCtx, detailId}`; `syncRouteToState()` (L1275) is the single point that reconciles
hash → `state`, called on every `hashchange` and on load — this is the correct refresh-safe pattern
and should be replicated in the real FE build, not re-derived.

## §1.2 Pages — Actions & Fields

### P-01 Warehouse Gate (`renderGate()` L1425)
- Search box (code/name) — `applyGateSearch()` L1424
- Click row → `pickWh(code)` L1339 → navigates into P-02 `sku` view for that warehouse

### P-02 List by Product (`renderList()` L1488)
- **View toggle** (segmented, `viewToggle()` L1406): ตามสินค้า / ตามตำแหน่ง / แตก-แพ็ค / ประวัติการปรับ
- **Stats row** (4 cards, 3 clickable filters via `quickFlag()` L1219): สินค้า(SKU) · ต่ำกว่าขั้นต่ำ ·
  สต็อกติดลบ · ตำแหน่ง HOLD (not clickable — informational only)
- **Filter bar**: search (code/old_code/name), "ซ่อนสต็อก 0" toggle (`toggleHideZero()` L1217),
  reset (`resetFilters()` L1218)
- **Table** (≤8 cols, Rule #16 compliant — 6 cols): สินค้า · คงเหลือ · จองแล้ว · พร้อมใช้ · สถานะสต็อก ·
  row-action (eye icon — **note:** Rule #41 normally bans the eye icon since row-click already opens
  view; this is a pre-existing, non-blocking WARN not raised by the UX checker as BLOCK — carried as
  observation, not re-specified as a fix here)
- Row click → `openDrawer(pid)` → D-01 Product Drawer
- Header actions: Export (`openExport()`, Finance/Auditor only), Refresh (`refreshData()`), **ปรับสต็อก**
  (`openAdjust()`, `canAdjust()` only) — Rule #46.1 compliant (single primary, rightmost)
- Sortable columns: สินค้า, คงเหลือ, จองแล้ว, พร้อมใช้ (`sortBy()` L1246) — sorts by **base-unit** value
  always, per OB-5
- Pagination + page-size select (Rule #10 compliant)

### P-03 List by Location (`renderLocationView()` L1653)
- View toggle (same component, `location` active)
- Stats row: ตำแหน่งทั้งหมด · มีของ/ว่าง breakdown
- Filter bar: search, location-type filter, health filter (`applyLocFilter()` L1347)
- Cards/rows per location with `.util-bar` utilization indicator (`utilClass()` L992: is-high ≥90%,
  is-mid ≥60%, is-low otherwise)
- Click → `openLocation(locId)` → D-03 Location Drawer

### P-04 Break/Pack (`renderBreakPackView()` L2475)
- Stats row: รายการค้าง(ล็อกอยู่) · เสร็จแล้ว · ตำแหน่งถูกล็อก
- Action bar: **สร้างคำสั่ง** (`openBPCreate()` L2295) → M-02 create modal
- Filter: ผู้รับผิดชอบ (search-combobox, all/mine/unassigned/by-person — `setBpFilter()` L1348)
- Table: เลขที่ · ประเภท(แตก/แพ็ค) · รหัส/ชื่อสินค้า · ปริมาณ(ชิ้นฐาน) · ผู้รับผิดชอบ · สถานะ(ล็อกอยู่/เสร็จ)
- Row click → `openBPDrawer(id)` → D-04

### P-05 Manual Adjustment (`renderAdjModal()` L2653 — modal, see §1.0 deviation note)
- Header: title + subtitle ("เพิ่ม/ลดสต็อกหลายรายการในครั้งเดียว — ปรับเฉพาะยอดคงเหลือ ห้ามแตะยอดจอง · บันทึก
  log ทุกครั้ง")
- **เหตุผลการปรับ** — required `<select>` from `ADJ_REASONS` (6 fixed values, L1031) — plain select is
  correct here per Rule #34 (short closed enum, not a master lookup)
- **Line grid** (`adjLineHTML()` L2612), one row per adjustment line:
  - **สินค้า** — search-combobox (Rule #94), options = `Object.values(PRODUCTS).filter(isStockable)`
    (service items never appear, OB-3/S-09)
  - **ตำแหน่ง** — search-combobox scoped to the current warehouse, each option labeled with its
    state: `· ว่าง — เพิ่มเข้าได้` / `· มีของ` / `· ล็อกอยู่` (searchable by the word "ว่าง")
  - **ปรับ** — two-button toggle: เพิ่ม (add) / ลด (reduce)
  - **จำนวน** — integer input, unit shown is the **location's own unit**, not necessarily base
  - **คงเหลือ** — live-computed "ปัจจุบัน N → หลังปรับ M" (or "รายการใหม่ในตำแหน่งนี้ · ปัจจุบัน 0 → N" when
    the line targets an empty location)
  - Delete-line button, disabled when only 1 line remains (last line cannot be removed)
  - Inline error under the row when validation fails (`adjLineError()`), see `05_RULES.md`
  - **เพิ่มบรรทัด** button below the grid (`adjAddLine()`)
  - **Summary bar**: "พร้อมบันทึก N/M บรรทัด" + "เพิ่มรวม +X ชิ้นฐาน" + "ลดรวม −Y ชิ้นฐาน" +
    "รายการใหม่ Z ตำแหน่ง" — computed live from all currently-valid lines
- **หมายเหตุ** — free-text, optional
- Footer: ยกเลิก (ghost) → primary **บันทึกการปรับ** (`submitAdjust()` L2696)

### P-06 Audit Log (`renderAdjLogView()` L2736)
- Stats row: เอกสารปรับ · ปรับเพิ่มรวม · ปรับลดรวม (all base-unit)
- Filter: search (doc no./actor/product/location/reason), direction filter (all/add/reduce)
- Table: เลขที่ · วันเวลา · ผู้ทำรายการ · เหตุผล · บรรทัด(count) · เพิ่ม(ฐาน) · ลด(ฐาน)
- Row click → `openAdjDrawer(id)` → D-05
- Header action: **ปรับสต็อก** (same entry point as P-02, `canAdjust()` gated)

## §1.3 Drawers — Content & Actions

### D-01 Product Drawer (`renderProductDrawer()` L1903)
- Header: avatar (2-letter code) + name + "Master หยุดใช้งาน" pill when `!prodActive(p)` (Rule #46.3
  compliant — pill directly after title) + code/type/location-count subtitle
- Header actions: **ปรับสต็อก** (secondary, `canAdjust()` gated) → divider → close (Rule #31.4)
- Tabs (full-width, `setTab()`):
  1. **ภาพรวม** (default) — 3 base-unit KPI cards (คงเหลือรวม/จองแล้ว/พร้อมใช้), in-transit note,
     negative/low-stock alert notes, unit-conversion table, detail fields (threshold, FIFO oldest,
     latest movement), 2-code reference block
  2. **ตำแหน่งจัดเก็บ** — delegates to `renderUomLocTab()` (shared with D-02)
  3. **การเคลื่อนไหว** — merged movement timeline across **all** balances of this product, each entry
     tagged `@ location-code`, newest-first, capped at 30 (`moves.slice(0,30)` L1997)

### D-02 Balance Drawer (`renderDrawer()` default branch, L2010)
- Same header/tab shape as D-01 but scoped to one `(pid, loc_id)` — subtitle shows
  `warehouse › location` path + the balance's own status pill
- Header actions: ปรับสต็อก (secondary) → **ดูมูลค่า/ซ่อนมูลค่า** (secondary, `canValuation()` gated —
  **this is the G-01 surface, see `00_OVERVIEW.md §0.1.4`; NOT specified further in this pack**) →
  divider → close
- Tabs: ภาพรวม (`renderOverviewTab()`) / การเคลื่อนไหว (`renderMovesTab()`) / ตำแหน่งจัดเก็บ
  (`renderUomLocTab()`)
- Footer: metadata text (as-of timestamp + "ปรับผ่าน Manual Adjustment เท่านั้น") + ปิด (secondary only
  — Rule #31.4 compliant, no other footer action)

### D-03 Location Drawer (`renderLocationDrawer()` L1797)
- Header: map-pin icon avatar + location code + type pill + health pill (ว่าง/มีของ/เต็ม/กันไว้-อายัด)
- Sections: hierarchy path chip, capacity+utilization (ความจุ + % used, hidden for VIRTUAL type),
  contents table ("สิ่งที่อยู่ในตำแหน่งนี้") showing **the location's own unit** per row with base-unit
  equivalent when `factor > 1` — row click drills into D-02 Balance Drawer (`openDrawer(balanceId)`),
  location metadata fields (warehouse/zone/area/rack, type, status)
- No action buttons other than close — this drawer is pure read/drill

### D-04 Break/Pack Drawer (`renderBPDrawer()` L2385)
- Header: gradient avatar (warning colors for Break, primary/teal for Pack) + order id + type pill +
  status pill (ล็อกอยู่/เสร็จแล้ว)
- Sections: product summary, route (source card → arrow → destination table, supports multiple
  destinations), assignee (search-combobox to (re)assign, only while `status='locked'`), lock-status
  block (shows locked base quantity + all locked location codes) shown only while locked, timestamps
- Footer (only while locked): **ยกเลิกคำสั่ง** (secondary, left) ← spacer → **ดำเนินการเสร็จ** (primary,
  right, blocked with a warning toast if no assignee yet); when done, footer collapses to a
  read-only completion timestamp

### D-05 ADJ Log Drawer (`renderAdjDrawer()` L2835)
- Detail view of one ADJ document — actor, timestamp, reason, note, and the full per-line breakdown
  (product, location, direction, quantity in the line's unit, before→after in base units)
- Read-only — no edit/delete affordance anywhere (consistent with append-only, OB-11)

## §1.4 Component Notes (observed, not re-specified)

- **Status pills**: stock status uses 3 short labels only in list context (ปกติ/ต้องเติม/ขาดสต็อก, OB-7)
  — full per-row status (available/damaged/blocked/quarantine, `statusPill()` L1126) is reserved for
  drawer-level display, not the aggregate list, consistent with OB-5 (1 product = 1 row = no single
  meaningful per-row status without drilling in)
- **Extended badge palette**: 10 location-type pills + 4 stock-status pills exceed ci-tokens'
  5-pair whitelist — flagged as a WARN by the UX checker and accepted as a genuine business need
  (distinguishing 10 location types is required by OB-4/S-03); this FRD does not ask for a palette
  reduction
- **Overlay Portal (Rule #95, OB-9)**: all dropdowns (`ddBox`) portal to `#dd-portal` on open,
  computing `position:fixed` from `getBoundingClientRect()`, flipping up on bottom-edge collision —
  this is the correct pattern for dropdowns living inside the wide adjustment modal's scrollable body
- **Esc chain (OB-9)**: two independent `keydown` listeners in capture phase — one closes an open
  dropdown first (`e.stopImmediatePropagation()`, L2288) so a second Esc is needed to close the
  modal/drawer itself; verified present and correctly ordered
