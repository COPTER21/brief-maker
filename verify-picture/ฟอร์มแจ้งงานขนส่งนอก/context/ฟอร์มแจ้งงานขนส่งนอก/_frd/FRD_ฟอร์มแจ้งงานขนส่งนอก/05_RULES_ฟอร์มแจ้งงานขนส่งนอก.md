# 05_RULES — F-TMP-003

## §5.1 Business Rules
| ID | Rule | อ้าง |
|---|---|---|
| BR-01 | แถวว่างทั้งแถวไม่นับ · แถวที่เริ่มกรอกต้องครบ 5 ช่อง (ต้นทาง · ปลายทาง · เลขที่PO · จำนวน · วันที่นัดส่ง) | DEC-04 |
| BR-02 | ส่งแจ้งงานได้เมื่อ ≥ 1 แถวครบ และไม่มีแถวไม่ครบ · ร่างไม่ครบได้ | DEC-04 |
| BR-03 | จำนวน = จำนวนเต็ม > 0 | DEC-04 · DEC-12 (VALID) |
| BR-04 | วันที่นัดส่งก่อนรอบวันที่ = เตือน ไม่บล็อก → event `otn_early_delivery_date` | DEC-04 · DEC-13 (VALID) · NTF |
| BR-05 | ไม่มีขั้นพิจารณา — ส่งแล้วมีผลทันที · ล็อกแก้ไข · สาย DOA ว่าง (TODO: DOA engine · 03_LOGIC §3.4) | DEC-03 |
| BR-06 | ออกเลขตอนบันทึกครั้งแรก (OTN) · no-gap ✗ | DEC-09 · DEC-14 (VALID) |
| BR-07 | ชื่อผู้ขนส่ง snapshot ลงเอกสาร · ไม่ตามแก้เมื่อ master เปลี่ยน | — |
| BR-08 | ยกเลิก: เจ้าของ + role-mgr-sales · สถานะร่าง/ส่งแจ้งงานแล้ว · เหตุผลบังคับ · ยกเลิกโดยผู้อื่นแจ้งเจ้าของ (`otn_cancelled`) | G7 (decisions.yaml) |
| BR-09 | ร่างเห็นเฉพาะเจ้าของ (+ role-mgr-sales) | DEC-08 |
| BR-10 | แบบพิมพ์ A4 1 หน้า 5 คอลัมน์ · ≥ 20 บรรทัด · เกิน = แถวไหลหน้าถัดไป หัวตารางซ้ำ บล็อกผู้จัดทำไม่ถูกตัด | DEC-05 · DEC-15 (VALID) |
| BR-11 | จำนวนรวม/จำนวนรายการ = ค่าแสดงผลเท่านั้น (ไม่มีบนกระดาษ — ไม่เก็บ ไม่พิมพ์) | DEC-06 |
| BR-12 | ถ้อยคำบนแบบพิมพ์ตาม FM-SAL-16 Rev.00 ("รอบวันที" คงตามกระดาษ · หน้าจอใช้ "รอบวันที่") | DEC-11 (VALID) |
| BR-13 | ไม่เปลี่ยนค่าในระบบ · ไม่ส่งต่อระบบอื่น | DEC-01 · DEC-02 |

| VR-01 | ผู้ขนส่ง | required | กรุณาเลือกผู้ขนส่ง |
