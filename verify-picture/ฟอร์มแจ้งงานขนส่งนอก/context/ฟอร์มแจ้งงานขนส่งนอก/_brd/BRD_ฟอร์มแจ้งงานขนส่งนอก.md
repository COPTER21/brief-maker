## 1. Business Context
### 1.1 ปัญหา / โอกาส
ฝ่ายขาย (Sales Admin) แจ้งงานให้ผู้ขนส่งภายนอก (ขนส่งนอก) ด้วยไฟล์ Excel FM-SAL-16 — หัวฟอร์มเว้นชื่อผู้ขนส่ง + รอบวันที่ · ตาราง ต้นทาง/ปลายทาง/เลขที่PO/จำนวน/วันที่นัดส่ง 20 บรรทัด · ลงท้ายผู้จัดทำ · ไฟล์ไม่มีเลขที่ ไม่มีประวัติว่าแจ้งใครเมื่อไร ค้นย้อนหลังด้วยเลขที่ PO ไม่ได้ · ตารางไม่มีลำดับ/หน่วย และไม่มีการตรวจวันที่นัดส่งเทียบรอบวันที่ · เวลาพิมพ์ Excel คอลัมน์ "วันที่นัดส่ง" หลุดไปหน้า 2
### 1.2 เป้าหมาย
1. ใบแจ้งงานขนส่งนอกเป็นเอกสารในระบบ มีเลขที่ ช่องตรงกระดาษ 1:1 (DEC-06) — PDF Replica หน้าตาเหมือน FM-SAL-16 ครบ 5 คอลัมน์ในหน้าเดียว (DEC-15)
2. ค้นย้อนหลังได้ด้วยเลขที่/ผู้ขนส่ง/เลขที่PO/ปลายทาง · ส่งออก CSV รายการ
3. ผู้จัดการฝ่ายขายรู้เมื่อมีการแจ้งงาน และเมื่อมีรายการนัดส่งก่อนรอบวันที่ (NTF_BRIEF)
### 1.3 ตัวชี้วัด
ไม่มีใน input → **OQ-01** (ห้ามแต่งตัวเลข)
### 1.4 ที่มา
แบบฟอร์มลูกค้า FM-SAL-16 (xlsx 1 ชีต · print area A1:E26) → FORM_SPEC 8 ช่อง · gate 10 หมวด = AI-DEFAULT ทั้งหมด (โหมดไม่เฝ้า · `4_knowledge/governance/unattended-policy.md`)

## 2. Scope
### 2.1 In Scope
- รายการใบแจ้งงาน (segmented tabs ตามสถานะ · ค้นหาเลขที่/ผู้ขนส่ง/เลขที่PO/ปลายทาง · กรองผู้ขนส่ง/ผู้จัดทำ · CSV) · สร้าง/แก้ร่าง wizard 3 ขั้น · ดู 4 แท็บ (รายละเอียด › PDF Preview › ลายเซ็น / อนุมัติ › ประวัติ)
- เลือกผู้ขนส่งจาก Vendor master (ประเภทขนส่ง) · รอบวันที่ (พ.ศ.) · ตารางรายการไม่จำกัดแถว (ต้นทาง · ปลายทาง · เลขที่PO · จำนวน · วันที่นัดส่ง)
- ส่งแจ้งงาน (ไม่มีขั้นพิจารณา — DEC-03) · ยกเลิก (เหตุผลบังคับ — G7) · แนบไฟล์ · PDF FM-SAL-16 Replica ทุกสถานะ · เลขที่ OTN จาก ENG-DOC-NUM
- แจ้งเตือน: ส่งแจ้งงาน → ผู้จัดการฝ่ายขาย · นัดส่งก่อนรอบวันที่ → ผู้จัดการฝ่ายขาย · ยกเลิกโดยผู้อื่น → เจ้าของ (NTF_BRIEF)
### 2.2 Out of Scope
- ดึงรายการจาก Sales Order / PO ลูกค้า / ใบส่งของอัตโนมัติ (DEC-01/02 — ผู้ใช้กรอกเลขที่PO เอง) · ส่งใบแจ้งงานถึงผู้ขนส่งทางอีเมล/พอร์ทัล · ผู้ขนส่งตอบรับงานในระบบ · คิดค่าขนส่ง · ทำซ้ำเอกสาร (DEC-10) · สายอนุมัติ (DEC-03)
### 2.3 Assumptions
- ผู้จัดทำ = Sales Admin / เจ้าหน้าที่ประสานงานขาย · แจ้งผู้ขนส่งด้วยการพิมพ์/ส่ง PDF ออกนอกระบบ
- Vendor master มีประเภท "ขนส่ง" ให้กรองรายชื่อผู้ขนส่งได้ (OQ-04)

## 4. User Journey
### 4.1 Happy Path
1. Sales Admin: สร้างใบแจ้งงาน → เลือกผู้ขนส่ง → รอบวันที่ (ค่าเริ่ม = วันนี้) → กรอกรายการ (เพิ่มรายการ = ยกต้นทางและวันที่นัดส่งจากแถวก่อน) → แนบใบยืนยันรับงาน (ไม่บังคับ) → ตรวจสอบ → **บันทึกและส่งแจ้งงาน** → ได้เลข OTN · สถานะ "ส่งแจ้งงานแล้ว" → พิมพ์/ดาวน์โหลด PDF ส่งผู้ขนส่ง
2. ผู้จัดการฝ่ายขายได้รับแจ้ง (otn_submitted) · มีแถวนัดส่งก่อนรอบวันที่ → otn_early_delivery_date
### 4.2 Alternative
- ข้อมูลยังไม่ครบ → บันทึกแบบร่าง (ต้องมีผู้ขนส่ง + รอบวันที่) → กลับมาแก้ภายหลัง
- แจ้งผิด/ผู้ขนส่งรับงานไม่ได้ → ยกเลิกเอกสาร (เหตุผลบังคับ) แล้วสร้างใบใหม่ (ไม่มีทำซ้ำ — DEC-10)
- วันที่นัดส่งก่อนรอบวันที่ → เตือนใต้แถว ไม่บล็อก (DEC-13)
