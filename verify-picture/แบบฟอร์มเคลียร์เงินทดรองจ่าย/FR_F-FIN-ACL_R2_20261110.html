ตรวจแล้ว

  • ตรวจซ้ำ BUG-01: เปิดใช้งานแบบเอกสาร ACL เพื่อปลด blocker การสร้างใบเคลียร์
  • ยืนยันว่า blocker เดิมได้รับการแก้ไข
  • สร้างใบเคลียร์และกดบันทึกร่าง
  • เปิดรายการสถานะร่างจากหน้ารายการเพื่อดูรายละเอียดใน View Drawer
  • ตรวจซ้ำ BUG-02 และ BUG-03 หลังแก้ไข
  • Create, Update และ Delete รายการ
  • ตรวจ UI และ UX ของส่วนที่เหลือ

ไม่ได้ตรวจ

  • การคำนวณรวมค่าใช้จ่าย ยอดเหลือส่งคืน และกรณีใช้เกิน — ยังไม่มีผลตรวจการคำนวณจากผู้ตรวจ
  • การแนบใบเสร็จและสลิปโอนเงินคืน — ยังไม่มีผลตรวจการแนบไฟล์จากผู้ตรวจ
  • การส่งอนุมัติ การอนุมัติ การไม่อนุมัติ และการส่งกลับเป็นร่าง — ยังไม่มีผลตรวจสายอนุมัติจากผู้ตรวจ
  • สิทธิ์ผู้ใช้งาน ประวัติ และการเข้าถึงข้ามผู้ใช้ — ยังไม่มีผลตรวจ Permission และ Audit จากผู้ตรวจ
  • PDF, CSV, notification และผลลัพธ์หลังอนุมัติ — ยังไม่มีผลตรวจ PDF, CSV และ integration จากผู้ตรวจ

1Logic — ทำงานถูกตามกฎธุรกิจ

#กฎ / Scenarioผลที่คาดหวังผลจริงผลอ้างอิง
L-01เปิดใช้งานแบบเอกสาร ACLแก้ไข blocker เดิมเพื่อให้สามารถเริ่มสร้างใบเคลียร์และทดสอบ flow ต่อได้ผู้ตรวจยืนยันว่า BUG-01 ได้รับการแก้ไขแล้วและกำลังจะเริ่มทดสอบต่อผ่านBUG-01
L-02สร้างและบันทึกใบเคลียร์เมื่อบันทึกร่างสำเร็จ ระบบต้องแจ้งผลสำเร็จ ปิดหรือเปลี่ยนสถานะ Create Drawer อย่างถูกต้อง และแสดงรายการร่างที่สร้างเพียงหนึ่งรายการผู้ตรวจยืนยันเมื่อ 2026-11-11 ว่าปัญหาการแจ้งผลและสถานะ Create Drawer ได้รับการแก้ไขแล้วผ่านBUG-02
L-03เปิดดูรายละเอียดใบเคลียร์สถานะร่างเมื่อเลือกรายการ ระบบต้องเปิด View Drawer และแสดงข้อมูลจาก API ได้ครบผู้ตรวจยืนยันเมื่อ 2026-11-11 ว่าปัญหา View Drawer โหลดข้อมูลไม่สำเร็จได้รับการแก้ไขแล้วผ่านBUG-03
L-04แก้ไขใบเคลียร์ผู้ใช้สามารถแก้ไขรายการที่ระบบอนุญาตและบันทึกข้อมูลที่แก้ไขได้ถูกต้องผู้ตรวจยืนยันว่า Update ทำงานครบและไม่พบปัญหาผ่านAPI-04 · AC-01
L-05ลบหรือยกเลิกรายการผู้ใช้สามารถดำเนินการลบหรือยกเลิกตาม action ที่ระบบกำหนด และรายการเปลี่ยนสถานะถูกต้องผู้ตรวจยืนยันว่า Delete ทำงานครบและไม่พบปัญหาผ่านAPI-08 · AC-10
L-06คำนวณยอดเคลียร์คำนวณรวมค่าใช้จ่ายและยอดเหลือส่งคืนตาม FRDยังไม่ได้ตรวจหลังแก้ blockerไม่ได้ตรวจBR-01 · BR-02 · BR-03
L-07ส่งและพิจารณาตามสายอนุมัติส่ง อนุมัติ หรือไม่อนุมัติตามสาย DOA และสิทธิ์ที่กำหนดยังไม่ได้ตรวจหลังแก้ blockerไม่ได้ตรวจAC-04 · AC-05 · AC-07
L-08ตรวจสลิปเงินคืนก่อน Finance รับเคลียร์กรณีเหลือคืนมากกว่า 0 ต้องมี refund slip ก่อนรับเคลียร์ยังไม่ได้ตรวจหลังแก้ blockerไม่ได้ตรวจAC-06 · BR-04
L-09ควบคุมสิทธิ์และการเข้าถึงข้ามผู้ใช้ผู้ใช้แต่ละบทบาทเห็นข้อมูลและดำเนินการได้เฉพาะตามสิทธิ์ที่กำหนดยังไม่ได้ตรวจหลังแก้ blockerไม่ได้ตรวจAC-10 · TC-D01..06

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-01แบบเอกสาร ACL ยังไม่เปิดใช้งาน ทำให้สร้างใบเคลียร์และทดสอบ flow ต่อไม่ได้Criticalแก้แล้ว
ขั้นตอนทำซ้ำ
  1. เข้าสู่เมนูแบบฟอร์มเคลียร์เงินทดรองจ่าย
  2. ตรวจข้อความแจ้งเตือนและสถานะปุ่มสร้างใบเคลียร์
  3. พยายามเริ่มสร้างรายการใหม่
ผลที่ควรเป็นแบบเอกสาร ACL เปิดใช้งานและสามารถกดสร้างใบเคลียร์ใหม่เพื่อดำเนินรายการได้
ผลที่เกิดจริงรอบก่อนแสดง badge "แบบเอกสารนี้ยังไม่เปิดใช้งาน — สร้างใบเคลียร์ใหม่ไม่ได้" และปุ่มสร้างถูก disabled; ผู้ตรวจยืนยันว่ารอบนี้แก้ไขแล้ว
BUG-03View Drawer แสดงโหลดข้อมูลไม่สำเร็จทั้งที่ API ตอบข้อมูลครบCriticalแก้แล้ว
ขั้นตอนทำซ้ำ
  1. สร้างใบเคลียร์และตรวจว่ามีรายการสถานะร่างในหน้ารายการ
  2. กดรายการที่สร้างเพื่อเปิด View Drawer
  3. ตรวจข้อความใน Drawer และตรวจ API response
ผลที่ควรเป็นView Drawer เปิดและแสดงรายละเอียดใบเคลียร์จาก API response ได้ครบ
ผลที่เกิดจริงรอบก่อน View Drawer แสดงว่า "โหลดข้อมูลไม่สำเร็จ" ทั้งที่ API ตอบข้อมูลครบ; ผู้ตรวจยืนยันเมื่อ 2026-11-11 ว่าแก้ไขแล้ว
BUG-02บันทึกร่างสำเร็จแต่ระบบแจ้งว่าทำรายการไม่สำเร็จและ Create Drawer ไม่ปิดHighแก้แล้ว
ขั้นตอนทำซ้ำ
  1. เปิด Create Drawer ของแบบฟอร์มเคลียร์เงินทดรองจ่าย
  2. กรอกข้อมูลที่จำเป็นสำหรับสร้างใบเคลียร์
  3. กดบันทึกร่าง
  4. สังเกต Toast, สถานะ Create Drawer และตรวจรายการที่หน้ารายการ
ผลที่ควรเป็นระบบแจ้งว่าบันทึกร่างสำเร็จ ปิดหรือเปลี่ยนสถานะ Drawer ตาม flow และสร้างรายการร่างเพียงหนึ่งรายการ
ผลที่เกิดจริงรอบก่อนระบบขึ้น Toast ว่า "ทำรายการไม่สำเร็จ" และ Create Drawer เปิดค้างทั้งที่สร้างรายการร่างสำเร็จ; ผู้ตรวจยืนยันเมื่อ 2026-11-11 ว่าแก้ไขแล้ว
