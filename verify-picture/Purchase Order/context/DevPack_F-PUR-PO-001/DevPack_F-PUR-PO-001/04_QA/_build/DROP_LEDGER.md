## เคสที่ **ไม่ได้ตัด** แม้จะยาก — เพราะเป็นข้อตกลงสำคัญ

| TC | ทำไมต้องเก็บไว้ให้คนตรวจเอง |
|---|---|
| **TC-17b** vs **TC-18** | คู่ตรงข้ามที่สำคัญที่สุดของฟีเจอร์ — ยอดเกินใบขอซื้อ **ปิดปุ่มจริง** / ยอดเกินงบ **เตือนเฉย ๆ** · ถ้าสองเคสนี้ให้ผลเหมือนกันแปลว่าผิดข้อตกลง |
| **TC-19** | ต้องเห็นด้วยตาว่าเลือก "คนจริง" ไม่ใช่รหัสตำแหน่ง |
| **TC-31** | ต้องเห็นด้วยตาว่าปุ่มยกเลิกหายไปจริงทั้งบนลิ้นชักและในเมนูแถว |
| **TC-36** | ต้องลองคลิกทุกช่องเพื่อพิสูจน์ว่าแก้ไม่ได้จริง |
| **TC-39** | ต้องไล่หาปุ่มลบเองเพื่อยืนยันว่าไม่มี |
| **TC-44** | ต้องกวาดตาดูทุกจอเพื่อจับปีพุทธศักราชที่อาจหลุด |
| **TC-67** | ต้องอ่านชื่อขั้นและแท็บทีละคำเทียบกับมาตรฐาน |
| **TC-72** | ต้องเลื่อนหน้าลงไปกดเมนูแถวล่างสุดจริง ๆ จึงจะเห็นปัญหา |
