## §1.2 P-01 · หน้ารายการใบสั่งซื้อ

### Anatomy (บนลงล่าง)
1. **แถบสรุป 4 ตัว** — `ใบที่รอผู้อนุมัติ` · `ส่งผู้ขายแล้ว/รับบางส่วน` · `บาท · ยังไม่รับของ` (ภาระผูกพันคงค้าง — S-12) · `ต้องติดตามผู้ขาย`
2. **แถบกรอง** — ช่องค้นหา (`ค้นเลขที่ / ผู้ขาย / ใบขอซื้อ / ผู้จัดซื้อ`) + `ทุกสถานะเอกสาร` + `ทุกสถานะรับของ` + `ผู้จัดซื้อทุกคน` + ปุ่ม `ล้างตัวกรอง`
3. **ตาราง** 8 คอลัมน์

### คอลัมน์ (#103 — 1 ข้อมูล = 1 คอลัมน์)

| # | หัวคอลัมน์ | เนื้อหา | หมายเหตุ |
|---|---|---|---|
| 1 | เลขที่ ↓ | เลขเอกสาร (หรือ `(ยังไม่ออกเลข)`) + บรรทัดรอง: วันที่ · เลขใบขอซื้อ | เรียงได้ · บรรทัดรองเป็น meta ของข้อมูลเดียวกัน |
| 2 | ผู้ขาย | ชื่อผู้ขาย + บรรทัดรอง: รหัส `V-xxxx` | |
| 3 | กำหนดรับ | วันที่ **ค.ศ.** | |
| 4 | สถานะเอกสาร | `docPill()` — ฉบับร่าง/รออนุมัติ/อนุมัติแล้ว/ส่งผู้ขายแล้ว/รับบางส่วน/ปิดแล้ว/ยกเลิก | 1 pill ต่อเซลล์ |
| 5 | การรับของ | pill แกนรอง — ยังไม่รับ/รับบางส่วน/รับครบ | |
| 6 | ลายเซ็น | `renderSignProgress()` — `n/N` + แถบความคืบหน้า | Q-document บังคับ (#98) |
| 7 | ยอดสุทธิ | ตัวเลขชิดขวา · `tabular-nums` | |
| 8 | (เมนู) | ปุ่ม ⋮ → `openRowMenu()` | |

### Interaction
- **คลิกแถว** → `openViewDrawer(id)` (row = view)
- **ปุ่ม ⋮** → เมนู `เปิดดู` · `ทำสำเนา` · `พิมพ์ / ดู PDF` · [`ยกเลิก`] · [`ปิดใบก่อนกำหนด`] — รายการท้าย 2 ตัวขึ้นตามสถานะ
- **#66 flip-up:** เมนูพลิกขึ้นบนอัตโนมัติเมื่อพื้นที่ใต้ปุ่มไม่พอ ([`:3333`](../01_HTML/F-PUR-PO.html#L3333)) — **แก้ในรอบ re-gate นี้**
- กรอง/เรียง → `renderTableOnly` ไม่ re-render ทั้งหน้า (#29)
- **empty state** → `emptyStateHTML()`

### Footer contract (#100)
ซ้าย `[ย้อนกลับ]` secondary (ขั้น > 1) · ขวา `[ยกเลิก]` ghost → ขั้น 1–4 `[ถัดไป]` primary · ขั้น 5 `[บันทึกแบบร่าง]` secondary → `[บันทึกและส่งอนุมัติ]` primary

> **★ hard control (L-09):** ปุ่ม `บันทึกและส่งอนุมัติ` ได้ attribute `disabled` **จริง** พร้อม `title="เกินยอดคงเหลือของใบขอซื้อ"` เมื่อยอดสุทธิเกินยอดคงเหลือของใบขอซื้อ ([`:2548`](../01_HTML/F-PUR-PO.html#L2548)) + มี guard ซ้ำใน `submitForApproval()`
> **★ soft (L-09):** ผลตรวจงบเกินวงเงิน **ไม่ปิดปุ่ม** — แสดง banner เตือนเท่านั้น

### Validation
`wizardNext()` ตรวจต่อขั้น → `markErr(fieldId, true)` ชี้ช่องที่ขาด + toast ตาม microcopy กลาง
**edit mode เริ่มที่ขั้น 2** · คลิก stepper ที่ทำแล้วย้อนกลับได้

## §1.5 P-03 · รายละเอียดใบสั่งซื้อ — **LOCKED L-01 · Iron Rule #101**

### แท็บ (ลำดับล็อก — ห้ามสลับ ห้ามเพิ่มแท็บเอกสารแนบ)

`รายละเอียด` › `การรับของ` › `PDF Preview` › `ลายเซ็น / อนุมัติ` › `ประวัติ`

### แท็บ 1 · รายละเอียด (landing) — ลำดับ section
banners (คำเตือน hard/soft) → `ข้อมูลเอกสาร` (KV 2 คอลัมน์) → `สถานะ` (3 คอลัมน์: pill เอกสาร · pill รับของ · แถบความคืบหน้า) → `เอกสารอ้างอิง` (ใบขอซื้อ · ผลเทียบราคา) → `คู่ค้าและผู้รับผิดชอบ` → `เงื่อนไข` → `ยอดรวม` → `รายการสินค้า (N)` (`linesTableView` read-only) → **`เอกสารแนบ (N ไฟล์ · Document Center)`** → `ข้อมูลระบบ`

> **เอกสารแนบเป็น section ในแท็บนี้ ไม่ใช่แท็บแยก** (#101)

### แท็บ 2 · การรับของ
การ์ดสรุป (สถานะการรับของ · ความคืบหน้า % · ส่งให้ผู้ขายเมื่อ) + ตารางรายบรรทัด:
`สินค้า` · `หน่วย` · `สั่ง` · `รับแล้วสะสม` · `คงเหลือรับ` · `รับเกินได้ %` · `สถานะบรรทัด`
**ทุกช่องอ่านอย่างเดียว — ยืนยันด้วยการวัด: editable input = 0** (BR-13 · L-06)
+ `.note` ยอดรับสะสมมาจากใบรับของเท่านั้น + `.note.warn` เพดานรับเกิน
+ ปุ่ม `ปิดใบก่อนกำหนด` เมื่อสถานะ = รับบางส่วน

### แท็บ 3 · PDF Preview
`.a4` + 3 ช่องลงนาม · ปุ่มดาวน์โหลด/พิมพ์ · **ปี ค.ศ. ทุกจุด** · สเปกเต็มที่ `PRINT_SPEC_F-PUR-PO-001.md`

### แท็บ 4 · ลายเซ็น / อนุมัติ
`ทะเบียน DOA` (`DOA-PUR-PO-01` · สายอนุมัติตามวงเงิน · ตั้งค่าที่หน้า DOA กลาง) + timeline `.tl` ทุกขั้น:

> **ห้ามแสดงรหัสตำแหน่ง/role id** (L-03 · LOCK-02) — ตรวจแล้วไม่มี

### แท็บ 5 · ประวัติ
timeline ต่อท้ายอย่างเดียว ทุกเหตุการณ์ + ค่าก่อน/หลัง · **ไม่มีปุ่มลบใด ๆ** (L-06 · LOCK-04)

| combobox | ปิด · เปิด (`position:fixed` z 70 · max-height 280 · scroll) · ไม่พบผลลัพธ์ · เลือกแล้ว (มีปุ่มล้าง) |
| ตาราง | มีข้อมูล · **empty state** · กำลังกรอง |
| แถว line editor | ปกติ · **ขยาย** (แถวเดียว) · error รายช่อง |
| toast | success · warning · error — มุมขวาล่าง |

## §1.8 Esc chain / dismiss

| ลำดับ | การกระทำ |
|---|---|
| 1 | มี combobox/เมนูเปิดอยู่ → ปิดเมนูก่อน (`closePops()` / `closeRowMenu()`) |
| 2 | มี modal เปิดอยู่ → ปิด modal (`closeModal()`) |
| 3 | มี drawer เปิดอยู่ → ปิด drawer (`closeCreateDrawer()` / `closeViewDrawer()`) แล้วกลับ `#/list` |

**คลิกนอกพื้นที่:** combobox และเมนูแถวปิดเมื่อคลิกนอก (ตรวจแล้วทุกตัว) · backdrop ของ drawer/modal ปิดได้

## §1.9 Responsive (#97)

วัดจริง `documentElement.scrollWidth` vs `innerWidth` ที่ **1600 · 1440 · 1280 · 1180 · 1024 · 900 · 768**
→ **เท่ากันทุกความกว้าง ไม่มี horizontal scroll แม้ที่ 768**

| ความกว้าง | พฤติกรรม |
|---|---|
| ≥ 1180 | เต็มรูปแบบ |
| < 1180 | media query ปรับ layout · `.page-fill` คิดความสูงใหม่ |
| 1024 | drawer `min(กว้าง, 100vw)` ไม่ล้น · ตาราง B2 scroll ใน wrapper ไม่ยุบคอลัมน์ |
