## 2. โครงหน้า (ตาม pattern เอกสารตาราง)

```
.doc-page
├── .doc-content
│   ├── HEADER   โลโก้ + ชื่อบริษัท + ที่อยู่ + เลขผู้เสียภาษี + สำนักงานใหญ่/สาขา + หัวเรื่อง "ใบสั่งซื้อ / PURCHASE ORDER"
│   ├── META     เลขที่ PO · วันที่เอกสาร · วันที่ต้องการรับ · เงื่อนไขชำระเงิน · สกุลเงิน · อ้างอิง PR/ใบเทียบราคา · หน้า x/y
│   ├── PARTIES  ซ้าย = ผู้ขาย (ชื่อ/ที่อยู่/เลขผู้เสียภาษี/ผู้ติดต่อ/โทร) · ขวา = สถานที่ส่งของ (คลัง/ที่อยู่จัดส่ง/ผู้รับ)
│   ├── ITEMS    ตารางรายการ (§3)
│   └── NOTES + TOTALS   ซ้าย = หมายเหตุ/เงื่อนไขพิเศษ + จำนวนเงินเป็นตัวอักษร · ขวา = บล็อกยอดรวม (§4)
└── .doc-bottom
    ├── SIGNATURES  ช่องลายเซ็นตามสาย DOA (§5)
    └── FOOTER      ชื่อไฟล์/เลขที่ + วันที่พิมพ์ (ค.ศ.) + หน้า
```

## 3. ตารางรายการ (ITEMS) — 1 row = 1 บรรทัด (ตารางผอม)

| คอลัมน์ | ที่มา (PREBRIEF §3.2) | จัดชิด | รูปแบบ |
|---|---|---|---|
| ลำดับ | `line_no` | กลาง | เลข |
| รายการ | `item_name` + `<span class="sub">` รหัสสินค้า / สเปคย่อย / วันที่ต้องการรับต่อบรรทัด | ซ้าย | ข้อความ |
| จำนวน | `qty_ordered` | ขวา | `#,##0.00` (ตัดทศนิยมท้ายถ้าเป็นจำนวนเต็ม) |
| หน่วย | `uom` | กลาง | ข้อความ |
| ราคา/หน่วย | `unit_price` | ขวา | `#,##0.00` |
| ส่วนลด | `line_discount` | ขวา | `#,##0.00` หรือ `x.xx%` |
| ภาษี | `vat_mode` | กลาง | `7%` / `0%` / `ยกเว้น` |
| จำนวนเงิน | `line_amount` (computed) | ขวา | `#,##0.00` |

- หัวตาราง = **แถบ navy เข้ม ตัวอักษรขาว** · เนื้อตาราง minimal (ไม่มีเส้นแนวตั้ง ไม่มี zebra)
- ตัวเลขเงินทุกช่อง class `num`
- รายการเกิน 1 หน้า → ขึ้นหน้าใหม่พร้อมหัวตารางซ้ำ + `หน้า x/y` · บล็อกยอดรวมอยู่หน้าสุดท้ายเท่านั้น

## 4. บล็อกยอดรวม (TOTALS) — สูตรตรงกับ PREBRIEF §3.3

| บรรทัด | สูตร | รูปแบบ |
|---|---|---|
| ยอดรวมก่อนส่วนลด | `Σ (qty × unit_price)` | `#,##0.00` |
| ส่วนลดรวม (บรรทัด + ท้ายบิล) | `Σ line_discount + header_discount` | `#,##0.00` |
| ยอดรวมก่อนภาษี | `ยอดรวมก่อนส่วนลด − ส่วนลดรวม` | `#,##0.00` |
| ฐานภาษี | `Σ ยอดบรรทัดที่ VAT = 7%` (ปันส่วนลดท้ายบิลตามสัดส่วน) | `#,##0.00` |
| ภาษีมูลค่าเพิ่ม 7% | `ฐานภาษี × 0.07` | `#,##0.00` |
| **ยอดรวมทั้งสิ้น** | `ยอดรวมก่อนภาษี + VAT` | `#,##0.00` · **แถบ navy เข้ม ตัวอักษรขาว** |
| จำนวนเงิน (ตัวอักษร) | `scripts/baht_text.py <ยอดรวมทั้งสิ้น>` | เช่น "หนึ่งแสนสี่หมื่นแปดพันบาทถ้วน" |

> ถ้ามีบรรทัด VAT 0% / ยกเว้น ปนอยู่ → แสดงยอดแยก "มูลค่าที่ไม่คิดภาษี" เพิ่มอีก 1 บรรทัด

## 5. ช่องลายเซ็น (SIGNATURES) — ผูกสาย DOA

| ช่อง | เนื้อหา | ที่มา |
|---|---|---|
| ผู้จัดทำ | ชื่อ-นามสกุล + ตำแหน่ง + วันที่ (**ค.ศ.**) | ผู้จัดซื้อผู้รับผิดชอบ |
| ผู้อนุมัติ slot 1..n | ชื่อ-นามสกุล + ตำแหน่ง + วันที่อนุมัติ (**ค.ศ.**) | `approval_chain` snapshot จาก **DOA_BRIEF §4** |
| ผู้ขายรับทราบ | ช่องว่างให้เซ็น + วันที่ | — |

- **จำนวนช่องลายเซ็นเปลี่ยนตามจำนวน slot ที่ resolve จริง** (1–3 ช่องตาม matrix DOA_BRIEF §3) — ห้าม hardcode 2 ช่องตายตัว
- แสดง **ชื่อคนจริง + ตำแหน่ง** — **ห้ามพิมพ์ role ID ลงเอกสาร** (DOA-UI-LOCK 2026-08-17)
- ลายเซ็น + footer ห่อใน `.doc-bottom` → ชิดล่างหน้าอัตโนมัติ

## 6. Field map (PDF ← entity)

| ช่องในเอกสาร | field | หมายเหตุ |
|---|---|---|
| เลขที่ | `po_no` | จาก **ENG-DOC-NUM** `PO-YYYY-NNNN` (ค.ศ.) — ห้าม format เอง |
| วันที่เอกสาร · วันที่ต้องการรับ | `doc_date` · `required_date` | **ค.ศ.** รูปแบบ `DD/MM/YYYY` |
| ผู้ขาย | `vendor_*` | soft-ref LD-4C-02 — ถ้าค่าหายจาก master ให้พิมพ์ค่าที่ snapshot ไว้ในใบ |
| อ้างอิง PR | `pr_ref` | **nullable** — ไม่มีให้เว้นว่าง ไม่พิมพ์ขีด (PO เปิดตรงได้ · PREBRIEF BR-03) |
| อ้างอิงใบเทียบราคา | `compare_ref` | nullable |
| สถานที่ส่งของ | `warehouse_*` / `ship_to_address` | soft-ref |
| เงื่อนไขชำระเงิน · สกุลเงิน | `payment_term` · `currency` | — |
| หมายเหตุ | `remark` | ตัดที่ความยาวปลอดภัย ไม่ให้ดันลายเซ็นตกหน้า |
| ลายเซ็น | `approval_chain[]` | ชื่อ + ตำแหน่ง + วันที่ |

## 7. กติกาการพิมพ์

1. **A4 แนวตั้งเสมอ** — ห้ามเปลี่ยนขนาดหน้า
2. **ปี ค.ศ. ล้วนทุกจุด** รวมวันที่พิมพ์ใน footer — ห้ามปน พ.ศ. แม้จุดเดียว (PREBRIEF FN-94)
3. ห้ามเขียน hex สีเองใน body — ใช้ class จาก `assets/base.css` เท่านั้น
4. ห้ามใช้ฟอนต์อื่นแทน Sarabun
5. ใบสถานะ `draft` **ไม่พิมพ์เป็นเอกสารจริง** — ถ้าพิมพ์ตัวอย่างต้องมีลายน้ำ "ร่าง — ยังไม่อนุมัติ" และไม่มีเลขที่
6. ใบที่ `cancelled` พิมพ์ได้แต่ต้องมีลายน้ำ "ยกเลิก" + เหตุผลยกเลิก
7. ใบที่ผ่าน **re-approve** (S-08) ใช้เลขเดิม + ระบุ "ฉบับแก้ไข ณ {วันที่ ค.ศ.}" ใต้เลขที่
