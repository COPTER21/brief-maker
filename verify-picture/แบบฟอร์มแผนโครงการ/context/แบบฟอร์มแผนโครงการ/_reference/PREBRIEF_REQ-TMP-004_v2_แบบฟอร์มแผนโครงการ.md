- **เป้าหมายและ KPI** — บนกระดาษ 3 แถว (min_rows) · ช่องในแถว: เป้าหมายเชิงปริมาณ (Quantitative Target), เป้าหมายเชิงคุณภาพ (Qualitative Target), KPI, วิธีการวัดผล (Measurement Method)
- **แผนการดำเนินงาน (กิจกรรม)** — บนกระดาษ 10 แถว (min_rows) · ช่องในแถว: ลำดับ (No.), กิจกรรม (Activity), ผู้รับผิดชอบ (Responsible), วันที่เริ่ม (Start), วันที่สิ้นสุด (End), ระยะเวลา (Duration), สถานะ (Status)
- **รายการงบประมาณ** — บนกระดาษ 6 แถว (min_rows) · ช่องในแถว: รายการค่าใช้จ่าย (Expense Item), งบประมาณที่ขอ (Requested Budget), งบประมาณที่ได้รับอนุมัติ (Approved Budget), หมายเหตุ (Remarks)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- ระยะเวลาดำเนินการ / ระยะเวลากิจกรรม เป็นช่องกรอกเอง ทั้งที่คำนวณได้จากวันเริ่ม–สิ้นสุด → **วันที่สิ้นสุด ≥ วันที่เริ่มต้น (บล็อก) · ระยะเวลา = คำนวณ**
- กิจกรรมในแผนอาจอยู่นอกช่วงวันที่โครงการ → **วันที่กิจกรรมอยู่นอกช่วงโครงการ = เตือน**
- คอลัมน์ งบประมาณที่ได้รับอนุมัติ อยู่แถวเดียวกับ งบประมาณที่ขอ แต่ผู้กรอกต่างกัน (ผู้อนุมัติ) → **งบที่อนุมัติ ≥ 0 · เกินงบที่ขอ = เตือน**
- สถานะกิจกรรมใช้ค่าภาษาอังกฤษ (Not Started/In Progress/Completed/Delayed) ขณะที่ระดับความรุนแรงใช้ภาษาไทย (สูง/กลาง/ต่ำ) → **ใช้ค่าตามต้นฉบับ 1:1**

## 8. กติกา / declaration
- DOA: ถาม (มีช่องลงชื่อผู้อนุมัติ 2 จุด) — gate G2
- DOCCFG: ประกาศ doc_type + print_config (form_code/revision/min_rows/sign_boxes) — ร่างก่อน HTML
- MDOC: ลงทะเบียนแบบเอกสาร (F-DOCCFG / F003) · source=request
- NTF: event ของ feature เอง (เช่น ยกเลิกระหว่างรอ) — DOA ส่งแจ้งรออนุมัติ/ผลเอง
