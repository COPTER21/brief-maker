## 1. Business Context
### 1.1 ปัญหา / โอกาส
ฝ่ายขายเก็บความพึงพอใจของลูกค้าในประเทศต่องาน Sale admin ด้วยแบบฟอร์ม Word FM-SAL-20 — เลือกระดับความพึงพอใจ 5 ระดับ (มากที่สุด · มาก · ปานกลาง · น้อย · ควรปรับปรุง) รวม 5 หัวข้อ (ความรวดเร็วในการตอบคำถาม · การให้ข้อมูลสินค้า · การแก้ไขปัญหาน้ำตาลเสียหาย · ความเหมาะสมในการแก้ไขปัญหา · คุณภาพสินค้า) + ข้อเสนอแนะเพิ่มเติม · ไฟล์กระจัดกระจาย ไม่มีเลขที่ ไม่ผูกกับลูกค้าใน Customer master · นำไปสรุป (FM-SAL-21) ต้องรวบรวมเอง
### 1.2 เป้าหมาย
1. บันทึกแบบประเมินเป็นเอกสารในระบบ ช่องตรงกระดาษ 1:1 (DEC-06) — PDF Replica หน้าตาเหมือน FM-SAL-20 ใน 1 หน้า
2. ผูกกับลูกค้าใน Customer master + ประจำเดือน เพื่อให้สรุปผลรายเดือน/รายลูกค้าได้ (ต่อยอดไป FM-SAL-21)
3. ผู้จัดการฝ่ายขายรู้ทันทีเมื่อมีหัวข้อที่ได้ระดับ "น้อย"/"ควรปรับปรุง" (event sda_low_score_recorded)
### 1.3 ตัวชี้วัด
ไม่มีใน input → **OQ-01** (ห้ามแต่งตัวเลข)
### 1.4 ที่มา
แบบฟอร์มลูกค้า FM-SAL-20 (docx 1 หน้า) → FORM_SPEC 9 ช่อง · gate 10 หมวด = AI-DEFAULT ทั้งหมด (โหมดไม่เฝ้า · `4_knowledge/governance/unattended-policy.md`)

## 2. Scope
### 2.1 In Scope
- รายการแบบประเมิน (segmented tabs ตามสถานะ · ค้นหา · กรองเดือน/ผู้บันทึก · CSV) · สร้าง/แก้ร่าง wizard 3 ขั้น · ดูรายละเอียด 4 แท็บ (รายละเอียด › PDF Preview › ลายเซ็น / อนุมัติ › ประวัติ)
- เลือกระดับความพึงพอใจ 5 หัวข้อ (ข้อละ 1 ระดับ เก็บค่า 5–1) · ข้อเสนอแนะเพิ่มเติม · เลือกลูกค้าจาก Customer master (ในประเทศ) · ประจำเดือน + วันที่ (พ.ศ.)
- บันทึกผล (ไม่มีขั้นพิจารณา — DEC-03) · ยกเลิก (เหตุผลบังคับ — G7) · แนบไฟล์ · PDF FM-SAL-20 Replica ทุกสถานะ · เลขที่ SDA จาก ENG-DOC-NUM
- แจ้งเตือน: ระดับต่ำ → ผู้จัดการฝ่ายขาย · ยกเลิกโดยผู้อื่น → เจ้าของ (NTF_BRIEF)
### 2.2 Out of Scope
- สรุปผลการประเมินในประเทศ (FM-SAL-21 — เอกสารอีกใบ) · แบบประเมินลูกค้าต่างประเทศ (FM-SAL-22/23) · ส่งแบบประเมินให้ลูกค้ากรอกเองผ่านลิงก์/พอร์ทัล · คะแนนรวม/ถ่วงน้ำหนักบนแบบพิมพ์ (กระดาษไม่มี — DEC-06) · ทำซ้ำเอกสาร (DEC-10) · ส่งต่อระบบอื่น (DEC-02)
### 2.3 Assumptions
- ผู้บันทึก = เจ้าหน้าที่ Sale admin ที่รับแบบประเมินจากลูกค้า (ลูกค้าตอบบนกระดาษ/อีเมล/โทรศัพท์ แล้วเจ้าหน้าที่บันทึกเข้าระบบ) → ยืนยันใน OQ-02
- Customer master แยกลูกค้าในประเทศ/ต่างประเทศได้ (OQ-04)

## 4. User Journey
### 4.1 Happy Path
1. Sale admin: สร้างแบบประเมิน → เลือกลูกค้า → วันที่ (ประจำเดือนเติมเอง) → เลือกระดับ 5 ข้อ → ข้อเสนอแนะเพิ่มเติม (ไม่บังคับ) → แนบภาพแบบประเมินกระดาษ (ไม่บังคับ) → ตรวจสอบ → **บันทึกผลแบบประเมิน** → ได้เลข SDA · สถานะ "บันทึกผลแล้ว"
2. มีข้อที่ได้ "น้อย"/"ควรปรับปรุง" → ผู้จัดการฝ่ายขายได้รับแจ้ง (sda_low_score_recorded)
### 4.2 Alternative
- ลูกค้าตอบไม่ครบ → บันทึกแบบร่าง (ต้องมีลูกค้า + วันที่ + ประจำเดือน) → กลับมาแก้ภายหลัง
- บันทึกผิด → ยกเลิกเอกสาร (เหตุผลบังคับ) แล้วสร้างใบใหม่ (ไม่มีทำซ้ำ — DEC-10)
- เลือกประจำเดือนไม่ตรงวันที่ → เตือน ไม่บล็อก (DEC-12)
```mermaid

A -->|ยกเลิก + เหตุผล| X[ยกเลิก]
B -->|ยกเลิก + เหตุผล| X
```
