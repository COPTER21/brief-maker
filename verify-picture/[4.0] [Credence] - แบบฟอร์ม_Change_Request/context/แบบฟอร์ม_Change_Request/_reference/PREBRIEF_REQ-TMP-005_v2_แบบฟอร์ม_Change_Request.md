### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- สะกด ตําแหน่ง (ํ + า) → **แก้คำสะกดเป็น ตำแหน่ง (G5)**
- ป้าย ผู้ขอซื้อ ไม่ตรงกับเอกสาร Change Request (ไม่ใช่การขอซื้อ) → **คงคำตามกระดาษ (G5 1:1) · บันทึก OQ ลูกค้าว่าควรเป็น ผู้ขอ/ผู้ร้องขอ หรือไม่**
- กระดาษไม่กำหนดว่าต้องไม่ก่อนวันที่ขอ → **วันที่ต้องการส่งมอบ ≥ วันที่ขอ (เตือน)**
- มีเส้นให้ระบุเฉพาะตัวเลือก อื่นๆ → **ติ๊ก อื่นๆ = ต้องระบุข้อความ**
- กระดาษไม่ระบุว่าเลือกได้กี่ข้อ → **เลือกอย่างน้อย 1 ข้อ (บล็อก)**
