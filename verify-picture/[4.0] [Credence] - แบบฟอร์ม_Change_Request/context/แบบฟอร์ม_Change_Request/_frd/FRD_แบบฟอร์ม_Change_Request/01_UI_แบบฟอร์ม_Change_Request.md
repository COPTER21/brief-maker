## §1.2 P-01 รายการ
- head: แบบฟอร์ม Change Request (Change Request Form) · sub ≤60 ตัว + badge ≤3 (จำนวน · รอฉันพิจารณา · รออนุมัติ · ค่า 0 ซ่อน) · ขวา: ส่งออก CSV (secondary) · สร้างคำขอ (primary · disabled เมื่อ doc_type ปิด)

- คอลัมน์: เลขที่ · วันที่ · ผู้ขอ (person icon) · เรื่องที่ต้องการ · ประเภท (ตัวแรก +n) · วันที่ต้องการส่งมอบ · สถานะเอกสาร · ลายเซ็น n/N · ⋮ (ดูรายละเอียด · แก้ไข[ร่างของตน] · พิมพ์ · ยกเลิกเอกสาร)
- footer: แสดงต่อหน้า 10/25/50 · x – y จาก N รายการ · pager
