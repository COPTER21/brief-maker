## §1.4 P-03 แท็บ
- รายละเอียด: แบนเนอร์ตามสถานะ (รอ/ร่างกลับจากไม่อนุมัติ/ยกเลิก/SDA ถูกยกเลิก) · ข้อมูลเอกสาร · ตารางหัวข้อ × ลูกค้า · สรุปผลการประเมิน · ข้อเสนอแนะ · เอกสารแนบ · ข้อมูลระบบ
- PDF Preview: iframe srcdoc จาก `form.tpl.html` + `docPrintData(r)` · 2 หน้า · ดาวน์โหลด/พิมพ์
- ลายเซ็น / อนุมัติ: summary card (DOA entry · x/y) + timeline ส่ง → ขั้น 1..N → ผลลัพธ์ · ปุ่มตัดสิน inline เฉพาะผู้พิจารณาขั้นปัจจุบัน
- ประวัติ: append-only

## §1.5 ปุ่มหัว drawer ตามสถานะ
ร่าง (เจ้าของ) = ยกเลิก · แก้ไข · ส่งอนุมัติ · รอ (ผู้พิจารณาขั้นปัจจุบัน) = ไม่อนุมัติ · รับทราบและอนุมัติ · รอ (เจ้าของ/admin) = ยกเลิกเอกสาร · อนุมัติแล้ว = ล็อก
