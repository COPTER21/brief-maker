### 3.1 รายการซ้ำ
- **ลูกค้าที่ประเมิน (คอลัมน์)** — บนกระดาษ 6 แถว (min_rows) · ช่องในแถว: หัวข้อการประเมิน (ชื่อลูกค้า — หัวคอลัมน์), (แถวว่างใต้ชื่อลูกค้า), 1. ความรวดเร็วในการตอบคำถาม, 2. การให้ข้อมูลสินค้า, 3. การแก้ไขปัญหา (สินค้าเสียหาย), 4. ความเหมาะสมในการแก้ปัญหา, 5. คุณภาพสินค้า

### 3.2 ตัวเลือก

### 3.3 สูตร + ค่าคงที่บนกระดาษ
- ค่าคงที่ "1. ความรวดเร็วในการตอบคำถาม … 5. คุณภาพสินค้า" = หัวข้อการประเมิน 5 ข้อ (ตรงกับ q1–q5 ของ FM-SAL-20 · ถ้อยคำบนกระดาษสั้นกว่า FM-SAL-20) → ควรอ่านจาก `SalesConfig.sda_topics[] (ใช้ชุดเดียวกับ SDA · ป้ายย่อสำหรับใบสรุป)` (ห้าม hardcode)
- ค่าคงที่ "ระดับความพึงพอใจ" = สเกล 5 ระดับ มากที่สุด/มาก/ปานกลาง/น้อย/ควรปรับปรุง (ไม่ได้พิมพ์บนกระดาษ — มาจาก FM-SAL-20) → ควรอ่านจาก `SalesConfig.sda_scale[] (label + weight 5–1)` (ห้าม hardcode)

### 3.4 ลายเซ็น + control
- S1 ผู้สรุปผลการประเมิน · Sales Administrative Manager (ผู้ขอ)
- S2 ผู้รับทราบและอนุมัติ · Managing Director (ผู้อนุมัติ)
- Doc No. บนกระดาษ Doc No.FM-SAL-21 · Rev.00 : 01/07/2569 · เลขรันบนกระดาษ: ไม่มี (ระบบออกเลขเอง)

### 3.5 ข้อมูลตัวอย่างที่ขัดกัน → กฎตรวจที่ควรมี
- ชื่อลูกค้าซ้ำในคอลัมน์ (หจก. นิวไทยที เบเกอรี่ ×2 · นายสรไกจ อาจหาญ ×2) — ข้อมูลตัวอย่างจากการคัดลอก → **ลูกค้าเดียวกันซ้ำในใบสรุปเดียวกันไม่ได้ (1 ลูกค้า = 1 คอลัมน์ · ถ้ามีแบบประเมินหลายใบในเดือนใช้ใบล่าสุด) → บล็อก**
- แถวว่างไม่มีป้าย → **แสดงวันที่ประเมิน + เลขที่ SDA อ้างอิง (AI-DEFAULT รอยืนยัน)**
- ไม่มีช่องประจำเดือน/งวด ทั้งที่เป็นใบสรุป → **เพิ่มช่อง ประจำเดือน (บังคับ) ใช้ดึงแบบประเมินในเดือนนั้น**
- ถ้อยคำหัวข้อสั้นกว่าใน FM-SAL-20 (เช่น "การให้ข้อมูลสินค้า" vs "การให้ข้อมูลเกี่ยวกับสินค้า") → **จับคู่ตามลำดับข้อ q1–q5 · พิมพ์ถ้อยคำตามกระดาษ FM-SAL-21**
- เส้นลงชื่อผู้อนุมัติขึ้นบรรทัดใหม่ ("____" ตกบรรทัด) ในต้นฉบับ → **จัดเส้นลงชื่อให้เท่ากันทั้ง 2 ช่อง (layout เท่านั้น)**
