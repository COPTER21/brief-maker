
## §1.2 OV-01 Create (drawer) — cascade ⭐
```
Section 0 · เลือกโควตา แปลง รอบปลูก (บังคับก่อน):
  0a search-select "ค้นหาเลขโควตา" → farmer snapshot card (read-only)
  0b select "เลือกแปลง (ของโควตา)" → plot snapshot
  0c select "เลือกรอบปลูก (ของแปลง)" → crop snapshot
Section 1 · ข้อมูลพื้นฐาน: วันที่สำรวจ(date) · ผู้สำรวจ (ผู้บันทึก ↔ recorder) · ปี(พ.ศ.) · เดือนที่ปลูก(select 1–12) · อายุอ้อย(เดือน) **derived read-only** (คำนวณจากเดือนปลูก+ปี พ.ศ. · FN-AT-CROP-192)
Section 2 · ข้อมูลพืชผล: พันธุ์อ้อย · ประเภทอ้อย(select อ้อยใหม่/อ้อยตอ) · ปริมาณรวม(ตัน ≥0 · ↔ total_tons) · ขนาดแปลง(ไร่ >0) · สีดิน(select) · การตรวจสีใบ(select)
Section 2b · การวัดขนาดอ้อย (optional): ระยะร่อง(ซม.) · ความสูงลำต้น หัว/กลาง/ท้าย(ซม.) · ความยาวปล้อง(ซม.) · เส้นผ่านศูนย์กลางลำ(ซม.) · จำนวนลำเฉลี่ยต่อกอ · จำนวนกอใน 10 เมตร
Section 2c · ดิน/สภาพแปลง (optional): ชนิดดิน(select) · ความหนาแน่นวัชพืช(select ไม่มี/น้อย/ปานกลาง/มาก)
Section 2d · โรค/ศัตรูพืช: พบโรค/ศัตรูพืช(select ไม่พบ/พบ) · ระดับ(select น้อย/ปานกลาง/มาก/ไม่พบ) · รายละเอียด(textarea)
Section 2e · ตำแหน่งที่ตั้ง: พิกัด(lat,long) · รหัสไปรษณีย์(5 หลัก)
Section 3 · รูปภาพประกอบ (4 หมวด): รูปกับแปลง · รูปพืชผล · รูปลำต้นในกอ · รูปสีดิน (upload หลายไฟล์/หมวด)
Footer: ยกเลิก · ยืนยันสร้าง
```
> วัดขนาด/ดิน/วัชพืช/รหัสไปรษณีย์ ทั้งหมด optional · agronomic panel นี้แสดงบน Edit (OV-02) + Detail tab1 + Export ด้วย
Fields ล็อกจนครบ quota+plot+crop (LOCK-03)

## §1.5 OV-03 Verify/Reject (modal, single/bulk)
radio ผลตรวจสอบ: ยืนยัน(verified) / ปฏิเสธ(rejected) · ปฏิเสธ → reason textarea **บังคับ** · ยืนยัน → note optional · bulk → "ยืนยัน/ปฏิเสธ N รายการ" + skip non-waiting · Confirm/ยกเลิก

radio: ยกเลิก(cancelled) / ลบ(deleted) · เหตุผล **บังคับ** · Confirm/ยกเลิก
