## 2. โครงหน้า (ตาม pattern เอกสารตาราง)

```
.doc-page
├── .doc-content
│   ├── HEADER   โลโก้ + ชื่อบริษัท + ที่อยู่ + เลขผู้เสียภาษี + สำนักงานใหญ่/สาขา + หัวเรื่อง "ใบรับของ / GOODS RECEIPT NOTE"
│   ├── META     เลขที่ GRN · วันที่รับจริง · อ้างอิง PO · เลขที่ใบส่งของผู้ขาย · วันที่บนใบส่งของ · หน้า x/y
│   ├── PARTIES  ซ้าย = ผู้ขาย (ชื่อ/ที่อยู่/เลขผู้เสียภาษี/ผู้ติดต่อ) · ขวา = สถานที่รับ (คลังปลายทาง/location · quarantine location ถ้ามี · ผู้ส่ง/ทะเบียนรถ)
│   ├── ITEMS    ตารางรายการรับ (§3)
│   └── NOTES + TOTALS   ซ้าย = หมายเหตุ + สรุปผล QC + จำนวนเงินเป็นตัวอักษร · ขวา = บล็อกยอดรวม (§4)
└── .doc-bottom
    ├── SIGNATURES  ผู้ส่งของ · ผู้รับของ · ผู้ตรวจคุณภาพ (§5)
    └── FOOTER      ชื่อไฟล์/เลขที่ + วันที่พิมพ์ (ค.ศ.) + หน้า
```

## 3. ตารางรายการรับ (ITEMS) — 1 row = 1 บรรทัด (ตารางผอม)

| คอลัมน์ | field | จัดชิด | รูปแบบ |
|---|---|---|---|
| ลำดับ | `line_no` (+ `<span class="sub">` อ้าง PO line) | กลาง | เลข |
| รายการ | `item_name` + `<span class="sub">` รหัสสินค้า / สเปคย่อย / ประเภทบรรทัด (สินค้า/บริการ) | ซ้าย | ข้อความ |
| สั่ง | `qty_ordered` | ขวา | `#,##0.00` (ตัดทศนิยมท้ายถ้าเป็นจำนวนเต็ม) |
| รับแล้วก่อนหน้า | `qty_received_before` | ขวา | `#,##0.00` |
| **รับใบนี้** | `qty_received_now` | ขวา | `#,##0.00` · **น้ำหนัก 600** (คอลัมน์หลักของเอกสารนี้) |
| ไม่ผ่าน QC | `qty_rejected` + `<span class="sub">` เหตุผล | ขวา | `#,##0.00` · เว้นว่างถ้า 0 (ห้ามพิมพ์ 0.00 รก) |
| คงเหลือ | `qty_open_after` (computed §3.3) | ขวา | `#,##0.00` |
| หน่วย | `uom` | กลาง | ข้อความ |
| ราคา/หน่วย | `unit_price` (จาก PO · อ่านอย่างเดียว) | ขวา | `#,##0.00` |
| จำนวนเงิน | `line_receipt_amount` (computed) | ขวา | `#,##0.00` |

- หัวตาราง = **แถบ navy เข้ม ตัวอักษรขาว** · เนื้อตาราง minimal (ไม่มีเส้นแนวตั้ง ไม่มี zebra)
- ตัวเลขทุกช่อง class `num`
- บรรทัด **ประเภทบริการ**: ช่อง "ไม่ผ่าน QC" ว่างเสมอ + `<span class="sub">` ระบุ "บริการ — ยืนยันงานเสร็จ" (PREBRIEF BR-08)
- บรรทัดที่ **รับเกิน** คงเหลือ: ใส่ `<span class="sub">` "รับเกิน {n} {uom} (tolerance {x}%)" ใต้ชื่อรายการ
- รายการเกิน 1 หน้า → ขึ้นหน้าใหม่พร้อมหัวตารางซ้ำ + `หน้า x/y` · บล็อกยอดรวมอยู่หน้าสุดท้ายเท่านั้น

## 4. บล็อกยอดรวม + สรุป QC — สูตรตรงกับ PREBRIEF §3.3

| บรรทัด | สูตร | รูปแบบ |
|---|---|---|
| ยอดรวมก่อนภาษี (มูลค่าที่รับ) | `Σ line_receipt_amount` | `#,##0.00` |
| ภาษีมูลค่าเพิ่ม 7% (อ้างอิง) | `Σ (มูลค่าที่รับของบรรทัด VAT 7%) × 0.07` | `#,##0.00` · **ระบุกำกับว่า "อ้างอิงจาก PO — ภาษีจริงตามใบกำกับของผู้ขาย"** |
| **มูลค่ารับเข้ารวม** | `ยอดรวมก่อนภาษี + VAT` | `#,##0.00` · **แถบ navy เข้ม ตัวอักษรขาว** |
| จำนวนเงิน (ตัวอักษร) | `scripts/baht_text.py <มูลค่ารับเข้ารวม>` | เช่น "แปดหมื่นสองพันห้าร้อยบาทถ้วน" |

**บล็อกสรุปผลตรวจคุณภาพ (ซ้ายของ TOTALS — บังคับมีเสมอ)**

| บรรทัด | เนื้อหา |
|---|---|
| รับเข้าคลังปกติ | `Σ จำนวนเข้าคลังปกติ` + ชื่อคลัง/location ปลายทาง |
| **เข้าพักรอตรวจสอบ (quarantine)** | `Σ จำนวนที่ไม่ผ่าน QC` + ชื่อ quarantine location + เหตุผลรวม — **พิมพ์เฉพาะเมื่อ > 0** |
| ผลตรวจโดย | ชื่อผู้ตรวจคุณภาพ + วันที่ (**ค.ศ.**) |

## 5. ช่องลายเซ็น (SIGNATURES) — **ไม่ใช่สาย DOA**

| ช่อง | เนื้อหา | ที่มา |
|---|---|---|
| ผู้ส่งของ (ฝ่ายผู้ขาย) | ช่องว่างให้เซ็น + ชื่อผู้ส่ง/ทะเบียนรถ (ถ้ามี) + วันที่ | `deliverer_name` (nullable) |
| **ผู้รับของ** | ชื่อ-นามสกุล + ตำแหน่ง + วันที่ (**ค.ศ.**) | `receiver` — **คนจริง** (PREBRIEF BR-23) |
| **ผู้ตรวจคุณภาพ** | ชื่อ-นามสกุล + ตำแหน่ง + วันที่ (**ค.ศ.**) | `qc_inspector` — พิมพ์เฉพาะเมื่อมีการบันทึกผล QC |

- **3 ช่องคงที่** (ไม่ผันตาม matrix ใด ๆ) — GRN ไม่มีสายอนุมัติ **ห้ามพิมพ์ช่อง "ผู้อนุมัติ"**
- แสดง **ชื่อคนจริง + ตำแหน่ง** — ห้ามพิมพ์ role ID ลงเอกสาร
- ลายเซ็น + footer ห่อใน `.doc-bottom` → ชิดล่างหน้าอัตโนมัติ

## 6. Field map (PDF ← entity)

| ช่องในเอกสาร | field | หมายเหตุ |
|---|---|---|
| เลขที่ | `grn_no` | จาก **ENG-DOC-NUM** `GRN-YYYY-NNNN` (ค.ศ.) — ห้าม format เอง |
| วันที่รับจริง · วันที่บนใบส่งของ | `receive_date` · `delivery_note_date` | **ค.ศ.** รูปแบบ `DD/MM/YYYY` |
| อ้างอิง PO | `po_no` | **บังคับมีเสมอ** (PREBRIEF BR-01) |
| เลขที่ใบส่งของผู้ขาย | `delivery_note_no` | บังคับ · ถ้าซ้ำใบเดิมยังพิมพ์ได้ (เตือนเฉพาะบนหน้าจอ — BR-18) |
| ผู้ขาย | `vendor_*` | soft-ref LD-4C-02 — ถ้าค่าหายจาก master ให้พิมพ์ค่าที่ snapshot ไว้ในใบ |
| คลังปลายทาง · quarantine | `warehouse_*` · `quarantine_location` | soft-ref · quarantine พิมพ์เฉพาะเมื่อมีของไม่ผ่าน |
| ผู้ส่ง/ทะเบียนรถ | `deliverer_name` · `vehicle_no` | nullable — ไม่มีให้เว้นว่าง ไม่พิมพ์ขีด |
| หมายเหตุ | `remark` | ตัดที่ความยาวปลอดภัย ไม่ให้ดันลายเซ็นตกหน้า |
| ผู้รับของ · ผู้ตรวจ QC | `receiver` · `qc_inspector` | ชื่อ + ตำแหน่ง + วันที่ |

## 7. กติกาการพิมพ์

1. **A4 แนวตั้งเสมอ** — ห้ามเปลี่ยนขนาดหน้า
2. **ปี ค.ศ. ล้วนทุกจุด** รวมวันที่พิมพ์ใน footer — ห้ามปน พ.ศ. แม้จุดเดียว (PREBRIEF FN-94)
3. ห้ามเขียน hex สีเองใน body — ใช้ class จาก `assets/base.css` เท่านั้น
4. ห้ามใช้ฟอนต์อื่นแทน Sarabun
5. ใบสถานะ `draft` **ไม่พิมพ์เป็นเอกสารจริง** — พิมพ์ตัวอย่างต้องมีลายน้ำ "ร่าง — ยังไม่รับเข้า" และไม่มีเลขที่ (เลขออกตอน post เท่านั้น)
6. ใบที่ `reversed` พิมพ์ได้ แต่ต้องมีลายน้ำ **"กลับรายการ"** + เหตุผลกลับรายการ + วันที่-ผู้กลับรายการ
7. **ห้ามพิมพ์ช่องลายเซ็นผู้อนุมัติ** ในใบนี้ทุกกรณี — GRN ไม่มี DOA
