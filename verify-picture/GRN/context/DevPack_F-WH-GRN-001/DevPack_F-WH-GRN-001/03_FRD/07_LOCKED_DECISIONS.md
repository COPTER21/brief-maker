## §7.2 Locked Decisions

### LD-01 · FRD variant = FULL
`states = 4` + engine เจ้าของ 4 ตัว + engine กลาง 3 ตัว + permission matrix จริง → FULL (9 files + INDEX) ตามกติกา fallback ของ `frd-generator-v6`

### LD-02 · แท็บลายเซ็นไม่ตรง Rule #101 ตามตัวอักษร — และนั่นถูกแล้ว
Iron Rule #101 นิยามแท็บ "ลายเซ็น / อนุมัติ" บนสมมติฐานว่ามี DOA (การ์ด KV 4 ช่อง + DOA entry + ปุ่มอนุมัติ inline)
feature นี้ **ชิปไม่มี `doa`** (LOCK-04) → แท็บถูกดัดแปลงเป็น **ผู้รับของ + ผู้ตรวจคุณภาพ + ผู้ส่งของ** ไม่มีปุ่มอนุมัติ
**ตัดสิน:** ยึด LOCK-04 (สัญญาของ registry ชนะรูปแบบ archetype) · ใส่ปุ่มอนุมัติ = **DIVERGENCE** ต้องกลับไปแก้ registry ก่อน

### LD-03 ★ · ไฟล์ HTML ในแพ็กนี้ **ไม่ byte-identical** กับ `input/09142026-grn/1_HTML/F-WH-GRN.html`
