## สิ่งที่ไม่รองรับ (ตัดสินแล้ว — อย่าเผลอทำ)

- ปฏิเสธของตั้งแต่หน้าประตู (ไม่รับเข้าเลย) — [ASSUMED OQ-GRN-01] ของที่มาถึงต้องบันทึกเข้า quarantine ก่อนเสมอ แล้วคืนด้วย RTV (owner Strike)
- รับของโดยไม่มี PO (unplanned receipt) — [มติ · BASELINE N-09] ให้ใช้ Stock Adjustment (W3Q) แทน
- 1 GRN รับข้าม PO หลายใบพร้อมกัน — [มติ · BASELINE N-08] 1 GRN = 1 PO เพื่อให้ sync สถานะกลับ PO ตรงไปตรงมา
- แก้ใบ GRN หลัง post — [มติ CONTEXT_PACK §2.8] movement append-only ต้องกลับรายการแล้วออกใบใหม่
- สายอนุมัติ / DOA ของการรับของ — [มติ CONTEXT_PACK §2.2] รับของไม่ใช่การอนุมัติ ห้ามใส่ slot picker อนุมัติและห้ามออก DOA_BRIEF
- Lot / Batch / Serial + วันหมดอายุ — [มติ · BASELINE N-01] ยังไม่มี Lot master ในเลนนี้
- เลือก bin / putaway strategy ในใบรับ — [มติ · OB-14] เป็นงานของ F-WH-PUTAWAY (W3Q) รอบนี้รับถึงระดับ location เท่านั้น
- ASN / inbound delivery ล่วงหน้า · barcode/RF scan — [มติ · BASELINE N-03/N-04] backlog
- Landed cost / ต้นทุนเฉลี่ยตอนรับ — [มติ · BASELINE N-05/N-06] เป็นงานของ F069/F070 (W4)
- post JE / GL จริง — [TODO: JE posting] เป็นงานของ W5 รอบนี้เป็น mock + note GR/IR ใน BRD
