## §4.3 Relationships
warehouses 1:N zones 1:N areas 1:N racks 1:N locations; areas 1:N locations (direct, when allows_direct_location); locations 1:N stock_balances (F-INV-STOCK).
geo_subdistricts N:1 geo_districts N:1 geo_provinces; warehouses N:1 geo_subdistricts (snapshot codes + postcode).

## §4.4 Constraints + Indexes
```sql
-- locations flexible parent (LD-01)
ALTER TABLE locations ADD CONSTRAINT chk_flexible_parent CHECK (
  (parent_type='rack' AND rack_id IS NOT NULL AND area_id IS NULL) OR
  (parent_type='area' AND area_id IS NOT NULL AND rack_id IS NULL));
CREATE UNIQUE INDEX uq_loc_code   ON locations(COALESCE(rack_id,area_id), code);
CREATE INDEX ix_loc_type ON locations(type);
CREATE INDEX ix_loc_status ON locations(status);
-- node uniqueness within parent
CREATE UNIQUE INDEX uq_zone_code ON zones(warehouse_id, code);
CREATE UNIQUE INDEX uq_area_code ON areas(zone_id, code);
CREATE UNIQUE INDEX uq_rack_code ON racks(area_id, code);
CREATE UNIQUE INDEX uq_wh_code   ON warehouses(code);
-- child lookups
CREATE INDEX ix_zone_wh ON zones(warehouse_id);
CREATE INDEX ix_area_zone ON areas(zone_id);
CREATE INDEX ix_rack_area ON racks(area_id);
```
App triggers: (a) parent=area → assert `areas.allows_direct_location=true` (FN-14); (b) zone temp_controlled=true → temp_min/max NOT NULL (FN-09); (c) disable area.allows_direct_location → assert no direct locations exist (FN-10); (d) delete node → assert no children (FN-07).

## §4.6 Data Classification Policy
- **Public:** geo reference (province/district/subdistrict names + postcode) — read-only lookup.
- **Internal (default, all owned columns):** ตำแหน่ง/โครงสร้าง/ที่อยู่คลัง — RBAC by role; WORM audit.
- **Confidential:** none.
- **Restricted:** none → ไม่ต้อง register Policy Center Restricted Resources.
- **PII overlay:** `created_by` / `modified_by` (user refs).
- **Enforcement mapping:** DB (no column-level mask needed) · API (RBAC by role, §02) · UI (action visibility by role, §4.2 BRD) · Audit (WORM ทุก mutation).
- Default rule (R10): ถ้าไม่ระบุ = Internal (ห้าม default Public) — geo เป็น Public โดยตั้งใจเพราะเป็น public reference.
