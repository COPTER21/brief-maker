## 2. โครงหน้า (ตาม pattern เอกสารตาราง)

```
.doc-page
├── .doc-content
│   ├── HEADER   โลโก้ + ชื่อบริษัท + ที่อยู่ + เลขผู้เสียภาษี + สำนักงานใหญ่/สาขา
│   │            + หัวเรื่อง "ใบปรับยอดสต๊อก / STOCK ADJUSTMENT"
│   ├── META     เลขที่ ADJ · วันที่เอกสาร · **วันที่มีผล** · ประเภทการปรับ · สถานะ · หน้า x/y
│   ├── PARTIES  ซ้าย = คลัง/สาขาที่ปรับ (รหัสคลัง + ชื่อ + ที่อยู่คลัง)
│   │            ขวา = ผู้จัดทำ (ชื่อ + ตำแหน่ง) + ศูนย์ต้นทุน + จำนวนไฟล์หลักฐานแนบ
│   ├── ITEMS    ตารางรายการปรับยอด (§3) — **มีคอลัมน์เหตุผลเสมอ (บังคับทุกบรรทัด)**
│   └── NOTES + TOTALS   ซ้าย = หมายเหตุ + รายการไฟล์หลักฐาน + จำนวนเงินเป็นตัวอักษร
│                        ขวา = บล็อกยอดรวมมูลค่าที่ปรับ (§4)
└── .doc-bottom
    ├── SIGNATURES  ช่องลายเซ็น 3 ช่อง (§5)
    └── FOOTER      เลขที่ใบ + วันที่พิมพ์ (ค.ศ.) + หน้า + ลายน้ำสถานะ (§7)
```

## 3. ตารางรายการ (ITEMS) — 1 row = 1 บรรทัด (ตารางผอม)

| คอลัมน์ | ที่มา (PREBRIEF §3.2) | จัดชิด | รูปแบบ |
|---|---|---|---|
| ลำดับ | `line_no` | กลาง | เลข |
| **ช่องเก็บ (bin)** | `bin_code` + `<span class="sub">` คลัง / โซน / **ประเภท location** (เช่น `WH-BKK-01 · โซน A · storage`) | ซ้าย | ข้อความ |
| รายการ | `item_name` + `<span class="sub">` รหัสสินค้า | ซ้าย | ข้อความ |
| **ยอดระบบ** | `system_qty_snapshot` | ขวา | `#,##0.00` (ตัดทศนิยมท้ายถ้าเป็นจำนวนเต็ม) |
| **ยอดที่ถูกต้อง** | `correct_qty` | ขวา | `#,##0.00` |
| **ผลต่าง** | `delta_qty` | ขวา | `+#,##0.00` / `−#,##0.00` — **มีเครื่องหมายเสมอ** |
| หน่วย | `uom` | กลาง | ข้อความ |
| ต้นทุนอ้างอิง/หน่วย | `unit_cost_ref` | ขวา | `#,##0.00` |
| **มูลค่าที่ปรับ** | `line_amount` = `delta_qty × unit_cost_ref` | ขวา | `+#,##0.00` / `−#,##0.00` |
| **เหตุผล** | `reason_code` → ชื่อเหตุผล (+ คำอธิบายเพิ่มเป็น `sub` เมื่อเลือก "อื่น ๆ") | ซ้าย | ข้อความ · **ห้ามว่าง** (BR-06) |

**กติกาตาราง**
- หัวตาราง = แถบ navy เข้ม ตัวอักษรขาว · เนื้อตาราง minimal ไม่มีเส้นแนวตั้ง/zebra (R3/R4 ของ skill)
- **ไม่มีคอลัมน์ VAT / ส่วนลด** — การปรับยอดไม่ใช่รายการภาษี/การค้า (PREBRIEF §3.6)
- **ไม่มีคอลัมน์ "ไปที่ / bin ปลายทาง"** — การย้ายของเป็นของ Stock Transfer (BR-05) · ใบนี้มี location เดียวต่อบรรทัด
- บรรทัดที่ bin เป็น **quarantine** หรือ **damage** ให้แสดงประเภทใน `sub` ให้เด่น (เช่น `QA-01 (quarantine)` · `DM-01 (ของเสีย)`) — ผู้อนุมัติต้องเห็นว่าเป็นของกลุ่มพิเศษ
- แถวผลต่าง **+** และ **−** ใช้สีต่างกันได้เล็กน้อย (เขียว/แดงอ่อน) แต่ต้องอ่านออกเมื่อพิมพ์ขาวดำ → **เครื่องหมาย +/− คือตัวหลัก ไม่พึ่งสี**
- เกิน 1 หน้า → ทำซ้ำหัวตารางทุกหน้า + `หน้า x/y` ใน META

## 4. บล็อกยอดรวม (TOTALS)

| บรรทัด | สูตร (PREBRIEF §3.3) | หมายเหตุ |
|---|---|---|
| จำนวนบรรทัดที่ปรับเพิ่ม / ปรับลด | นับตามทิศของผลต่าง | ช่วยตรวจเร็ว |
| มูลค่าปรับเพิ่มรวม | `Σ line_amount` ของบรรทัด + | แสดงเป็นบวก |
| มูลค่าปรับลดรวม | `Σ \|line_amount\|` ของบรรทัด − | แสดงเป็นลบ |
| ★ **มูลค่าที่ปรับรวม (ค่าสัมบูรณ์)** | `Σ \|line_amount\|` | **แถบ navy เข้ม ตัวอักษรขาว — ตัวเลขหลักของใบ** เพราะเป็นฐานสายอนุมัติ (DOA_BRIEF §3) |
| มูลค่าสุทธิ (+/−) | `Σ line_amount` | บรรทัดรอง ใต้ค่าสัมบูรณ์ |
| จำนวนเงินเป็นตัวอักษร | `scripts/baht_text.py <มูลค่าที่ปรับรวม (ค่าสัมบูรณ์)>` | อยู่ฝั่งซ้ายคู่กับหมายเหตุ |

**ข้อความบังคับใต้ TOTALS** (กันเข้าใจผิดเรื่องบัญชี):
> "มูลค่าตามใบนี้คำนวณจากต้นทุนอ้างอิงในทะเบียนสินค้า — รายการบัญชีจริงเกิดเมื่อระบบบัญชีบันทึกรายการ"

> ★ **ห้ามสลับลำดับ**: ค่าสัมบูรณ์ต้องเด่นกว่ายอดสุทธิเสมอ — ใบผสม +/− ที่สุทธิใกล้ศูนย์ต้องไม่ดูเหมือนใบที่ "แทบไม่ได้ปรับอะไร" (gap G-02)

## 5. ช่องลายเซ็น (SIGNATURES) — 3 ช่อง (ล็อกตาม Pattern Q / iron rule #98)

| ช่อง | ใคร | ที่มา |
|---|---|---|
| 1 | **ผู้จัดทำ** | `creator` (คนจริง — ชื่อ + ตำแหน่ง · PREBRIEF §3.1) |
| 2 | **ผู้อนุมัติ** (ตามสาย DOA — คนที่อนุมัติล่าสุด · สายเต็มดูที่ tab ลายเซ็นในระบบ) | `approver_slot[]` (ชื่อ + ตำแหน่ง + วันที่ **ค.ศ.**) — **ห้ามพิมพ์รหัส role** |
| 3 | **ผู้ผ่านรายการ (หัวหน้าคลัง)** | `posted_by` (ชื่อ + ตำแหน่ง + วันที่ผ่านรายการ **ค.ศ.**) — เว้นว่างถ้ายังไม่ post |

> **ไม่มีช่องเซ็นคู่ค้า** (ต่างจาก RTV) — ใบภายในล้วน
> ช่องผู้อนุมัติพิมพ์ชื่อผู้อนุมัติล่าสุดตามสายที่ resolve จริง (สายเต็ม 1–4 ขั้นตาม matrix DOA_BRIEF §3)
> ลายเซ็น + footer อยู่ใน `.doc-bottom` ชิดล่างหน้าเสมอ (R5 ของ skill)

## 7. กติกาพิมพ์

- พิมพ์ได้ตั้งแต่สถานะ **`รออนุมัติ`** ขึ้นไป (มีเลขที่แล้ว) · ก่อน `อนุมัติแล้ว` ต้องมี **ลายน้ำ "ตัวอย่าง"**
- ใบที่ **ยกเลิก** → ลายน้ำ "ยกเลิก" · ใบที่ **กลับรายการแล้ว** → ลายน้ำ "กลับรายการ" + พิมพ์เลขใบกลับรายการใน META — **ห้ามพิมพ์ออกมาเหมือนใบปกติ**
- ทุกวันที่บนใบเป็น **ปี ค.ศ.** — รวมวันที่ในช่องลายเซ็นและ footer
- ตัวเลขเงินทุกช่อง `#,##0.00` + class `num` (ชิดขวา) · **ผลต่างและมูลค่าต้องมีเครื่องหมาย +/− เสมอ**
- เก็บสำเนาผ่าน `ENG-DOC-STORE` เท่านั้น (DOCCFG_BRIEF §3) — ห้าม feature เก็บไฟล์เอง
- **ห้ามพิมพ์คำว่า "ใบนับสต๊อก / นับรอบ / count sheet"** ที่ใดในเอกสาร (BR-24 · scope lock)
