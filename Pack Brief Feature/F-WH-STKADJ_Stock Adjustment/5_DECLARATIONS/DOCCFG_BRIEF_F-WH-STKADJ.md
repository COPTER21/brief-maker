## 4. Dev wiring note (Phase B)

- `adj.number = ENG-DOC-NUM.next('ADJ', company_ctx)` ที่ transition `ร่าง → รออนุมัติ` — **ห้าม format เอง ห้าม +1 เอง**
- เลขที่ออกแล้ว **immutable** — ใบที่ถูกตีกลับยังใช้เลขเดิม (ไม่ออกเลขใหม่แม้แก้บรรทัด/มูลค่าจนสายอนุมัติเปลี่ยน) · ใบที่ยกเลิกเก็บเลขไว้ไม่นำกลับมาใช้ซ้ำ
- ใบกลับรายการเรียก `next('ADJ', ...)` อีกครั้ง — **ไม่ใช่การ renumber ใบเดิม**
- render PDF แล้วเรียก `ENG-DOC-STORE.store(pdf,'ADJ',adj_id,'approved_final')` — engine เช็ค flag เองว่าเก็บหรือไม่
- **ห้ามอ่าน/เขียนตาราง config ตรง** — ผ่าน engine API เท่านั้น
- ปีในเลขรันเป็น **ค.ศ.** ทุกจุด — ทั้งบนหน้าจอ ใน list และใน PDF (GOLDEN §1 · TASTE_LOG)
- ใน HTML Phase A จุดที่ยังต่อ engine ไม่ได้ใช้ marker **`FWD-WIRE: ENG-DOC-NUM`** (ใน .md ใช้ `TODO:` ตามปกติ · _RUNNER_BRIEF §2.11)
- ร่างแสดงข้อความ `(ร่าง — ยังไม่ออกเลขที่)` แทนเลข **ห้ามแสดงเลขคาดเดาล่วงหน้า**
