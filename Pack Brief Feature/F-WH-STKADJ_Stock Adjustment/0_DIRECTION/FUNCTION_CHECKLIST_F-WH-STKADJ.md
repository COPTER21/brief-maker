## สิ่งที่ไม่รองรับ (ตัดสินแล้ว — อย่าเผลอทำ)
- นับสต๊อกรอบ / cycle count / ใบนับ / blind count — [OQ-STK-01] เป็น backlog ไม่อยู่ scope นี้ owner Strike
- เปลี่ยน/ย้าย location ของสินค้า (bin → bin, คลัง → คลัง) — [มติ/CHECKLIST W3Q] เป็นของ F-WH-STKTRF Stock Transfer
- เขียนของเข้า/ออก location ประเภท in-transit — [PREBRIEF_F-WH-PUTAWAY §3.0.2] จองไว้ให้ Stock Transfer เท่านั้น
- ย้ายของจาก quarantine ออกไป storage — [PREBRIEF_F-WH-PUTAWAY §3.0.2] ทางออกของ quarantine คือ RTV
- โพสต์ JE เข้า GL จริง — [แผน W5] รอบนี้ mock + TODO: JE posting
- คำนวณต้นทุนจริง FIFO/Moving Average — [แผน W5] รอบนี้ใช้ต้นทุนอ้างอิงจาก Item Master (mock)
- ตั้งค่าสายอนุมัติ/วงเงินในหน้านี้ — [GOLDEN §3] เป็นของ DOA กลาง F-DLG-001 feature แค่ประกาศ
- ตั้งค่ารูปแบบเลขรันในหน้านี้ — [GOLDEN §3] เป็นของ F-DOCCFG feature แค่ประกาศ
- สร้าง/แก้ Location Master (zone/bin/ความจุ) — [LD-4C-02] เป็น config อ่านอย่างเดียว
- Lot/Batch/Serial และวันหมดอายุ — [มติ] ไม่มี Lot master ในเลนนี้
- นำเข้ารายการปรับยอดจาก CSV/Excel — [มติ] backlog
- ปรับ "ราคา" ต้นทุน (revaluation) โดยไม่ปรับจำนวน — [มติ] คนละ feature อยู่ W5
- ปรับยอดข้ามคลังในใบเดียว — [AI-DRAFT] 1 ใบ = 1 คลัง เพื่อให้ DOA/JE ผูกคลังเดียวชัด
