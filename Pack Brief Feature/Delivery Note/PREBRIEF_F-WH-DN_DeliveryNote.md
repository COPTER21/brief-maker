## 1. สรุป + ผู้ใช้ + สิทธิ์
**ทำอะไร** [มติ] — รับของจากใบแพ็คที่แพ็คเสร็จ → **ยืนยันออกใบส่งของ** (รวมหลายใบแพ็คของลูกค้าเดียวกันได้) → กรอกผู้รับ/ผู้รับผิดชอบ/ขนส่ง/รอบส่ง → **ยืนยันพร้อมส่ง** (ล็อกเป็น read-only) → **ออกรถ = ตัดสต๊อกจริง (Goods Issue)** → อัพเดตสถานะระหว่างทาง → **บันทึกผลส่ง (POD)** พร้อมลายเซ็น/รูป → อัพเดตกลับ SO + คืนสต๊อกส่วนที่ไม่รับ → ส่งต่อวางบิล · แขนง: ส่งไม่สำเร็จ → นัดใหม่/ตีกลับ · ยกเลิก (คืนสต๊อกถ้าตัดแล้ว)

**หน้าจอ** — list 2 แท็บ (รอออกใบส่งของ / ใบส่งของ) · modal ใบแพ็ค · **modal ยืนยันออกใบส่งของ** · **modal ยืนยันออกรถ** · landing 4 แท็บ: ข้อมูลจัดส่ง (stepper + ฟอร์ม/read-only + tracking + attempts + POD + **Document Flow → SO**) / รายการ·กล่อง / ใบส่งของ (พิมพ์) / ประวัติ · modal: POD · ส่งไม่สำเร็จ · ตีกลับทั้งใบ · ยกเลิก · backorder

| Role | ทำอะไรได้ |
|---|---|
| หัวหน้าคลัง (`wh_lead`) | ออกใบส่งของ · แก้ข้อมูลจัดส่ง · ยืนยันพร้อมส่ง · ออกรถ · นัดส่งใหม่ · ตีกลับ · ยกเลิก · POD แทนได้ |
| พนักงานคลัง / คนขับ (`picker`) | ออกรถ (ใบที่รับผิดชอบ) · อัพเดตสถานะขนส่ง · บันทึก POD · บันทึกส่งไม่สำเร็จ |
| Sales / อื่น | ดูอย่างเดียว |

## 5. State Machine
`(คิว) → ร่าง → พร้อมส่ง · รอออกรถ → กำลังจัดส่ง → ส่งสำเร็จ / ส่งบางส่วน` · แขนง: `ส่งไม่สำเร็จ · รอนัดใหม่` ⇄ `พร้อมส่ง` · `ตีกลับทั้งใบ` · `ยกเลิก`
| จาก | ไป | ใครกด | เงื่อนไข |
|---|---|---|---|
| คิว | ร่าง | หัวหน้าคลัง | ยืนยันออกใบส่งของ (confirm) |
| ร่าง | พร้อมส่ง | หัวหน้าคลัง | ครบ BR-04 |
| พร้อมส่ง | ร่าง | หัวหน้าคลัง | แก้ไขข้อมูลส่ง |
| พร้อมส่ง | กำลังจัดส่ง | หัวหน้าคลัง/ผู้รับผิดชอบ | ยืนยันออกรถ → **Goods Issue** (3PL ต้องมี tracking) |
| กำลังจัดส่ง | ส่งสำเร็จ / ส่งบางส่วน | ผู้ส่ง/หัวหน้า | POD (ชื่อผู้รับ) |
| กำลังจัดส่ง | ส่งไม่สำเร็จ | ผู้ส่ง | เหตุผล |
| ส่งไม่สำเร็จ | พร้อมส่ง | หัวหน้าคลัง | นัดส่งใหม่ (≤3) |
| กำลังจัดส่ง/ส่งไม่สำเร็จ | ตีกลับทั้งใบ | หัวหน้าคลัง | เหตุผล → reverse GI + ใบแพ็คกลับคิว |
| ร่าง/พร้อมส่ง/กำลังจัดส่ง | ยกเลิก | หัวหน้าคลัง | เหตุผล (+reverse GI ถ้าตัดแล้ว) |
Stepper 4 ขั้น (UI): ① สร้างใบส่งของ ② พร้อมส่ง·จัดรถ ③ ออกรถ·ตัดสต๊อก ④ ลูกค้าเซ็นรับ (POD) — ยกเลิก/ตีกลับ = ขั้น 4 สถานะแดง
