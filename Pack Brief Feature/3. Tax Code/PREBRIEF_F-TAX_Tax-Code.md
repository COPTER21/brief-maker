## 1. สรุป + ผู้ใช้ + สิทธิ์
ทะเบียนกลางของ "รหัสภาษี" ทั้งระบบ — นิยาม รหัส ชื่อ ประเภท (VAT / หัก ณ ที่จ่าย / ยกเว้น) และอัตรา % ให้เอกสารซื้อ-ขาย, ทะเบียนสินค้า และบัญชีอ้างอิงชุดเดียวกัน หัวใจเชิงบัญชี: **อัตราของรหัสที่ถูกใช้แล้วแก้ไม่ได้ — อยากได้อัตราใหม่ให้สร้างรหัสใหม่แล้วปิดตัวเก่า** [มติ + STD]
สิทธิ์: mock ผู้ใช้ฝ่ายบัญชี (พิมพ์ใจ) จัดการได้ทุกอย่าง — role-gate จริงเป็นเรื่อง FRD/Policy Center [AI-DRAFT]
