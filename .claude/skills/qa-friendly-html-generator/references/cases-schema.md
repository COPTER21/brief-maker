# cases.json — schema

ไฟล์นี้คือ "เนื้อหาแบบทดสอบ" ที่ Claude เขียนเองจาก BRD + FRD + HTML (ไม่ใช่ engine).
เขียนเป็นภาษาผู้ใช้ทั่วไป ตาม **iron-rules.md** อย่างเคร่งครัด.


## กติกาของ steps
- step = อาเรย์ 4 ช่อง: `[do, dataText, expect, regionKey]`
- `do` — สั่งทำทีละขั้น ภาษาคนไม่รู้ระบบ (ดู iron-rules R2)
- `dataText` — ข้อความข้อมูลที่ใช้ในขั้นนั้น เช่น `ชื่อ “จัดทำใบเสนอราคา”` หรือ `"—"` ถ้าไม่มี
  - ถ้าเคสมี `data` set → ช่องนี้จะกลายเป็นปุ่ม **data sample** (เปิด modal). ถ้า `"—"` จะไม่มีปุ่ม
- `expect` — สิ่งที่ผู้ทดสอบควรเห็นบนจอ (เขียนจากสิ่งที่ตาเห็นจริง อ่านจาก HTML)
- `regionKey` — คีย์ภาพหน้าจอ (ต้องตรงกับ key ใน shot-spec.json / shots_b64.json) หรือ `""` ถ้าขั้นนั้นไม่มีภาพ → ปุ่ม 👁 จะเป็นจุดจาง

## priority → ป้าย
`high → สำคัญมาก` · `med → ปานกลาง` · `low → ทั่วไป`

## ฟิลด์เสริม (v2 Pipeline Mode)
- `"sys": true` (optional, ระดับเคส) — เคสที่ "ทดสอบโดยระบบ/AI แล้ว — ข้ามในรอบผู้ใช้"
  (simulate/หลังบ้าน/ข้าม tenant จาก testcases-*.md). template จะแสดงแบบจาง + ป้าย,
  ไม่นับใน progress/รายงานสรุป แต่โชว์ในรายงานรายเคสว่า "ทดสอบโดยระบบ/AI".
  ใช้ตาม iron-rules R14 — ห้ามลบเคสเหล่านี้ทิ้งเงียบ ๆ.
