# Document Type Registry

แต่ละ type = ชุด block + field ที่ต้องมี. เพิ่ม type ใหม่ได้โดยเพิ่มแถวในตารางนี้
แล้วประกอบจาก block เดิม (ไม่ต้องสร้าง CSS ใหม่).

## เอกสารแบบตาราง (Tabular)

| Type | ชื่อไทย / EN | Parties (label) | Meta fields | ราคา? | VAT? | ลายเซ็น |
|---|---|---|---|---|---|---|
| **PR** | ใบขอซื้อ / Purchase Requisition | ผู้ขอซื้อ (แผนก) | เลขที่ PR, วันที่, ความเร่งด่วน, งบประมาณ | optional | ✗ | ผู้ขอ/ผู้ตรวจ/ผู้อนุมัติ |
| **PO** | ใบสั่งซื้อ / Purchase Order | ผู้ขาย + สถานที่ส่งมอบ | เลขที่ PO, วันที่, อ้างอิง PR, เครดิต, กำหนดส่ง | ✓ | ✓ | ผู้จัดทำ/ตรวจ/อนุมัติ |
| **SO** | ใบสั่งขาย / Sales Order | ลูกค้า + สถานที่ส่ง | เลขที่ SO, วันที่, อ้างอิง PO ลูกค้า, เครดิต | ✓ | ✓ | ผู้จัดทำ/ตรวจ/อนุมัติ |
| **QO** | ใบเสนอราคา / Quotation | ลูกค้า (ผู้รับใบเสนอราคา) | เลขที่, วันที่, ยืนราคาถึง, เครดิต | ✓ | ✓ | ผู้เสนอราคา/ผู้มีอำนาจ (2 ช่อง) |
| **INV** | ใบแจ้งหนี้/ใบกำกับภาษี / Tax Invoice | ลูกค้า (เรียกเก็บจาก) | เลขที่, วันที่, อ้างอิง PO/DO, ครบกำหนด | ✓ | ✓ | ผู้รับวางบิล/ผู้ส่งมอบ |
| **RC** | ใบเสร็จรับเงิน / Receipt | ผู้ชำระเงิน | เลขที่, วันที่, อ้างอิง INV, วิธีชำระ | ✓ | ✓ | ผู้รับเงิน |
| **DO** | ใบส่งของ / Delivery Order | ลูกค้า + สถานที่ส่ง | เลขที่, วันที่, อ้างอิง SO, ทะเบียนรถ | ✗ ปริมาณเท่านั้น | ✗ | ผู้ส่งของ/ผู้รับของ |
| **CN** | ใบลดหนี้ / Credit Note | ลูกค้า | เลขที่, วันที่, อ้างอิง INV เดิม, เหตุผล | ✓ | ✓ | ผู้จัดทำ/อนุมัติ |

> Tax Invoice (INV) ต้องมีคำว่า **"ใบกำกับภาษี"** บนหัวเอกสาร + เลขผู้เสียภาษีทั้งสองฝ่าย
> + ระบุสำนักงานใหญ่/สาขา (ข้อกำหนดสรรพากร).

## เอกสารแบบจดหมาย/บันทึก (Letter / Memo)

| Type | ชื่อไทย | โครง | หมายเหตุ |
|---|---|---|---|
| **LT** | หนังสือภายนอก / จดหมายธุรกิจ | HEADER(โลโก้ซ้าย) → ที่+ส่วนราชการ → วันที่กลาง → เรื่อง/เรียน/อ้างถึง/สิ่งที่ส่งมาด้วย → body → ขอแสดงความนับถือ+ลงนาม → เจ้าของเรื่อง | B8 (สารบรรณ) เลขไทย |
| **MEMO** | บันทึกข้อความ (ภายใน) | B8 + title "บันทึกข้อความ" ขวา + ฟิลด์ "ส่วนงาน" | โครงเนื้อหาเดียวกับ LT |
| **CERT** | หนังสือรับรอง / ใบรับรอง | HEADER → ข้อความรับรอง → ออกให้ ณ วันที่ → ลงนาม + ตราประทับ | 1 ช่องลายเซ็น |
| **APPROVAL** | ใบอนุมัติ / บันทึกขออนุมัติ | HEADER → รายละเอียดเรื่องขออนุมัติ → ตาราง(ถ้ามี) → ความเห็น/อนุมัติ → ลงนามหลายชั้น | ผสม table + letter |

## วิธีเลือก
1. user ระบุ type ตรง ๆ → ใช้แถวนั้น
2. user เล่าเนื้อหา → จับว่า "มีรายการสินค้า/ราคา" = ตาราง, "เป็นข้อความเล่า" = จดหมาย
3. type ที่ไม่มีในตาราง → เลือกแถวที่ใกล้สุดเป็นฐาน แล้วปรับ label/field (engine เดียวกัน)
