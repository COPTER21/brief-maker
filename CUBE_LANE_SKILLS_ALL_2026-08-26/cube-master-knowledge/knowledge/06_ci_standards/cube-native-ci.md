# CUBE NATIVE — Corporate Identity

## Quick Reference (TL;DR)

```
Navy (primary surface) :  #0B1D3A
Primary (action)       :  #0B5CFF
Teal (success/accent)  :  #00A88E
Fonts                  :  Inter (EN) + Noto Sans Thai (TH)
```

---

## 🎨 Color Palette

### Primary Brand
| token | hex | usage |
|---|---|---|
| `navy` | `#0B1D3A` | primary dark surface, sidebar, header dark mode |
| `primary` | `#0B5CFF` | call-to-action, primary button, link, focus ring |
| `teal` | `#00A88E` | success state, positive metric, accent highlight |

### Supporting (typical SaaS palette)
| token | hex | usage |
|---|---|---|
| `bg` | `#F8F9FB` | page background (light mode) |
| `surface` | `#FFFFFF` | card/panel surface |
| `border` | `#E5E7EB` | divider, input border |
| `text-strong` | `#0B1D3A` | heading text |
| `text-default` | `#374151` | body text |
| `text-muted` | `#6B7280` | secondary text, helper |
| `danger` | `#DC2626` | error, destructive action |
| `warning` | `#F59E0B` | warning, attention |
| `success` | `#00A88E` | (same as teal) |

---

## 🔤 Typography

### Font stack
```css
font-family: 'Inter', 'Noto Sans Thai', -apple-system, BlinkMacSystemFont, sans-serif;
```

- **Inter**: Latin / Numbers
- **Noto Sans Thai**: Thai text (default mix for both)
- **Fallback**: system stack

### Type scale (suggested)
| level | size | weight | usage |
|---|---|---|---|
| heading-1 | 24px | 700 | page title |
| heading-2 | 20px | 600 | section title |
| heading-3 | 16px | 600 | card title |
| body | 14px | 400 | default body |
| caption | 12px | 400 | helper, label |

---

## 📐 Layout Principles

### Drawer vs Modal
- **Create / Edit** = Drawer slide-in **540px** (NOT modal)
- **Confirmation / Detail view** = Modal centered

### Hash routing
- `#/route` — refresh-safe SPA pattern
- HTML generated by `html-generator-v9` ใช้ pattern นี้

### Component standards
- Form fields stack vertical with 16px spacing
- Buttons aligned right in actions area
- Icons: Lucide icons (consistent set)
- Spacing scale: 4 / 8 / 12 / 16 / 24 / 32 / 48 px
