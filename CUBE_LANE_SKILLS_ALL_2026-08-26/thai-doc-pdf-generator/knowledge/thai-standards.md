# Thai Document Standards — ข้อกำหนดเอกสารไทย

## ตัวเลข & เงิน
- จำนวนเงินทุกช่อง format `#,##0.00` (ทศนิยม 2 ตำแหน่งเสมอ)
- VAT มาตรฐาน = **7%** คำนวณจากยอดหลังหักส่วนลด
- ยอดรวมทั้งสิ้นต้องมี **จำนวนเงินเป็นตัวอักษร** ในวงเล็บ → `scripts/baht_text.py`
- ปัดเศษ VAT/ยอดรวมแบบปัดครึ่งขึ้น (ROUND_HALF_UP)

## ภาษีมูลค่าเพิ่ม (เอกสารกลุ่มขาย)
- "ใบกำกับภาษี" ต้องแสดง:
  - เลขประจำตัวผู้เสียภาษี **ทั้งผู้ขายและผู้ซื้อ** (13 หลัก)
  - ระบุ **(สำนักงานใหญ่)** หรือ **(สาขาที่ ...)** ต่อท้ายเลขภาษี
  - คำว่า "ใบกำกับภาษี" บนหัวเอกสารชัดเจน
  - เลขที่และวันที่ออกใบกำกับภาษี
- หัก ณ ที่จ่าย (WHT) ถ้ามี → เพิ่ม row ใน totals (เช่น "หัก ณ ที่จ่าย 3%")

## วันที่
- ใช้ **พุทธศักราช (พ.ศ.)** เป็นหลัก เช่น "3 มิถุนายน 2569"
- เดือนเขียนเต็มภาษาไทย (มกราคม…ธันวาคม)
- ถ้า user ให้ ค.ศ. → แปลงเป็น พ.ศ. (+543) เว้นแต่สั่งเป็นอย่างอื่น

## เลขที่เอกสาร
- รูปแบบนิยม: `<PREFIX>-<ปีพ.ศ.>-<running>` เช่น `PO-2569-00142`
- ถ้า user ไม่ระบุ → ใช้ placeholder รูปแบบนี้ + หมายเหตุใน print-spec ว่า running มาจากระบบ

## ลายเซ็น (สำคัญ — มาตรฐานไทย)
- เอกสารอนุมัติใช้สายอนุมัติ **ผู้จัดทำ → ผู้ตรวจสอบ → ผู้อนุมัติ** (สอดคล้อง COSO Maker/Checker/Approver)
- ใต้เส้นลายเซ็นมี: `(วงเล็บชื่อ)` → ตำแหน่ง → วันที่
- บางเอกสารต้องมีที่ว่างสำหรับ **ตราประทับบริษัท** (ใบกำกับภาษี/หนังสือรับรอง)

## ที่อยู่บริษัท
- ลำดับ: เลขที่/อาคาร → ถนน → แขวง/ตำบล → เขต/อำเภอ → จังหวัด → รหัสไปรษณีย์
- บริษัทจำกัด นำหน้าด้วย "บริษัท" ลงท้าย "จำกัด" / มหาชน = "จำกัด (มหาชน)"

## สำเนา
- ป้ายมุมขวา: **ต้นฉบับ / สำเนา / สำเนาลูกค้า** (block `.doc-copy`)
- ใบกำกับภาษีมักออก "ต้นฉบับ" (ลูกค้า) + "สำเนา" (เก็บ)

## A4 & การพิมพ์
- ทุกเอกสาร **A4 แนวตั้ง** (210×297mm) — กำหนดใน base.css `@page`
- ขอบกระดาษ 14mm (เผื่อเครื่องพิมพ์/เย็บแฟ้ม)
- พิมพ์ขาวดำได้อ่านง่าย (navy/ink เป็นหลัก ไม่พึ่งสีเพื่อสื่อความหมาย)
