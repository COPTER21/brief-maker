## §4.6 Data Classification & Sensitive Data
- **4 levels ตามมาตรฐาน CUBE 4.0** (Public/Internal/Confidential/Restricted) — feature นี้สูงสุด = **Confidential** (pricing/cost)
- **Default = Internal** — ไม่มี field Public, ไม่มี Restricted, ไม่มี PII (D7 not triggered)
- **Enforcement:** Confidential → API: exclude/mask ตาม role `canSeePricing` · UI: `•••` + tab ราคา empty-state · Export: exclude column · Audit: log view+mutation
- **Policy Center linkage:** pricing fields → Data Classification module (override runtime + audit) · role list ดู 05_RULES §5.3
