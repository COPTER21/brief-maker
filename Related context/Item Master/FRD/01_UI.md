## §1.2 Per-Page Detail

### P-01 ทะเบียนสินค้า (`#/products`)
**Stats (4):** สินค้าทั้งหมด · ใช้งาน · **เลิกผลิต · ยกเลิก** · ร่าง (backlog)
**Filter bar:** search (placeholder `ค้นหารหัส / ชื่อ / GTIN / หมวด / กลุ่ม...`) · select ประเภท · หมวดหมู่ · สถานะ (5 ค่า — ไม่มีรออนุมัติ) · ปุ่ม ghost `ล้างตัวกรอง`
**Table 8 คอลัมน์:** รหัส (mono, sortable) · สินค้า (thumb/initials + ชื่อ, sortable) · รหัสเก่า (sortable) · ประเภท (type-pill, sortable) · หน่วยฐาน (+`+N` conv count) · ราคา/ต้นทุน (num; ไม่มีสิทธิ์ → header `— จำกัด —`, cell `•••`) · สถานะ (pill) · actions
**Row actions (hover, absolute slot):** แก้ไข (draft/active/obsolete) · จัดเก็บ (active) — คลิกแถว = เปิด P-04
**Actions header:** `นำเข้าจำนวนมาก` (secondary) · `เพิ่มสินค้า` (primary)
**Empty 2 เคส (Rule #39):** RAW ว่าง → "ยังไม่มีสินค้าในทะเบียน" + ปุ่ม เพิ่มสินค้า · filter ไม่เจอ → "ไม่พบสินค้าตามเงื่อนไข" + ปุ่ม ล้างตัวกรอง
**Pagination:** page size 10/20/50 + windowing `1 2 … n-1 n n+1 … last`
| Action | API |
|---|---|
| load/filter/sort/page | F-PDM-API-01 |
| คลิกแถว | F-PDM-API-02 (view) |

### P-02 / P-03 Wizard (`create` / `edit/:id`)
**Steps:** 1 ข้อมูลหลัก · 2 หน่วยนับ · 3 ราคา · 4 รูปภาพ & เอกสาร
**Step 1:** รหัส (readonly — create: gen จากประเภท + regen เมื่อเปลี่ยนประเภท; edit: lock IR-01) · ชื่อไทย* · ชื่ออังกฤษ · ประเภท* (เปลี่ยน → behavior defaults + regen code เฉพาะ create) · หมวดหลัก*/ย่อย · กลุ่ม · GTIN · HS Code · รหัสเก่า
**Step 2:** หน่วยฐาน* (lock เมื่อ `has_txn` + `conv-locked-note`) · หน่วยแปลง rows (`1 <uom> = <factor> <base>` + flags ซื้อ/ขาย/เริ่มต้น(เดี่ยว)/เก็บสต็อก + ลบ) · stock preview (`ถ้ามี N <base> ...`) · behavior toggles 3 ตัว
**Step 3:** วิธีคิดต้นทุน · ต้นทุนมาตรฐาน · ราคาซื้อ · ราคาขาย · สกุลเงิน · Posting Group* (เมื่อ stocked) · กลุ่มภาษี · Reorder (จุดสั่งซ้ำ/ปริมาณ/สต็อกปลอดภัย/MOQ) · **Min/Max** (stocked เท่านั้น — ไม่นับสต็อกแสดง info แทน)
**Step 4:** รูปภาพ (gallery + ตั้งปก + ลบ) · เอกสารแนบ (list + ลบ + แนบ)
**Footer contract:** ซ้าย `ย้อนกลับ` (step>1) · ขวา `ยกเลิก` ghost + `บันทึกแบบร่าง` secondary + primary = `ถัดไป` | step 4: **`บันทึกและเปิดใช้งาน`** (create/draft) หรือ **`บันทึก`** (edit ของ active/obsolete) — submitting state (Rule #44: disabled + loader `กำลังบันทึก…`)
**Step gates:** step1 → code required+dup / ชื่อไทย / หมวดหลัก · step2 → uom + VR-04 + VR-03 · step3 → VR-MM
| Action | API |
|---|---|
| บันทึกแบบร่าง | F-PDM-API-03 (create) / API-04 (edit) |
| บันทึกและเปิดใช้งาน | F-PDM-API-03 + API-05 (หรือ create-with-activate) |
| บันทึก (edit non-draft) | F-PDM-API-04 |

### P-04 View (`view/:id`) — 5 แท็บ
**Header:** avatar/thumb + ชื่อ + status pill + subtitle (code · type) + **actions ตามสถานะ** (Rule #31.4) + divider + X
| สถานะ | Header actions (ซ้าย→ขวา) |
|---|---|
| draft | แก้ไข (secondary) · **เปิดใช้งาน** (primary) |
| active | แก้ไข · **เลิกผลิต** (secondary) · จัดเก็บ (danger) |
| obsolete | แก้ไข · **ใช้งานอีกครั้ง** (secondary) · **ยกเลิกถาวร** (danger) |
| discontinued | จัดเก็บ (danger) |
| archived | — (ดูอย่างเดียว) |
**Tabs:** ภาพรวม (ข้อมูลสินค้า 2-pair grid + พฤติกรรม badges + **แจ้งเตือนระดับสต็อก Min/Max** + info Inventory Monitoring) · หน่วยนับ (base + conv table + IR-02 note) · ราคา (Confidential tag — role fail → empty "ข้อมูลจำกัด (Confidential)") · รูปภาพ & เอกสาร · ประวัติ (timeline audit + version)
**Footer:** `version N · สร้าง <วันที่>` + spacer + `ปิด` (secondary)

### P-05 Status modals
| Modal | เนื้อหา | ปุ่มยืนยัน |
|---|---|---|
| เลิกผลิต | warning: ขายสต็อกคงเหลือได้ งดซื้อ/ผลิตเพิ่ม · กลับมาใช้งานได้ | `เลิกผลิต` (primary) |
| ยกเลิกถาวร | warning: ปิดการขาย/ซื้อทุกช่องทาง · ขั้นต่อไป = จัดเก็บ | `ยกเลิกถาวร` (danger) |
| จัดเก็บ | soft delete + `has_txn` → warning "มี transaction อ้างอิง ... archived เท่านั้น (BR-002)" | `จัดเก็บ` (danger) |
> `ใช้งานอีกครั้ง` = direct action (ไม่มี modal — positive, มี validate gate)

### P-06 Bulk import (3 state)
pick (`เลือกไฟล์ CSV / Excel` + คอลัมน์ CSV note) → preview (ตาราง 7 คอลัมน์ + pill ✓ พร้อมนำเข้า / ✗ error ต่อแถว + ปุ่ม `นำเข้า N แถว` disabled เมื่อ N=0) → done (summary + ตารางแถวข้าม + "รายการที่นำเข้าอยู่ในสถานะ ร่าง")

## §1.3 User Journey (Happy Path)

```
Maker เปิด #/products → เพิ่มสินค้า → wizard 4 ขั้น (gen code อัตโนมัติ)
  ↓ step gates: dup code / VR-04 / VR-03 / VR-MM
กด "บันทึกและเปิดใช้งาน" → validateActivation ผ่าน
  ↓ (API-03 create + activate)
toast "บันทึกและเปิดใช้งานแล้ว" → กลับ list → record สถานะ ใช้งาน (audit: สร้างรายการ + เปิดใช้งาน)
```
**Branch — ไม่พร้อม:** validateActivation fail → toast `ข้อมูลไม่พร้อมใช้งาน: <fields> (NOT_READY)` + เด้ง step 3
**Branch — ร่างก่อน:** บันทึกแบบร่าง → draft → เปิดจาก view กด `เปิดใช้งาน` ทีหลัง
**Branch — วงจรชีวิต:** active → เลิกผลิต → (ใช้งานอีกครั้ง | ยกเลิกถาวร → จัดเก็บ)

## §1.6 Routing / Overlay Rules (observed)
- Hash SPA refresh-safe: ทุก drawer/modal (ยกเว้น bulk) express ผ่าน `#/products/<mode>/<id>`
- **Esc chain:** modal → drawer → หน้า list
- Modal เปิดจาก view: ยกเลิก/ยืนยัน → **กลับ view เดิม + คง tab** (`closeModalToCtx`) · เปิดจาก list → กลับ list
- Guard hash ตรง: edit ของ pending/discontinued/archived → เด้ง view · action ผิดสถานะ → toast `INVALID_STATE` + ปิด modal
