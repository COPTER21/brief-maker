## §6.6 Cross-Module Tests (XT-01…XT-07)

| # | คู่ | ทดสอบอะไร | ผ่านเมื่อ |
|---|---|---|---|
| **XT-01** ⭐ | **Leave ✅** | อนุมัติรอบออกงาน (ชุด F) → Leave เรียก `resolve` ด้วย `as_of` ที่หลัง `last_working_day` | Leave ได้ `employment_state = left` และเตือน/บล็อกใบลาที่คร่อม — **ปิด `OQ-L11`** |
| **XT-02** | **Attendance ✅** | อ่านขอบเขตวันที่ของคนในชุด F | ได้ `start_date` และ `last_working_day` · **ไม่มี endpoint ให้ Attendance เขียนกลับ** |
| **XT-03** | **Payroll ⏳ (stub)** | อ่านขอบเขตวันที่ | ได้ค่าครบ · **ไม่มีตัวเลขเงินใน response** |
| **XT-04** | **Welfare ⏳ (stub)** | อ่านสัญญาณ joiner/leaver | ได้สัญญาณพร้อม `link_status` |
| **XT-05** ⭐ | **Roles & Permissions ✅** | ส่ง `ack` 3 แบบ: ครบ · ขาด `ack_ref` · ซ้ำ `request_id` เดิม | ครบ = ปิดรายการ + ยิง SecC · ขาด = **422 ไม่ปิด** · ซ้ำ = **idempotent ไม่ยิงซ้ำ** |
| **XT-06** | **Operation Process ✅** | สร้างรอบ → งานโผล่ใน "งานของฉัน" · ปิดงานที่ OP → สถานะสะท้อนกลับ | เป็นงานใบเดียวกัน · **feature ไม่เขียนสถานะทับ OP** |
| **XT-07** ⭐ | **ENG-CSQ · ENG-NOTIFY** | เดินเคสชุด G จนติดธง overdue | ยิง SecC `revocation_overdue` ซ้ำพร้อม `severity` ที่โต · ยิง NTF ที่ **ปิดไม่ได้** · **ไม่มี event ท่อ OC/DC/SC ออกไปเลย** |
