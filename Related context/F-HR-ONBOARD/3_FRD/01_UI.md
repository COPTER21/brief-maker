### §1.2.7 ลิ้นชักรอบ › แท็บ **ภาพรวม**

คน + ป้ายสถานะ + **ธงเพิกถอนค้าง (ถ้ามี)** · ตำแหน่ง · แผนก · วันสำคัญ · แถบสถานะรอบ · **การ์ด "ขอบเขตวันที่ที่เผยแพร่"** (วันที่ + ปลายทาง + เวอร์ชันค่าที่ใช้ + สัญญาณ joiner/leaver · FN-53 · FN-57) · **สายอนุมัติแบบไทม์ไลน์** (ตำแหน่ง → ชื่อผู้เซ็น → เวลา → สถานะ · จำนวนขั้นเท่าที่ engine คืน) · **กล่องเตือนงานค้างของปลายทาง** (ใบลาคร่อมวันสุดท้าย · วันที่ยังไม่ยืนยัน + ลิงก์อ่านอย่างเดียว · FN-55 · FN-56) · **ผู้ใต้บังคับบัญชาและงานอนุมัติที่ค้าง** (FN-77) · ผลการทบทวนทดลองงาน (FN-14) · ธงสิทธิ์การจ้างกลับ (FN-72) · ปุ่ม **แก้วันสำคัญ** · **ส่งอนุมัติ** / **อนุมัติ** / **ไม่อนุมัติ** ตามสถานะและบทบาท

**ส่วนท้ายลิ้นชัก:** ข้อความ **"รหัสรอบภายในของระบบ — ไม่ใช่เลขที่เอกสารที่ต้องยื่นให้ใคร"** ⭐ (พิสูจน์ LOCK-DOC ด้วยตา)

### §1.2.8 ลิ้นชักรอบ › แท็บ **งานในชุด**

ตารางงาน (งาน · กลุ่ม · ผู้รับผิดชอบ · กำหนดเสร็จ · ความจำเป็น · สถานะ · **งานจริงในกระบวนการทำงาน** · หลักฐาน) · ปุ่ม **เพิ่มงานเฉพาะรอบนี้** (บังคับเหตุผล) · เปิดงานได้ที่ modal งาน (ปิดงาน · แนบหลักฐาน · ระบุผู้รับมอบ) · **ปุ่มเปิดงานตัวจริงใน "งานของฉัน"** ต่อแถว (FN-61) · **ส่วนงานส่งมอบความเป็นเจ้าของข้อมูล 5 รายการ** พร้อมช่องผู้รับมอบและปุ่ม **ขอสิทธิ์ชั่วคราวให้ผู้รับมอบ** (FN-75 · FN-76)

**modal ส่งอนุมัติ** อยู่ที่แท็บนี้และแท็บภาพรวม — แสดง **ช่องผู้เซ็นเท่าจำนวนที่ engine คืน** แต่ละช่องเป็น combobox คน (FN-24) · ปุ่มยืนยันปิดจนกว่าจะเลือกครบ (ข้อความ: **"เลือกผู้อนุมัติให้ครบทุกขั้นก่อน"**)

### §1.2.9 ลิ้นชักรอบ › แท็บ **สิทธิ์และบัญชี** ⭐ (แท็บที่สำคัญที่สุด)

| ส่วน | เนื้อหา |
|---|---|
| แถบสรุป | **ความคืบหน้า x/y รายการ** · **กำหนดมีผล** (`revocation_due_at`) · ปุ่มหลักตามชนิดรอบ |
| ปุ่ม (เข้างาน) | **ส่งคำขอเปิดสิทธิ์** (แสดงรายการให้ยืนยันก่อนส่ง) |
| ปุ่ม (ออกงาน) | **เพิกถอนสิทธิ์ทั้งหมด** (เปิดเฉพาะรอบที่อนุมัติแล้ว · กันกดซ้ำ) · **เพิ่มรายการสิทธิ์ที่พบภายหลัง** (บังคับเหตุผล) |
| ตารางทะเบียนสิทธิ์ | **7 คอลัมน์** — ชนิด · รายการ · **ที่มา** · สถานะการเปิด · **สถานะการเพิกถอน** · **ผลตอบกลับจากต้นทาง** (ผู้ทำ · เวลา · รหัสอ้างอิง) · การดำเนินการ (**มีแค่ "ส่งซ้ำ" หรือป้ายสถานะ**) |
| ส่วนชนิดสิทธิ์ | นับรายชนิดครบ 8 ชนิด (บัญชีผู้ใช้ · SSO · บทบาทในระบบ · ปัจจัยยืนยันตัวตน · โทเคน/กุญแจ API · VPN/ใบรับรอง · เมล/แชท/ประชุม · กล่อง/กลุ่ม/ไดรฟ์ร่วม · บัตร/กุญแจ/ที่จอด) |
| ⭐ กล่องเหตุการณ์ความปลอดภัย | ปรากฏเมื่อติดธง overdue — **ระดับความรุนแรง** · ชั่วโมงที่เลยกำหนด · รายการที่ค้าง · ผู้รับที่ถูกยกระดับ · **ข้อความว่าผู้รับปิดการแจ้งนี้ไม่ได้** (FN-36) |
| ส่วนคำขอคืนสิทธิ์ | ปรากฏเมื่อยกเลิกหลังเพิกถอน — **เคยเพิกถอนเมื่อ + การอ้างอิงการเพิกถอนเดิม** (FN-51) |
| `.tip` ⓘ | **"ปิดรายการได้ด้วยผลตอบกลับจากต้นทางเท่านั้น"** + **"ไม่มีชั้นอนุมัติคั่นก่อนการเพิกถอน"** |
| **ไม่มีเด็ดขาด** ⭐ | ❌ ช่องติ๊ก ❌ ปุ่มปิดรายการ ❌ ตัวเลือกผู้อนุมัติ ❌ ปุ่มเลื่อนเวลาเพิกถอน (FN-39 · AR-2 · AR-3 · AR-7) |

### §1.2.10 ลิ้นชักรอบ › แท็บ **ทรัพย์สิน** · แท็บ **ประวัติ**

- **ทรัพย์สิน** — ตาราง (รายการ · จำนวน · สถานะ · วันที่ · ผู้ส่งมอบ/ผู้รับคืน · **ทะเบียนกลาง** พร้อมป้าย "ยังไม่เชื่อม") · ปุ่มเพิ่มรายการ · บันทึกส่งมอบ/คืน/**คืนไม่ได้ + เหตุผล** · กล่องเตือนว่าค้างแล้วปิดรอบไม่ได้ **แต่ไม่บล็อกการเพิกถอน** (FN-43)
- **ประวัติ** — รายการ append-only (เวลา · ผู้กระทำ · การกระทำ · ค่าก่อน→หลัง · เหตุผล) + ส่วน **"สิ่งที่ทำกับประวัตินี้ไม่ได้"** 3 แถว (ลบถาวร · แก้ประวัติ · ลบข้อมูลบุคคล) (FN-68 · FN-82)

### §1.2.11 modal ทั้ง 14 ตัว (440px)

| id | ชื่อ | บังคับอะไร |

| `dates` | แก้วันสำคัญ | ไม่ตกในงวดที่ปิด |

| `addasset` | เพิ่มรายการทรัพย์สิน | **ชื่อรายการ** |

## §1.3 Microcopy ที่ต้องตรงกับหน้าจอ (ส่งต่อ `06_TESTS §6.7`)

| จุด | ข้อความ (verbatim) |
|---|---|
| ค่าที่ต้นทางยังไม่เผยแพร่ | **`ยังไม่มีค่าให้อ่าน`** |
| ฟอร์มยังกรอกไม่ครบ | **`ยังกรอกไม่ครบ — ดูช่องที่ขึ้นสีแดง`** |
| ยกเลิก/ปิดงานโดยไม่ใส่เหตุผล | **`ต้องกรอกเหตุผลก่อน`** |
| ส่งอนุมัติโดยเลือกผู้เซ็นไม่ครบ | **`เลือกผู้อนุมัติให้ครบทุกขั้นก่อน`** |
| ขอสิทธิ์ชั่วคราวโดยไม่เลือกผู้รับมอบ | **`เลือกผู้รับมอบข้อมูลก่อน`** |
| ส่งซ้ำรายการสิทธิ์ | **`ส่งคำขอซ้ำแล้ว ครั้งที่ `** + เลขครั้ง |
| ผลตอบกลับกลับมา | **`ได้รับผลตอบกลับจาก สิทธิ์ผู้ใช้งาน `** + รายละเอียด |
| บันทึกผลทบทวนทดลองงาน | **`บันทึกผลการทบทวนทดลองงานแล้ว`** |
| ล้างตัวกรอง | **`ล้างตัวกรองแล้ว`** |
| ปุ่มไปยังระบบสรรหา | **`การสรรหาและคัดเลือกผู้สมัครเป็นของ feature สรรหา ซึ่งยังไม่มีในระบบ — ที่นี่กรอกรหัสผู้สมัครเองได้`** |
| ปุ่มไปยังทะเบียนทรัพย์สิน | **`ทะเบียนทรัพย์สินกลางยังไม่มีในระบบ — ที่นี่เก็บรายการระดับรอบและช่องอ้างอิงไว้ก่อน`** |
| ปุ่มไปยังสวัสดิการ | **`สวัสดิการยังไม่มีในระบบ — สัญญาณเริ่ม/สิ้นสุดสิทธิ์รอปลายทางมาอ่าน`** |
| ปุ่มไปยังคำสั่งเปลี่ยนแปลงพนักงาน | **`เปิด คำสั่งเปลี่ยนแปลงพนักงาน (แท็บใหม่) — คำสั่งที่มีเลขที่เอกสารออกที่นั่น ไม่ออกที่นี่`** |
| ปุ่มไปยังหนังสือรับรอง | **`เปิด หนังสือรับรอง (แท็บใหม่) — หนังสือรับรองการทำงานออกที่นั่น ไม่ออกที่นี่`** |
| ปุ่มไปยังสายอนุมัติ | **`เปิด สายอนุมัติ (แท็บใหม่) — สายอนุมัติและการมอบฉันทะตั้งที่นั่น ที่นี่ใช้สายที่ได้มาเท่านั้น`** |
| ส่วนท้ายลิ้นชักรอบ | **`รหัสรอบภายในของระบบ — ไม่ใช่เลขที่เอกสารที่ต้องยื่นให้ใคร`** |
| ป้ายสถานะรอบ | `ร่าง` · `รอวันเริ่มงาน` · `กำลังดำเนินการ` · `รออนุมัติ` · `ไม่อนุมัติ` · `อนุมัติแล้ว` · `กำลังเพิกถอน` · `เพิกถอนแล้ว` · `ปิดรอบแล้ว` · `ยกเลิก` |
| ธงความปลอดภัย | **`เพิกถอนค้าง`** · `ออกทันที` |

> ⚠️ **หมายเหตุสำหรับ QA:** ป้าย **`กำลังเพิกถอน`** เป็นสถานะที่หน้าจอแสดงระหว่าง "อนุมัติแล้ว" กับ "เพิกถอนแล้ว" (ตอนที่คำขอออกไปแล้วแต่ผลตอบกลับยังไม่ครบ) — **ไม่ใช่ state ใหม่ในโมเดล** แต่เป็น **มุมมองของ `approved` + มีรายการที่ `revoke_state = requested`** · บันทึกไว้ที่ `05_RULES §5.2.3` และที่ Drift Log ของ `UI_BRIEF`
