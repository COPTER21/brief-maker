## §5.2 State Machine

### §5.2.1 รอบเข้างาน (T-1…T-6)

| # | จาก → ไป | ใครกด | เงื่อนไข | ผลข้างเคียง |
|---|---|---|---|---|
| T-1 | ร่าง → รอวันเริ่มงาน | HR | คน + วันเริ่มงาน + แม่แบบครบ · **SOW สร้างสำเร็จ** | ยิง `onb_case_started` |
| T-2 | รอวันเริ่มงาน → กำลังดำเนินการ | **ระบบ** | `today ≥ start_date` | **เผยแพร่ `start_date`** + สัญญาณ joiner |
| T-3 | กำลังดำเนินการ → ปิดรอบแล้ว | HR | `closeBlockers` ว่าง (งานบังคับครบ + `grant_state=granted` ครบ) | — |
| T-4 · T-5 · T-6 | (ทุกสถานะก่อนปิด) → ยกเลิก | HR (**เหตุผลบังคับ**) | — | ปิดงานค้าง · **ถ้าเปิดสิทธิ์แล้ว → คำขอปิดทันที + SecC** · ถอน `start_date` ที่เผยแพร่ |

### §5.2.2 รอบออกงาน (T-7…T-16)

| # | จาก → ไป | ใครกด | เงื่อนไข | ผลข้างเคียง |
|---|---|---|---|---|
| T-7 | ร่าง → รออนุมัติ | HR / หัวหน้า | ครบ VR-04…VR-06 · ไม่ชนงวดปิด · **resolve + freeze** | `doa_pending` (engine ยิงเอง) |
| T-8 | รออนุมัติ → อนุมัติแล้ว | ผู้ถือ slot ครบทุกขั้น | SoD ผ่าน · **ตรวจงวดปิดซ้ำ** | **เผยแพร่ `last_working_day`** · สัญญาณ leaver · **ตั้ง `revocation_due_at`** · checklist ปิดสิทธิ์เดินได้ · ยิง `ofb_case_approved` · **ถ้า `is_immediate_exit` → ส่งคำขอเพิกถอนทันที** |
| T-9 | รออนุมัติ → ไม่อนุมัติ | ผู้ถือ slot | **บังคับ `reject_reason`** | **ไม่มีสิทธิ์ใดถูกแตะ** |
| T-10 | ไม่อนุมัติ → ร่าง | HR | แก้แล้วส่งใหม่ | **re-resolve สายใหม่ทั้งสาย** |
| **T-11** ⭐ | อนุมัติแล้ว → เพิกถอนสิทธิ์แล้ว | **ระบบ** (จากผลตอบกลับ) | **ทุกแถว `revoke_state = revoked` พร้อม `ack_*` ครบ** | SecC ต่อรายการ + สรุป `is_final` · ยิง `ofb_access_revoked` |
| T-12 | เพิกถอนสิทธิ์แล้ว → ปิดรอบแล้ว | HR | `closeBlockers` ว่าง | บันทึกธงจ้างกลับ |
| T-13 | อนุมัติแล้ว → ยกเลิก | HR (**เหตุผล + A-3 สายเดิม**) | — | ปิดงานค้าง · **ถอน `last_working_day` ที่เผยแพร่** |
| **T-14** ⭐ | เพิกถอนสิทธิ์แล้ว → ยกเลิก | HR (**เหตุผล + A-3 สายเดิม**) | — | **คำขอคืนสิทธิ์ใหม่ทุกแถว + `reversal_of`** · ประวัติเดิมคงอยู่ · SecC `access_restored` |
| T-15 · T-16 | ร่าง/รออนุมัติ → ยกเลิก | HR (**เหตุผลบังคับ**) | — | งานอนุมัติที่ค้างถูกปิด |

### §5.2.3 ธงและสถานะที่แสดงผล (ไม่ใช่ state ในโมเดล) ⭐

| ป้ายบนจอ | ความจริงในโมเดล | หมายเหตุ |
|---|---|---|
| **`กำลังเพิกถอน`** | `case_status = approved` **และ** มีแถวที่ `revoke_state = requested` | **สถานะเชิงการแสดงผล** — ทำให้ผู้ใช้เห็นว่าคำขอออกไปแล้วแต่ยังไม่ครบ · **QA ต้องไม่นับเป็น state ที่ 8** (`01_UI §1.3`) |
| **`เพิกถอนค้าง`** | `revocation_flag = 'overdue'` | ธงที่อยู่ร่วมกับ `approved` ได้ · **คอลัมน์แยกจากสถานะรอบ** (LD-05) |
| **`ออกทันที`** | `is_immediate_exit = true` | ธงที่ทั้งเลือกสายอนุมัติและย่นเวลาเพิกถอน |
| **`ยังไม่เชื่อม`** | `linkage_status.<x> = 'not_linked'` | Module Linkage |

## §5.4 Edge Cases

### §5.4.1 จากต้นทาง (☑ ยืนยันแล้ว 18 ข้อ)

| # | สถานการณ์ | ระบบทำอะไร | ทดสอบ |
|---|---|---|---|

| EC-02 | ผู้สมัครไม่มาเริ่มงานหลังเปิดบัญชีแล้ว | คำขอปิดบัญชีทันที + ปิดงานค้าง + SecC `access_revoked_on_cancel` | AT-90 |
| EC-03 | เลื่อนวันเริ่มงานหลังงานบางใบเสร็จแล้ว | คำนวณใหม่เฉพาะงานที่ยังไม่เสร็จ | AT-91 |
| EC-04 | วันสุดท้ายตกในงวดที่ปิด | บล็อก + วันที่เร็วสุด + **ตรวจซ้ำตอนอนุมัติ** | AT-92 |

| EC-06 | ผู้ที่จะออกเป็นหัวหน้าของผู้ถือ slot | engine เลื่อนขึ้นชั้นเหนือ (OQ-DOA-02) | AT-94 |
