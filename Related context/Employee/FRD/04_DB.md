**Constraints:**
- PRIMARY KEY (id)
- UNIQUE (tenant_id, code)
- UNIQUE (tenant_id, national_id) WHERE national_id IS NOT NULL AND deleted_at IS NULL (E08)
- CHECK (status IN ('onboarding','probation','active','leave','suspended','resigned','terminated'))
- CHECK (supervisor_id <> id) (R12)
- FK branch_id/division_id/dept_id/position_id → org masters; supervisor_id → T_employee
- FK approver_role/approved_by → Pre-DOA (nullable until DOA wire)

**Indexes:**
- IDX_emp_tenant_status ON (tenant_id, status)
- IDX_emp_tenant_dept ON (tenant_id, dept_id)
- IDX_emp_tenant_branch ON (tenant_id, branch_id)
- IDX_emp_code ON (tenant_id, code)
- IDX_emp_search ON (tenant_id, first_th, last_th, nickname)
- IDX_emp_created_at ON (created_at DESC)

CREATE POLICY tenant_isolation ON T_employee

## §4.6 Data Classification & Sensitive Data ⭐ (v5.1)

### §4.6.1 Classification Levels
| Level | นิยาม | ในฟีเจอร์นี้ | UI | Export |
|---|---|---|---|---|
| Public | เผยแพร่ภายนอกได้ | portfolio.url (ตามเจ้าของ) | แสดงปกติ | ทุก role |
| Internal | คนในบริษัท (default) | code, status, org refs, audit, lifecycle ส่วนใหญ่ | แสดงปกติ (authenticated) | internal roles |
| Confidential | จำกัด role | birth_date, religion, addr, dependents, emergency, photo, phone, personal_email | mask `***` ถ้า role ไม่ผ่าน | excluded ถ้า role ไม่ผ่าน |
| Restricted | จำกัดถึง person (ACL) | national_id, sso_no, tax_id, bank_account, bank_name, grade, salary | hidden + audit access | excluded + require Restricted Resources approval |

### §4.6.2 Default Rule
- Default = **Internal** (ไม่มี default Public) — ทุก column ระบุชัดใน §4.2

### §4.6.3 Enforcement Mapping
| Classification | DB | API | UI | Audit |
|---|---|---|---|---|
| Public | — | — | — | — |
| Internal | RLS (tenant) | JWT auth | — | mutation only |
| Confidential | RLS | mask if no permission (ENG pii-masking) | `***` | mutation + role check |
| Restricted | RLS + (optional column encryption) | excluded if not ACL | hidden | **every access logged** |

### §4.6.4 Masking Rules
- national_id → `X-XXXX-XXXXX-XX-X` แสดง 4 ท้าย; bank_account → แสดง 4 ท้าย; sso/tax → masked เต็มยกเว้น HR Manager+
- ดู 03_LOGIC ENG `pii-masking-engine`

### §4.6.5 Audit on Access (Restricted)
- ทุกการอ่าน Restricted field (เช่น เปิด salary/bank) → audit log (who/when/field/employee)

### §4.6.6 Policy Center Linkage
