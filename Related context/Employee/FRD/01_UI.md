## §1.3 P-01 Employee List

**Layout:** `list-view` (A)

**Components:**
- Page Header: h1 "พนักงาน" + subtitle "ทะเบียนประวัติพนักงานทั้งหมด" + ปุ่ม `+ เพิ่มพนักงานใหม่` (→ P-03), `นำเข้า CSV` (→ P-06), `ส่งออก CSV` (→ API-09)
- Filter bar (1 row): search (รหัส/ชื่อ/ชื่อเล่น) + dropdown สายงาน (division) + dropdown สถานะ + ปุ่ม Reset + ตัวนับผลลัพธ์
- Table (≤ 8 cols, single-line rows): **รหัส** (mono, 4-digit, FIRST col) · พนักงาน (avatar+ชื่อ+ชื่อเล่น) · ตำแหน่ง (+tier) · สังกัด (แผนก) · สาขา · บัญชีผู้ใช้ (badge linked/none) · สถานะ (tone badge) · actions (ดู/แก้ไข/ลบ)
- Table footer: ตัวนับรวม

**Actions → API:**
- หน้าโหลด/filter/search → `F-EMP-API-01`
- คลิกแถว/ดู → P-02 (`F-EMP-API-02`)
- แก้ไข → P-04 · ลบ → P-05 · เพิ่ม → P-03 · นำเข้า → P-06 · ส่งออก → `F-EMP-API-09`

## §1.4 P-02 Employee Profile (tabbed HRIS)

**Layout:** `view-tabbed-profile` (international HRIS standard — BambooHR/Workday/SuccessFactors)

**Components:**
- Hero: avatar/รูป + ชื่อ-สกุล + รหัส + สถานะ badge + tier + ประเภทการจ้าง
- Quick-facts strip (6): ตำแหน่ง / สังกัด / สาขา / เริ่มงาน / อายุงาน / บัญชีผู้ใช้
- 7 horizontal tabs (underline active, 1 active):
  1. **ภาพรวม** (default) — สรุป + การจ้าง + หมายเหตุ (card)
  2. **ส่วนตัว** — ข้อมูลส่วนบุคคล + ที่อยู่ 2 ชุด + ติดต่อ (sensitive masked ตาม role)
  3. **งาน & การจ้าง** — สังกัด + lifecycle cards (สรรหา/onboarding/ทดลองงาน/พ้นสภาพ) + contract_end
  4. **การศึกษา & ประสบการณ์** — repeatable lists
  5. **ครอบครัว & ฉุกเฉิน** — dependents + emergency
  6. **เอกสาร & Portfolio** — documents + portfolio links
  7. **บัญชีผู้ใช้** — linked user info (read-only, จาก F-IAM-01)
- Top actions: `แก้ไข` (→ P-04), `ลบ` (→ P-05)

**Actions → API:** หน้าโหลด → `F-EMP-API-02`; แท็บบัญชี → `F-EMP-API-11`; sensitive fields ผ่าน masking (ดู 03_LOGIC ENG masking)

## §1.5 P-03 / P-04 Create & Edit (full-page form) ⭐

**Layout:** `full-page-form` (NON-STANDARD — BRD §14.6 / 07_LOCKED LD-01)

**Components:**
- Back-link + form-head (โหมด สร้าง/แก้ไข)
- 6 form tabs (`.profile-tabs`):
  1. **personal** — prefix/ชื่อ-สกุล(ไทย/อังกฤษ)/ชื่อเล่น/เพศ/วันเกิด/เลขบัตร/สัญชาติ/ศาสนา/สมรส/กรุ๊ปเลือด/ทหาร/ส่วนสูง-น้ำหนัก + รูป(upload) + ติดต่อ
  2. **address** — ที่อยู่ปัจจุบัน + ทะเบียนบ้าน (combobox cascade) + toggle same_addr
  3. **eduexp** — การศึกษา (repeatable) + ประสบการณ์ (repeatable)
  4. **family** — dependents (repeatable) + emergency
  5. **employ** — 4 numbered lifecycle cards (1 สรรหา / 2 onboarding / 3 ทดลองงาน / 4 พ้นสภาพ) + การจ้าง + สังกัด (position→auto division/dept) + supervisor + grade/sso/tax/bank
  6. **docs** — เอกสารแนบ (upload) + portfolio links
- Sticky action bar: `ยกเลิก` / `บันทึกข้อมูลพนักงาน`

**Address cascade behavior:** จังหวัด→เปิดอำเภอ→เปิดตำบล→zip auto-fill+disabled (ดู 03_LOGIC ENG address-cascade-resolver)

**Actions → API:** บันทึก(สร้าง) → `F-EMP-API-03`; บันทึก(แก้ไข) → `F-EMP-API-04`; cascade lookup → `F-EMP-API-10`

## §1.6 P-05 Delete Confirm / P-06 Import CSV

**P-05 `modal-confirmation`:** ยืนยันลบ; ถ้ามี linked user → แสดง block message (ห้ามลบ) → `F-EMP-API-11` ตรวจก่อน, `F-EMP-API-05` เมื่อยืนยัน
**P-06 `modal`:** อัปโหลด CSV → preview ผ่าน/ไม่ผ่าน รายแถว → เลือก merge/replace → apply (`F-EMP-API-08`)
