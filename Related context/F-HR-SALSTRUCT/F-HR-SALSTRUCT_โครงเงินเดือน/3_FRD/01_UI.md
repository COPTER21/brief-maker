### P-06 · เทียบเวอร์ชัน (drawer read-only)
ตารางต่อระดับ: ค่าเดิม → ค่าใหม่ → ส่วนต่าง → % · ระดับที่ไม่เปลี่ยนแสดงส่วนต่าง 0 (ไม่ซ่อน) · hint `ไม่แตะอัตราของพนักงาน` · **ไม่มีปุ่มแก้ใน drawer นี้**

## §1.3 User Journey (Happy Path)

**A · ประกาศกระบอกเวอร์ชันใหม่:** P-01 → ปุ่มสร้างเวอร์ชันใหม่ → ขั้น 1 ข้อมูลระดับ → ขั้น 2 กระบอก + วันมีผล + เหตุผล (ระบบตรวจ BR-01/03/04/23 สด) → ขั้น 3 ตรวจสอบและยืนยัน (เห็นตารางเทียบ + "สถานะหลังบันทึก: รอมีผล") → ยืนยัน → แถวขึ้น `รอมีผล` → (ระบบ) ถึงวันมีผล → `ใช้งาน` · เวอร์ชันเดิม `ถูกแทนที่`

**B · ผูกอัตราพนักงาน:** P-03 → `ผูกอัตราพนักงาน` → ขั้น 1 เลือกคน (ระบบเสนอระดับ) → ขั้น 2 กรอกอัตรา (เห็น compa-ratio ทันที · เตือนนอกกระบอก/ต่ำกว่ากฎหมายถ้าเข้าเงื่อนไข) → ขั้น 3 ยืนยัน → เรคคอร์ดใหม่ `รอมีผล`/`ปัจจุบัน` · เรคคอร์ดเดิมเป็น `ประวัติ`
