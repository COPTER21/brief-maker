## §1.3 Components (จาก catalog + custom)
- `switch` toggle (on/off) · `cfg-input` (number/text/select) · **payment types checklist** (.pt-item + checkbox + name + desc) · **Flow Preview** (chip PR→CP→PO เปลี่ยนตาม toggle, ข้าม=เส้นประจาง) · `num-preview` (เลขสด เช่น PR-2569-0232) · boundary ref card (pill ชี้โมดูล) · locked rules card · header: ปุ่ม บันทึก/คืนค่า (dirty-gated) + badge สถานะ
- hint = hover tooltip (Iron #33, ไม่มี overflow clip) · `.cfg-note` (สำหรับ payment-term source + UNLK note)

## §1.4 User Journey (UI)
1. Admin เปิด `#/` แท็บ ตั้งค่าทั่วไป → ปรับ toggle/ค่า → **Flow Preview อัปเดตสด**
2. กลุ่ม Payment Types: checklist ดึงจาก Payment Term → เลือกเปิดใช้ + ตั้ง default/%/งวด/วัน
3. แท็บ เลขที่เอกสาร → ตั้ง prefix/หลัก/รีเซ็ต/next ต่อชนิด → ดูตัวอย่างสด
4. กด บันทึก → toast + badge "บันทึกแล้ว" + audit (ค่ามีผล forward-only)

## §1.6 States
- **Dirty:** มีการแก้ → badge "ยังไม่บันทึก" + เปิดปุ่มบันทึก/คืนค่า
- **Disabled cascade:** ปิด enable_comparison → ลูก (required/min/threshold/award) disabled · payment type ปิด → param (%/งวด/วัน) ของ type นั้น disabled
- **Validation error:** prefix ว่าง/digits 0/ปิดทุก payment type → block save + inline error
