## §4.6 Data Classification & Sensitive Data (v5.1)

### §4.6.1 Classification Levels
| Level | นิยาม | ตัวอย่างใน F-PR | UI | Export |
|---|---|---|---|---|
| Public | เผยแพร่ภายนอก | — | ปกติ | ทุก role |
| Internal | คนในบริษัท (default) | status, dates, branch, dept | ปกติ | internal roles |
| Confidential | จำกัด role | requester, release_ref, vendor | mask `***` ถ้าไม่ผ่าน | excluded ถ้าไม่ผ่าน |
| Restricted | จำกัดถึง person (ACL) | unit_price, subtotal, vat_total, grand_total, line_amount | hidden + audit access | require Restricted Resources approval |

### §4.6.2 Default Rule
- Default = **Internal** (ห้าม default Public)
- Field ราคา/ยอด → Restricted (purchase price = ข้อมูลอ่อนไหวเชิงพาณิชย์)

### §4.6.3 Enforcement Mapping
| Classification | DB | API | UI | Audit |
|---|---|---|---|---|
| Internal | RLS (tenant) | JWT auth | — | mutation |
| Confidential | RLS + column ACL | role check | mask if no perm | view + mutation |
| Restricted | RLS + row ACL | role + ACL | hide if no perm | view + mutation + export |

### §4.6.4 PII Overlay
- `requester` / `requester_id` → Confidential + **PII** (PDPA scope)
- `unit_price`/amounts → Restricted + **ไม่ PII** (ข้อมูลพาณิชย์ ไม่ใช่ personal data)

### §4.6.5 Security Bible Domain Mapping
- **D5 (Financial):** amount fields → audit log mandatory; Restricted
- **D7 (PII):** requester → PDPA scope (mask/log)
- **D9 (Audit):** ทุก mutation → T_audit_log diff

### §4.6.6 Linkage with Policy Center
- Classification → Data Classification module (Policy Center, override runtime + audit)
- Restricted fields (ราคา/ยอด) → Restricted Resources registry (ACL per-record) — **OQ-05**
- PII (requester) → PDPA consent scope
