## §4.2 Per-Table Schema

> **⭐ Data Classification (v5.1):** ทุก field มี `Classification` (Public/Internal/Confidential/Restricted) · default = Internal

### T_comparison

**Purpose:** Header ของใบเปรียบเทียบราคา 1 ใบ

| Column | Type | Null | Default | Classification | PII | Description |
|---|---|---|---|---|---|---|
| `id` | uuid | NO | gen_random_uuid() | Internal | — | PK |
| `tenant_id` | uuid | NO | — | Internal | — | FK → T_tenant; RLS |
| `cp_no` | varchar(20) | NO | — | Internal | — | เลขที่ CP — `CP-YYMM-NNNNN` |
| `cp_date` | date | NO | — | Internal | — | วันที่เอกสาร |
| `buyer` | varchar(120) | NO | — | Internal | Yes | ชื่อผู้จัดทำ (employee) |
| `buyer_id` | uuid | YES | — | Internal | — | FK → T_employee |
| `status` | varchar(16) | NO | 'draft' | Internal | — | enum: draft/pending/approved/awarded/cancelled |
| `winner_total` | numeric(15,2) | NO | 0 | **Confidential** | — | Σ ราคาผู้ชนะ (ก่อน VAT) — computed ENG winner-selection |
| `vat_amount` | numeric(15,2) | NO | 0 | **Confidential** | — | VAT 7% (เอกสาร) |
| `grand_total` | numeric(15,2) | NO | 0 | **Confidential** | — | winner_total + vat |
| `item_count` | integer | NO | 0 | Internal | — | จำนวน line |
| `vendor_count` | integer | NO | 0 | Internal | — | จำนวนผู้ขายที่เทียบ |
| `po_count` | integer | NO | 0 | Internal | — | จำนวน PO ที่ต้องแยก |
| `reject_reason` | varchar(300) | YES | — | Internal | — | เหตุผลตีกลับ |
| `submitted_at` | timestamp | YES | — | Internal | — | set on submit |
| `approved_at` | timestamp | YES | — | Internal | — | set on approve |
| `approved_by` | uuid | YES | — | Internal | — | FK → T_user (approver) |
| `awarded_at` | timestamp | YES | — | Internal | — | set on award |
| `created_at` | timestamp | NO | NOW() | Internal | — | audit |
| `updated_at` | timestamp | NO | NOW() | Internal | — | audit + optimistic lock |
| `created_by` | uuid | NO | — | Internal | — | FK → T_user |
| `version` | integer | NO | 1 | Internal | — | optimistic locking (PR-2) |

**Constraints:**
- PRIMARY KEY (id)
- UNIQUE (tenant_id, cp_no)
- CHECK (status IN ('draft','pending','approved','awarded','cancelled'))
- CHECK (winner_total >= 0 AND grand_total >= 0)

**Indexes:**
- IDX_cp_tenant_status ON (tenant_id, status)
- IDX_cp_date ON (tenant_id, cp_date DESC)
- IDX_cp_buyer ON (tenant_id, buyer_id)

**RLS:** `USING (tenant_id = current_setting('app.current_tenant')::uuid)`

## §4.6 Data Classification & Sensitive Data ⭐ (v5.1)

### §4.6.1 Classification Levels (CUBE 4.0 Standard)

| Level | นิยาม | ตัวอย่างใน feature นี้ | UI Behavior | Export |
|---|---|---|---|---|
| Public | เผยแพร่ภายนอกได้ | — | — | — |
| Internal | เห็นได้เฉพาะคนใน (default) | สถานะ, วันที่, เลขที่ CP, ชื่อผู้ขาย, po_id | แสดงปกติ | export ได้ทุก internal role |
| Confidential | จำกัด role | ราคา/หน่วย, winner_total, subtotal, grand_total, เลขภาษีผู้ขาย | mask `***` ถ้า role ไม่ผ่าน | excluded column ถ้าไม่ผ่าน |
| Restricted | จำกัดถึง person (ACL) | — (ดู OQ-05) | — | — |

### §4.6.2 Default Rule
- Default = **Internal** · ห้าม default Public · ราคา/ยอด = Confidential (ข้อมูลการค้าผู้ขาย)

### §4.6.3 Enforcement Mapping

| Classification | DB | API | UI | Audit |
|---|---|---|---|---|
| Internal | RLS (tenant) | JWT auth | — | mutation only |
| Confidential | RLS + column ACL | role check (procurement/finance) | mask `***` ถ้าไม่ผ่าน | view + mutation |

### §4.6.4 PII Overlay
- `buyer` → Internal + PII (ชื่อพนักงาน, PDPA scope) · ผู้ติดต่อผู้ขายใน vendor master = Confidential + PII (อยู่ที่ Vendor master)

### §4.6.5 Security Bible Domain Mapping
- **D5 (Financial):** ทุก field ราคา/ยอด → audit log + Confidential
- **D7 (PII):** buyer name → PDPA scope (ไม่ encrypt — เป็นชื่อในระบบ internal)
- **D9 (Audit):** ทุก mutation + state transition → T_audit_log (diff)

### §4.6.6 Linkage with Policy Center
- Confidential fields (ราคา/ยอด) → register ที่ Policy Center → Data Classification
- ไม่มี Restricted ในเวอร์ชันนี้ (ถ้า OQ-05 = Restricted → wire Restricted Resources)
