## §1.2 Screen Anatomy

### R-01 · ทะเบียนหน่วยวัด

โครงจากบนลงล่าง — **ขาดชั้นไหนถือว่าไม่ผ่าน**

| ชั้น | มีอะไร | หมายเหตุ |
|---|---|---|
| 1 · หัวหน้า | ชื่อหน้า + ป้ายจำนวนรวม · คำอธิบายหนึ่งบรรทัด · ปุ่ม **ส่งออก CSV** · **นำเข้า CSV** · **สร้างหน่วยวัด** | ปุ่มหลักอยู่ขวาสุดเสมอ · ปุ่มรองเรียงซ้ายของมัน |
| 2 · การ์ดสรุป | **4 ใบ** — ทั้งหมด · ใช้งาน · ไม่ใช้งาน · ร่าง | **กดได้ → กรองตาราง** · กดใบ *ทั้งหมด* = ล้างตัวกรองสถานะ+หมวด · ตัวเลขต้องตรงข้อมูลจริงเสมอ |
| 3 · แถบเลือกหลายรายการ | จำนวนที่เลือก · ปุ่มตั้งสถานะ 3 ค่า · ปุ่มลบ · ปุ่มยกเลิกการเลือก | **โผล่เฉพาะเมื่อเลือก ≥ 1 รายการ** · อยู่บนสุดของกล่องตาราง |
| 4 · แถบกรอง | ช่องค้นหา · ตัวเลือกหมวด · ตัวเลือกสถานะ · ปุ่มล้างตัวกรอง | **แถวเดียวเท่านั้น** · ปุ่มล้างโผล่เฉพาะเมื่อมีตัวกรองทำงานอยู่ |
| 5 · ตาราง | 8 คอลัมน์ (ดู §1.4) | หัวตารางค้างเมื่อเลื่อน · เลื่อนอยู่ใน**กล่องตาราง** ไม่ใช่ทั้งหน้า |
| 6 · ท้ายตาราง | ปุ่มแบ่งหน้า (ซ้าย) · ช่วงรายการ `X – Y จาก Z รายการ` (ขวา) | **ติดขอบล่างจอเสมอ** ทุกขนาดหน้าจอ |

**ข้อบังคับเชิงโครง**

- กล่องตาราง **ยืดเต็มพื้นที่ที่เหลือ** — ข้อมูลน้อยแค่ไหนขอบล่างก็ยังชิดขอบจอ ที่ว่างอยู่ *ใน* ตาราง
- **ทั้งหน้าไม่เลื่อน** — การเลื่อนเกิดในกล่องตารางเท่านั้น
- **จำนวนแถวต่อหน้า = 25** (ค่าตั้งต้น · อ่านจาก config ไม่ hardcode)

| เนื้อ | **1 กลุ่ม** ชื่อ *ข้อมูลหน่วยวัด* · **ตาราง 2 คอลัมน์ · 6 ช่อง** |
| ท้ายลิ้นชัก | *ยกเลิก* (ซ้ายสุด) → ที่ว่าง → *ยืนยันสร้าง* / *บันทึกการแก้ไข* (ขวาสุด) |

**ลำดับช่องกรอก (ตายตัว)**

| ลำดับ | ช่อง | ชนิด | บังคับ |
|:--:|---|---|:--:|
| 1 | รหัสหน่วย | ข้อความ | ⬜ |
| 2 | สัญลักษณ์ | ข้อความ | ⬜ |
| 3 | **ชื่อ (ไทย)** | ข้อความ | ✅ |
| 4 | ชื่อ (อังกฤษ) | ข้อความ | ⬜ |
| 5 | **หมวดหน่วยวัด** | ตัวเลือก 6 ค่า | ✅ |
| 6 | สถานะ | ตัวเลือก 3 ค่า | — (ค่าตั้งต้น *ใช้งาน*) |

> 🔴 **ห้ามมีข้อความคำอธิบายใต้ช่องกรอกใด ๆ** (`FN-04` · `LOCK-05`)
> ห้ามมีไอคอนเครื่องหมายคำถาม/คำอธิบายลอย · **ข้อความแจ้งข้อผิดพลาดไม่นับเป็นคำอธิบาย** — ต้องมี

> 🔴 **ห้ามมีปุ่ม "บันทึกร่าง"** — สถานะ *ร่าง* ตั้งได้จากช่องสถานะโดยตรงอยู่แล้ว

### R-04 · รายละเอียดหน่วยวัด

| ส่วน | มีอะไร |
|---|---|
| หัวลิ้นชัก | บล็อกแสดงตัวตน (ตัวย่อรหัส + ชื่อไทย + ป้ายสถานะ + หมวด/สัญลักษณ์) · ปุ่ม *แก้ไข* · ปุ่ม *เปลี่ยนสถานะ* · เส้นคั่น · ปุ่มปิด |
| แถบแท็บ | **ภาพรวม** · **การใช้งาน** (มีตัวเลขกำกับ) · **ประวัติ** |
| เนื้อ | ตามแท็บที่เลือก (ดู §1.3) |
| ท้ายลิ้นชัก | ข้อความ *แก้ไขล่าสุด {วันที่} · {ผู้แก้}* (ซ้าย) → ที่ว่าง → ปุ่ม *ปิด* (ขวา) |

> ปุ่มท้ายลิ้นชักของหน้ารายละเอียด **มีได้แค่ *ปิด*** — ปุ่มทำงานทั้งหมดอยู่หัวลิ้นชัก
> 🔴 **ห้ามมีปุ่มลบในหน้านี้** (`FN-40②`)

## §1.3 เนื้อของแต่ละแท็บ

| แท็บ | แสดงอะไร |
|---|---|
| **ภาพรวม** | ตารางนิยาม 6 บรรทัด — รหัสหน่วย · สัญลักษณ์ · ชื่อไทย · ชื่ออังกฤษ · หมวด · สถานะ (เป็นป้ายสี) |
| **การใช้งาน** | จำนวนสินค้าที่ใช้ · ลบออกจากทะเบียนได้มั้ย (*ทำได้* / *ทำไม่ได้ — มีสินค้าอ้างอิงอยู่*) · เลือกได้ในทะเบียนสินค้ามั้ย (ผูกกับสถานะ) |
| **ประวัติ** | เส้นเวลา 2 เหตุการณ์ — *แก้ไขล่าสุด* และ *สร้างรายการ* พร้อมผู้ทำและวันที่ |

> **ทุกแท็บต้องมีเนื้อหาจริง** — ห้ามมีแท็บที่กดแล้วเงียบ
> ⚠️ แท็บ *ประวัติ* เนื้อบางเพราะโมเดลยังไม่เก็บรายเหตุการณ์ (`OQ-08`) — โครงเส้นเวลาวางไว้รองรับแล้ว

|:--:|---|:--:|---|---|

| 2 | **รหัส** | ✅ | ซ้าย | 🔴 **ตัวหนังสือล้วน — ห้ามมีไอคอน/รูปประจำตัวนำหน้า** (`FN-18`) |

**พฤติกรรมของแถว**

- กด**ทั้งแถว** = เปิดหน้ารายละเอียด
- กดที่ช่องเลือก หรือ คอลัมน์จัดการ = **ไม่เปิด**หน้ารายละเอียด
- 1 ข้อมูล = 1 คอลัมน์ — ห้ามซ้อนบรรทัดรองใต้ค่าหลัก

## §1.5 สถานะของหน้าจอ (State Matrix)

| สถานะ | เมื่อไหร่ | ต้องแสดงอะไร |
|---|---|---|
| ปกติ | มีข้อมูลและไม่ได้กรอง | ตารางเต็ม + แบ่งหน้า |
| **ค้นหาไม่พบ** | มีตัวกรองทำงานอยู่แต่ไม่มีผล | ไอคอน + *"ไม่พบรายการที่ค้นหา"* + คำแนะนำ + **ปุ่มล้างตัวกรองที่กดแล้วกลับมาได้จริง** |
| **ยังไม่มีข้อมูล** | ทะเบียนว่างเปล่า | ไอคอน + *"ยังไม่มีหน่วยวัด"* + คำชวน + **ปุ่มสร้างหน่วยวัด** |
| กำลังบันทึก | กดปุ่มบันทึกแล้วยังไม่เสร็จ | ปุ่มถูกปิด + ไอคอนหมุน + ข้อความ *"กำลังบันทึก…"* |
| กรอกไม่ผ่าน | ชื่อว่าง หรือ รหัสซ้ำ | ขอบช่องที่ผิดเป็นสีเตือน + ข้อความใต้ช่องนั้น + **ลิ้นชักยังเปิดค้าง** |
| เลือกหลายรายการ | เลือก ≥ 1 | แถบเครื่องมือโผล่พร้อมจำนวนที่ถูกต้อง |
| ลบไม่ได้เลย | เลือกเฉพาะหน่วยที่ถูกใช้ | **ปุ่มยืนยันลบถูกปิด** |

> **พื้นที่ข้อความแจ้งข้อผิดพลาดต้องถูกจองไว้ล่วงหน้า** — ข้อความโผล่แล้วฟอร์มต้องไม่กระตุก

## §1.6 หน้าต่างนำเข้าไฟล์ (M-01) — 3 จังหวะ

| จังหวะ | แสดงอะไร | ปุ่ม |
|:--:|---|---|
| **1 · เลือกไฟล์** | กล่องเลือกไฟล์ **เท่านั้น** | *ดาวน์โหลด template ตัวอย่าง* (ซ้าย) · *ยกเลิก* (ขวา) |
| **2 · ตรวจผล** | แถบสรุป *"ตรวจแล้ว N แถว — นำเข้าได้ X · ติดปัญหา Y"* + ตารางรายแถว 5 คอลัมน์ (รหัส · ชื่อ · หมวด · **สถานะ** · ผลตรวจ) | *ยกเลิก* · *นำเข้า X แถว* (ปิดถ้า X = 0) |
| **3 · ผลลัพธ์** | แถบสรุปผล + ตารางแถวที่ถูกข้ามพร้อมสาเหตุ (ถ้ามี) | *ปิด* |

> 🔴 **จังหวะที่ 1 ห้ามมีข้อความอธิบายคอลัมน์** (`FN-13`) — ผู้ใช้ที่ไม่รู้โครงไฟล์ให้กดโหลดไฟล์ตัวอย่าง
> **ห้ามเขียนข้อมูลทันทีที่เลือกไฟล์** — ต้องผ่านจังหวะที่ 2 และให้ผู้ใช้กดยืนยันเสมอ

## §1.8 ถ้อยคำบนจอ

**ยึด `microcopy.md` ของ `html-generator-v8` เป็นหลัก — ห้ามแต่งคำใหม่ถ้ามีคำมาตรฐานอยู่แล้ว**

| จุด | คำที่ใช้ | ที่มา |
|---|---|---|
| ปุ่มสร้าง | `สร้างหน่วยวัด` | มาตรฐาน (`สร้าง` + ชื่อสิ่งของ) |
| ปุ่มยืนยันตอนสร้าง | `ยืนยันสร้าง` | มาตรฐาน |
| ปุ่มยืนยันตอนแก้ | `บันทึกการแก้ไข` | มาตรฐาน |
| ปุ่มยกเลิกในฟอร์ม | `ยกเลิก` | มาตรฐาน |
| ปุ่มปิดหน้ารายละเอียด | `ปิด` | มาตรฐาน |
| ระหว่างบันทึก | `กำลังบันทึก…` | มาตรฐาน |
| กรอกไม่ครบ | `กรุณากรอกข้อมูลให้ครบถ้วน` | มาตรฐาน |
| ชื่อไทยว่าง | `กรุณากรอกชื่อภาษาไทย` | เฉพาะ feature |
| รหัสซ้ำ | `รหัส {X} ถูกใช้แล้ว` | เฉพาะ feature |
| ช่วงรายการ | `X – Y จาก Z รายการ` | มาตรฐาน |
| ยืนยันลบ | `ลบหน่วยวัด {N} รายการ?` + *"จะลบจริง {N} รายการ · ข้าม {M} รายการที่ถูกสินค้าใช้อยู่"* | เฉพาะ feature |

**ป้ายสถานะ**

| สถานะ | คำ | โทนสี |
|---|---|---|
| `draft` | ร่าง | เทา |
| `active` | ใช้งาน | เขียว |
| `inactive` | ไม่ใช้งาน | เหลือง/ส้ม |

> ⚠️ ชุดสีนี้ **ต่างจากตารางมาตรฐานกลาง** (ซึ่งกำหนด *ใช้งาน* = ฟ้า · *ปิดใช้งาน* = เทา)
> เลือกตามนี้เพื่อให้ **ตรงกับทะเบียนสินค้าและแคตตาล็อกที่ใช้ชุดสถานะ 3 ค่าเดียวกัน** —
> เป้าหมายของกฎคือ *"สถานะเดียว = สีเดียวทุกไฟล์"* ซึ่งการตามพี่น้องในเลนรักษาไว้ได้ดีกว่า
> → ยกเป็นข้อเสนอปรับตารางกลางที่ `PROPOSALS_outbound`

|---|---|
| เปิดลิ้นชัก | โฟกัสต้องเข้าไปในลิ้นชักอัตโนมัติ |
| กด Tab ในลิ้นชัก | **โฟกัสต้องวนอยู่ในลิ้นชัก ไม่หลุดไปพื้นหลัง** |
| ปิดด้วย Esc | ปิดทีละชั้น — เมนูที่กางอยู่ปิดก่อน **ลิ้นชักยังเปิด** → กดอีกครั้งจึงปิดลิ้นชัก |
| ปิดลิ้นชัก | โฟกัสกลับไปที่ปุ่มที่เปิดมัน |
| ปิดได้ 3 ทาง | คลิกฉากหลัง · ปุ่มกากบาท · ปุ่ม Esc |
| ป้ายกำกับ | ทุกปุ่มไอคอนล้วนต้องมีคำอธิบายสำหรับโปรแกรมอ่านหน้าจอ · ช่องเลือกต้องบอกสถานะติ๊ก/ไม่ติ๊ก |
| ความคมชัดตัวอักษร | ต้องอ่านออกบนพื้นทุกแบบ รวม **แถบเลือกหลายรายการที่พื้นเข้ม** |

## §1.10 การแสดงผลบนจอขนาดต่าง ๆ

| ความกว้าง | พฤติกรรม |
|---|---|
| ≥ 1180px | เต็มรูปแบบ |
| 768–1180px | เมนูซ้ายยุบเป็นแบบเลื่อนออก + มีปุ่มเปิดเมนูที่แถบบน · ลิ้นชักไม่ล้นจอ · ระยะขอบเนื้อหาลดลง |
| < 768px | ไม่รับประกัน — ให้เลื่อนแนวนอนแทนที่จะพังโครง |

> **ห้ามซ่อนความสามารถใด ๆ ตอนจอแคบ** — ยุบเข้าเมนูได้ แต่ต้องยังเข้าถึงได้ทุกอย่าง
> **ห้ามมีแถบเลื่อนแนวนอนของทั้งหน้า** ในช่วง 768–1180px

## §1.11 เมนูที่กางจากภายในลิ้นชัก

เมนู *เปลี่ยนสถานะ* อยู่ในหัวลิ้นชัก — ต้องถูกย้ายไปวางที่ชั้นบนสุดของหน้า (portal) เพื่อไม่ให้ถูกลิ้นชักบัง

| ข้อกำหนด | รายละเอียด |
|---|---|
| ลำดับชั้น | **สูงกว่าลิ้นชัก** — วัดด้วยการยิงพิกัดกลางเมนูแล้วต้องเจอตัวเมนู ไม่ใช่ลิ้นชัก |
| ตำแหน่ง | กางลงล่าง · ถ้าพื้นที่ล่างไม่พอให้พลิกขึ้นบน · ถ้ายังไม่พอให้หดแล้วเลื่อนภายใน |
| ปิดเมื่อ | เลือกค่า · คลิกนอกเมนู · กด Esc |
| ค่าปัจจุบัน | **กดไม่ได้** และแสดงจางลง |

> ⚠️ **ข้อควรระวังสำหรับ dev:** ถ้าเขียน CSS ให้ class เมนูของตัวเองแล้วกำหนดลำดับชั้นทับ
> ค่าที่ชุดพื้นฐานให้มา เมนูจะจมใต้ลิ้นชักทันที — ต้องมีตัวทดสอบยิงพิกัดจริงกำกับเสมอ
