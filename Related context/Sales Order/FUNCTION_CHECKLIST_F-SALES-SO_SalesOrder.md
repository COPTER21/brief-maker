## สิ่งที่ไม่รองรับ (ตัดสินแล้ว)
- แก้ SO ที่ยืนยันแล้ว — ยกเลิก/ทำสำเนา หรือ close short + SO ใหม่ [AI-DRAFT · OQ-7] (S-33)
- ของแถม/ส่วนลดนอกโปรฯ/TA แบบ manual — ต้องผ่าน Promotion/TA หรือ DOA แยก [AI-DRAFT · OQ-8] (S-34)
- ต่างสกุลเงิน · Drop-ship · Consignment — phase ถัดไป (S-35)
- ยกเลิก SO ที่ส่งแล้ว — ต้อง RMA/CN [มติ] (BR-16)
- สต๊อกไม่พอแล้วยังส่งอนุมัติ — บล็อก (ไม่ soft) [มติ 18 ส.ค.] (BR-09)
- สายอนุมัติตามวงเงิน — DOA-SALES-SO ไม่มีวงเงิน [มติ]
