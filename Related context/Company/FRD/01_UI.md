## §1.2 Components per Page
- **List (P-02..P-05):** page header (title + count badge + hint) · action bar (Export CSV / นำเข้า CSV[div,dept,pos] / +เพิ่ม) · filter bar (search + status) · data table (≤8 cols, row-click → P-06, row-actions: edit/toggle/delete with stopPropagation) · footer pagination.
- **Org chart (P-04/P-05):** view-switch (รายการ | ผังองค์กร) · tree nodes (Company/Division/Dept/Position) คลิก node → P-06.
- **P-01 Company:** profile hero (logo image ถ้ามี ไม่งั้นไอคอนตึก) · mini-stat cards (สาขา/สายงาน/แผนก/ตำแหน่ง) · detail cards (4 กลุ่ม) · Export/Edit.
- **Company Edit drawer (D-01):** กลุ่มแรก = **"โลโก้บริษัท"** — preview 84px + ปุ่ม `อัปโหลดโลโก้` (input image) + `ลบโลโก้` + field-help (PNG/JPG/SVG ≤2MB). เลือกไฟล์ → DOM-patch preview ทันที (ไม่ full re-render, กัน jitter, คงค่า field อื่น) → บันทึก = API-13 / ลบ = API-14.
- **P-06 Detail:** back-link · hero (icon+ชื่อ+code+status+tags) · detail cards (kv) · related tables (เช่น สายงาน→แผนก+ตำแหน่ง) · Edit.
- **D-01 Drawer:** form groups ตาม entity (ดู 04_DB fields) · footer: ghost(ยกเลิก) → spacer → primary(บันทึก).
- **M-02 Import modal:** seg Replace(default)/Merge · ดาวน์โหลด Template · drop zone · validation result (pass/fail + error รายแถว + preview 8 แถว) · footer: ยกเลิก / นำเข้า N รายการ (disable ถ้า ok=0).
