```
HR Admin เข้าเมนู "ตั้งค่า HR"  →  #/hr-config  →  redirect  →  #/hr-config/leave (P-02)
  ↓ กด "+ สร้างค่าใหม่"
```

## §1.6 Empty States & Errors (UI)

| State | UI behavior (ข้อความจริงบนจอ) |
|---|---|
| ยังไม่มีข้อมูลในกลุ่มนี้ | `emptyStateHTML()` + CTA "สร้างค่าใหม่" |
| กรองแล้วไม่เจอ | empty state โหมด "กำลังกรองอยู่" + ปุ่ม `ล้างตัวกรองแล้ว` → toast |
| ไม่มี feature ใดอ้างค่านี้ (tab ใครใช้ค่านี้) | `ยังไม่มี feature ใดอ้างค่านี้` |
| ยังไม่ได้เลือกบริษัท | `ยังไม่ได้เลือกบริษัท` |
| กด action โดยเป็น HR Staff | toast `บทบาท HR Staff ดูได้อย่างเดียว` (warning) |
| กดเมนู sidebar ที่อยู่นอก scope | toast `“<ชื่อเมนู>” อยู่นอกขอบเขตต้นแบบรอบนี้` (info) |
| validate ไม่ผ่านในขั้น 1–2 | toast `ยังกรอกไม่ครบ ตรวจข้อความสีแดง` (error) + error ใต้ field |
| validate ไม่ผ่านที่ขั้น 3 | toast `ยังตั้งวันมีผลไม่ได้ ตรวจข้อความสีแดง` (error) |
| API 403 | "ไม่มีสิทธิ์ทำรายการนี้" + ลิงก์ติดต่อผู้ดูแล |
| API 500 | "เกิดข้อผิดพลาด — กรุณาลองใหม่" + ปุ่มลองใหม่ |
| เครือข่ายหลุด | banner "การเชื่อมต่อขาดหาย — ร่างถูกเก็บไว้ในเครื่อง" |
