## §1.2 Per-Page Detail

### P-01: แท็บ "บัญชีบริษัท" (accounts list) — Pattern A

**Purpose:** Manage a company's bank accounts; switch company; see masked numbers + defaults + status.
**ERP Context:** Sidebar active = "ธนาคาร / บัญชีบริษัท" (Finance) · Shell-bar white 52px · content 22px.
**Header (verbatim):** title `ธนาคาร / บัญชีบริษัท` · sub `จัดการบัญชีธนาคารของบริษัท ผูกบัญชีแยกประเภท (GL) และตั้งค่าบัญชีจ่าย/รับเริ่มต้น`.
**Components:**
- Company bar (`co-bar`): label `บริษัท` (plain `<select>` — enum, not master combobox), meta `เลขผู้เสียภาษี` · `บัญชีจ่ายเริ่มต้น` · `บัญชีรับเริ่มต้น` (fallback `ยังไม่ตั้ง`).
- Stat cards: `บัญชีทั้งหมด` (meta `ในบริษัทนี้`) · `ใช้งานอยู่` (meta `พร้อมใช้ในเอกสาร`) · `บัญชีจ่ายเริ่มต้น` · `บัญชีรับเริ่มต้น` (fallback `ยังไม่ได้ตั้งค่า`).
- Filter bar: search placeholder `ค้นหาธนาคาร / ชื่อบัญชี / เลขบัญชี` · status `<select>` (`ทุกสถานะ`/`ใช้งาน`/`ปิดใช้งาน`/`เก็บถาวร`) · reset `ล้างตัวกรอง`.
- Data table — headers (verbatim): `ธนาคาร` · `ชื่อบัญชี` · `เลขบัญชี` · `ประเภท` · `บัญชี GL` · `ค่าเริ่มต้น` · `สถานะ` · `จัดการ`. Footer: `แสดง {n} จาก {total} รายการ` + company name.
- Header actions: `จำลองเลือกในเอกสาร` (secondary) · `สร้างบัญชี` (primary, +).

**Actions:**
| Action | Triggers | Calls (API) |
|---|---|---|
| Change company (`changeCompany`) | reload list | F-BNK-API-01 |
| Search / status filter / `ล้างตัวกรอง` | refresh table | F-BNK-API-01 |
| Click row (`openView`) | open view drawer P-04 | F-BNK-API-03 |
| `ดูเต็ม` (reveal) | reveal full number (gated) | **F-BNK-API-05** |
| `ซ่อน` (hide) | re-mask (client) | — |
| `แก้ไข` (row) | open edit drawer P-03 | F-BNK-API-04 (on save) |
| `เก็บถาวร` (row) | open M-01 | F-BNK-API-08 |
| `สร้างบัญชี` | open create drawer P-03 | F-BNK-API-02 (on save) |
| `จำลองเลือกในเอกสาร` | open M-03 (mock) | (mock; real consumers use API-16) |

**States:**
- Loading: skeleton table.
- Empty (unfiltered): title `ยังไม่มีบัญชีธนาคาร` · desc `เริ่มต้นด้วยการสร้างบัญชีธนาคารแรกของบริษัทนี้` · action `สร้างบัญชี`.
- Empty (filtered): title `ไม่พบรายการที่ค้นหา` · desc `ลองปรับคำค้นหรือล้างตัวกรอง` · action `ล้างตัวกรอง`.
- Loaded: table with masked numbers (default `••••••NNNN`), default flags (`จ่าย`/`รับ`/`—`), status pill.

**Masking / reveal (R10):** number masked to last-4 by default. `ดูเต็ม` (icon scan-line, tooltip `ต้องมีสิทธิ์ · ระบบจะบันทึกการเข้าถึง`) → API-05. Denied → toast `คุณไม่มีสิทธิ์ดูเลขบัญชีเต็ม` (warning), stays masked. Success → toast `บันทึกการเข้าถึงเลขบัญชีเต็มแล้ว` (info) + audit `revealed`.

**Permissions:** finance_admin = all; finance_user = view masked only (no create/edit/archive, no reveal); accounting = view (ref).

### P-03: Drawer สร้าง/แก้บัญชี — Pattern B (680)

**Eyebrow:** `สร้างบัญชีธนาคาร` / `แก้ไขบัญชีธนาคาร`. **Title:** `บัญชีธนาคารใหม่` (create) / account id (edit).
**Sections:** `ข้อมูลบัญชี` · `การผูกบัญชีแยกประเภท (GL)` · `ค่าเริ่มต้นการชำระเงิน`.
**Fields (verbatim labels):**
- `ธนาคาร *` — **master combobox #94** `acc-bank`, placeholder `ค้นหาธนาคาร (พิมพ์ชื่อ / รหัส / SWIFT)`, searches name/code/SWIFT, empty `ไม่พบธนาคาร`.
- `เลขที่บัญชี *` — placeholder `ตัวเลข 10-15 หลัก`, help `กรอกเฉพาะตัวเลข ไม่ต้องมีขีดหรือเว้นวรรค`; input strips non-digits live.
- `ชื่อบัญชี *` — placeholder `ชื่อเจ้าของบัญชี`.
- `ประเภทบัญชี *` — `<select>` enum (ออมทรัพย์/กระแสรายวัน/ฝากประจำ).
- `สาขา` — placeholder `เช่น สยามพารากอน`.
- `สกุลเงิน` — value `THB — บาทไทย` **readonly**, info-tip `เฟสนี้รองรับ THB เท่านั้น — สกุลเงินอื่นจะเปิดใช้พร้อม multi-currency (OQ-2)`.
- `บัญชี GL (ผังบัญชี) *` — **master combobox #94** `acc-gl`, placeholder `ค้นหาบัญชีจากผังบัญชี (CoA)`, help `ใช้สำหรับตั้งรายการบันทึกบัญชี (posting) เมื่อมีการรับ-จ่ายผ่านบัญชีนี้`, empty `ไม่พบบัญชี GL`.
- Default toggles: `บัญชีจ่ายเริ่มต้น` (desc `ตั้งค่าได้เพียง 1 บัญชีต่อบริษัท — เลือกใหม่จะย้ายค่าเริ่มต้นมาบัญชีนี้`) · `บัญชีรับเริ่มต้น` (desc `ตั้งค่าได้เพียง 1 บัญชีต่อบริษัท`).
**Footer:** `ยกเลิก` (ghost) · primary `ยืนยันสร้าง` (create) / `บันทึกการแก้ไข` (edit); submitting `กำลังบันทึก…`.
**Validation (inline, on submit; toast `กรุณากรอกข้อมูลให้ครบถ้วน`):** `กรุณาเลือกธนาคาร` · `กรุณากรอกเลขที่บัญชี` / `เลขบัญชีต้องเป็นตัวเลข 10-15 หลัก` / `เลขบัญชีนี้มีอยู่แล้วในบริษัทนี้` · `กรุณากรอกชื่อบัญชี` · `กรุณาเลือกบัญชี GL`.
**Esc chain (#94.3 / #15):** Esc closes combobox list first (stopPropagation) → drawer stays; Esc again closes drawer.

### M-01 / M-02 / M-03: Modals — Pattern D (440)
- **M-01 archive:** title `เก็บถาวรบัญชีนี้?` · sub `{nameTh} · {maskedNo}` · body `ต้องการเก็บถาวรบัญชี "{accName}" ใช่หรือไม่ บัญชีจะถูกย้ายไปสถานะเก็บถาวร`. Used-in-doc warn note: `บัญชีนี้ถูกใช้ในเอกสารและรายการกระทบยอดธนาคารแล้ว จึงลบถาวรไม่ได้ — ระบบจะเก็บถาวร (soft archive) เท่านั้น เอกสารและรายการกระทบยอดเดิมยังอ้างอิงบัญชีนี้ได้ตามปกติ` (icon lock). Else info note about disappearing from new-doc pickers.
