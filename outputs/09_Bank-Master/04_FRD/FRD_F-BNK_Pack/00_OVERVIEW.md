## §0.3 Scope

### In Scope
- **Level 1 — Bank (รายชื่อธนาคาร):** preset ธปท. 22 (read-only) + create/edit/delete **custom** foreign banks (SWIFT self-entered).
- **Level 2 — CompanyBankAccount (บัญชีธนาคารบริษัท):** per-company account CRUD — bank (combobox #94) + account number (masked) + name + type + branch + currency (THB) + GL binding (combobox #94 from CoA) + default pay/receive toggles.
- **Multi-company:** company switcher; default pay / default receive = 1 each per company.
- **Lifecycle:** active ⇄ inactive → archived (soft archive; **no hard delete on accounts**).
- **Data protection (R10):** mask account number to last-4 everywhere; full reveal gated by `canRevealFull`; **every reveal writes append-only audit**.
- **Audit:** append-only, 2 streams (account + bank).
- **Consumer hooks (soft-reference picker):** expose active accounts to Payment Voucher, Receipt Voucher, Bank Reconciliation, **Payroll** (mock picker in prototype).
- **Inbound:** GL account from Chart of Accounts (CoA).

### Out of Scope (see §0.11 Scope Lock — immutable)
- **Bank API / auto statement import (S-06)** — deferred to Bank Reconciliation phase (OOS-1).
- **Multi-currency** — THB only; `currency` column present to enable later toggle without schema change (OOS-2 / OQ-2).
- **Tier / Lite-Full linkage** — Shared-Foundation master has no tier; no 🔗/✋ dual-mode (OOS-3).
- **PromptPay / e-payment ID** on account — future field, decided when building Payment/Receipt Voucher (OOS-4).
- **Per-account purpose tag** (e.g. payroll-only) — over-engineering for master (OOS-5).
- **Per-bank account-number format table** — validate generic numeric 10–15 digits only (OOS-6 / S-04).

### Out of Scope (from Phase 2.5 skipped probes)
- None skipped — Lane Mode answered all activated probes with conservative defaults (see §0.13).

## §0.9 Glossary

| Term | Definition |
|---|---|
| Bank (E1) | Bank list entry — preset (BOT/ธปท. 22, read-only) or custom (user-created foreign bank) |
| CompanyBankAccount (E2) | A company's bank account record (the master transaction) |
| `canRevealFull` | Permission allowing a user to reveal the full (unmasked) account number |
| Reveal | Action of unmasking a full account number — always writes an audit entry |
| Soft-reference | Master used as picker input only; value snapshotted into consuming document; no FK cascade (Global Contract #6) |
| Soft archive | Terminal deactivation of an account (no hard delete) — Global Contract #7 |
| Preset / custom bank | Preset = ธปท. standard (never edit/delete); custom = user-created (edit/delete if `used=0`) |
| BOT / ธปท. | Bank of Thailand (source of the 22-bank preset) |
| Snapshot | Copy of master values into a document at pick time (не live lookup) |
