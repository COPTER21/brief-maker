## §1.1 Route Contract

| Page | Hash route | Entry | Exit |
|---|---|---|---|
| P-01 BOM list | `#/bom` | app menu/direct | create, detail |
| P-02 create | `#/bom/create` | “สร้างสูตรใหม่” | cancel/list, save/detail |
| P-03 edit | `#/bom/edit/:id` | “แก้ไขสูตร” | cancel/detail, save/detail |
| P-04 detail | `#/bom/view/:id` | table row/sibling version | edit, sibling detail, list |

Unknown `:id` must show a visible not-found state and offer a return to `#/bom`; it must not silently open another record.

## §1.2 P-01 — BOM List

### Anatomy

1. page header and primary action “สร้างสูตรใหม่”
2. four summary cards calculated from the current dataset
3. search and status filter
4. sortable/selectable BOM table
5. bulk action bar when at least one row is selected
6. row action/status menu and link to detail

Each summary card is actionable and applies its corresponding status/all filter. Search, parent/status filter, summary-card filter, sorting, and pagination operate as one composed query; changing a filter resets offset without discarding the other filter values.

### Visible columns and behavior

| Field | Display | Behavior |
|---|---|---|
| selection | checkbox | select individual/all visible rows |
| `code` | BOM code | opens P-04 |
| parent | Item code/name/image | current Item display by code |
| `version` | text | sortable where implemented |
| `status` | Thai badge | `ร่าง`, `ใช้งาน`, `ไม่ใช้งาน` |
| `is_default` | default indicator | only active BOM may display as default |
| component count | integer | derived from lines |
| total cost | currency/decimal | mask or omit without D-CLASS permission |
| `modified_date` | localized date | from server timestamp |

Search matches BOM code, parent code/name, version, and BOM name. Status filter supports all three states. An empty result must be distinguishable from initial loading and request failure.

### Bulk actions

- status action sends selected IDs to API-05 and displays a per-record result ledger
- delete opens confirmation text `ลบสูตรการผลิต ${ids.length} รายการ?`
- records with `used>0` are skipped; if every selected record is ineligible, destructive confirmation is disabled
- selection is reconciled after filter, refresh, mutation, and partial failure

## §1.3 P-02/P-03 — Create/Edit Wizard

### Step 1: “ข้อมูลสูตร”

| Control | Contract |
|---|---|
| parent Item combobox | active FG only; searchable by code/name; selecting parent sets output base UoM |
| version | required free text; server enforces normalized uniqueness per parent |
| name | required free text |
| `out_qty` | required decimal >0; initial value 1 |
| output UoM | read-only/base UoM from parent |
| `eff_from` | optional date; persistence only, no automatic status change |
| `is_default` | toggle; enabled/effective only when target status is active |

“ถัดไป” validates Step 1 and opens Step 2. Parent changes must clear or revalidate dependent state; line UoM behavior follows Step 2 rules.

### Step 2: “ส่วนประกอบ”

Each row contains component master combobox, quantity, compatible UoM, scrap percent, read-only standard cost, calculated line cost, and remove action.

- component options: active RM/PM/TR only; exclude selected parent
- changing component clears `uom_code`, then assigns/permits only its base-UoM category
- duplicate component rows are rejected at save
- quantity must be >0; `scrap_pct` accepts 0..100 inclusive under current provisional rule
- displayed calculations use decimal semantics matching ENG-01; UI calculation is preview only
- cost cells are hidden/masked when user lacks permission

### Footer actions

| Label | Result |
|---|---|
| `ย้อนกลับ` | Step 2 → Step 1 |
| `ยกเลิก` | return without mutation; if dirty, follow shared unsaved-change behavior |
| `บันทึกร่าง` | create/update with target `draft`; server clears `is_default` |
| `บันทึก + เปิดใช้งาน` | create/update with target `active`; server may atomically set default |

Button loading state prevents repeat clicks, but correctness relies on `Idempotency-Key`. On validation or API error, preserve entered values and focus/scroll to the first actionable error.

## §1.4 P-04 — Detail

### Header actions

- “แก้ไขสูตร” opens P-03
- “เปลี่ยนสถานะ” exposes allowed target statuses; no approval dialog
- back closes to `#/bom`

### Tabs

| Tab | Visible data |
|---|---|
| `ภาพรวม` | header fields, status/default, output, optional effective date, usage count, total cost |
| `ส่วนประกอบ (${b.lines.length})` | component, qty, UoM, scrap, standard cost, line cost |
| `ประวัติ` | append-only audit entries with actor/time/action and meaningful diff |

Overview also renders `เวอร์ชันอื่นของสินค้านี้ (${others.length})`. Every sibling card/row is keyboard- and pointer-activatable and navigates to `#/bom/view/:id`; this is the actual FN-09 fix.

## §1.5 UI State Matrix

| State | List | Form | Detail |
|---|---|---|---|
| loading | table skeleton/progress | submit loading | detail skeleton/progress |
| empty | no matching BOM + clear filter/create action | no lines prompt | no audit/sibling message |
| validation error | — | inline/summary; values retained | — |
| request error | retryable visible error | error + retry, no duplicate save | retryable visible error |
| unauthorized | route-level forbidden | controls unavailable | cost masked or page forbidden by action scope |
| stale edit | refresh/reopen prompt | 409 conflict; do not overwrite | refresh data |
| partial bulk | result ledger success/skip/fail | — | — |

## §1.6 Validation and Verbatim Microcopy

| Trigger | Required visible text |
|---|---|
| parent empty | `เลือกสินค้าผลผลิตก่อน` |
| version empty | `ระบุเวอร์ชันสูตร (เช่น v1)` |
| duplicate version | `เวอร์ชัน ${f.ver} ของสินค้านี้มีอยู่แล้ว` |
| name empty | `ระบุชื่อสูตร` |
| no line | `ต้องมีส่วนประกอบอย่างน้อย 1 รายการ` |
| self-component | `ส่วนประกอบห้ามเป็นตัวสินค้าเอง (${l.item}) — กัน BOM วน` |
| non-positive qty | `ปริมาณของ ${l.item} ต้องมากกว่า 0` |
| duplicate component | `วัตถุดิบ ${l.item} ซ้ำ — รวมเป็นรายการเดียว` |

Interpolation uses the current field value/item code. Backend errors map to the same visible wording where the HTML provides it.

## §1.7 Master Combobox and Overlay Behavior

- Item and UoM are master-data comboboxes, not free-text selects.
- Popup is rendered in the overlay portal above drawers/tables, positioned from the trigger, and repositioned on scroll/resize.
- keyboard: Arrow keys move, Enter selects, Escape closes the top overlay, Tab follows normal focus order.
- cascade clear: parent/component change clears invalid dependent values before new options render.
- close order follows the current global Escape chain; confirmation modal closes before underlying form/drawer.

## §1.8 Accessibility and Responsive Contract

- desktop-base responsive behavior must remain usable from 768px upward per synced v8 rules
- every icon-only button has an accessible name; status is not communicated by color alone
- focus is trapped in modal/drawer, restored to the opener on close, and visible on keyboard navigation
- tables preserve accessible header relationships; sibling versions and menu actions work by keyboard
- no secret, token, or raw authorization detail is rendered in errors
