## 1. สรุป + ผู้ใช้ + สิทธิ์

**ทำอะไร:** เมื่อยอดสินค้าในระบบไม่ตรงกับของจริงในช่องเก็บ (bin) — ของหาย ของแตกเสียหาย ยอดคลาดเคลื่อนจากการรับ/จ่ายผิด — ต้องออก **ใบปรับยอดสต๊อก** ระบุ bin + สินค้า + ยอดที่ถูกต้อง ระบบคำนวณ **ผลต่าง (+/−)** และ **มูลค่าที่ปรับ** ให้เห็นก่อน แล้วบังคับเลือก **เหตุผลทุกบรรทัด** จากนั้นส่ง **สายอนุมัติตามมูลค่า** เมื่ออนุมัติครบจึง **ผ่านรายการ (post)** เกิด **movement แบบ append-only** และตั้งท่อ JE ไว้ให้ W5 ต่อ

**ไม่ทำอะไร (ย้ำ):** ไม่ใช่ระบบ**นับสต๊อก** (cycle count/ใบนับรอบ) และไม่ใช่ระบบ**ย้ายของ** (เปลี่ยน bin/คลัง = Stock Transfer) — ทั้งสองอย่างมีเจ้าของแยก (§10)

| Role | เห็นอะไร | ทำอะไรได้ |
|---|---|---|
| **เจ้าหน้าที่คลัง** | ใบของตัวเอง + ใบในคลังที่ตัวเองสังกัด | สร้าง/แก้ร่าง · กรอกรายการ + เหตุผล · แนบหลักฐาน · ส่งอนุมัติ · ยกเลิกร่างของตัวเอง |
| **หัวหน้าคลัง** | ทุกใบในคลังที่ดูแล | ทุกอย่างของเจ้าหน้าที่ + **ผ่านรายการ (post)** ใบที่อนุมัติครบ + ขอกลับรายการ |
| **ผู้อนุมัติ (ตาม DOA slot)** | ใบที่ถูกส่งมาถึง slot ตัวเอง | อนุมัติ / ตีกลับพร้อมเหตุผล · ดูมูลค่าที่ปรับ + หลักฐานแนบ |
| **บัญชี** (อ่านอย่างเดียวรอบนี้) | ใบที่ post แล้ว + มูลค่า + เหตุผล | ดู/พิมพ์ PDF · ดูประวัติ · **ยังไม่ post JE จริง** (`TODO: JE posting`) `[AI-DRAFT]` |
| **ผู้ตรวจสอบ (audit)** | ทุกใบทุกสถานะ + ประวัติเต็ม | อ่านอย่างเดียว · ดู movement append-only + คู่ reversal |

> สิทธิ์ทั้งหมด `[AI-DRAFT]` — ผูกกับ Security Preset ตอน BRD (§S4) · การกำหนดสิทธิ์จริงเป็นของ Policy Center ไม่ hardcode ใน feature

Warehouse (คลัง/สาขา)   WH-BKK-01 · WH-CNX-01 · WH-TRN (in-transit เสมือน — ห้ามแตะ)

#### 3.0.2 `location_type` — สิทธิ์ของ **StockAdj** ต่อประเภท (ยกมาอ้าง + ระบุสิทธิ์ตัวนี้)

| type | ชื่อไทย | StockAdj ปรับยอดได้? | หมายเหตุ |
|---|---|---|---|
| `staging` | โซนพักรับเข้า | 🟡 **ได้** (ของมีจริงแต่ยังไม่ putaway) | เพิ่ม/ลดในบิ๊นเดิม · ไม่ย้าย `[AI-DRAFT]` |

| `quarantine` | กักกัน (QC ไม่ผ่าน) | ✅ **ได้ ภายใน bin เดิมเท่านั้น** | ห้ามย้ายออกไป storage — ทางออกคือ **RTV** (S-18) |
| `in-transit` | ระหว่างทาง | ❌ **ห้ามแตะเด็ดขาด** | จองให้ **StockTransfer** — กรองออกจาก picker (S-20 · OB-6) |
| `damage` | ของเสีย/รอทำลาย | ✅ **ได้ — เขียนได้เฉพาะ StockAdj** | ตัดจำหน่าย (S-19) |

**กติกาข้ามประเภทที่ยกมาบังคับใช้ (Putaway §3.0.2):**
1. `quarantine` ไปไหนไม่ได้นอกจาก quarantine ด้วยกัน หรือออกด้วย RTV
2. `in-transit` ห้ามมีใครเขียนตรง ๆ นอกจาก StockTransfer
3. `damage` เขียนได้เฉพาะ StockAdj
4. `staging + storage + in-transit` = ทรัพย์สินใช้ได้ · `quarantine + damage` = กันออกจากยอดขายได้

#### 3.0.3 ฐานยอดที่ feature นี้อ่าน (Putaway §3.4)
**ยอดคงเหลือราย bin** = `Σ movement เข้า − Σ movement ออก` ต่อคู่ **(bin, สินค้า)** — ตัวเลขนี้คือ "ยอดระบบ" ที่ §3.2 snapshot มาใช้

#### 3.0.4 ชุด location ตั้งต้น
ใช้ **ชุดเดียวกับ Putaway §3.0.5 เป๊ะ** (`WH-BKK-01`: `ST-DOCK-01/02` · `A-01-01-A`…`A-02-04-C` · `B-01-01-A`…`B-03-02-B` · `C-01/C-02` · `QA-01` · `DM-01` · `WH-CNX-01`: `CNX-ST-01` · `CNX-A-01-01-A` · `CNX-QA-01` · `WH-TRN`: `TR-BKK-CNX`/`TR-CNX-BKK` **ห้ามใช้**)

## 7. Data behaviour
- **เลขรัน**: `ADJ-YYYY-NNNN` จาก **ENG-DOC-NUM** ตาม config ที่ประกาศใน `DOCCFG_BRIEF` — ปี **ค.ศ.** · ออกเลขตอน**ส่งอนุมัติ** (BR-21) · ห้าม hardcode ในหน้า feature (OB-8)

- **Soft archive**: ไม่มี hard delete ทุกระดับ — ใบยกเลิกยังอยู่ · movement append-only (BR-16)
- **Audit append-only**: ทุกเหตุการณ์บันทึกพร้อม ใคร-เมื่อไหร่-ค่าเดิม/ค่าใหม่ (BR-25) · แสดงใน tab ประวัติ
- **Document Center**: ไฟล์แนบผูกกับใบ + โผล่ใน **เอกสารแนบที่ landing** (Pattern Q)
- **ปี ค.ศ. ล้วน** ทุก timestamp/วันที่ ทั้งหน้าจอและ PDF (OB-14)
