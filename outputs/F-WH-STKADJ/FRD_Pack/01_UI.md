## §1.2 Per-Page Detail

### P-01: รายการใบปรับยอดสต๊อก (list + landing)
**Purpose:** ค้นหา/ติดตาม/กรองใบ + KPI + Document Center · **Pattern:** A + KPI row
**ERP shell:** Sidebar active "ใบปรับยอดสต๊อก" (module Warehouse map · Pattern N) · Breadcrumb Warehouse › ใบปรับยอด · ปี ค.ศ.
**Components:**
- KPI cards (4): `ใบรออนุมัติ` · `ใบเกินเกณฑ์อายุ` (meta "ตามเกณฑ์ NC rules") · `มูลค่าปรับสะสมเดือนนี้` (meta "จากใบที่ผ่านรายการ") · `ใบที่กลับรายการ` (meta "reversal (append-only)") — คลิก → cross-filter list
- Filter bar: เลขที่ (`q`) · คลัง · สถานะ · ประเภทการปรับ · ช่วงวันที่ (ค.ศ.) · ผู้จัดทำ · เหตุผล · ปุ่ม `ล้างตัวกรอง`
- Data table 9 cols: `เลขที่` · `คลัง` · `ประเภท` · `มูลค่าปรับ (Σ|฿|)` · `สถานะเอกสาร` · `ลายเซ็น` (n/N) · `วันที่มีผล` · `ผู้จัดทำ` · (actions kebab)
- Document Center section (landing): รวมไฟล์แนบล่าสุดทุกใบ + กรองตามใบ
- Primary action: `สร้างใบปรับยอด` → เปิด wizard

**Actions:**
| Action | Triggers | Calls (API) |
|---|---|---|
| คลิกแถว / ดูรายละเอียด | เปิด view drawer | F082-API-02 |
| สร้างใบปรับยอด | เปิด wizard | navigate `#/create` |
| filter / ค้นหา / KPI คลิก | refresh table | F082-API-01 |
| row menu ตามสถานะ | อนุมัติ/ตีกลับ/ผ่านรายการ/กลับรายการ/ยกเลิก/แก้ไข/ส่งอนุมัติ | API-05..10 (confirm ก่อน) |

**States:** Loading (skeleton) · Empty filtered ("ไม่พบรายการที่ค้นหา" + ล้างตัวกรอง) · Empty unfiltered ("ยังไม่มีใบปรับยอด" + สร้างใบปรับยอด) · Loaded · **FN:** FN-26, FN-90

### P-02: สร้าง/แก้ใบปรับยอด (wizard)
**Purpose:** สร้างใบ 5 ขั้น · **Pattern:** Q wizard + B2 v2
**Step 1 ข้อมูลใบปรับยอด:** คลัง* (combobox) · วันที่มีผล (ค.ศ.)* · ประเภทการปรับ* · ศูนย์ต้นทุน · **แหล่งที่มา** (segmented ปรับตรง/จากใบนับ → ref_count_doc combo display-only) · เหตุผลรวมของใบ (+ปุ่มเติม) · หมายเหตุ · เลขที่เอกสาร (disabled "(ร่าง — ยังไม่ออกเลขที่)") · ผู้จัดทำ (chip) · **FN:** FN-09, FN-41, FN-52
**Step 2 รายการปรับยอด (B2 v2):** grid 9 cols `# · ช่องเก็บ(bin) · สินค้า · หน่วย · ยอดระบบ · [ยอดที่ถูกต้อง|จำนวนที่ปรับ(+/−)] · ผลต่าง(ชิปเขียว/แดง) · ต้นทุนอ้างอิง · มูลค่าที่ปรับ` · segmented "โหมดกรอก" · ปุ่ม `เพิ่มบรรทัด` · totals footer (บรรทัด+/− · มูลค่าสุทธิ · **Σ ค่าสัมบูรณ์·ฐาน DOA**) · ป้าย `FWD-WIRE: valuation engine (W5)` · **FN:** FN-04..08, FN-10..13
**Step 3 เหตุผล + หลักฐาน:** เหตุผลรายบรรทัด (บังคับ · dropdown กรองตามทิศ) · คำอธิบายเพิ่ม ("อื่น ๆ") · แนบไฟล์ (`แนบเพิ่ม`) · **FN:** FN-18, FN-33, FN-37, FN-40, FN-51
**Step 4 ผู้อนุมัติ (DOA slot):** แสดง Σ|มูลค่า| → `<n> ชั้น` (ป้าย FWD-WIRE DOA engine · จุดตัด mock 20,000/200,000/1,000,000) → slot การ์ด เลือก **คนจริง** (avatar+ตำแหน่ง+ชื่อ) · **FN:** FN-14, FN-15, FN-16, FN-17, FN-42, FN-43
**Step 5 ตรวจทานและส่ง:** สรุปหัวใบ+บรรทัด+totals+สาย+ไฟล์ · ปุ่ม `บันทึกร่าง` / `ส่งอนุมัติ` · **FN:** FN-19, FN-20
**Footer:** `กลับ` · `ยกเลิก` · `ถัดไป` · `บันทึกร่าง` · `ส่งอนุมัติ`
**Actions/API:** save draft → API-03 · แก้ → API-04 · ส่งอนุมัติ → confirm modal (slot picker) → API-05
**States:** per-step validation (toast ตาม BR ดู 06_TESTS §6.10) · double-submit guard (FN-92)

### P-03: รายละเอียดใบปรับยอด (4 tabs)
**Purpose:** ดูใบเต็ม + ดำเนินการตามสถานะ · **Pattern:** Q view drawer C+H+I
- **รายละเอียด:** หัวใบ + ตารางบรรทัด (อ่านอย่างเดียวหลังส่ง) + totals + ป้ายสถานะ + `FWD-WIRE: JE posting` + `FWD-WIRE: valuation engine` + **เอกสารแนบ + ใบนับต้นเรื่อง (trace กลับ display-only)** + ปุ่มตามสถานะ · **FN:** FN-30, FN-31, FN-52
- **PDF Preview:** A4 (Pattern H) — เลขที่ · วันที่ (ค.ศ.) · คลัง · ตาราง 10 cols · totals (headline Σ ค่าสัมบูรณ์) · 3 ช่องลายเซ็น · `ดาวน์โหลด`/`พิมพ์` · **FN:** FN-34, FN-38
- **ลายเซ็น / อนุมัติ:** การ์ดผู้อนุมัติจริง (avatar+ชื่อ+ตำแหน่ง+ผล+เวลา ค.ศ.) เรียงตามชั้น + ทะเบียน DOA `DOA-WH-STKADJ` · **FN:** FN-28
- **ประวัติ:** timeline append-only ทุกเหตุการณ์ + movement + คู่ reversal · **ไม่มีปุ่มลบ** · **FN:** FN-29, FN-39, FN-45
**Header actions ตามสถานะ:** draft→แก้ไข/ส่งอนุมัติ/ยกเลิก · pending→อนุมัติ/ตีกลับ/ยกเลิก · approved→ผ่านรายการ · posted→กลับรายการ · icon: คัดลอกเลขที่/พิมพ์/ดาวน์โหลด · footer `ปิด` · **FN:** FN-21..25, FN-27

### P-04..P-07 modals
- **P-04 submit** (`openSubmitModal`): เลือกผู้อนุมัติทุก slot (คนจริง) → `ส่งอนุมัติ` → ออกเลขที่ · **FN:** FN-17, FN-20
- **P-05 approve/reject:** approve (ขั้น n/N, หมายเหตุ) → API-06 · reject (เหตุผลบังคับ) → API-07 · **FN:** FN-21, FN-22

## §1.3 User Journey (Happy Path S-07)

```
เจ้าหน้าที่คลัง → P-01 list → "สร้างใบปรับยอด"
  ↓ wizard step1 (คลัง/วันที่/ประเภท/แหล่งที่มา) → step2 (บรรทัด+ผลต่าง+มูลค่า)
  ↓ step3 (เหตุผล+หลักฐาน) → step4 (Σ|มูลค่า| → สาย DOA → เลือกคนจริง) → step5
  ↓ "ส่งอนุมัติ" (API-05) → ออกเลขที่ ADJ-YYYY-NNNN → status pending → แจ้ง slot1
ผู้อนุมัติ → P-03 → "อนุมัติ" (API-06) × ทุก slot → status approved
หัวหน้าคลัง → P-03 → "ผ่านรายการ" (API-09) → [BR-15 ตรวจยอดซ้ำ] → movement append-only + JE รอลงบัญชี → status posted
```

### Branch: ตีกลับ (S-08)
```
pending → ผู้อนุมัติ "ตีกลับ" + เหตุผล (API-07) → status draft (returned) → maker แก้ → ส่งใหม่
```
### Branch: กลับรายการ (S-10 · FIX-03)
```
posted → หัวหน้าคลัง "กลับรายการ" + เหตุผล (API-10) → สร้างใบกลับรายการใหม่ (pending)
  → วิ่งสาย DOA ตาม abs ของใบกลับรายการ → post → ต้นฉบับ = reversed + movement ทิศตรงข้าม
```
