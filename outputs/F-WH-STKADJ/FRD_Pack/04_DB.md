## §4.6 Data Classification & Sensitive Data

### §4.6.1 Levels (CUBE 4.0)
Public / Internal (default) / Confidential (จำกัด role) / Restricted (จำกัด person, ACL).

### §4.6.2 Default Rule
Default = **Internal** · ห้าม default Public · field ≠ Internal ระบุชัดใน §4.2.

### §4.6.3 Enforcement Mapping
| Classification | DB | API | UI | Audit |
|---|---|---|---|---|
| Internal | RLS (tenant) | JWT | — | mutation |
| Confidential | RLS + column ACL | role check | mask `***` ถ้าไม่ผ่าน | view + mutation |
| Restricted | — (ไม่มีใน feature นี้) | — | — | — |

### §4.6.4 PII Overlay
