1Logic — ทำงานถูกตามกฎธุรกิจ

เทียบผลจริงกับ FRD / Test Case — ข้อที่ไม่ผ่านต้องผูกกับ Bug ในข้อ 4

#กฎ / Scenarioผลที่คาดหวังผลจริงผลอ้างอิง
L-01เปิด/ดูไฟล์เอกสารแนบเปิดดูไฟล์แนบได้ (FN-33)เปิดดูไม่ได้ไม่ผ่านBUG-01
L-02พิมพ์ / ดาวน์โหลด PDF เอกสาร A4ได้ PDF/พิมพ์เอกสารจริงเต็มหน้า (FN-34 · FN-38)ดาวน์โหลดเป็น mock · พิมพ์ได้หน้าว่าง · มีข้อความ dev ค้างไม่ผ่านBUG-02
L-03กรองรายการหน้า list ตามช่วงวันที่ตารางแสดงเฉพาะใบในช่วงวันที่ที่เลือก (FN-90)คืนข้อมูลชุดเดิม ไม่กรองตามวันที่ไม่ผ่านBUG-03
L-04ฐานคิดสายอนุมัติ DOA = Σ ค่าสัมบูรณ์ (ไม่ใช่ยอดสุทธิ)ใบ +1,000,000/−1,000,000 (สุทธิ≈0) ยังต้องวิ่งชั้นอนุมัติสูงสุดตาม abs 2,000,000—ไม่ได้ตรวจBR-09 · FN-43
L-05ห้าม post ตรงจากร่าง — ต้องส่งอนุมัติเสมอปุ่ม 'ผ่านรายการ' enable เฉพาะสถานะ 'อนุมัติแล้ว'—ไม่ได้ตรวจBR-08 · FN-23
L-06SoD — ผู้อนุมัติต้องไม่ใช่ผู้จัดทำใบเดียวกันอนุมัติใบตัวเองไม่ได้ (ERR_SOD_SELF_APPROVAL)—ไม่ได้ตรวจ§5.3 SoD · BR-10
L-07post แล้วยกเลิกไม่ได้ มีแต่กลับรายการ และกลับรายการต้องวิ่งสาย DOA ก่อน (ไม่ auto-post)ใบ posted ไม่มีปุ่มยกเลิก · กลับรายการสร้างใบใหม่วิ่งอนุมัติตาม abs ตัวเอง—ไม่ได้ตรวจBR-17 · FIX-03 · FN-25
L-08ยกเลิกได้เฉพาะ ร่าง/รออนุมัติ ('อนุมัติแล้ว' ยกเลิกไม่ได้)ใบ 'อนุมัติแล้ว' ไม่มีปุ่มยกเลิก (ERR_CANCEL_NOT_ALLOWED)—ไม่ได้ตรวจBR-27 · FIX-02 · FN-24
L-09movement append-only — ไม่มีปุ่มลบ/แก้ที่ใดเลยtab ประวัติไม่มีปุ่มลบ/แก้ movement · reversal = แถวใหม่ทิศตรงข้าม ผูกคู่ 2 ทาง—ไม่ได้ตรวจBR-16 · FN-45
L-10ปรับลดจนติดลบ บล็อก / ผลต่าง=0 บล็อกยอดระบบ+ปรับ ≥ 0 (ERR_NEGATIVE_STOCK) · ผลต่าง≠0 ทุกบรรทัด (ERR_ZERO_DELTA)—ไม่ได้ตรวจBR-02/03 · FN-11/12
L-11เลขที่เอกสารออกตอนส่งอนุมัติ (ไม่ใช่ตอนร่าง)ร่างแสดง '(ร่าง — ยังไม่ออกเลขที่)' · เลข ADJ-YYYY-NNNN ออกตอนส่งอนุมัติ—ไม่ได้ตรวจBR-21 · FN-19/20
L-12ตรวจยอดซ้ำก่อน post (snapshot vs ยอดล่าสุด)ยอดเปลี่ยน → เตือน 2 ยอด ให้เลือก 'คิดจากยอดล่าสุด/ตีกลับไปแก้' ไม่ overwrite เงียบ—ไม่ได้ตรวจBR-15 · FN-27

4Bug ที่พบ

เรียงจากรุนแรงมากไปน้อย · ทำซ้ำได้ตามขั้นตอน

BUG-01เอกสารแนบเปิดดูไม่ได้Highรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดใบที่มีไฟล์แนบ
  2. ไปที่ส่วนเอกสารแนบ (Document Center หน้า list หรือ view drawer › tab รายละเอียด)
  3. กดเปิด/ดูไฟล์แนบ
ผลที่ควรเป็นเปิด/แสดงไฟล์แนบได้ (FN-33) — จำเป็นต่อการตรวจหลักฐาน โดยเฉพาะใบ 'ตัดจำหน่ายของเสีย' ที่บังคับแนบหลักฐาน (BR-23)
ผลที่เกิดจริงกดแล้วเปิดดูไฟล์แนบไม่ได้
BUG-02พิมพ์/ดาวน์โหลด PDF ยังเป็น mock — พิมพ์ได้หน้าว่าง + มีข้อความ dev ค้างHighรอแก้
ขั้นตอนทำซ้ำ
  1. เปิดใบ → view drawer → tab 'PDF Preview'
  2. กด 'ดาวน์โหลด'
  3. กด 'พิมพ์'
ผลที่ควรเป็นได้ไฟล์ PDF A4 เอกสารจริงตาม thai-doc-pdf-generator (เลขที่/วันที่ ค.ศ./ตารางบรรทัด/totals/ช่องลายเซ็น) · พิมพ์ได้เนื้อหาเต็ม (FN-34 · FN-38)
ผลที่เกิดจริงดาวน์โหลดยังเป็น mock · พิมพ์แล้วได้หน้าว่าง · มีข้อความค้างบนจอว่า 'template ตาม thai-doc-pdf-generator'
BUG-03ตัวกรองวันที่ไม่กรองข้อมูล (คืนชุดเดิม)Highรอแก้
ขั้นตอนทำซ้ำ
  1. หน้า list ใบปรับยอด
  2. ตั้งช่วงวันที่ในตัวกรอง (ค.ศ.)
  3. ดูผลลัพธ์ในตาราง
ผลที่ควรเป็นตารางแสดงเฉพาะใบในช่วงวันที่ที่เลือก (FN-90)
ผลที่เกิดจริงยังแสดงข้อมูลชุดเดิม ไม่กรองตามวันที่ — ผลลัพธ์ดูเหมือนถูกกรองแต่จริง ๆ ไม่ได้กรอง (เสี่ยงเข้าใจผิดว่าเห็นครบ)

5ข้อเสนอแนะ (ไม่ใช่ Bug)

ทำงานถูกตาม spec แล้ว แต่ควรปรับให้ดีขึ้น — ส่งต่อเป็น Enhancement ถ้าทีมเห็นด้วย

#ข้อเสนอเหตุผล
S-01เอา card เอกสารแนบ (Document Center) ออกจากหน้า listผู้ตรวจเห็นว่าไม่จำเป็น/รกหน้า list — แต่ FRD §1.2 P-01 + FN-33 กำหนดให้ Document Center อยู่บน landing โดยตั้งใจ (Pattern Q) → เป็นการเปลี่ยน scope ต้องให้ BA เคาะก่อน ไม่ใช่ให้ dev แก้เอง

6การรับรองผลตรวจ

ข้าพเจ้าได้ตรวจฟีเจอร์นี้ตามขอบเขตในข้อ 0 บน environment และ build ที่ระบุ ผลทั้งหมดมาจากการทดสอบจริง ข้อที่ระบุว่า "ผ่าน" คือได้ตรวจแล้วไม่พบปัญหา ส่วนที่ "ไม่ได้ตรวจ" อยู่นอกความรับผิดชอบของรายงานฉบับนี้
