### P-02: สร้างใบเบิก (wizard 5 ขั้น · drawer B + Stepper)
**Purpose:** สร้างใบเบิกหลายรายการผ่าน wizard ลำดับล็อก
**Pattern:** B (create drawer wide) + Stepper #47 (5 steps · สุดท้าย "ตรวจสอบและยืนยัน")

**Steps (`STEP_KEYS` L2285):**
1. **เลือกแหล่งที่มา** — radio "สร้างใหม่ (สำรองจ่ายเอง)" (checked) · "จากใบขออนุมัติเดินทาง" **disabled** (ไม่รองรับรอบนี้)
2. **ข้อมูลหลัก** — ผู้เบิก* (search-select #102 `wizemp`) → แสดง hookbox "ตำแหน่ง/แผนก/ศูนย์ต้นทุน (ดึงจากตำแหน่ง ณ วันเบิก · Movement)" (FN-06) · วันที่เอกสาร (พ.ศ.) · ช่องทางจ่าย (PAY_OPTS: ผ่านรอบเงินเดือน/โอนตรง/ใบสำคัญจ่าย PV/เงินสดย่อย F091)
3. **รายการค่าใช้จ่าย** — line editor B2 v2 (`lineEditor()` L2312): grid วันที่·หมวด(HR Config)·รายละเอียด·จำนวนเงิน·VAT segmented(ไม่คิด/VAT/รวมแล้ว NET)·รวม·ลบ · เพิ่มรายการ · totbox (รวมเป็นเงิน/VAT/รวมทั้งสิ้น) · **over-cap → panel เตือน + input เหตุผลบังคับ** (FN-04)
4. **เอกสารแนบ** — hookbox หมวดที่บังคับแนบใบเสร็จ (FN-12) · upload-zone (PDF/JPG/PNG · OCR ไม่รองรับ)
5. **ตรวจสอบและยืนยัน** — kv สรุป (ผู้เบิก/วันที่/ช่องทางจ่าย/จำนวนรายการ/ยอดรวม) · over-cap summary · **budgetHookHTML (F117 งบ + F102 สวัสดิการ · display-only)** · **advanceHookHTML (F103 หักลบทดรอง · display-only)** · สายอนุมัติ (DOA resolve ตามวงเงิน · label ช่วง)

**Step-advance gate (FN-92 · BUG-4 fix):** ขั้น 2 ต้องเลือกผู้เบิก · ขั้น 3 ต้องมี ≥1 รายการ + ยอดรวม>0 ถึงกด "ถัดไป" ได้ (`wizNext()` L2338)
**Footer:** ย้อนกลับ/ยกเลิก · "ถัดไป" (disabled จน canNext) · ขั้น 5 → "บันทึกและส่งอนุมัติ" (disabled + title เตือนเมื่อ ยอด=0 หรือ over-cap เหตุผลไม่ครบ · `openSubmit()` → P-04)
**Validate (FN-05/FN-92):** `canSubmit = grand>0 && n>0 && overCapReasonsOk` L2346

## §1.3 User Journey (Happy Path — ใบเบิกยอดเข้าสาย DOA · มีวงเงิน)

```
ผู้เบิก → #/expense (list)
  ↓ สร้างใบเบิก (wizard step1 แหล่งที่มา → step2 ผู้เบิก+cc snapshot)   [Movement resolve · FN-02/06]
step3 เพิ่มรายการ (VAT/totals · over-cap เตือน+เหตุผล)                  [ENG-EXP-01 · FN-03/04]
  ↓ step4 แนบใบเสร็จ (หมวดบังคับ) → step5 ตรวจสอบยืนยัน                 [FN-12/05 · budget/advance hook display-only]
ส่งอนุมัติ (DOA slot picker เลือกคนตามตำแหน่งแต่ละขั้น)                 [API-05 → resolve DOA · pending_approval · NTF ยื่น]
  ↓ อนุมัติแต่ละขั้น (1–3 ขั้น ตามวงเงิน)                              [API-06 · chain advance ทีละขั้น]
อนุมัติครบสาย → ออกเลข EXP-2569-NNNN + PDF + 7C (FC/EC)               [API-06 final · FN-11/22/23 · NTF ผล]
  ↓ เลือก/ยืนยันช่องทางจ่าย → ส่งจ่าย (hook) + หักลบทดรอง F103         [API-10 · FN-12/16 · display-only]
สถานะ "จ่ายแล้ว" อ่านจากปลายทาง                                        [API-11 · display-only จาก Payroll/Finance]
```
