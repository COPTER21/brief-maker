# Promotion — Final Handoff Pack

ชุดเอกสารพร้อมส่งต่อของ Feature F-SALES-PROMO Promotion จัดหมวดตามลำดับการอ่าน

1. `00_context/` — PREBRIEF และ FUNCTION CHECKLIST ต้นทาง
2. `01_prototype/` — HTML source of truth ที่ PM/BA อนุมัติ
3. `02_qc/` — รายงาน UX, coverage สองรอบ, AI review และ UAT selection
4. `03_brd/` — BRD Markdown และ DOCX
5. `04_frd/` — FRD Pack แบบ FULL
6. `05_ui-brief/` — UI handoff สำหรับ dev
7. `testcase_qa/` — AI test cases ฉบับเต็มและ QA-friendly/UAT HTML สำหรับ tester
8. `08_tldr/` — สรุปฟีเจอร์อ่านง่าย
9. `09_declarations/` — DOA declaration แบบไม่มีวงเงินและอนุมัติตามลำดับ
10. `10_handoff/` — ข้อเสนอเชื่อมต่อและรายการงานของ feature อื่นในอนาคต

## Scope note

- Promotion ใช้ได้กับทุกลูกค้า กลุ่มลูกค้า หรือช่องทาง แต่ไม่เจาะลูกค้ารายคน
- การตรวจสินค้าคงเหลือเกิดที่ Sales Order ไม่ใช่ Promotion
- จำนวนครั้งใช้จริงนับจาก Invoice
- Campaign Management เป็นการเชื่อมต่อในอนาคตและยังไม่อยู่ในรอบนี้
- Quotation, Sales Order และ Invoice ยังไม่มีเอกสารต้นทางในรอบที่ทำแพ็กนี้ จึงระบุไว้เป็นสัญญาเชื่อมต่อสำหรับทีมพัฒนาต่อ

Raw results, screenshots, capture data และ build scripts อยู่ภายนอก pack ที่ `test-artifacts/15_Promotion/`
