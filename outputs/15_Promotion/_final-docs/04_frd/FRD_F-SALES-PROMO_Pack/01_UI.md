## §1.4 P-03 Create/Edit Wizard

### Step 1 — ชนิดและขอบเขต

- promotion type segmented choice (one of four)
- name, description, owner, validity, scope and multi-reference
- coupon, priority, exclusive, stack TA, quotas, budget, GL
- changing type clears incompatible rule fields

### Step 2 — เงื่อนไข

| Type | Editor |
|---|---|
| LINE_DISC | target/ref, percent or amount, value, minimum base quantity |
| FREE_GOODS | buy/get product, UOM, quantity, repeat |
| THRESHOLD | add/remove ascending tiers |
| BUNDLE | add/remove unique items, quantities/UOM, bundle price, repeat |

### Step 3 — ตรวจสอบและยืนยัน

- summary of all inputs, human-readable rule, DOA summary
- overlap note lists conflicting code/priority/exclusive
- footer: “กลับ”, “บันทึกร่าง”, “บันทึกและส่งอนุมัติ”/equivalent AS-BUILT text

Validation uses inline `.field-error` plus toast “กรุณากรอกข้อมูลให้ครบถ้วน”. Input focus must remain stable during rerender.

## §1.7 Overlay / Keyboard Contract

- Overlay stack: master combobox portal above drawer/modal; modal above drawer; toast above all
- Esc order: close open combobox → modal → drawer; no hidden layer remains interactive
- Backdrop closes only the top dismissible overlay; click inside modal stops propagation
- Opening an overlay moves focus to first actionable/input; closing returns focus to trigger in production
- Body scroll locked while drawer/modal open; menu itself remains scrollable
