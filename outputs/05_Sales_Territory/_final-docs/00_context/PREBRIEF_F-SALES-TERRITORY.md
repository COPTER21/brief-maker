## 1. สรุป + ผู้ใช้ + สิทธิ์

**ทำอะไร** — ทะเบียนเขตขาย (Route): ผู้ดูแลสร้าง/แก้เขต กำหนดประเภท · ภาค (8 ทิศ) · จังหวัด (ไม่บังคับ) · พนักงานขายผู้รับผิดชอบ (1 คน/เขต) · จำนวนร้านในเขตจาก survey (universe) — แล้วดูภาพรวม coverage ต่อเขต และภาระงานของพนักงานขายแต่ละคน [แผน]

**ไม่ทำอะไร** — ไม่สร้าง/แก้ข้อมูลพนักงานขาย (อยู่ Sales Team / Salesperson) · ไม่แก้จำนวนลูกค้า/ยอดขาย (มาจาก Customer + Sales Order) · ไม่มีแผนที่ในรอบนี้ · ไม่มีอนุมัติ (DOA) [มติ]

| Role | เห็นอะไร | ทำอะไรได้ |
|---|---|---|
| ผู้ดูแลโมดูลขาย (Sales Admin) | ทุกแท็บ | สร้าง · แก้ · เก็บเข้าคลัง · กู้คืน |
| หัวหน้าขาย / ผู้จัดการเขต | ทุกแท็บ | ดู · (แก้ได้ไหม → OQ-02) |
| พนักงานขาย | อาจเห็นเฉพาะเขตตัวเอง [AI-DRAFT] → OQ-02 | ดูอย่างเดียว |
| ผู้ดูแลระบบ | ทุกแท็บ | เท่า Sales Admin |

### 3.2 แหล่งตัวเลือก (soft reference)
- **พนักงานขาย** ← Sales Team / Salesperson master (sprint ถัดไป) · field ที่ใช้: `id · name · team · role · cap` · BACKEND `GET /api/sales/salespersons?status=active` · ตอนนี้ mock ในไฟล์ตาม contract นั้น · ปลายทางเก็บ `salesperson_id` (soft ref)
- **จังหวัด** ← system geo dataset 77 จังหวัด · BACKEND `GET /api/system/geo/provinces` (ตามมติตัด Address Master — seed ตอน install)

### 3.3 Computed / แสดงอย่างเดียว (มาจากปลายทาง — read-only)

| Utilization | งาน/เดือน ÷ capacity ของพนักงานขาย | computed · capacity จาก Salesperson |

### 3.4 Config ที่หน้านี้อ่าน
- capacity ต่อบทบาท (GT 220 · Key Account 20 · B2B 30 งาน/เดือน) — [AI-DEFAULT] mock ในไฟล์ · ปลายทางควรมาจากโปรไฟล์บทบาทใน Salesperson master → OQ-06
- เกณฑ์ coverage สี (≥25% เขียว) — [AI-DRAFT] → OQ-04

### 3.6 แผนที่ (geo dataset — offline)
- **THMAP** = SVG paths + centroid 77 จังหวัด ฝัง inline (แปลงจาก GeoJSON ราชการ · ~56KB) — ไม่มี CDN/leaflet (กติกา single-file offline) · [AI-DEFAULT] ตอน dev อาจย้าย geo ไป static asset ร่วมของระบบ → OQ-12
