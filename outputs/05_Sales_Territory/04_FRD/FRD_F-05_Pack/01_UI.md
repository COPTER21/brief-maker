## §1.2 P-01 Anatomy and States

### Header and tabs

- Title/subtitle and primary button text: `สร้างเขต`.
- Tabs verbatim: `โครงสร้างเขต`, `ภาระงาน`, `แผนที่`.
- Tab change updates only page state; route remains `#/sales-territory`.
- Structure content extends document height; vertical scroll belongs to outer page, not a nested list box.

### S-01 Structure

| UI action | Expected behavior | API |
|---|---|---|
| Search input `ค้นหา รหัส / ชื่อ / จังหวัด / พนักงานขาย` | debounce/cancel stale request; match code/name/province/rep | API-01 |
| Status dropdown | filter Active/Archived per observed choices | API-01 |
| `ล้างตัวกรอง` | reset query and status to HTML default | API-01 |
| Click row | open S-06 | API-02 |
| Row `แก้ไข` | open S-05 with code locked | API-02 then API-04 |
| `เก็บเข้าคลัง` | open S-07 | API-05 on confirm |
| `กู้คืน` | restore archived Route | API-06 |
| `สร้างเขต` | open S-04 | API-03 on confirm |

States:

- Loading: table/list skeleton without moving header/tabs.
- Loaded: rows and count/KPI derived only from returned owned fields.
- Filter empty text exactly: `ไม่พบ Route` + `ลองเปลี่ยนคำค้นหรือตัวกรองสถานะ` + `ล้างตัวกรอง`.
- API error: preserve filters and offer retry; generic fallback text must follow current central microcopy, not replace HTML-specific approved text.
- 403: hide mutation actions and show access-denied state; Manager/Salesperson behavior awaits OQ-02.

### S-02 Workload

- Keep the approved mock/read-only cards/table and source labelling.
- No call to Customer/Sales Order/Target/Visit/Salesperson module in current release.
- When data provider is absent, core list/create/edit/archive/restore remains usable.
- Coverage threshold, capacity and formula are prototype `[AI-DEFAULT]`; never persist them as business truth before OQ-04/OQ-06.

### S-03 Map

- Render from versioned local geo asset; external map service is not a critical dependency.
- Interactive target must be a valid province/pin inside the visible map canvas.
- Pointer outside all sides/corners of the canvas, including the side list, produces no hover, tooltip, selection or state mutation.
- Asset missing/corrupt shows a contained error state while S-01 remains usable `[AI-DEFAULT]` (OQ-19).

### S-04/S-05 Create/Edit drawer

Fields extracted from HTML:

| Field | UI behavior | API field/rule |
|---|---|---|
| รหัส Route | required; create editable; edit disabled/immutable | `route_code`, BR-ST-04/05 |
| ชื่อ Route | required | `route_name` |
| ประเภท Route | required dropdown | `route_type`, OQ-07 |
| ภูมิภาค | required | `region` |
| จังหวัด | optional searchable master combobox | `province_code`; blank allowed |
| พนักงานขาย | optional searchable future/mock combobox | `salesperson_ref`; no hard FK |
| ร้านในเขต (universe) | optional editable non-negative integer/blank | `universe`, OQ-05 |

Interaction contract:

- Open focuses first enabled field.
- Master combobox supports typing, wheel scroll, Up/Down, Enter, Esc, clear and outside click; overlay is portalled and must not be clipped.
- Esc closes combobox first, then drawer. Backdrop/X also close; edit cancel returns to view drawer when opened from view.
- Create footer: `ยกเลิก` + `ยืนยันสร้าง`; edit footer: `ยกเลิก` + `บันทึกการแก้ไข`.
- Submit state exactly `กำลังบันทึก…`; invalid required fields toast exactly `กรุณากรอกข้อมูลให้ครบถ้วน`.
- Success messages exactly `สร้างเขตสำเร็จ` and `บันทึกการแก้ไขแล้ว`.
- On 409 stale conflict `[AI-DEFAULT]`, keep drawer values and request reload; exact new conflict copy is an OQ and must not be hardcoded silently.

### S-06 View drawer

- Read-only owned fields and audit summary.
- Footer button exactly `ปิด`; header actions `แก้ไข`, `เก็บเข้าคลัง` for authorized Active rows.
- Buttons `ดูลูกค้าในเขต (...)` and `แผนเยี่ยมในเขต` remain labelled future/mock hooks; current click may show the existing warning toast but must make no runtime integration call.
- Existing warning text is HTML evidence, not a promise that target modules exist.

### S-07 Archive modal

- Title exactly `เก็บ Route เข้าคลัง`.
- Body names the Route and explains exclusion from new documents/workload, history snapshot preservation and reversibility.
- Buttons: `ยกเลิก`, `เก็บเข้าคลัง`; X/backdrop/Esc dismiss without mutation.
- Confirm calls API-05 once with idempotency protection; success text follows HTML dynamic form `เก็บ Route {code} เข้าคลังแล้ว`.
- Restore success text follows HTML `กู้คืน Route {code} แล้ว`.

## §1.3 Journey

```text
Open #/sales-territory
  → S-01 list/search/filter
  → create S-04 → validate → API-03 → close → "สร้างเขตสำเร็จ"
  → click row → S-06
       → edit S-05 → API-04 → return S-06 → "บันทึกการแก้ไขแล้ว"
       → archive S-07 → API-05 → close overlays → archived row
  → archived row → restore API-06 → active row
  → S-02/S-03 remain read-only and resilient when future providers are absent
```
