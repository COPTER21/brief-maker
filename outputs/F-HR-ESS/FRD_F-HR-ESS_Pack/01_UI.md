## §1.2 Per-Page Detail

### P-01: หน้ารวมของฉัน (dashboard · tab `home`)
**Purpose:** สรุป read จากหลาย surface + จุดเริ่มยื่นคำขอ. **Pattern:** J1. **FN:** FN-01.
**Components:**
- **self-banner** (`.self-banner`) — "คุณกำลังดูข้อมูลของตนเอง (**<ชื่อ · id>**) — ข้อมูลส่วนตัว/เงินเดือนแสดงเฉพาะของคุณเท่านั้น" (self-scope · SecC)
- **launcher card** — "ต้องการยื่นคำขอใช่ไหม?" + ปุ่ม primary "ยื่นคำขอ" → `openModal('actionPicker')`
- **5 qcards** (`.qgrid`): สลิปล่าสุด (→ `openView('payslip',last.id)`) · โควตาลาคงเหลือ (→ `goTab('pay')`) · OT เดือนนี้ (→ `goTab('pay')`) · ใบเบิกค้าง (→ `goTab('docs')`) · แจ้งเตือน (+ badge unread → `goTab('notify')`)
- **ทางลัดของฉัน** section — พนักงาน/แผนก-สาขา + ปุ่ม "ดูโปรไฟล์ของฉัน" → `openView('profile',EMP.id)`
**Actions:**
| Action | Trigger | Calls |
|---|---|---|
| เปิด action-picker | ปุ่ม "ยื่นคำขอ" (header + launcher) | `openModal('actionPicker')` (M-01) |

| ดูโปรไฟล์ | "ดูโปรไฟล์ของฉัน" | `openView('profile',EMP.id)` (D-02) → API-06 |

**Purpose:** ใบเบิก+ยื่นเบิก (FN-05) · หนังสือรับรอง+ขอ (FN-06) · สวัสดิการ/อบรม (FN-07) · โปรไฟล์+ขอแก้ (FN-08). **Pattern:** A.

### P-04: แจ้งเตือน (tab `notify`)

## §1.3 User Journey (COSO-aware · display-only)

```
1. login → หน้ารวมของฉัน (P-01, 5 การ์ดสรุป read)          [System serve read · Employee view]
2. สลับแท็บ home/pay/docs/notify                            [Employee view]
3. แตะการ์ด/แถว → drawer อ่านรายละเอียด (read-only)          [System serve read]
4. กด "ยื่นคำขอ" → action-picker (M-01) เลือกประเภท          [Employee]
5. เลือกประเภท → navigate OUT ไปหน้า owner feature           [Maker/Checker/Approver = owner feature]
   (form/submit อยู่ที่นั่น — ESS ไม่รับคำขอ)
6.(Exception) เข้าถึงข้อมูลคนอื่น → ปิดบัง + 403 (M-02)       [System guard]
```
**Alternative:** ดูสลิปย้อนหลัง/YTD (read · self · all-or-nothing) · ดูตารางกะ (read) · ค้น/กรอง feed · ดู access-audit ใน profile drawer (FN-93).

## §1.6 Overlay / z-index / Esc chain (BASE-KIT · ห้ามแก้)
- z-scale: shell 20 · sticky 30 · dropdown 40 · backdrop 50 · drawer 55 · portal 60 · toast 90 (`:root --z-*`).
- Esc chain: Esc ปิด overlay ชั้นบนสุดก่อน (drawer/modal) · `trapFocus`/`lockScroll`/`releaseFocus` (a11y).
- DSP-01/DSP-02 precedent: action-picker เปิด **ทับ** profile drawer ได้ (deep-link "ขอแก้ข้อมูล" ใน D-02) — layering ต้องถูก (modal เหนือ drawer). render preservation (#29) คง scroll/focus ข้าม re-render.
