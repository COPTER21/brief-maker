# F-VENDOR — Final Documentation Pack

ชุดเอกสารส่งมอบสำหรับ AI Coding Agent ใช้ implement ฟีเจอร์ทะเบียนคู่ค้า โดยไม่มี codebase ระบบจริงใน scope

## ลำดับการอ่าน

1. `vendor.html` — HTML prototype และ UI source of truth
2. `FRD_F-VENDOR_Pack/INDEX.md` — จุดเริ่มอ่าน FRD Pack
3. `UI_BRIEF_F-VENDOR.md` — รายละเอียด UI ที่สกัดจาก HTML
4. `testcases-F-VENDOR.md` — Test Case สำหรับ AI/browser-use และ integration runner
5. `testcase-F-VENDOR.html` — แบบทดสอบฉบับผู้ใช้ เปิดใน browser ได้ทันที

## หมายเหตุ

- เอกสารในโฟลเดอร์นี้เป็นชุดส่งมอบเดียวกันและต้องควบคุมเวอร์ชันร่วมกัน
- ไม่มีเอกสาร PDF ธุรกรรมใน scope ของ F-VENDOR
- Open Questions สำหรับ production integration อยู่ใน `FRD_F-VENDOR_Pack/00_OVERVIEW.md`
- ไฟล์ HTML ทั้งสองไฟล์เป็น self-contained และเปิดใช้งานจากโฟลเดอร์นี้ได้โดยตรง
