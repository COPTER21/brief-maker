# PROPOSALS outbound — F-WH-PACK Packing

## สรุป

ไม่มีการแก้ artifact ของ feature อื่นในรอบนี้ และไม่มีข้อเสนอที่ถือเป็น contract ที่อนุมัติแล้ว

## เรื่องที่ต้องส่งให้เจ้าของ feature อื่นพิจารณา

### Delivery Note

- ขอให้เจ้าของ Delivery Note ยืนยันข้อมูลรับเข้าจากงานแพ็คที่เสร็จแล้ว ได้แก่ ใบขายต้นทาง กล่อง น้ำหนัก ป้ายกล่อง และรายการสินค้าตามกล่อง
- ขอให้ยืนยันผลสำเร็จ/ล้มเหลว การลองใหม่ และจุดเวลาที่ถือว่าออกใบส่งของแล้ว
- จนกว่าจะได้คำตอบ ปุ่ม “ออกใบส่งของ” ใน HTML เป็น mock เท่านั้น และ FRD ปิด adapter จริงไว้

### Transfer

- ขอให้เจ้าของงานโอนระหว่างคลังยืนยันว่ามีเส้นทาง Picking → Packing หรือไม่ และยืนยันข้อมูลอ้างอิงต้นทางถ้ามี
- รอบนี้ยึด Picking final ที่รองรับ source SO เท่านั้น จึงไม่รับ Transfer เป็น contract จริง

### Shared UI tooling

- `html-ui-brief` ระบุให้ตรวจด้วย `ui-brief-check.py --verify` แต่ไม่พบสคริปต์ดังกล่าวใน workspace
- ไม่ได้สร้าง checker ทดแทน เพราะกติกาโครงการให้ใช้ shared checker เท่านั้น ควรเพิ่มเครื่องมือกลางก่อนรอบตรวจถัดไป

## ไม่เสนอแก้

- ไม่เสนอแก้ HTML ต้นทาง เพราะ PM/BA ให้ใช้ `f-wh-packing.html` ตามสภาพและผู้ใช้ waive UX gate แล้ว
- ไม่เสนอ DOA หรือ Document Configuration เพราะผู้ใช้เลือกข้ามทั้งสอง declaration
