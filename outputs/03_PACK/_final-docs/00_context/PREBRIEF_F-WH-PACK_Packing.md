## 1. สรุป + ผู้ใช้ + สิทธิ์
**ทำอะไร** [มติ] — รับของจากใบหยิบที่หยิบเสร็จ (แตกงานต่อ SO) → เปิดใบแพ็ค → **เลือกกล่องจาก list** → **ใส่สินค้าลงกล่อง** (สแกน/คลิก/ปุ่มทั้งหมด · เห็นจำนวนคงเหลือตลอด) → **ชั่งน้ำหนัก + ปิดกล่อง (ติดป้าย)** → เปิดกล่องใหม่จนครบ → **ปิดงานแพ็ค** → พิมพ์ป้ายกล่อง + ใบแพ็ค → **ออกใบส่งของ (DN)** · แก้ไขกล่อง (reopen) · ยกเลิก (งานกลับคิว) · ทางลัด: แพ็คทั้งใบลงกล่องเดียว / แบ่งกล่องอัตโนมัติตามความจุ

**หน้าจอ** — list 2 แท็บ (คิวรอแพ็ค / ใบแพ็ค) · modal งานจากใบหยิบ · landing 4 แท็บ: **กล่องและรายการ** (workspace) / รายละเอียด·อ้างอิง / **ป้ายกล่อง·ใบแพ็ค** / ประวัติ · modal: กล่องกำหนดเอง · ยกเลิก

| Role | ทำอะไรได้ |
|---|---|
| หัวหน้าคลัง (`wh_lead`) | เริ่มแพ็คทุกงาน · แก้ไขทุกใบ · reopen กล่อง/ใบ · ออกใบส่งของ · ยกเลิก |
| พนักงานคลัง (`picker/packer`) | เริ่มแพ็ค · ทำงานเฉพาะใบที่ตนเปิด/ถูกมอบหมาย · ปิดกล่อง · ปิดงานแพ็ค · ยกเลิกใบของตน |
| Sales / อื่น | ดูอย่างเดียว (ไม่มีปุ่มเริ่มแพ็ค) |

## 5. State Machine
`(คิวรอแพ็ค)` → `กำลังแพ็ค` → `แพ็คเสร็จ · รอส่ง` → `ออกใบส่งของแล้ว` · แขนง: `ยกเลิก` (ก่อน DN → กลับคิว)
| จาก | ไป | ใครกด | เงื่อนไข |
|---|---|---|---|
| คิว | กำลังแพ็ค | หัวหน้าคลัง/พนักงาน | เริ่มแพ็ค (ยังไม่มีกล่อง) |
| กำลังแพ็ค | แพ็คเสร็จ | ผู้แพ็ค | คงเหลือ=0 + ไม่มีกล่องเปิด |
| แพ็คเสร็จ | กำลังแพ็ค | หัวหน้าคลัง | แก้ไขกล่อง (ก่อน DN) |
| แพ็คเสร็จ | ออกใบส่งของแล้ว | หัวหน้าคลัง | ออก DN → SO shipped |
| กำลังแพ็ค/แพ็คเสร็จ | ยกเลิก | ผู้แพ็ค/หัวหน้า | เหตุผล · ก่อน DN |
สถานะกล่อง: เปิดอยู่ (active) → ปิดแล้ว (ล็อก+ป้าย) ⇄ เปิดแก้ไข · สถานะขั้นตอน (stepper): ① เปิดกล่อง ② ใส่สินค้า ③ ชั่ง·ปิดกล่อง ④ ปิดงานแพ็ค
