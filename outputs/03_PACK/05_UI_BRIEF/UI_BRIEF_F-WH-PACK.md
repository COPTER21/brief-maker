## 4. Page Anatomy

### 4.1 Packing list (`#/list`)

Header/count/actions → queue/packs tab → search/filter controls → table rows/progress/actions. Queue row opens source detail and start action. Packs row opens detail. Export is visible in pack list. Backing anchors: list/render helpers and mock `PICKS`, `PACKS`, `PERSONAS` around lines 820–951.

### 4.2 Queue detail overlay

Identity: Pick no., source type/ref, customer/destination, warehouse, picker/time, item/piece counts, due/priority/pickup. Body lists item/lot/expiry/location/picked qty. Primary action “เริ่มแพ็ค” invokes `startPack(jobId)` line 1003.

### 4.3 Packing workspace

- Header identity/status/action changes by `pack.status` and `canPack`.
- Tabs: “กล่องและรายการ”, “รายละเอียด·อ้างอิง”, “ป้ายกล่อง·ใบแพ็ค”, “ประวัติ”.
- In-progress tab: four-step progress; left remaining list; right scanner/active carton; closed-carton section; shortcuts.
- Non-in-progress: summary strip + closed carton table; mutation widgets removed.

### 4.4 Print tab

Visible band at line 1133 states label count/150×100 and PACKSLIP A4. Buttons: “พิมพ์ป้ายกล่อง”, “พิมพ์ใบแพ็ค”. Backend binding must use API-14/15 and `06_PRINT` templates instead of the prototype mock/window-only action.

### 4.5 History tab

Reverse chronological audit entries sourced from append-only backend read model. Prototype `pushAudit` messages are presentation examples; production audit code/action IDs are authoritative.

### 4.6 Modals

Custom carton: name + tare; cancel/reopen style uses `reasonModal` line 998 and requires reason. Modal footer uses “ปิด” plus action label supplied by caller.

## 7. Interaction Spec

### 7.1 Esc chain

Global key handler line 967: modal first, then view drawer. Production must extend this with dropdown/tooltip topmost handling per central kit without changing business outcome.

### 7.2 Keyboard/focus

- F3: open carton only when none active; otherwise toast “ปิดกล่องปัจจุบันก่อน (F2)”.
- F2: close active carton.
- Ctrl/Cmd+Z: `undoLast`, except normal input contexts per handler.
- Enter in scan: call `scanAdd`; blank Enter closes non-empty active carton, otherwise guidance toast (lines 1183–1184).
- Scanner should keep/restore focus after operation; rerender must not drop typed value unexpectedly.

### 7.3 Mutation feedback

Disable repeated submit while pending; use result toast only after response. 409 stale must prompt refresh/reconcile, not silently overwrite. 503 print/DN preserves pack state and offers retry.
