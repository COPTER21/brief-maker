## §1.2 Per-Page Detail

### P-01: ทะเบียนรหัสภาษี (List) — Pattern A

**Purpose:** จุดเข้าหลัก — ค้นหา/กรอง/ดู/บริหารรหัสภาษีทั้งหมด
**Components (canonical):** Page Header (`.ph` title + `.ph-count` "N รายการ") · Stat cards ×4 (`.stat` กดกรองเร็ว) · Filter Bar (search + 2 select + ล้างตัวกรอง) · Data Table (`.utbl` sortable) · Bulk Bar (เมื่อ select ≥1) · Table Footer + Pager

**Table columns (verbatim จาก HTML `renderList`):** checkbox · `รหัส` (`cell-code`, ไม่มี icon) · `ชื่อรหัสภาษี` (name_th + name_en) · `อัตรา` (ta-r, `{rate}%`, sort เชิงตัวเลข) · `ประเภท` (`.type-pill` catLabel) · `ใช้ในสินค้า/เอกสาร` (ta-r, `{used} รายการ`, sort เชิงตัวเลข) · `สถานะ` (`.pill` is-active/is-inactive/is-draft) · `จัดการ` (ปุ่ม `แก้ไข` เท่านั้น — **ไม่มีลบเดี่ยว**)

**Stat cards (4):** `รหัสภาษีทั้งหมด` (total) · `ใช้งานอยู่` (active) · `ไม่ใช้งาน` (inactive) · `ร่าง` (draft) — คลิก toggle filter (กดซ้ำยกเลิก, `quickFilter`)

**Actions:**
| Action | Trigger (verbatim) | Calls (API) |
|---|---|---|
| โหลด/กรอง/sort/หน้า | `onSearch` / `onFilter` / `quickFilter` / `sortBy` / `goToPage` | F-TAX-API-01 GET /tax-codes |
| คลิกแถว | `openView(id)` → drawer | F-TAX-API-03 GET /tax-codes/:id |
| คลิก `แก้ไข` | `openEdit(id)` | F-TAX-API-03 (โหลด) → F-TAX-API-04 (save) |
| `สร้างรหัสภาษี` | `openCreate()` | → P-02 → F-TAX-API-02 |
| `ส่งออก CSV` | `exportCSV()` | F-TAX-API-09 GET /tax-codes/export |
| `นำเข้า CSV` | `bulkImport()` | → P-05 → F-TAX-API-08 |
| checkbox → bulk bar | `toggleSel`/`toggleSelPage` → `bulkSetStatus`/`openBulkDelete` | F-TAX-API-06 / F-TAX-API-07 |

**States:** Loading (mock 600ms loader บน save) · **Empty (no data)** title `ยังไม่มีรหัสภาษีในระบบ` desc `เริ่มต้นด้วยการสร้างรหัสภาษีแรกเข้าสู่ทะเบียน` + ปุ่ม `สร้างรหัสภาษี` · **Empty (filtered)** title `ไม่พบรหัสภาษีที่ตรงกับตัวกรอง` desc `ลองปรับคำค้นหรือล้างตัวกรองเพื่อดูรายการทั้งหมด` + ปุ่ม `ล้างตัวกรอง` · Loaded (table)

### P-02 / P-03: สร้าง / แก้ไขรหัสภาษี — Pattern B (drawer 680)

**Purpose:** ฟอร์มเดียว create/edit (`formHTML(mode,r)`)
**Fields (form-grid 2-col, verbatim label):**
| Field | Label UI | Control | เงื่อนไข |
|---|---|---|---|
| code | `รหัสภาษี` | text `#in-code` placeholder "เช่น VAT7" | เว้นว่าง=auto · **disabled + lock-tag เมื่อ used>0** |
| rate | `อัตรา (%)` * | text inputmode numeric `#in-rate` | **exempt→"0" disabled + tag "ยกเว้นภาษี = อัตรา 0"** · **disabled + lock-tag เมื่อ used>0** |
| name_th | `ชื่อ (ไทย)` * | text `#in-name-th` | required |
| name_en | `ชื่อ (อังกฤษ)` | text `#in-name-en` | optional |
| category | `ประเภทภาษี` * | select `#in-category` (vat/wht/exempt) `onchange=onTypeChange` | default vat · **disabled + lock-tag เมื่อ used>0** |
| status | `สถานะ` | select `#in-status` (draft/active/inactive) | default create = active |

**Lock behavior (IR-TAX-01):** `locked = isEdit && used>0` → code/rate/category `disabled` + `.lock-tag` "ล็อก — ถูกใช้งานแล้ว". name_th/name_en/status ยังแก้ได้.
**Footer:** `ยกเลิก` (ghost) · **create** = `ยืนยันสร้าง` / **edit** = `บันทึกการแก้ไข` (primary, icon check). Save → loader `กำลังบันทึก…` (กัน double-submit). **ไม่มีข้อความ hint ใต้ช่อง** (FN-04) — มีได้เฉพาะ lock-tag + error line.

### P-04: รายละเอียดรหัสภาษี — Pattern C (view drawer tabbed)

**Header:** avatar(initials) · eyebrow `รหัสภาษี · {code}` · title name_th · subtitle status pill + catLabel · actions: `แก้ไข` + `เปลี่ยนสถานะ` (dropdown `.status-menu`) + close.
**Status menu (`เปลี่ยนสถานะเป็น`):** 3 ค่า (draft/active/inactive); ค่าปัจจุบัน `disabled` + mark `ปัจจุบัน` — เปลี่ยนทันทีทุกทิศ (`setStatus`), ไม่มี gate.
**Tabs:** `ภาพรวม` (def-grid: รหัส/อัตรา/ชื่อไทย/ชื่ออังกฤษ/ประเภท/สถานะ) · `การใช้งาน` (badge count `{used}`; แสดง "จำนวนที่ถูกอ้างอิง: {used} รายการ" — **ไม่มีแถว "ลบออกจากทะเบียน"**, FN-23) · `ประวัติ` (timeline: แก้ไขล่าสุด {updated_by·date} / สร้างรายการ {created_by·date}, FN-93)
**Footer:** meta `แก้ไขล่าสุด {date}` + `ปิด`.

### P-05: นำเข้ารหัสภาษีจากไฟล์ — Pattern D (modal wide 640, 3-step)

**Header:** icon `upload` · title `นำเข้ารหัสภาษีจากไฟล์` · desc `CSV / Excel — ระบุสถานะได้ในไฟล์`.
**Step `pick`:** upload-box `เลือกไฟล์ CSV / Excel` + สถานะไฟล์ (`ยังไม่ได้เลือกไฟล์` / `ไฟล์ที่เลือก: {name}`) · footer ปุ่ม `ดาวน์โหลด template ตัวอย่าง` (→ `taxcode_import_template.csv`) + `ปิด`. **จอแรกไม่มีข้อความอธิบายคอลัมน์** (FN-16). Preview เกิดเฉพาะเมื่อเลือกไฟล์จริง (`bulkFileChosen` ตรวจ `input.files[0]`).
**Step `preview`:** สรุป `ตรวจแล้ว {n} แถว — นำเข้าได้ {ok} · ติดปัญหา {err} (แถวผิดจะถูกข้าม)` · ตารางรายแถว (รหัส/ชื่อ/ประเภท/อัตรา/สถานะ/ผลตรวจ) ผลตรวจ = `พร้อมนำเข้า` หรือ error 1 ใน 6 codes (verbatim ดู 05_RULES §5.6) · footer `ยกเลิก` + `นำเข้า {ok} แถว` (disabled ถ้า ok=0).
**Step `done`:** `นำเข้าเสร็จ {ok} รายการ (สถานะตามไฟล์)` (+ ตารางแถวที่ข้ามถ้ามี) · footer `ปิด` → list+stat อัพเดต (FN-19).

---

### P-06: ยืนยันลบ bulk — Pattern D (modal 440 confirm)

**Header:** icon `trash-2` · title `ลบรหัสภาษี {n} รายการ?` · desc: ถ้ามี used>0 → `มี {used} รายการถูกอ้างอิงในสินค้า/เอกสาร — จะถูกข้าม ไม่ลบ` มิฉะนั้น `การกระทำนี้ย้อนกลับไม่ได้`.
**Footer:** `ยกเลิก` (ghost) + `ลบ {n-used} รายการ` (danger).

## §1.3 User Journey (Happy Path — S-01 สร้างรหัสภาษี)

```
บัญชี เปิด #/tax-codes (P-01 list)
  ↓ กด "สร้างรหัสภาษี" → openCreate() → drawer P-02
กรอก ชื่อไทย* + ประเภท* + อัตรา* (รหัสเว้นว่าง=auto)
  ↓ (exempt → rate ล็อก 0)
กด "ยืนยันสร้าง" → saveUnit('create')
  ↓ validate (name/rate/dup) → loader "กำลังบันทึก…" → API F-TAX-API-02 POST /tax-codes
ปิด drawer → toast "สร้างรหัสภาษี \"{name}\" สำเร็จ" → list refresh (page=1)
  ↓
รหัส active โผล่ให้ Item Master/เอกสารเลือก (F-TAX-API-10 lookup, BR-07)
```

### Branch: แก้ไขตัว used>0 (S-04)
```
คลิก "แก้ไข" (P-03) → code/rate/category disabled + lock-tag "ล็อก — ถูกใช้งานแล้ว"
  ↓ แก้ได้เฉพาะ ชื่อ/สถานะ → "บันทึกการแก้ไข" → F-TAX-API-04 PUT
  server guard (F-TAX-FN-03): คงค่า code/rate/category เดิมเสมอแม้ payload ฝืนส่ง (EC-07)
  ↓ toast "บันทึกการแก้ไข \"{name}\" แล้ว"
```

## §1.6 Empty States & Errors (UI)

| State | UI behavior (verbatim จาก HTML) |
|---|---|
| No data | `ยังไม่มีรหัสภาษีในระบบ` / `เริ่มต้นด้วยการสร้างรหัสภาษีแรกเข้าสู่ทะเบียน` + ปุ่ม `สร้างรหัสภาษี` |
| Filtered empty | `ไม่พบรหัสภาษีที่ตรงกับตัวกรอง` / `ลองปรับคำค้นหรือล้างตัวกรองเพื่อดูรายการทั้งหมด` + ปุ่ม `ล้างตัวกรอง` |
| Validation: ชื่อไทยว่าง | field has-err + `กรุณากรอกชื่อภาษาไทย` |
| Validation: รหัสซ้ำ | field has-err + `รหัส {code} ถูกใช้แล้ว` |
| Validation: อัตราผิด | field has-err + `กรุณากรอกอัตรา 0–100` |
| API 403 (production) | "คุณไม่มีสิทธิ์เข้าถึงส่วนนี้" (deferred OQ-TAX-06) |
| API 5xx (production) | "เกิดข้อผิดพลาด กรุณาลองใหม่" (microcopy กลาง) + retry |
