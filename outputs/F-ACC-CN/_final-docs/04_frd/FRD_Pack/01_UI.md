## §1.2 Per-Page Detail

### P-01: รายการใบลดหนี้ (`#/list`)
**Purpose:** ค้นหา/กรอง/ดูสถานะ/สถิติ CN ทั้งหมด + จุดเข้าสร้าง
**Pattern:** A list-view + Q surface 1

**Stat tiles (4 · `listStats()` #70):**
1. รออนุมัติ (count) · sub = ฿รวม grand ของ pending
2. ลดหนี้เดือนนี้ (อนุมัติแล้ว) = ฿รวม grand ของ approved/sent เดือนปัจจุบัน · sub = n ใบ
3. ฉบับร่าง (count) · sub "ยังไม่ส่งอนุมัติ"
4. **ภาษีขายที่ลดเดือนนี้** = ฿รวม netVat · sub "ภ.พ.30 เดือน MM/YYYY"
> Stat คลิกได้ = filter (`f.stat` → pending/month/draft/vat)

**Table columns (`listHead`/`rowCells`, 10 คอลัมน์):** เลขที่ (sort) · วันที่ (sort) · ลูกค้า · ใบแจ้งหนี้อ้างอิง · เหตุผล · สถานะเอกสาร (pill) · ลายเซ็น (progress) · ยอดลดหนี้ (sort, ฿grand) · ภาษีขายที่ลด (฿netVat) · ⋮

**Filters (`filterSelects`):** สถานะเอกสาร (all/draft/pending_approval/approved/sent/cancelled) · เหตุผล (all + CN_REASONS) · ลูกค้า (all + PARTNERS)

**Actions:**
| Action | Triggers | Calls (API) |
|---|---|---|
| Search (`searchText`) | client filter | F-ACC-CN-API-01 |
| Filter change (`setFilter`) | refresh table | F-ACC-CN-API-01 |
| Sort (`sortBy` code/date/total) | re-order | F-ACC-CN-API-01 |
| Click row | navigate view | F-ACC-CN-API-02 → P-04 |
| "สร้างใบลดหนี้" | navigate create | → P-02 |
| CSV export | download (`csvHead`/`csvRow`) | F-ACC-CN-API-10 |
| ⋮ row → "ยกเลิก" (draft/pending) / "ทำสำเนา" | modal / prefillDup | F-ACC-CN-API-08 / P-02 |

**States:** Loading (skeleton) · Empty ("ยังไม่มีใบลดหนี้" + CTA) · Loaded.

## §1.3 User Journey (Happy Path — S-01)

```
เจ้าหน้าที่ลูกหนี้ @ P-01 → "สร้างใบลดหนี้" → P-02
  s1 เลือกใบแจ้งหนี้คงค้าง (API-11) → ดึงลูกค้า+บรรทัด (FN-04)
  s2 เลือกเหตุผล (RET→เลือกใบรับคืน API-12) + คำอธิบาย ≥10
  s3 ปรับจำนวน/ราคา ≤ เพดาน + (option) ส่วนลดท้ายบิล → VAT/grand คำนวณสด (ENG-cn-totals)
  s4 แนบเอกสาร → s5 ทบทวน + DOA preview
  "บันทึกและส่งอนุมัติ" (API-03 create draft) → submit modal
    เลือกคนต่อขั้น (resolveDoa freeze) → confirmSubmit (API-05)  [draft → pending_approval]
ผู้อนุมัติ @ My Approval → P-04 sign/approve
  อนุมัติแต่ละขั้น (API-06) → ขั้นสุดท้าย re-check outstanding
    ครบสาย → issueCreditNote: ออกเลข CN-YYYY-NNNN · cn_applied↑ · ภาษีขายลด · JE · CSQ/NTF  [→ approved]
เจ้าหน้าที่ → "ส่งให้ลูกค้า" (API-09) → เก็บสำเนา PDF  [approved → sent]
```

### Branch: ไม่อนุมัติ (S-07)
```
pending → ผู้อนุมัติ "ไม่อนุมัติ" + เหตุผล (API-07) → draft + approval_history append + badge "ถูกตีกลับ N ครั้ง"
```
### Branch: ยกเลิก (S-09) · re-check เกิน (S-11)
```
draft/pending → "ยกเลิก" + เหตุผล (API-08) → cancelled + คืนยอด held
pending ขั้นสุดท้าย: ถ้า outstanding ลดจนไม่พอ (demoPay/RV) → approveGuard block → ให้ "ไม่อนุมัติ" กลับไปแก้
```
