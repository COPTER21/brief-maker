## §0.3 Scope

### In Scope
1. สร้าง/แก้ร่าง/ส่งอนุมัติ/อนุมัติ/ไม่อนุมัติ/ส่งลูกค้า/ยกเลิก ใบลดหนี้ **ที่อ้างใบแจ้งหนี้เสมอ** (Pattern Q document + B2 v2 line editor)
2. เหตุผลจาก master (RET รับคืน / DISC ส่วนลดภายหลัง / PRICE ผิดราคา / QTY คิดจำนวนเกิน) — แต่ละเหตุผลมี `legal_basis` + `mode` (qty|price)
3. Line editor ล็อกสินค้าจากใบเดิม — ลดจำนวน (mode qty) หรือ ลดราคาต่อหน่วย (mode price)
4. **ส่วนลดท้ายบิล (end-bill discount)** — ฿/% · ยอดสุทธิ ≥0 และ ≤ ยอดคงค้าง · ลดฐานภาษี → VAT/ภ.พ.30 คำนวณใหม่ตามสัดส่วน (FN-19 · BR-11 · BR-12 · ม.86/10)
5. อนุมัติตามมูลค่าผ่าน DOA 3-tier (slot picker เลือกคนต่อขั้น) — **tier คิดจากยอดสุทธิ `grand` หลังหักส่วนลดท้ายบิล** (OQ-b RESOLVED)
6. ออกเลข `CN-YYYY-NNNN` เมื่ออนุมัติครบ (doccfg / ENG-DOC-NUM) · ลด outstanding AR · ลดภาษีขายเดือน cnDate · JE (จำลอง)
7. PDF ใบลดหนี้ A4 อ้างเลข/วันที่ใบเดิม + มูลค่าเดิม/ที่ถูกต้อง/ผลต่าง + เหตุผล (pdfdoc)
8. รายการ/ค้นหา/กรอง/สถิติ 4 tile/CSV · ประวัติ append-only · ทำสำเนา

### Out of Scope (ตัดสินแล้ว)
- **ลดหนี้ไม่อ้างใบแจ้งหนี้ (ลดลอย)** — ปิด (tile "ปิดไว้") — reason: OQ-CN-01 lock

## §0.9 Glossary

| Term | Definition |
|---|---|
| CN | Credit Note — ใบลดหนี้ลูกค้า |
| outstanding | ยอดคงค้างใบแจ้งหนี้ = invGrand − paid − cnApplied(approved/sent) |
| available | ยอดที่ลดได้ = outstanding − cnHeld(draft/pending) |
| end-bill / ส่วนลดท้ายบิล | ส่วนลดหักเพิ่มจากยอดรวมทั้งใบ (฿ หรือ %) ลดฐานภาษี (BR-11/BR-12) |
| grand | ยอดลดหนี้สุทธิ = max(0, after − ebAmt − coupon) — ฐานคิด DOA tier |
| netBefore / netVat | ฐานภาษี / ภาษีขายที่ลดจริง หลังหักส่วนลดท้ายบิล (ม.86/10) |
| DOA | Delegation of Authority — สายอนุมัติตามมูลค่า (F-DLG-001) |
| ม.86/10 / ม.82/10 | ประมวลรัษฎากร — ออกใบลดหนี้อ้างใบกำกับเดิม / เดือนภาษี |
