# 01_UI — F-WH-PICK Picking

> HTML is the de facto UI source: `../f-wh-picking.html`.

## §1.0 Layout Decision Log

| Page | Route | Observed pattern | Evidence |
|---|---|---|---|
| P-01 | `#/list` | ERP shell + list/table + 2 tabs | `.shell`, `.sb-item.active`, table render, queue/pick tabs |
| P-02 | `#/create/:soId` | wide create drawer + 3-step wizard | create drawer renderer, stepper, assignee combobox |
| P-03 | `#/view/:pickId` | wide tabbed transaction drawer + A4 | view drawer, 4 tabs, actions by state, print tab |

Overlays observed: SO drill, assign, pick-line, relocate/manual, hold, cancel, close-short and internal replenishment mock. Dropdown uses portal above drawer. No invented page/route.

## §1.1 P-01 List

- Tabs: “คิวรอหยิบ (SO)” and “ใบหยิบ”
- Queue row shows customer/delivery/warehouse/due/method/remaining/status/priority and selection guard
- Pick row shows ref/assignee/progress/priority/due/status
- Actions: search/filter, create, row drill, export; Finance release is mock-only
- API: F-WH-PICK-API-01, 02

## §1.2 P-02 Create drawer

1. เลือก SO: same warehouse, max wave, eligible only
2. มอบหมาย: assignee combobox, equipment, priority, note; selected value keeps comfortable vertical spacing
3. ตรวจสอบ: allocated route/lot/qty/rule; relocate/refresh/manual as rendered

Primary save paths: draft or assigned. Internal requestReplenish mock has no row icon per LOCK-12.

## §1.3 P-03 View drawer

Tabs: “รายการหยิบ”, “รายละเอียด · SO”, “ใบหยิบ”, “ประวัติ”. Header/footer actions derive from role + status.

| State | Visible actions |
|---|---|
| draft | assign, cancel, print |
| assigned | start, reassign, cancel, print |
| in_progress | pick line, relocate, hold, pick-all mock, close-short |
| on_hold | resume |
| picked | send Packing |
| to_pack/cancelled | read/print/history only |

## §1.6 Accessibility/interaction

Keyboard combobox, visible focus, disabled buttons, Esc closes topmost overlay first, portal menu avoids clipping, responsive desktop base at 1024 and 1440. Preserve current HTML wording and selectors when implementing.
