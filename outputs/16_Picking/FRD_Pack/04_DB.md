## §4.5 Field dictionary / constraints

- quantities use base UOM decimal precision from Item master and cannot be negative
- `picked_qty + short_qty ≤ required_qty`
- `source_type='SO'` in this release
- status check: draft, assigned, in_progress, on_hold, picked, to_pack, cancelled
- snapshots remain readable when master is inactive

## §4.6 Classification enforcement

Public: none. Internal: operational values; API requires authenticated tenant. Confidential: employee/actor and detailed audit; only authorized roles, exclude unnecessary fields from export/print, audit access. Restricted: none currently; future reclassification must wire Policy Center before exposure.

## §4.7 Migration

Create tables/checks/indexes/RLS, seed no business record, register outbox event types. Rollback only before production data; after launch use forward migration.
