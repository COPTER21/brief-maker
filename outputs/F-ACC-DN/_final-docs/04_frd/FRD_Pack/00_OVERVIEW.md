## §0.3 Scope

### In Scope
1. สร้าง/แก้ร่าง/ส่งอนุมัติ/อนุมัติ/ไม่อนุมัติ/ส่งผู้ขาย/ยกเลิก ใบลดหนี้ผู้ขาย **ที่อ้างใบตั้งหนี้ (AP Invoice) เสมอ** (Pattern Q document + B2 v2 line editor)
2. เหตุผลจาก master (RTV คืนสินค้าจากผู้ขาย / OVERPRICE ผู้ขายคิดราคาเกิน / SHORT ของขาด/ไม่ครบ) — แต่ละเหตุผลมี `legal_basis` + `mode` (qty|price)
3. Line editor ล็อกสินค้าจากใบตั้งหนี้เดิม — ลดจำนวน (mode qty) หรือ ลดราคาต่อหน่วย (mode price)
4. **ส่วนลดท้ายบิล (end-bill discount)** — ฿/% · ยอดสุทธิ ≥0 และ ≤ ยอดคงค้าง · ลดฐานภาษี → **ภาษีซื้อ (input VAT) คำนวณใหม่ตามสัดส่วน** (FN-19 · BR-11 · BR-12 · ม.86/10)
5. **เครดิตคงเหลือกับผู้ขาย (vendor credit)** — เพดาน DN = `dnRoom` = grand ใบเดิม − ลดหนี้แล้ว − กันยอด (**ไม่หัก paid**) · ใบจ่ายครบยังออก DN ได้ (คืนของหลังจ่าย) · แยกยอด `applyToAp` / `vendorCredit` · card + section รายผู้ขาย (display-only) (FN-04/FN-20 · BR-13)
6. อนุมัติตามมูลค่าผ่าน DOA 3-tier (slot picker เลือกคนต่อขั้น) — **tier คิดจากยอดสุทธิ `grand` หลังหักส่วนลดท้ายบิล** (LD-05)
7. ออกเลข `DN-YYYY-NNNN` เมื่ออนุมัติครบ (doccfg / ENG-DOC-NUM) · ลด outstanding AP (`dn_applied` = applyToAp) · JE (จำลอง)
8. **กลับภาษีซื้อ (ภ.พ.30) ตาม vendorCn** — กรอกเลขที่ + วันที่ใบลดหนี้จากผู้ขาย · ไม่มี → "รอเอกสาร" · เดือนภาษี = เดือนของ vendorCnDate · ปุ่มบันทึกภายหลังบนใบ approved/sent (FN-21 · BR-14 · ม.82/10)
9. PDF ใบลดหนี้ฝั่งซื้อ A4 อ้างเลข/วันที่ใบกำกับเดิมของผู้ขาย + มูลค่าเดิม/ที่ถูกต้อง/ผลต่าง + เหตุผล (pdfdoc)
10. รายการ/ค้นหา/กรอง/สถิติ 4 tile/CSV · ประวัติ append-only · ทำสำเนา

### Out of Scope (ตัดสินแล้ว)
- **ลดหนี้ไม่อ้างใบตั้งหนี้ (ลดลอย)** — ปิด (tile "ปิดไว้") — reason: OQ-DN-01 lock
- **ลดเกินมูลค่าที่ลดได้ (dnRoom)** — บล็อกทั้งตอนส่งและตอนอนุมัติ — reason: BR-02 / BR-13 / LOCK-04
- **เรียกเงินคืนเมื่อจ่ายครบ (refund)** — reason: LITE → ส่วนเกินคงค้างเป็นเครดิตคงเหลือกับผู้ขายแทน (OQ-DN-03)
- **ยกเลิกใบลดหนี้หลังอนุมัติ** — ใช้ "ออกเอกสารแก้ไข" (display-only, OQ-DN-04)
- **หน้าจอคืนสินค้าจากผู้ขาย (RTV) จริง** — เป็น W3-LITE (mock lookup [ASSUMED contract])
- **flow ใช้/ตัดยอดเครดิตคงเหลือกับผู้ขาย** (หักใบถัดไป/ขอคืน/อายุ) — display-only ในรอบนี้ (OQ-DN-06)

### Out of Scope (Demo-only artifacts — DEV STRIP)
HTML มีของทดสอบที่ **ห้าม render ใน production build** (`data-demo` / `.demo-only` · FIX-04):
- **persona switcher** (`switchPersona` / `PERSONAS` · `data-demo="persona-switch"`) — สลับบทบาททดสอบ
- **`demoPay(id)`** (S-11 harness) — จำลองว่ามีใบลดหนี้อีกใบได้รับอนุมัติเพิ่มระหว่างรอ → กินเพดาน dnRoom (หน้าจริงไม่มีปุ่มนี้)

## §0.9 Glossary

| Term | Definition |
|---|---|
| DN | Debit Note — ใบลดหนี้ผู้ขาย (ฝั่ง AP/ซื้อ) |
| outstanding | ยอดคงค้างใบตั้งหนี้ = invGrand − paid − dn_applied(approved/sent) |
| **dnRoom** | มูลค่าที่ลดได้ = invGrand − ลดหนี้แล้ว(approved/sent) − กันยอด(draft/pending) · **ไม่หัก paid** (BR-13) — เพดานการออก DN |
| dnSplit | แยกผลของ DN: `applyToAp = min(grand, outstanding)` · `vendorCredit = max(0, grand − applyToAp)` |
| vendorCredit / เครดิตคงเหลือกับผู้ขาย | ส่วนของยอดลดหนี้ที่เกินคงค้าง (เกิดเมื่อคืนของหลังจ่ายครบ) — display-only (OQ-DN-06) |
| end-bill / ส่วนลดท้ายบิล | ส่วนลดหักเพิ่มจากยอดรวมทั้งใบ (฿ หรือ %) ลดฐานภาษี (BR-11/BR-12) |
| grand | ยอดลดหนี้สุทธิ = max(0, after − ebAmt − coupon) — ฐานคิด DOA tier |
| netBefore / netVat | ฐานภาษี / **ภาษีซื้อ (input VAT)** ที่ลดจริง หลังหักส่วนลดท้ายบิล (ม.86/10) |
| vendorCn / vendorCnDate | เลขที่ + วันที่ใบลดหนี้ที่ได้รับจากผู้ขาย — คุมเดือนภาษี ภ.พ.30 (BR-14) |
| RTV | Return to Vendor — คืนสินค้าจากผู้ขาย (W3-LITE mock) |
| DOA | Delegation of Authority — สายอนุมัติตามมูลค่า (F-DLG-001) |
| ม.86/10 / ม.82/10 | ประมวลรัษฎากร — ออกใบลดหนี้อ้างใบกำกับเดิม / เดือนภาษี |
