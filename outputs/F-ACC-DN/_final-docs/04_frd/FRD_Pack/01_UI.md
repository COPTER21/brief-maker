## §1.2 Per-Page Detail

### P-01: รายการใบลดหนี้ผู้ขาย (`#/list`)
**Purpose:** ค้นหา/กรอง/ดูสถานะ/สถิติ DN ทั้งหมด + จุดเข้าสร้าง + เครดิตคงเหลือกับผู้ขาย
**Pattern:** A list-view + Q surface 1 + KPI credit card

**Stat tiles (4 · `listStats()`):**
1. รออนุมัติ (count) · sub = ฿รวม grand ของ pending
2. ลดหนี้เดือนนี้ (อนุมัติแล้ว) = ฿รวม grand ของ approved/sent เดือนปัจจุบัน · sub = n ใบ
3. ฉบับร่าง (count) · sub "ยังไม่ส่งอนุมัติ"
4. **ภาษีซื้อที่ลดเดือนนี้** = ฿รวม netVat · sub "ภ.พ.30 เดือน MM/YYYY" (⚠️ เฉพาะที่มี vendorCn — ดู BR-14)
> Stat คลิกได้ = filter (`f.stat` → pending/month/draft/vat)

**Vendor Credit card (FN-20 · display-only):** KPI card "เครดิตคงเหลือกับผู้ขาย" (รวม vendorCredit ของ DN approved/sent ที่ vendorCredit>0) → คลิกเปิด modal รายผู้ขาย (`vendorCreditLedger` · `ln 1236`). flow ใช้/ตัดยอด = OQ-DN-06 (ยังไม่ทำ).

**Table columns (`listHead`/`rowCells`):** เลขที่ (sort) · วันที่ (sort) · ผู้ขาย · ใบตั้งหนี้อ้างอิง · เหตุผล · สถานะเอกสาร (pill) · ลายเซ็น (progress) · ยอดลดหนี้ (sort, ฿grand) · ภาษีซื้อที่ลด (฿netVat) · ⋮

**Filters (`filterSelects`):** สถานะเอกสาร (all/draft/pending_approval/approved/sent/cancelled) · เหตุผล (all + DN_REASONS) · ผู้ขาย (all + PARTNERS)

**Actions:**
| Action | Triggers | Calls (API) |
|---|---|---|
| Search (`onSearchInput`) | client filter (code/ผู้ขาย/inv/rtv/vendorCn/vinv/reasonText/item) | F-ACC-DN-API-01 |
| Filter change (`setFilter`) | refresh table | F-ACC-DN-API-01 |
| Sort (`sortBy` code/date/total) | re-order | F-ACC-DN-API-01 |
| Click row | navigate view | F-ACC-DN-API-02 → P-04 |
| "สร้างใบลดหนี้ผู้ขาย" | navigate create | → P-02 |
| CSV export (`exportCSV`) | download (`csvHead`/`csvRow`) → toast "ส่งออก CSV {n} รายการ" | F-ACC-DN-API-10 |
| Vendor-credit card | modal รายผู้ขาย | F-ACC-DN-API-17 |
| ⋮ row → "ยกเลิก" (draft/pending) / "ทำสำเนา" | modal / prefillDup | F-ACC-DN-API-08 / P-02 |

**States:** Loading (skeleton) · Empty ("ไม่พบรายการ" / "ยังไม่มีใบลดหนี้ผู้ขาย" + CTA) · Loaded.
