## §1.1 Shared Shell

- Sidebar active: Warehouse → ตรวจนับใหญ่
- Header: title + description + “สร้างรอบนับ”
- Tab order: รอบนับ → ใบนับ → ผลต่าง → ประวัติ
- Stats: รอบทั้งหมด, รอบเปิดอยู่, ใบนับรอส่ง, รอตรวจผลต่าง
- z-index/CI ใช้ค่าจาก HTML AS-BUILT; UI Brief เป็นแหล่ง extraction รายละเอียด

## §1.2 P-01 รอบนับ

ค้นหาชื่อ/รหัส/คลัง, filter สถานะ, ล้างตัวกรอง, เปิดแถวแล้วไปแท็บใบนับ. Empty copy: “ไม่พบรอบนับที่ตรงกับตัวกรอง”

| Action | API |
|---|---|
| load/filter | F084-API-01 |
| สร้างรอบ | F084-API-02 |

## §1.3 P-02 ใบนับ

- draft + supervisor: “ล็อกพื้นที่และเก็บยอดตั้งต้น”
- frozen + supervisor: “มอบหมายใบนับ”
- recount ยังไม่มี assignee + supervisor: “มอบหมายนับซ้ำ”
- assigned current person: input ผลนับ, “สแกน”, “ส่งผลนับ”
- counter อื่น: เห็นค่าที่บันทึก/สถานะ แต่ไม่มี input/action
- supervisor column เพิ่ม “ยอดตั้งต้น”; counter ไม่เห็น column นี้

| Action | API |
|---|---|
| freeze | F084-API-03 |
| assign/reassign | F084-API-04 |
| submit count/recount | F084-API-05 |

## §1.4 P-03 ผลต่าง

Counter เห็น “ไม่มีสิทธิ์ดูผลต่าง”. Supervisor เห็น threshold/effective date, ฐานอนุมัติ, snapshot/count/recount/final diff/value. Footer แสดง action ตาม state: ส่งอนุมัติ, approve/reject current step, หรือสร้างร่างใบปรับยอด

## §1.5 P-04 ประวัติ

Timeline ทุก audit event; handoff summary เป็น section แบน `.history-handoff` ไม่ซ้อน `.card` และแสดง ack, ref_count_doc, จำนวนบรรทัด, absolute value

## §1.6 Overlay Registry

| Overlay | เปิด | ปิด | Guard |
|---|---|---|---|
| Create drawer | สร้างรอบนับ | X, ยกเลิก, Esc, backdrop function | ชื่อ+scope required |
| Assign modal | assign button | ยกเลิก, Esc, backdrop | supervisor + expected state + person required |
| DOA modal | ส่งอนุมัติ | ยกเลิก, Esc, backdrop | review + slotsครบ + person unique + not counter |
| Approve modal | อนุมัติขั้นนี้ | ยกเลิก, Esc, backdrop | current person/step |
| Reject modal | ไม่อนุมัติ | ยกเลิก, Esc, backdrop | current person/step + reason required |

Esc chain: modal → open combobox → drawer

## §1.7 State Matrix

| State | Label | Main action |
|---|---|---|
| draft | แบบร่าง | freeze |
| frozen | ล็อกพื้นที่แล้ว | assign |
| counting | กำลังนับ | assigned counter submit |
| recount | รอนับซ้ำ | assign + assigned recount submit |
| review | ตรวจผลต่าง | submit DOA |
| pending | รออนุมัติ | current step approve/reject |
| approved | อนุมัติแล้ว | handoff F082 |
| rejected | ไม่อนุมัติ | read history; lock released |
| closed | ปิดรอบ | read-only; lock released |
