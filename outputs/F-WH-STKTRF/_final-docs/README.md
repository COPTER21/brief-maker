# Stock Transfer — Final Documents

ชุดเอกสารส่งมอบของฟีเจอร์ `F-WH-STKTRF` จัดหมวดตาม pattern ของ `outputs/17_Delivery-Note/_final-docs`

1. `00_context/` — Feature Context Pack สำหรับใช้เป็น reference ข้ามฟีเจอร์
2. `01_prototype/` — HTML Prototype
3. `02_qc/` — รายงาน UX, Coverage และ Final Gate
4. `03_brd/` — BRD Markdown/Word และรายงานตรวจ BRD
5. `04_frd/` — FRD Pack ฉบับเต็ม
6. `05_ui-brief/` — HTML UI Brief
7. `06_print/` — Template, ตัวอย่าง PDF และ Print Spec
8. `08_tldr/` — หน้าสรุปฟีเจอร์แบบอ่านง่าย
9. `09_declarations/` — DOCCFG, DOA และ Notification declarations
10. `10_handoff/` — ประเด็นค้างและข้อเสนอส่งต่อ
11. `testcase_qa/` — AI Test Cases และ UAT สำหรับ Manual Test

## จุดเริ่มต้นแนะนำ

- ตรวจหน้าจอ: `01_prototype/F-WH-STKTRF.html`
- อ่านภาพรวม 2 นาที: `08_tldr/FEATURE_TLDR_F-WH-STKTRF.html`
- Manual test: `testcase_qa/testcase-F-WH-STKTRF.html`
- ส่ง context ให้ฟีเจอร์อื่น: `00_context/CTX_F-WH-STKTRF.md`
- ดูข้อสรุปคุณภาพ: `02_qc/_FINAL_GATE_REPORT.md`

> ไฟล์ใน `_final-docs` เป็นชุดรวมสำหรับส่งมอบ ส่วนไฟล์ต้นฉบับที่ feature root ยังคงไว้เพื่อให้ workflow และลิงก์เดิมไม่เสีย
