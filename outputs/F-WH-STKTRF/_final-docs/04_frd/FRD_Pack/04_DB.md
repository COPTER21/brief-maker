# 04_DB — F-WH-STKTRF

## 4.1 Entities

`stock_transfer` 1:N `stock_transfer_line`; 1:N approval slots, receipts, attachments, audit events and movement links. Reversal has a self-reference to the original transfer. Master IDs are soft references with display snapshots.

## 4.2 Table contract

All tables include `created_by`, `created_at`, `updated_by`, `updated_at`, integer `version`; classification defaults to Internal, never Public.

| Table/columns | Key constraints | Classification / PII |
|---|---|---|
| `stock_transfer`: id, code, status, mode, source/destination warehouse_id+snapshot, transit_location_id+snapshot, transfer_date, expected_date, reason_code+text, creator_id+snapshot, total_qty/value, shipped_by/at, reversal_of_id, accounting_status, version | code unique nullable until submit; reversal_of unique; status check | Internal; creator/shipper Confidential + PII |
| `stock_transfer_line`: id, transfer_id, item_id+snapshot, uom_id+snapshot, source_bin_id+snapshot, planned_dest_bin_id+snapshot, qty_requested, qty_shipped, qty_received, qty_written_off, qty_returned, unit_cost_snapshot | unique transfer+source+item+dest; qty nonnegative | Internal |
| `stock_transfer_approval`: id, transfer_id, approval_type, step_no, assignee_id+snapshot, status, acted_by/at, note, doa_policy_snapshot | unique type+step; immutable acted rows | Confidential; assignee/actor PII |
| `stock_transfer_receipt`: id, transfer_id, receipt_no, received_by/at, destination_bin snapshot, qty | receipt_no unique per transfer | Confidential; receiver PII |
| `stock_transfer_attachment`: id, transfer_id, purpose, storage_key, original_name, mime_type, size_bytes, uploaded_by/at | authorized object reference | Confidential; uploader PII |
| `inventory_movement`: id, transfer_id, line_id, movement_type, source_location, destination_location, qty, cost_snapshot, reversed_movement_id, posted_by/at, posting_status | append-only; reversed link unique | Internal; actor Confidential/PII |
| `stock_transfer_audit`: id, transfer_id, event_type, from_status, to_status, actor_id+snapshot, reason, occurred_at, correlation_id | append-only | Confidential; actor PII |

## 4.3 Indexes

Index code, status+date, source warehouse+date, destination warehouse+status, creator, reason, shipped_at, approval assignee+status, transfer FKs, movement reference, and audit occurred_at. Use a partial unique index on non-null `reversal_of_id`.

## 4.4 Invariants

- For each line: `qty_shipped = qty_received + qty_written_off + qty_returned + qty_in_transit`.
- Closed/full requires transit zero. `closed_diff` requires final shortage approval. Returned requires remaining zero through return movement.
- No UPDATE/DELETE permission on movement and audit business rows; corrections are compensating rows.

## 4.5 Field dictionary highlights

IDs are UUID/Internal; money decimal(18,4)/Internal; quantity decimal by UOM/Internal; reason/evidence/identity snapshots Confidential; timestamps Internal except actor-linked timestamps are Confidential in audit views.

## 4.6 Classification enforcement

Public: none. Internal: operational stock/document fields. Confidential: identities, reasons, audit, attachments. Restricted: none currently. API filters Confidential fields by permission; UI masks unauthorized actor details; audit export is logged; storage uses tenant-scoped signed access and retention from central policy.
