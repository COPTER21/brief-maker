# 01_UI — F-WH-DN Delivery Note

> HTML source of truth: `../f-wh-delivery-note.html`. Preserve current routes, text and visible state behavior.

## §1.0 Layout Decision Log

| Page | Route | Observed pattern | Evidence |
|---|---|---|---|
| P-01 | `#/list` | ERP shell + list/table + two tabs | shell/sidebar, `renderListPage`, queue/DN tab, search and toolbar |
| P-02 | `#/create/:packIds` | destructive-safe confirmation modal over list | `getRoute`, `createDN`, selected pack summary and assignment/transport form |
| P-03 | `#/view/:dnId` | wide tabbed document drawer + printable A4 | `renderViewDrawer`, delivery/lines/doc/history tabs, state actions |

Observed overlays: pack drill, reference confirmation, Manual create, Manual status, dispatch, failed, POD, return-all, cancel and backorder. Search dropdowns use overlay portal above drawer/modal. No invented route.

## §1.1 P-01 List

- Tabs: “รอออกใบส่งของ” and “ใบส่งของ”
- Queue shows Packing/source/customer or transfer route/warehouse/boxes/weight/deadline and combine selection
- Toolbar actions: “ออกใบส่งของ” and “สร้างแบบ Manual”
- Reference confirmation includes assignee/carrier/vehicle/driver/date; assignee has Employee results only
- Transport manual options: “กรอกเลขรถเอง” and “กรอกคนขนส่งเอง”
- API: F-WH-DN-API-01, 02, 03, 15

## §1.2 P-02 Reference confirmation

Route parses one or more comma-separated pack codes and calls `createDN`. The modal summarizes packs/boxes/weight, validates the combine key, and captures assignee/carrier/vehicle/driver/date before “ยืนยันออกใบส่งของ”. Cancelling leaves the queue unchanged.

## §1.3 P-03 View drawer

Tabs: “ข้อมูลจัดส่ง”, “รายการ · กล่อง”, “ใบส่งของ”, “ประวัติ”. Header identifies source; Stock Transfer shows `WH-01 → WH-02`. Reference customer snapshot is not editable.

| State/mode | Visible actions |
|---|---|
| reference draft | edit/save, ready, cancel, print |
| reference ready | edit delivery, dispatch, cancel, print |
| reference in_transit | update tracking, failed, POD, cancel |
| reference failed | reschedule, return all, cancel |
| delivered/partial/returned/cancelled | read/print/history; billing/backorder action when relevant |
| manual any | “อัปเดตสถานะ Manual”; reason modal; no automatic GI/source sync |
