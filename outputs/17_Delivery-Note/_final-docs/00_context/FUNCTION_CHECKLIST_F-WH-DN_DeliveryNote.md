## สิ่งที่ไม่รองรับ (ตัดสินแล้ว)
- จัด route/optimize หลายจุดต่อรอบ · แบ่งใบส่งของเป็นหลายรถ — phase ถัดไป (S-22)
- e-POD บนมือถือคนขับ (ลายเซ็นจริง/GPS) · API ขนส่ง 3PL จริง (สร้างพัสดุ/ดึงสถานะ/พิมพ์ label) — OQ-9, OQ-10
- คิดค่าขนส่งอัตโนมัติจากน้ำหนัก/ระยะ · Credit Note อัตโนมัติเมื่อปิดจบ — OQ-7, OQ-8 (AR module)
- แก้จำนวน/รายการในใบส่งของ — lines snapshot จากใบแพ็ค (ต้องแก้ที่ Packing)
- ตัดสต๊อกตอน POD (ตอนนี้ตัดตอนออกรถตาม SAP standard) — OQ-1 ถ้าต้องสลับให้ทำเป็น Warehouse Config
