## §1.3 List view (P-01) — Pattern A (drill-down)
- **Drill path** (breadcrumb chips มี level label): ทุก Warehouse › WH-01 › Zone › Area › Rack — คลิกย้อนได้
- **KPI stats (5):** Warehouse · Zone · Area · Rack · Location counts
- **Card (filter-in-card):** search (code/name); ที่ location-level เพิ่ม type (10) + status (7) + reset
- **Table (≤8 cols, เปลี่ยนตาม level ปัจจุบัน):**
  - WH level → list Zones: ชื่อ+code · อุณหภูมิ · #Areas · สถานะ · actions
  - Zone level → list Areas: ชื่อ+code · direct? · #Racks · #Loc ตรง · สถานะ · actions
  - Area level → **segmented** Racks / Location ตรง (ถ้า allows_direct) ใน card-head
  - Rack level → list Locations: รหัส+ชื่อ · Parent (badge) · ประเภท (pill 10) · ความจุ · หมุนเวียน · flags · สถานะ · actions
- **Footer:** count + pagination (PAGE_SIZE 10)
- **Row click:** non-leaf → drill ลง; location → open View. Eye action = view node เสมอ.

## §1.4 Hierarchy view (P-01b) — NON-STANDARD (LD-09 / OQ-2)
- ซ้าย: tree pane (WH→Zone→Area→Rack, collapsible, count + level label ทุก node)
- ขวา: **node summary panel** (ไม่ใช่ตาราง list): icon + level badge + ชื่อ/code/status · full path · attribute fields ของระดับนั้น · **child stat chips** (คลิก → สลับ List view ที่ node นั้น) · actions (แก้ไข/เพิ่มลูก/ลบ)
- State `sel` ใช้ร่วมกับ List view — สลับ view แล้ว context คงอยู่

## §1.5 Create/Edit node (P-02) — Pattern B drawer 540px
- **Warehouse:** code*, name*, **address block**: addr_line + **จังหวัด** (cascade) → **อำเภอ/เขต** (depend) → **ตำบล/แขวง** (depend) → **รหัสไปรษณีย์** (auto, read-only)
- **Zone:** code*, name*, warehouse* (lookup), toggle temp_controlled → temp_min/temp_max (required ถ้าเปิด)
- **Area:** code*, name*, zone* (lookup), toggle allows_direct (flexible-parent gate)
- **Rack:** code*, name*, area* (lookup), rows/cols/levels (grid)
- Footer (Rule #31): ยกเลิก (ghost) · spacer · ยืนยันสร้าง/บันทึก (primary)

## §1.6 Create/Edit Location (P-02b) — Pattern B, 2-step wizard
- **Step 1 — Parent & Identity:** parent_type (Rack/Area radio) → conditional lookup; ถ้า area เลือก → validate `allows_direct` (inline error + แนะนำเพิ่ม rack ถ้า false); code*; name; **type (10 core dropdown incl PACK)**
- **Step 2 — Capacity & Behavior:** capacity_uom + capacity_value (>0); rotation; coords (row/col/level/position); behavior toggles (pickable/putawayable/replenishable); mixing (mixed_lot/item/neg_stock); barcode/qr
- เลือก type → (Phase 3) auto-set default behavior (FN-23); footer per Rule #31.3

## §1.7 View (P-03/P-03b)
- **Location (Pattern C, 3 tabs):** ภาพรวม (code/name/type, full path, parent badge, status, block_reason) · ความจุ & flags (capacity, rotation, behavior, mixing, barcode) · ประวัติ (WORM audit timeline)
- **Node (Pattern C):** fields + full path + child counts + ปุ่ม "ดูรายการลูก (เจาะลง)"
- Header actions (Rule #31.4): แก้ไข (secondary) → ลบ/ปลดระวาง (danger) → divider → X. Footer = ปิด (secondary) เท่านั้น.

## §1.8 Bulk Generate (P-04) — Pattern B drawer
target area/rack · rack code pattern + qty + rows/cols/levels · location code pattern + type + capacity + rotation · **preview count** ก่อน generate · collision check → block · atomic.

## §1.9 Delete/Decommission (P-05) — Pattern D modal
- WH/Zone/Area/Rack: block ถ้ามีลูก (referential-safe) + warn-box
- Location: ปลดระวาง — block ถ้า stock≠0; stock=0 → soft decommission (คงประวัติ)
