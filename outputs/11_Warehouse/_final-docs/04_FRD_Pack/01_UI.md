## §1.2 Pages

### P-01 · List view (drill-down) — `state.view='list'`
- **Page header:** h1 "คลังและตำแหน่ง", sub "จัดโครงสร้างจัดเก็บครบ 5 ระดับ (คลัง › โซน › พื้นที่ › ชั้นวาง › ตำแหน่ง) พร้อม flexible parent — คลิกแถวเพื่อเจาะลงระดับถัดไป" (`renderHeader` L2359).
- **View switcher** segmented ใต้ header (`renderViewSwitcher` L2206, `setView` L2212): List / Hierarchy.
- **KPI row** (`renderKpi` L2375): 5 tiles — คลัง (Warehouse) / โซน (Zone) / พื้นที่ (Area) / ชั้นวาง (Rack) / ตำแหน่ง.
- **Drill breadcrumb** (`renderDrill` L2394): root → WH(code) → Zone(name) → Area(name) → Rack(name). Level 5 = ตำแหน่ง.
- **Filters:** branch combobox (D7), search (per-level placeholder `renderCard` L2433), type/status filter ที่ location level. `setSearch/setFilter/resetFilters` (L2589-2591).
- **Table** (`renderTable` L2494, columns per level `renderTableHead` L2557): create button `onCreate()` (label per level `createLabel` L2356). Row actions: view / edit / archive|decommission (`rowActionsNode/rowActionsLoc` L2472/2480).
- **Area sub-tabs** when `allows_direct`: seg control "ชั้นวาง" / "ตำแหน่งตรง" (`setAreaTab` L2594, L2450).
- **Empty state** (Iron #39, `emptyStateHTML` L1845) + **loading skeleton** (`renderLoading` L2337) + **error state** (`renderErrorState` L2346, desc "รายการที่คุณกำลังเจาะดูอาจถูกลบหรือย้ายไปแล้ว กรุณากลับไปที่รายการคลังทั้งหมด").
- **Pill palette (D10):** สถานะ = color-code (CUBE variants); ประเภท = icon+label ไม่ color-code. `statusPill/pillHtml/typePillHtml` (L2028/2488/2487). Sanctioned CI extension (LD-09).

### P-02 · Hierarchy Tree — `state.view='tree'` (NON-STANDARD, D12/LD-01)
- Left tree pane (`renderTree/treeNode` L2256/2261): WH→Zone→Area→Rack collapsible, count/level badge ทุก node; `toggleTreeNode/treeSelect/expandToSel` (L2240-2242).
- Right node summary panel (`renderNodeSummary` L2281): icon+level badge, ชื่อ/code/status, full path (`fullPathStr` L2161), attribute fields, child stat chips (`chipStat` L2319) — คลิก chip → สลับไป List (`chipToList` L2324), actions.
- Shares `state.sel` with List (switch view keeps selection — S-10).
- **Known gap (LD-02):** tree rows ไม่มี keyboard/arrow-key nav (UX-08) → dev-handoff gap, note in 07_LOCKED.

### P-03 · Node form drawer — `state.drawer.view='node-form'` (Pattern B)
`renderNodeForm` (L2697). Level-driven (warehouse/zone/area/rack):
- **Warehouse:** code (req, "ต้องไม่ซ้ำทั้งระบบ") · name · **branch** (req, Master Combobox #94) · addr_line · province→district→subdistrict cascade → postcode auto readonly (`waddr`/geo fns L2056/2051-2054).
- **Zone:** code (req, unique/คลัง) · name · warehouse (lookup active) · temp_controlled toggle → temp_min/temp_max (req if on).
- **Area:** code (req, unique/โซน) · name · zone (lookup active) · **allows_direct** toggle ("อนุญาตวางตำแหน่งตรงใต้พื้นที่ · วางบนพื้นได้โดยไม่ต้องผ่านชั้นวาง").
- **Rack:** code (req, unique/พื้นที่) · name · area (lookup active) · rows/cols/levels grid.
- Submit `submitNode` (L3038) → validate (`dup` L3043) → toast.

### P-04 · Location form (2-step wizard) — `state.drawer.view='loc-form'` (Pattern B + Stepper)
`renderLocForm` (L2766), steps "ต้นทาง & ข้อมูลระบุ" / "ความจุ & พฤติกรรม" (`stepper2` L2762).
- **Step 1** (`renderLocStep1` L2785): parent type radio-cards "ใต้ชั้นวาง (Rack)" / "ใต้พื้นที่โดยตรง (Area)" (`setParentType` L2831, XOR). If area & `allows_direct=false` → inline-warn "พื้นที่ <code> ตั้งค่า allows_direct = false — วางตำแหน่งตรงไม่ได้ ต้องเลือกพื้นที่อื่น หรือ [เพิ่มชั้นวางในพื้นที่นี้ก่อน]" (link `suggestAddRack` L2832). Rack/area picker = Master Combobox. code (req, "ต้องไม่ซ้ำภายใน parent เดียวกัน").
- **Step 2** (`renderLocStep2` L2805): type dropdown (10), cap_uom (pallet/box/piece/cbm/kg), cap_val (>0), rotation (FIFO/LIFO/FEFO/Manual), coords (row/col/level/position), behavior toggles (pickable/putawayable/replenishable), mixing toggles (mixed_lot/mixed_item/neg_stock), barcode/qr.
- Submit `submitLoc` (L3089). No barcode + `loc_require_barcode` ON → created **inactive**.

### P-05 · Bulk Generate drawer — `state.drawer.view='bulk'` (Pattern B)
`renderBulk` (L2983), head "สร้างจำนวนมาก (Bulk Generate)". target_area picker · rack template ("รูปแบบรหัสชั้นวาง" `{n}`, จำนวนชั้นวาง) · location pattern + capacity. **Preview box** "จะสร้างทั้งหมด: N ชั้นวาง × M = total" (`bulkCalc` L2962). Collision check (`bulkCollisions` L2969) → inline-warn. Submit `submitBulk` (L3131) atomic.

### P-06 · View Node drawer — `state.drawer.view='view-node'` (Pattern C)
`renderViewNode` (L2838): fields (per kind), full path, child stat chips (`childStat` L2879, drill `drillFromView` L2880), actions edit/archive (gated by `perms().del`).

### P-07 · View Location drawer (3 tabs) — `state.drawer.view='view-loc'` (Pattern C tabbed)
`renderViewLoc` (L2885), tabs (`tabBtn/setDrawerTab` L2904/2905): **ภาพรวม** (`viewLocOverview` L2906, incl "มีสต็อก" flag + activate-guard inline-warn if no barcode) / **ความจุ & flags** (`viewLocCapacity` L2921) / **ประวัติ** (`viewLocHistory` L2949, WORM audit). Actions: change-status, decommission (gated).

### P-08 · Confirm modals — `state.modal.type` (Pattern D, `renderModal` L3175)
- **delete-node** (archive): if `childCount>0` (active only) → danger, block; else warning confirm → soft archived.
- **decommission:** if `hasStock` → danger block; else warning confirm → decommissioned.
- **block:** requires reason input.
