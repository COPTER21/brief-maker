### P-02 / P-03: เพิ่ม / แก้ไขบัญชีธนาคาร
**Purpose:** สร้าง/แก้ไขบัญชี ผ่าน drawer form 3 sections
**Pattern:** B — drawer (680px), single-step (จาก §1.0)

**Sections (observed `formHTML`):**
1. **ข้อมูลบัญชี:** รหัส (เว้น = auto `{ธนาคาร}-{เลขรัน}`) · **ธนาคาร\*** (9 ค่า) · **เลขที่บัญชี\*** (10–12 หลัก ใส่ขีดได้) · **ชื่อบัญชี\*** · สาขา · ประเภทบัญชี (ออมทรัพย์/กระแสรายวัน/ฝากประจำ, default ออมทรัพย์) · พร้อมเพย์ผูกบัญชี (ว่าง/10/13 หลัก)
2. **บัญชีแยกประเภท (GL):** กลุ่มบัญชี GL (Bank Posting Group, `sdd`/select active-only + คงตัวที่ผูกไว้เดิม) · สกุลเงิน = "THB — บาทไทย" **disabled**
3. **การใช้งาน:** **ใช้กับฝั่ง\*** (checkbox: ฝั่งรับเงิน (Receipt) / ฝั่งจ่ายเงิน (Payment Voucher), ≥1) · บัญชีรับหลัก (★ checkbox) · บัญชีจ่ายหลัก (★ checkbox) · สถานะ (select 3 ค่า, default ใช้งาน)

**IR-BNK-01 (edit + used>0):** `ธนาคาร` + `เลขที่บัญชี` → `disabled` + `<span class="lock-tag">ล็อก — มีเอกสารผ่านแล้ว</span>` ต่อท้าย label. Field อื่น (ชื่อ/สาขา/ประเภท/พร้อมเพย์/กลุ่ม GL/ฝั่ง/★/สถานะ) แก้ได้ปกติ. Save guard: logic ไม่ assign `bank`/`account_no` แม้ฝืน DOM (ดู 03_LOGIC FN-02).

**Actions:**
| Action | Triggers | Calls (API) |
|---|---|---|
| เลือกกลุ่ม GL | populate จาก active-only picker | F-PG-API-01 GET /gl/posting-groups?kind=bank&status=active |
| ติ๊ก ★ รับ/จ่าย | client (ตัวเก่าหลุดตอน save) | — |
| "ยืนยันสร้าง" | `saveBank('create')` validate → create | F-BNK-API-02 POST /bank-accounts |

| "ยกเลิก" / X / Esc | close drawer | — |

**States:** validation error (field `has-err` + inline err + toast DEFAULT_GUARD) · edit prefill · IR lock (disabled + lock-tag) · saving (`#saveBtn is-disabled` + spinner — double-submit guard).
**Permissions:** Finance Admin only.

## §1.3 User Journey (Happy Path — เพิ่มบัญชี + ผูกกลุ่ม GL, S-01/S-02)

```
Finance Admin เปิด P-01 (List)
  ↓ กด "เพิ่มบัญชีธนาคาร"
P-02 drawer เปิด (default status=ใช้งาน, ฝั่งรับ=on)
  ↓ กรอก ธนาคาร* + เลขที่บัญชี* (10–12 หลัก) + ชื่อบัญชี* (+ สาขา/ประเภท/พร้อมเพย์ · code เว้น = auto)
  ↓ เลือก กลุ่มบัญชี GL (active-only) — หรือเว้นไว้ (บันทึกได้, view เตือน)
  ↓ เลือก ใช้กับฝั่ง ≥1 + (optional) ★ + สถานะ
  ↓ กด "ยืนยันสร้าง" → saveBank('create') validate
  ├─ ผ่าน → autoCode ถ้าเว้น → POST /bank-accounts (F-BNK-API-02) → close → toast "เพิ่มบัญชีธนาคาร "{code}" แล้ว" (success)
  └─ ไม่ผ่าน → field has-err (+ toast DEFAULT_GUARD ถ้า ★ ผิด) — ไม่ปิด drawer
```

### Branch: แก้บัญชี used>0 (S-04 · IR-BNK-01)
```
P-01 row → openEdit → ธนาคาร+เลขบัญชี disabled + lock-tag "ล็อก — มีเอกสารผ่านแล้ว"
  ↓ แก้ ชื่อ/สาขา/ประเภท/พร้อมเพย์/กลุ่ม GL/ฝั่ง/★/สถานะ → "บันทึกการแก้ไข" → PUT /:id (guard ไม่แตะ bank/account_no)
  → toast "บันทึกการแก้ไข "{code}" แล้ว"
```

### Branch: เปลี่ยนสถานะ (S-06, no approval)
```
P-04 view → "เปลี่ยนสถานะ" menu → เลือก 1/3 ค่า → POST /:id/status → toast "เปลี่ยนสถานะ "{code}" เป็น {label} แล้ว"
หรือ P-01 bulk bar → set status → POST /bulk-status → toast "เปลี่ยนสถานะ {n} รายการ เป็น {label} แล้ว"
side effect: หลุดจาก active → ★ ทั้ง 2 ฝั่งหลุด
```

### Branch: bulk ลบ (S-07)
```
P-01 select ≥1 → bulk "ลบ" → P-06 modal (บอกยอดข้าม) → "ลบ D รายการ" → POST /bulk-delete
→ close → toast "ลบแล้ว D รายการ · ข้าม M (มีเอกสารผ่านแล้ว)" (warning ถ้ามีข้าม) / "ลบแล้ว D รายการ" (success)
```

### Branch: นำเข้า CSV (S-08)
```
P-01 "นำเข้า CSV" → P-05 modal (pick → preview validate → done merge-only)
→ toast "นำเข้าแล้ว {ok} รายการ · ข้าม {err} แถว (IMPORT_ERROR)" (warning) / "นำเข้าแล้ว {ok} รายการ" (success)
```
