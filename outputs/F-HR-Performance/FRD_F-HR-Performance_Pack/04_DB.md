## §4.6 Data Classification & Sensitive Data ⭐

### §4.6.1 Classification Levels
| Level | ในfeature นี้ | UI Behavior | Export |
|---|---|---|---|
| **Public** | — (ไม่มี) | — | — |
| **Internal** | status, timestamps, cycle meta, weight, audit act/at | แสดงปกติ (authenticated) | ทุก internal role |
| **Confidential** | employee snapshot (name/pos/dept + PII), KPI title/target, reviewer/who names | mask `***` ถ้า role ไม่ผ่าน | excluded ถ้าไม่ผ่าน |
| **Restricted (SecC)** | self_score, mgr_score, weighted_score, decision, gap, self/mgr_note, pip_plan | hidden/`•••` + audit access · out-of-scope = **ไม่อยู่ใน DOM** | excluded + Restricted Resources approval |

### §4.6.2 Default Rule
Default = **Internal**. ห้าม default Public. Restricted/Confidential ระบุ explicit ใน §4.2.

### §4.6.3 Enforcement Mapping
| Classification | DB Layer | API Layer | UI Layer | Audit |
|---|---|---|---|---|
| Internal | RLS (tenant) | JWT auth | — | mutation |
| Confidential | RLS + column ACL | role check | mask if no perm | view + mutation |
| **Restricted** | RLS + **row ACL (scope_type)** | role + scope check (SELF/DEPT/ALL) | hide/mask + **out-of-scope excluded จาก payload/DOM** | view + mutation + export attempt |

> **scope_type (SEC · BR-11):** staff=SELF (`employee_ref=self`) · mgr=DEPT (`emp_dept_snap = requester.dept`) · HR(manage)=ALL. Enforced server-side (F131-FN-17) — ไม่ใช่แค่ UI hide. Out-of-scope rows/columns **ต้องไม่ถูกส่งใน API response** (mirror `scopeSelf()` + `mask()` ในโปรโตไทป์).

### §4.6.4 PII Overlay
- `emp_name_snap`, `emp_pos_snap`, `employee_ref`, `reviewer_name_snap`, `who` → **Confidential + PII** (PDPA scope, encrypt at rest column-level).
- `mgr_score`/`decision`/`gap` → **Restricted + ไม่ PII** (ข้อมูลผลงาน ลับต่อบุคคล แต่ไม่ใช่ personal identity).

### §4.6.5 Security Bible Domain Mapping
| Domain | เกี่ยวข้องกับ |
|---|---|
| **D7 (PII):** emp/reviewer/who snapshots → encrypt at rest + PDPA scope |
| **D9 (Audit):** ทุก mutation → T_perf_audit (append-only, immutable) |
| **D13 (RBAC/scope):** scope_type SELF/DEPT/ALL enforce row+column |
| **D-CLASS:** Restricted fields (score/decision/gap) → masking + Restricted Resources |

### §4.6.6 Linkage with Policy Center
- Restricted fields → **Restricted Resources registry** (Policy Center) — **wire status OPEN (OQ-PERF-10)**.
- PII fields → PDPA consent scope.
- Classification override → Data Classification module (runtime + audit).
