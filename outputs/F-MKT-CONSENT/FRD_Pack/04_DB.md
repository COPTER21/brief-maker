## §4.3 Relationships (ER)

```
T_consent_purpose (1) ──< (N) T_consent_policy_version   [immutable versions]
T_consent_purpose (1) ──< (N) T_consent_request_purpose >── (N) T_consent_request
T_consent_request (1) ──< (N) T_consent_request_send     [append-only]

T_consent (1) ──1:1── T_consent_evidence
T_consent (1) ──< (N) T_consent_history                  [append-only]

Customer(CUS-xxxx, external) ──< (N) T_consent           [subject_ref, no FK join]

```

## §4.6 Data Classification & Sensitive Data

### §4.6.1 Levels — feature นี้ใช้ Internal (default) + Confidential (highest) · **ไม่มี Restricted / Public**
### §4.6.2 Default Rule — default = Internal · ห้าม default Public
### §4.6.3 Enforcement Mapping
| Classification | DB | API | UI | Audit |
|---|---|---|---|---|
| Internal | RLS (tenant) | JWT auth | — | mutation |
| Confidential | RLS + column ACL | role check | mask `***` ถ้า role ไม่ผ่าน (auditor เห็น, external ห้าม) | view + mutation |

### §4.6.4 PII Overlay
PII fields: `subject_ref`, `id_method`, `ip_device` → pii_flag=true (PDPA scope) · encrypt at rest (D7)
### §4.6.5 Security Bible Domain Mapping
- **D7 (PII):** subject/id_method/ip_device → encrypt column-level + PDPA scope
- **D9 (Audit):** ทุก mutation ≥ Internal → T_audit_log + T_consent_history
- **D-CLASS:** mask Confidential ก่อนส่ง CSQ (BR-CSQ-03)
### §4.6.6 Linkage with Policy Center
- PII fields → PDPA consent scope (Policy Center) · Confidential → Data Classification module
- **ไม่มี Restricted Resources registry** (ไม่มี Restricted field)
