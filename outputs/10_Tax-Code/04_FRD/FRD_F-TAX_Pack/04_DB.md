# 04_DB — F-TAX Tax Code (รหัสภาษี)

> **Audience:** DBA / Backend developer
> **Purpose:** Tables + Field Dictionary + Relationships + Indexes + Data Classification
> **Naming:** Tables = `T_snake_case`, Fields = `snake_case`
> **Multi-company:** RLS by `company_id` (LOCK-02 / R15 / E18)

## §4.1 Table Overview

| Table | Purpose | Owner Feature | Multi-company |
|---|---|---|---|
| `T_tax_code` | Main tax code master (VAT/WHT) per company | F-TAX (this) | YES (RLS) |
| `T_tax_code_audit` | Append-only change history (ts/actor/action) | F-TAX (this) | YES |
| `T_income_type` | Reference list สำหรับ WHT (โยง ภ.ง.ด.3/53) | F-TAX (this, seed) | shared/global |
| `T_gl_account` | Chart of Accounts (GL) — **existing external master**, referenced only | Accounting (CoA) | YES |
| `Tax_Snapshot` | Immutable tax value embedded ใน consumer doc — **EXTERNAL contract, ไม่ใช่ table ของ feature นี้** | Consumer (External) | — |

## §4.2 Per-Table Schema

> **⭐ Data Classification (R10):** ทุก column มี `Classification` (Public/Internal/Confidential/Restricted). **Default = Internal** (ห้าม default Public). ไม่มี Restricted/PII ใน feature นี้ (BRD §16.1). GL mapping = Confidential (financial posting config).

### T_tax_code

**Purpose:** รหัสภาษี VAT/WHT ต่อบริษัท — master กลางที่เอกสารการเงินอ้าง.

| Column | Type | Null | Default | Classification | PII | Description |
|---|---|---|---|---|---|---|
| `id` | varchar(12) | NO | (`TX-NN` gen) | Internal | — | PK (BRD §6.2 #1) |
| `company_id` | uuid | NO | — | Internal | — | FK → T_company; RLS scope (LOCK-02) |
| `code` | varchar(40) | NO | — | Internal | — | รหัส เช่น VAT7; unique/company case-insensitive; lock เมื่อ used>0 (R01/R02) |
| `name` | varchar(200) | NO | — | Internal | — | ชื่อที่แสดงบนเอกสาร |
| `family` | varchar(8) | NO | — | Internal | — | enum: VAT / WHT; lock เมื่อ used>0 |
| `vat_kind` | varchar(12) | YES | — | Internal | — | VAT: standard/zero/exempt (null สำหรับ WHT); lock เมื่อ used>0 |
| `rate` | numeric(6,3) | YES | — | Internal | — | 0–100; zero/exempt→0; **lock เมื่อ used>0 (R02/R13)** |
| `direction` | varchar(10) | NO | — | Internal | — | VAT: sale/purchase/both · WHT: pay; lock เมื่อ used>0 |
| `gl_sale` | uuid | YES | — | **Confidential** | — | FK → T_gl_account (role VAT_SALE); required ก่อน active (VAT sale/both) |
| `gl_purchase` | uuid | YES | — | **Confidential** | — | FK → T_gl_account (role VAT_PURCHASE); required ก่อน active (VAT purchase/both) |
| `gl_wht` | uuid | YES | — | **Confidential** | — | FK → T_gl_account (**role WHT_PAYABLE เท่านั้น — LOCK-12/FLAG-1**); required ก่อน active (WHT) |
| `income_type` | varchar(80) | YES | — | Internal | — | FK → T_income_type.value (WHT); required ก่อน active (R03) |
| `income_category_code` | varchar(40) | YES | — | Internal | — | AUTO map จาก income_type (FN-12) — สำหรับรายงาน |
| `vat_report_category` | varchar(16) | YES | — | Internal | — | AUTO จาก vat_kind: STANDARD/ZERO_RATED/EXEMPT (VAT) — feed ภ.พ.30 |
| `report_mapping_rule` | varchar(48) | YES | `RESOLVE_BY_PAYEE_AND_PAYMENT_CONTEXT` | Internal | — | WHT contract (LOCK-05) — ไม่ hardcode ภ.ง.ด. |
| `eff_start` | date | YES | — | Internal | — | วันมีผลเริ่ม; required ก่อน active; ≤ eff_end (R14) |
| `eff_end` | date | YES | — | Internal | — | วันมีผลสิ้นสุด (null=ไม่มีกำหนด); auto set ตอน deactivate/archive/replacement |
| `status` | varchar(12) | NO | 'draft' | Internal | — | enum: draft/active/inactive/archived (§8 state machine) |
| `used` | integer | NO | 0 | Internal | — | read-only จาก consumer (badge FN-06); >0 → lock rate |
| `is_system_preset` | boolean | NO | false | Internal | — | 7 preset ไทย (R16/FN-15) |
| `replaces_tax_code_id` | varchar(12) | YES | — | Internal | — | FK → T_tax_code (lineage; รหัสนี้ใช้แทนตัวไหน) |
| `replaced_by_tax_code_id` | varchar(12) | YES | — | Internal | — | FK → T_tax_code (lineage; รหัสนี้ถูกแทนด้วยตัวไหน) |
| `version` | integer | NO | 1 | Internal | — | Optimistic locking (E15/OQ-9) |
| `created_by` | uuid | NO | — | Internal | — | FK → T_user |
| `created_at` | timestamp | NO | NOW() | Internal | — | Audit |
| `updated_by` | uuid | YES | — | Internal | — | FK → T_user |
| `updated_at` | timestamp | NO | NOW() | Internal | — | Audit + optimistic lock |

**Constraints:**
- PRIMARY KEY (`id`)
- **UNIQUE (`company_id`, `lower(code)`)** — R01/E14 (uniqueness ระดับ DB, ไม่พึ่ง client)
- CHECK (`rate` IS NULL OR (`rate` >= 0 AND `rate` <= 100)) — R13
- CHECK (`eff_end` IS NULL OR `eff_start` IS NULL OR `eff_end` >= `eff_start`) — R14
- CHECK (`status` IN ('draft','active','inactive','archived'))
- CHECK (`family` IN ('VAT','WHT'))
- CHECK (`family` <> 'WHT' OR `vat_kind` IS NULL)

**Indexes:**
- `IDX_taxcode_company_family_status` ON (`company_id`, `family`, `status`)
- `IDX_taxcode_pickable` ON (`company_id`, `family`, `status`, `eff_start`, `eff_end`) — consumer picker (§17.5 stress point)
- `UQ_taxcode_company_lowercode` UNIQUE ON (`company_id`, `lower(code)`)

**RLS Policy:**
```sql
CREATE POLICY company_isolation ON T_tax_code
  USING (company_id = current_setting('app.current_company')::uuid);
```

### T_tax_code_audit

**Purpose:** Append-only timeline (R05/S06-03). HTML implement เป็น `audit[]` `{ts, actor, action}` `unshift` ทุก event (L2640/2643/2650/2762).

| Column | Type | Null | Default | Classification | PII | Description |
|---|---|---|---|---|---|---|
| `id` | uuid | NO | gen_random_uuid() | Internal | — | PK |
| `company_id` | uuid | NO | — | Internal | — | RLS |
| `tax_code_id` | varchar(12) | NO | — | Internal | — | FK → T_tax_code |
| `ts` | timestamp | NO | NOW() | Internal | — | เวลา event |
| `actor` | varchar(120) | NO | — | Internal | — | ผู้กระทำ (user display / "ระบบ (Preset)") |
| `actor_id` | uuid | YES | — | Internal | — | FK → T_user (null = system) |
| `action` | varchar(300) | NO | — | Internal | — | ข้อความ event (เช่น "สร้างและเปิดใช้งานรหัสภาษี", "บันทึกร่าง — รอผูกบัญชี GL") |

**Constraints:** PRIMARY KEY (`id`); **append-only** (ไม่มี UPDATE/DELETE — enforce ด้วย DB trigger / revoke).
**Indexes:** `IDX_audit_taxcode_ts` ON (`tax_code_id`, `ts` DESC).

### T_gl_account (EXTERNAL — CoA, referenced only)

> **ไม่ใช่ table ของ feature นี้** — feature อ่านอย่างเดียวผ่าน lookup (F-TAX-API-11 / ENG-03). โครง fields ที่ใช้ (จาก HTML L2091-2100 + BRD A1):

| Column (ใช้) | Type | Description |
|---|---|---|
| `id` | uuid | PK |
| `company_id` | uuid | บริษัทเจ้าของ (filter) |
| `value` / `label` / `sub` | varchar | รหัส/ชื่อบัญชี แสดงใน combobox |
| `tax_role` | varchar | **VAT_SALE / VAT_PURCHASE / WHT_PAYABLE** / OTHER — filter key (R07) |
| `status` | varchar | active/inactive — รับเฉพาะ active (R06) |
| `posting_allowed` | boolean | รับเฉพาะ true (R06) |

> **E08/OQ-6:** ถ้า GL ที่ผูกไว้ถูก deactivate/ลบใน CoA ภายหลัง → พฤติกรรมต่อรหัส active ยังไม่ตัดสิน (Open Question). อย่า assume cascade.

## §4.6 Data Classification & Sensitive Data ⭐

### §4.6.1 Classification Levels (CUBE 4.0)
Public / Internal (default) / Confidential / Restricted — นิยามมาตรฐาน CUBE (view/export/audit behavior ต่อระดับ).

### §4.6.2 Default Rule
- **Default = Internal** (ทุก column ที่ไม่ระบุ). ห้าม default Public.
- Public ใช้เฉพาะ `T_income_type` (ข้อมูลกฎหมายภาษีสาธารณะ) — explicit, ไม่ใช่หลุด.

### §4.6.3 Enforcement Mapping (feature นี้)
| Classification | DB | API | UI | Audit |
|---|---|---|---|---|
| Public (`T_income_type`) | — | — | แสดงปกติ | — |
| Internal (ส่วนใหญ่) | RLS (company) | JWT auth | แสดงปกติ (authenticated) | mutation |
| Confidential (`gl_*` mapping) | RLS + role check | role check (`tax_code.view`+ accounting role) | แสดงปกติสำหรับ accounting role | view + mutation |
| Restricted | — | ไม่มี field ระดับนี้ | — | — |

### §4.6.4 PII Overlay
- **ไม่มี field ที่ `pii_flag=true`** ทั้ง feature. `actor`/`actor_id` = internal identity ไม่ใช่ personal data ในบริบท master นี้ (Internal).

### §4.6.5 Security Bible Domain Mapping
| Domain | เกี่ยวข้องกับ |
|---|---|
| **D5 (Financial):** `rate`, `gl_*` → audit log mandatory; `gl_*` = Confidential |
| **D9 (Audit):** ทุก mutation → T_tax_code_audit (append-only) |
| **D17 (Multi-tenant):** company_id RLS ทุก table |
| ~~D7 (PII)~~ | **ไม่ trigger** — ไม่มี PII |

### §4.6.6 Linkage with Policy Center
- Confidential `gl_*` → link Data Classification module (Policy Center) สำหรับ override runtime (audit).
- **ไม่มี Restricted field → ไม่ต้อง register Restricted Resources registry.**
