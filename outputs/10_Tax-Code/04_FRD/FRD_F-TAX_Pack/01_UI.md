## §1.2 Per-Page Detail

### P-01: รายการรหัสภาษี — Pattern A (list-view)

**Purpose:** ค้นหา/ติดตามสถานะ + ช่วงวันมีผลของรหัสภาษีบริษัทปัจจุบัน + เข้าถึง action.
**ERP Shell:**
- Sidebar module: "ตั้งค่าบัญชี" · active item: "รหัสภาษี" (HTML L1472/1477) — icon `percent`
- Breadcrumb: `ตั้งค่าบัญชี > รหัสภาษี` (L1532-1534)
- Company context chip: "บริษัทปัจจุบัน · 2BSimple จำกัด" (L1537) — read-only (LOCK-02)

**Header (verbatim จาก HTML L2314-2322):**
- Title: `รหัสภาษี` + count `N รหัส`
- Sub: `Master รหัสภาษีที่ทุกเอกสารการเงินอ้างอิง — VAT (ขาย/ซื้อ) และ ภาษีหัก ณ ที่จ่าย (WHT)`
- Actions: ปุ่ม secondary `ดูรายการที่เลือกได้ในเอกสารใหม่` (→ P-04) · ปุ่ม primary `สร้างรหัสภาษี` (→ P-02, gated `tax_code.create`)

**KPI stats row (L2325-2328):** clickable status filters — `รหัสทั้งหมด` (VAT n · WHT n), `ใช้งาน`, `ร่าง / ปิดใช้งาน`, (+ active-no-GL health). ยึดตัวเลขจาก list.

**Tabs (L2333):** `ภาษีมูลค่าเพิ่ม (VAT)` / `ภาษีหัก ณ ที่จ่าย (WHT)` — filter `state.tab` (default VAT, L2180).

**Table (8 คอลัมน์ — BRD C1 / HTML L2352):** รหัส · ชื่อ · อัตรา · ทิศทาง(VAT)/ประเภทเงินได้(WHT) · วันมีผลเริ่ม · วันมีผลสิ้นสุด · สถานะ (pill) · actions.

**Actions บนหน้านี้:**
| Action | Triggers | Calls (API) |
|---|---|---|
| คลิกแถว | เปิด view drawer (P-03) | F-TAX-API-02 GET /tax-codes/:id |
| `สร้างรหัสภาษี` | เปิด form drawer (P-02) | (client) openDrawer('create') → save = F-TAX-API-03 |
| ปุ่ม row `ปิดใช้งาน` (active + `deactivate`) L2307 | เปิด confirm (P-05) | F-TAX-API-06 |
| `ดูรายการที่เลือกได้ในเอกสารใหม่` | เปิด picker (P-04) | F-TAX-API-09 |
| เปลี่ยน tab / filter / sort | refresh table (client) | F-TAX-API-01 GET /tax-codes?family=&status= |

**States:** Loading (skeleton) · Empty (`ยังไม่มีรหัสภาษี` — microcopy กลาง Rule #39) · filter-empty (`ไม่พบรายการที่ค้นหา` + `ล้างตัวกรอง`) · Loaded.
**Status pills (ci-tokens §Pill):** active/ใช้งาน = info (ฟ้า) · draft/ร่าง = muted (เทา) · inactive/ปิดใช้งาน = muted · archived/เก็บถาวร = muted (HTML L2211/683).

**Permissions:** `view` เห็นทั้งหน้า; `create` เห็นปุ่มสร้าง; `deactivate` เห็นปุ่ม row ปิดใช้งาน. (Server re-check — E16/E18)

### P-02: สร้าง/แก้ไขรหัสภาษี — Pattern B (create/edit drawer, .standard 680px)

**Purpose:** กรอกข้อมูล + ผูก GL + วันมีผล → บันทึกร่าง (Maker) / เปิดใช้งาน (Approver).
**Eyebrow/Title (L2425-2426):** create = `รหัสภาษีใหม่` · edit = `แก้ไขรหัสภาษี` / `แก้ไข <code>` · replacement = `สร้างรหัสแทน`.
**Form fields (ปรับตามตระกูล/ทิศทาง — L2429-2494):**
- ตระกูล (VAT/WHT) · รหัส (code) · ชื่อ (name) · อัตรา (%) · ทิศทาง (VAT: ขาย/ซื้อ/ทั้งคู่; WHT: จ่าย)
- ประเภท VAT (standard/zero/exempt) — VAT เท่านั้น; zero/exempt → rate=0
- GL fields (master combobox #94, แสดงตาม direction L2486-2494): `ภาษีขาย` (VAT_SALE) · `ภาษีซื้อ` (VAT_PURCHASE) · `WHT ค้างจ่าย` (**WHT_PAYABLE เท่านั้น** — LOCK-12)
- ประเภทเงินได้ (WHT, search combobox → Income_Type L2108-2115) · วันมีผลเริ่ม/สิ้นสุด
- **Locked-when-used:** code/family/vatKind/rate/direction อ่านอย่างเดียวเมื่อ `used>0` (rateLocked L2424) + ป้าย "อ่านอย่างเดียว" + ปุ่ม `สร้างรหัสแทน` (rateReplaceBtn L2500-2502).

**Footer buttons (L2504/2540):**
| ปุ่ม | Label (verbatim) | Class | Calls |
|---|---|---|---|
| บันทึกร่าง | `บันทึกร่าง` | secondary + icon `save` | `saveDraft()` → F-TAX-API-03 (draft) / API-04 (edit draft) |
| ยืนยัน (create) | `ยืนยันสร้าง` | primary + `check` | `submitForm()` → F-TAX-API-03 + F-TAX-API-05 (activate) |
| ยืนยัน (edit) | `บันทึกการแก้ไข` | primary + `check` | `submitForm()` → F-TAX-API-04 (+API-05 ถ้า activate) |
| ยกเลิก | `ยกเลิก` | ghost | close drawer |

**Submitting state (Rule #44):** `กำลังบันทึก…`.
**Toasts:** create success `สร้างรหัสภาษีสำเร็จ` (L2680) · edit `บันทึกการแก้ไขแล้ว` · draft `บันทึกร่างแล้ว` (L2669) · no-perm `คุณไม่มีสิทธิ์บันทึกรหัสภาษี` / `คุณไม่มีสิทธิ์สร้างหรือเปิดใช้รหัสภาษี` (L2664/2673).
**Inline validation (verbatim, ดู 05_RULES §5.4):** L2597/2604/2606-2609/2613.

**States:** default form (VAT/standard/7%/both) · edit (prefill) · replacement (prefill locked + new code `-N`) · used-locked (read-only fields).

### P-04: ตัวเลือกตามวันที่เอกสาร (picker) — Pattern D (modal 440px)

**Purpose:** สาธิต/ให้ consumer ดูรหัสที่ pickable ตาม context + วันที่เอกสาร + สาธิต snapshot (External-facing contract).
**Content (renderModal 'picker' L2787-2824):**
- เลือก context: ขาย / ซื้อ / ใบสำคัญจ่าย + วันที่เอกสาร (documentDate)

**Calls:** F-TAX-API-09 GET /tax-codes/pickable?context=&date= .

## §1.3 User Journey (Happy Path — BRD §5.1)

```
Accountant (Maker) เปิด #/accounting/setup/tax-codes  [P-01]
  ↓ กด "สร้างรหัสภาษี" → form drawer [P-02]
  ↓ เลือกตระกูล + กรอกรหัส/ชื่อ/อัตรา/ทิศทาง (WHT: ประเภทเงินได้)
  ↓ เลือก GL (master combobox, filter role+company+active+posting)
  ↓ กด "บันทึกร่าง" → F-TAX-API-03 (status=draft, ไม่บังคับ GL)   [SoD: Maker]
  ↓ (Senior Accountant ทบทวน — optional, นอกจอ)
Acct/Fin Manager (Approver) เปิดแก้ไข → "บันทึกการแก้ไขและเปิดใช้งาน"
  ↓ F-TAX-API-05 activate → validate เต็ม (uniqueness, GL role, effStart, WHT income)
  ↓ status=active · snapshot-ready · audit "สร้างและเปิดใช้งานรหัสภาษี"   [SoD: Approver ≠ Maker]
```

### Branch: Replacement (BRD §5.2.1 / S-07)
```
เปิดแก้ไขรหัส used>0 [P-02] → fields อ่านอย่างเดียว + "สร้างรหัสแทน"
  → openReplacement() (code+"-N", อัตรา+วันมีผลใหม่)
  → Approver ยืนยัน → set replacedByTaxCodeId เดิม + effEnd เดิม = วันก่อน effStart ใหม่ + audit lineage
```

### Branch: Deactivate / Archive (BRD §5.2.2)
```
Approver เลือก "ปิดใช้งาน" (active) / "เก็บร่างถาวร" (draft) [P-05]
  → ยืนยัน → active→inactive / draft→archived · effEnd=today · audit · no hard delete
```

### Branch: Consumer Pick (BRD §5.2.3 — External-facing)
```
Consumer เปิด picker [P-04] → เลือก context + วันที่เอกสาร
  → isPickable filter → เลือก → captureSnapshot (immutable)
  → WHT ในซื้อ = advisory (block final; ยืนยันที่ Payment)
```
