## §1.2 Per-Page Detail

### P-01: หลักสูตร (Course Catalog)
**Purpose:** ค้นหา/ดูหลักสูตร + สร้างหลักสูตรใหม่
**Pattern:** A — list-view

**ERP Context:** Sidebar active "พัฒนาบุคลากร" (data-feature="train") · Shell = ตาม v9 spec

**Components:** Data Table (7 col: หลักสูตร/รหัส · หมวด · ผู้สอน · ระยะเวลา · ค่าใช้จ่าย · งบ · สถานะ) · Filter Bar (ค้นหา · หมวด · สถานะ · ล้างตัวกรอง) · ปุ่ม "สร้างหลักสูตร" (primary · hr/manager)

**Actions:**
| Action | Triggers | Calls (API) |
|---|---|---|
| คลิกแถว | เปิด P-06 view drawer | F-HR-TRAIN-API-03 GET /training/courses/:id |
| "สร้างหลักสูตร" | เปิด P-05 create drawer | (form) → F-HR-TRAIN-API-02 |
| ค้นหา/filter หมวด/สถานะ | refresh table (client) | F-HR-TRAIN-API-01 GET /training/courses?... |
| ล้างตัวกรอง | reset filter | F-HR-TRAIN-API-01 |

**States:** Loading (skeleton) · Empty (`ไม่พบหลักสูตร` + ล้างตัวกรอง) · Error (retry) · Loaded
**Permissions:** hr/manager = ดู+สร้าง · viewer = ดูอย่างเดียว (ไม่มีปุ่มสร้าง) · **งบ mask `••••••` สำหรับ viewer** (FN-94)

### P-03: ผล / ใบรับรอง (Results & Certificates)
**Purpose:** บันทึกผล/ออกใบรับรอง (list ผู้เรียนทุกรอบ ยกเว้น cancelled)
**Pattern:** A — list-view (action cell state-driven)

**Components:** Table (ผู้เรียน · หลักสูตร/รอบ · สถานะลงทะเบียน · ผล + eval chip · ใบรับรอง · จัดการ) · Filter (ค้นหา · สถานะ) · ชื่อผู้เรียนคลิกได้ → P-12 ประวัติ
**State-driven action cell:**
- `confirmed` + รอบยังไม่ closed → ปุ่ม "บันทึกผล" **disabled** (tooltip "บันทึกผลได้หลังปิดรอบ")

- `confirmed` + closed + attended → "บันทึกผล" (เปิด P-11)
- `passed` + !cert → "ออกใบรับรอง"
- `pending_doa` → chip "รออนุมัติ"

**Actions:**
| Action | Triggers | Calls |
|---|---|---|
| คลิกแถว | P-08 session view (tab ผู้เรียน) | F-HR-TRAIN-API-09 |
| คลิกชื่อผู้เรียน | P-12 ประวัติ | F-HR-TRAIN-API-27 |
| "บันทึกผล" | P-11 modal | F-HR-TRAIN-API-20 |

## §1.3 User Journey (Happy Path — หลักสูตรมีค่าใช้จ่าย)

```
HR L&D → #/train/course
  ↓ สร้างหลักสูตร (has_cost + งบ) → เผยแพร่           [API-02 → published]
#/train/plan → สร้างรอบอบรม (published เท่านั้น)        [API-08 → draft]
  ↓ เปิดรับสมัคร                                        [API-11 → open · NTF train_session_opened]
P-08 ผู้เรียน → ลงทะเบียน (จาก gap หรือเลือกเอง)        [API-14 · has_cost → pending_doa]
  ↓ ส่งอนุมัติ (DOA slot picker เลือกคนตามตำแหน่ง)      [API-15 · ผูก DOA entry]
Approver (หัวหน้า → ผจก.พัฒนาบุคลากร) อนุมัติ 2 ขั้น     [API-16 · ครบ → confirmed · NTF train_enroll_confirmed · EC event]
  ↓ ส่งค่าอบรม → Expense Claim (มูลค่า EC · กันซ้ำ)     [API-22 · hook display-only]
ปิดรอบ (จบการอบรม)                                     [API-12 → closed]
  ↓ เช็คชื่อเข้า/ขาด (attendance)                        [API-19]
บันทึกผล (ผ่าน/ไม่ผ่าน) + ประเมิน 1-5                   [API-20 → passed/failed · NTF train_result]
  ↓ ออกใบรับรองผู้ผ่าน (soft ref)                        [API-21]
```

### Branch: หลักสูตรฟรี (A1 · LOCK-01)
```
ลงทะเบียน [API-14] → confirmed ทันที (ข้าม DOA) + NTF train_enroll_confirmed · ไม่มี Expense
```
### Branch: ไม่อนุมัติ (A2)
```
Approver ระบุเหตุผล [API-17] → enrollment cancelled (append audit)
```
### Branch: ยกเลิกการลงทะเบียน (A3 · FN-11)
```
confirm → [API-18] cancelled (soft archive) คืนที่ว่าง · (ถ้าเคยส่ง EC → OQ-06 reverse ไม่ auto)
```

## §1.6 Empty States & Errors (UI · microcopy verbatim จากจอ)

| State | UI behavior (ข้อความจริงบนจอ) |
|---|---|
| หลักสูตรว่าง/filter ไม่เจอ | `ไม่พบหลักสูตร` · `ลองปรับคำค้นหรือล้างตัวกรอง แล้วลองอีกครั้ง` + ปุ่ม `ล้างตัวกรอง` |
| รอบว่าง | `ไม่พบรอบอบรม` · + ปุ่ม `สร้างรอบอบรม` |
| ผลว่าง | `ไม่พบรายการลงทะเบียน` · `บันทึกผลได้เมื่อผู้เรียนยืนยันลงทะเบียนแล้ว` |
| จำนวนรับเต็ม | note `จำนวนรับเต็มแล้ว (n/cap) — ลงทะเบียนเพิ่มไม่ได้จนกว่าจะมีการยกเลิก` + ปุ่ม disabled `จำนวนเต็มแล้ว` |
| viewer กระทำ | toast `สิทธิ์อ่านอย่างเดียว` (warning) |
| ประวัติว่าง | `ยังไม่มีประวัติอบรม` |
| API 403 | "คุณไม่มีสิทธิ์เข้าถึงส่วนนี้" + ติดต่อผู้ดูแล |
| API 500 | "เกิดข้อผิดพลาด กรุณาลองใหม่" + retry |
