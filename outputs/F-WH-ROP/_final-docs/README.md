# Reorder Point — Final Documents

ชุดเอกสารส่งมอบของ `F-WH-ROP` จัดหมวดตาม pattern ของ `outputs/17_Delivery-Note/_final-docs`

1. `00_context/` — Context Card และ Function Checklist
2. `01_prototype/` — HTML Prototype
3. `02_qc/` — รายงาน UX, Coverage และผล E2E
4. `03_brd/` — BRD Markdown และ Word
5. `04_frd/` — FRD Pack
6. `05_ui-brief/` — HTML UI Brief
7. `08_tldr/` — หน้าสรุปฟีเจอร์แบบอ่านง่าย
8. `09_declarations/` — Notification และ CSQ declarations
9. `10_handoff/` — Proposals และเรื่องที่ต้องประสานต่อ
10. `testcase_qa/` — AI Test Cases และ UAT สำหรับ Manual Test

ฟีเจอร์นี้ไม่มีเอกสารสำหรับพิมพ์ จึงไม่มีหมวด `06_print/`

เริ่มตรวจงานที่ `01_prototype/F-WH-ROP.html` และเริ่ม Manual Test ที่ `testcase_qa/UAT_F-WH-ROP.html`
