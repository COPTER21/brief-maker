# 04 DB · F-WH-ROP

## `rop_policy_version`

`policy_ref` PK, `tenant_id`, `item_id`, `warehouse_id`, `version`, `effective_date`, `enabled`, `min_qty`, `max_qty`, `safety_qty`, `lead_time_days`, `adu_window_days`, `pack_size`, `preferred_vendor_id` nullable, `created_at`, `created_by`, `correlation_id`. Unique `(tenant_id,item_id,warehouse_id,version)`; immutable after insert. Index active lookup by tenant/pair/effective date.

## `rop_run`

`run_id` PK, tenant, trigger_type (`schedule|movement|manual`), trigger_ref, scope_ref, started_at, completed_at, status, idempotency_key unique, correlation_id.

## `rop_suggestion_event`

`event_id` PK, run_id, tenant, policy_ref/version, snapshot_ref/as_of, item_id, warehouse_id, atp, adu, on_order, reorder_point, raw_qty, suggested_qty, pack_size, status (`triggered|near|normal|no_policy|snapshot_unavailable`), reason, occurred_at, idempotency_key unique. Append-only.

## `rop_integration_event`

`event_id` PK, tenant, kind (`notification.emitted|pr.draft.created|csq.master.changed`), source_ref, external_ref nullable, warehouse_id, payload_digest, status, occurred_at, idempotency_key unique, correlation_id. Store references/digest, not full external payload when unnecessary.

## Constraints and classification

- Decimal quantities ≥0; `safety≤min≤max`; lead≥0; pack≥1; ADU window in 30/60/90.
- Policy/stock data: Confidential. Actor reference/audit metadata: follow central classification.
- All rows tenant-scoped; warehouse authorization enforced before query.
- No F072 document table is owned by F085.
