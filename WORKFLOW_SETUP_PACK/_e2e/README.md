## 📐 ความกว้างที่ตรวจ — ยึด "โหมด" ไม่ใช่ "ขนาดจอ" (เปลี่ยน 2026-08-10 ตาม v8)

`html-generator-v8` Rule #97 ทำให้ระบบมี **2 โหมด**:

| โหมด | ช่วง | หน้าตา |
|---|---|---|
| adaptive | **768–1180** | sidebar เป็น off-canvas · เนื้อหาเต็มกว้าง |
| เต็มรูป | **≥1180** | sidebar กางอยู่ |

| | เดิม | ใหม่ |
|---|---|---|
| ความกว้าง | 1280 · 1440 · 1920 · 2560 | **1024** · 1280 · 1920 |
| ครอบโหมด | เต็มรูปล้วน — **adaptive ไม่เคยถูกแตะ** | ครบทั้ง 2 โหมด |
| เวลา | 4:08 | **3:23** |

**ตัด 2560** (เหนือ 1180 ได้แค่ที่ว่างเพิ่ม) · **ตัด 1440** (โหมดเดียวกับ 1280 แต่หลวมกว่า —
ของล้นเกิดที่แคบสุดเสมอ) · **เพิ่ม 1024** = ตัวแทนโหมด adaptive

> ⚠️ เปลี่ยนความกว้างต้องดู `deep` ด้วย — ถ้าความกว้างของ `deep` ไม่อยู่ในลิสต์
> `walk_behavior` + a11y จะ**ไม่ถูกเรียกเลยแบบเงียบ ๆ** · `uikit.py` fallback ไปตัวกว้างสุดให้แล้ว

## ⏱ อย่าใส่ `wait_for_timeout` เพิ่ม — ใช้ helper ของ `uikit.py`

`uikit.py` มี 3 ตัวช่วยที่**รอเงื่อนไขจริง** แล้วไปต่อทันทีที่พร้อม แทนการเดาเวลา:

| helper | ใช้เมื่อ | แทนอะไร |
|---|---|---|
| `ready(pg, url)` | เปิดหน้าใหม่ | `pg.goto(...); wait_for_timeout(1800–2200)` |
| `settle(pg)` | หลังสั่งอะไรที่ทำให้จอขยับ | `wait_for_timeout(200–900)` |
| `after(pg, js)` | `evaluate` แล้วรอจอนิ่ง | `pg.evaluate(js); wait_for_timeout(...)` |
| `hush(pg)` | **ก่อนถ่ายภาพ** | ดับ toast ที่ซ่อนตัวเองที่ 5 วิ |

`settle()` รอ 3 อย่าง: **JS timer สั้น (≤1500ms) เดินจบ** → **animation ที่มีวันจบ จบ** → **วาดอีก 2 เฟรม**
`ready()` เพิ่มอีก 2 ชั้น: **ฟอนต์พร้อม** → **ลายเซ็น layout นิ่ง 2 เฟรมติด**

**วัดแล้วที่ F-GLPG-001 (2026-08-06):** `e2e` 2:17.9 → **0:24.4** (5.6× · 46/46 เท่าเดิม 4 รอบ) ·
`render-gate` 0:17.3 (ภาพนิ่ง 36/36 ทุกไบต์)

### ❌ `ui-audit` แปลงไม่ได้ — ลองแล้วถอย

เร็วขึ้น 3.4× จริง แต่ **ผลแกว่ง 5↔7 จุด** (ของเดิมคงที่ 5·5·5) — ตัวที่แกว่งคือ `JS_TIP`
