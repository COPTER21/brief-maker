## 🎯 เป้าหมายของ prompt นี้

ติดตั้ง workflow ที่ผู้ใช้ **พิมพ์แค่ `/kickoff <feature>` ครั้งเดียว** แล้ว AI พาทำยาวจนจบ 12 step
โดย **หยุดคุยแค่ 3 จุด** — ไม่ต้อง prompt ใหม่ทุกขั้น

⚠️ **workspace ปลายทางมีชื่อโฟลเดอร์ไม่เหมือนต้นทางแน่นอน** — prompt นี้จึง **ห้ามใช้ path ตายตัว**
ทุก path ต้องมาจากการ **สำรวจจริง + ให้ผู้ใช้ยืนยัน** แล้วเขียนลง config ไฟล์เดียว

## B2 · จับคู่ **บทบาท → โฟลเดอร์จริง** แล้วถามผู้ใช้ยืนยันทีละข้อ

| บทบาท | คือโฟลเดอร์ที่เก็บอะไร | สัญญาณที่ใช้เดา (ไว้เสนอเป็นตัวเลือก) |
|---|---|---|
| `CENTRAL_PLAN` | **แผนกลางของทั้งระบบ** — อ่าน **ทุกไฟล์ในนี้ทุกครั้ง** ที่เริ่ม feature | มีไฟล์ชื่อแนว `CENTRAL_PLAN*` · `WAVE_PLAN*` · ผังภาพรวม `.html` |
| `BRIEF_ROOT` | **ที่เก็บแพ็กบรีฟรายฟีเจอร์** (ข้างในเป็นโฟลเดอร์ย่อยรายตัว) | มี `PREBRIEF_*.md` · `FUNCTION_CHECKLIST_*.md` (หรือ `_SEED_NOTES.md`) · `<Feature>.html` |
| `OUTPUT_ROOT` | **ที่เขียนผลงานลง** — 1 โฟลเดอร์ต่อ 1 feature | มี `FRD_Pack/` · `_e2e/` · `BRD_*.md` |
| `SHARED_E2E` | ที่วาง `uikit.py` ให้ทุก feature เรียกร่วมกัน | ปกติ `<OUTPUT_ROOT>/_SHARED/_e2e/` |
| `PENDING_REGISTRY` | ทะเบียนกลางของบั๊ก/ข้อเสนอที่ต้องส่งกลับเจ้าของ design system | ปกติ `<OUTPUT_ROOT>/_SHARED/DESIGN_SYSTEM_PENDING.md` |
| `LEGACY_CONTEXT` | *(มีก็ได้ไม่มีก็ได้)* แหล่ง context เก่าของ feature รุ่นก่อน | — |

**ถามแบบนี้ — เสนอตัวเลือกจากของที่ `ls` เจอจริง + ช่องพิมพ์เอง + ช่อง "ยังไม่มี ให้สร้างใหม่":**

```
🗺 ขอยืนยันแผนที่โฟลเดอร์ก่อนติดตั้งครับ

1) แผนกลาง (อ่านทุกไฟล์ทุกครั้งที่เริ่ม feature)
   A) <ที่เจอ>/   B) <ที่เจอ>/   C) พิมพ์เอง   D) ยังไม่มี — สร้างใหม่ชื่อ ...

2) ที่เก็บแพ็กบรีฟรายฟีเจอร์
   ...

3) ที่เขียนผลงานลง
   ...
```

| กรณี | ทำยังไง |
|---|---|
| เจอตัวที่น่าจะใช่ชัดเจน | **ยังต้องถามยืนยัน** — ตั้งเป็นตัวเลือกแรกพร้อมทำเครื่องหมายว่าน่าจะใช่ |
| เจอหลายอัน / ไม่เจอเลย | ถามอย่างเดียว **ห้ามเลือกให้** |
| ผู้ใช้ตอบ path ที่ไม่มีจริง | บอกว่าไม่เจอ แล้วถามใหม่ **ห้ามหาตัวแทนเอง** |
| ยังไม่มีโฟลเดอร์นั้น | ถามชื่อที่อยากใช้ แล้ว `mkdir -p` ให้ |

> **ทำไมต้องถามทั้งที่เดาได้:** `BRIEF_ROOT` คือ **contract ของ `qc-coverage-checker` (step 4)**
> หยิบผิดโฟลเดอร์ = ตรวจความครบเทียบผิดใบ แล้ว **ผ่านฉลุยทั้งที่ทำไม่ตรงบรีฟ**
> ค่าใช้จ่ายของการถาม 1 คำถาม ถูกกว่าเดินผิดยาว 12 step มาก

> ⛔ **ห้ามใส่ `PATH` ลงไฟล์นี้** — `env` ของ Claude Code เป็น string ตรงตัว **ไม่ขยายตัวแปร**
